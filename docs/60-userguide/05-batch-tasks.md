# 5. 批量任务

批量任务用于**多账号/多角色**场景：自动遍历条目表中的每一行，切换账号后执行指定脚本。

入口：主窗口左侧 **「批量」Tab**。

---

## 5.1 批量 Tab 三页

```
┌──────────────────────────────────────┐
│  [开始批量执行 (F9)]                  │
├──────────────────────────────────────┤
│  进度 │ 脚本 │ 配置                    │
│  ─────────────────────────────────── │
│  （子页内容）                         │
│                                      │
└──────────────────────────────────────┘
```

### 「进度」页

执行进度表，显示 **条目 × 脚本** 的矩阵状态：

| 列 | 说明 |
|----|------|
| 条目 | 行数据的显示标签（各列值用 `/` 连接） |
| 脚本 | 脚本名称 |
| 状态 | 待执行 / 运行中 / 成功 / 失败 / 跳过 |

状态用颜色区分：
- 灰底 = 待执行
- 蓝底 = 运行中
- 绿底 = 成功
- 红底 = 失败
- 黄底 = 跳过

### 「脚本」页

勾选要执行的脚本。脚本列表与「日常」Tab 下拉框中的脚本一致
（由工作流发现层自动扫描，通过「工具 → 脚本配置」管理暴露和排序）。

### 「配置」页

| 操作 | 说明 |
|------|------|
| 当前配置 | 下拉框选择批量配置（可多配置） |
| 选择要执行的行 | 勾选条目表中的行，支持「全选 / 全不选」 |

---

## 5.2 批量配置

入口：「工具 → 批量配置」。

批量配置对话框管理多个命名配置，每个配置定义一套条目表和关联工作流。

### 界面结构

```
┌──────────────────────────────────────────────┐
│  配置：[下拉选择] [新建] [删除]                │
│  列名（逗号分隔）：[col1, col2, col3, ...]    │
│  用户名列：[可选]                              │
│  ┌──────────────────────────────────────┐    │
│  │  条目表（双击编辑单元格）               │    │
│  │  col1  │ col2  │ col3  │ ...         │    │
│  │  ...   │ ...   │ ...   │ ...         │    │
│  └──────────────────────────────────────┘    │
│  [添加行] [删除行]           [↑ 上移] [↓ 下移]│
│  批次初始化 wf：[________] [浏览...]          │
│  条目准备 wf：  [________] [浏览...]          │
│  条目收尾 wf：  [________] [浏览...]          │
│  批次收尾 wf：  [________] [浏览...]          │
│                              [保存] [取消]    │
└──────────────────────────────────────────────┘
```

### 配置管理

| 操作 | 说明 |
|------|------|
| 新建 | 输入配置名，创建空配置（默认两列） |
| 删除 | 删除当前配置（不可恢复） |
| 切换 | 下拉框切换不同配置 |

### 列名定义

在「列名」输入框中用逗号分隔定义列，如：

```
account, role, tail
```

修改列名后表格列头立即更新，已有数据保留。

### 条目表

每行代表一个待执行的条目。双击单元格编辑值。

| 操作 | 说明 |
|------|------|
| 添加行 | 在末尾添加空行 |
| 删除行 | 删除选中行 |
| 复制为新行 | 右键菜单，复制当前行数据到新行 |
| 上移/下移 | 调整行顺序 |

### 用户名列

指定哪一列的值作为**角色名**（对应用户管理中的用户）。

执行时，批量运行器会：
1. 读取该行「用户名列」的值
2. 自动切换到对应用户的 session
3. 脚本执行完毕后落盘 session

> 如果不设置用户名列，则不切换用户（所有条目共享当前 session）。

### 字段语义约定

在燕云调律场景中，常用列名约定：

| 字段 | 含义 |
|------|------|
| account | 游戏账号（用于判断是否需要重新登录） |
| role | 游戏角色名（对应应用中的「用户」概念，填入用户名列） |
| tail | 尾号（仅用于 UI 列表中匹配账号） |

## 5.3 工作流槽位

每个配置有四个可选的生命周期 wf 槽位：

| 槽位 | 调用时机 |
|------|---------|
| **批次初始化 wf** | 整个批次开始时调用一次；仅 `success` 才建立批次 |
| **条目准备 wf** | 每个启用条目执行前调用；首条和后续条目行为一致 |
| **条目收尾 wf** | 条目准备成功、业务脚本执行后调用 |
| **批次收尾 wf** | setup 成功后，在遍历结束或停止时调用一次 |

### 生命周期 wf 的变量传递

生命周期 wf 接收以下通用变量：

| 变量 | 说明 |
|------|------|
| `batch_table` | 启用行列表（不含禁用行） |
| `batch_index` | 当前行在启用行中的序号（从 0 开始） |
| `batch_source_index` | 当前行在原配置表中的序号；批次级阶段为 -1 |
| `batch_row` | 当前行数据（dict） |
| `batch_phase` | 当前阶段名 |
| `batch_state` | 跨阶段透明传递的业务私有状态工作副本（dict） |
| `batch_item_result` | 条目/批次执行摘要；无摘要时为空 dict |
| 各列值 | 行数据各列直接展开为同名变量 |

Python 批量控制层不会读取 `batch_state` 内的账号、页面或角色等字段。条目准备
wf 应依据其中记录的**已确认真实状态**决定最小切换操作，不应通过
`batch_index - 1` 推断当前游戏状态。

每个阶段收到的是上一已提交状态的深拷贝。wf 可以原地修改这份工作副本，但
只有通过返回协议返回合法 `state` 时修改才会提交；异常、非法返回或无返回值
都会保留阶段开始前的状态。

### 返回协议

生命周期 wf 返回以下字典；空槽位或不返回值等同成功且保持原状态：

```wf
return {"status": "success", "message": "", "state": $batch_state}
```

| 字段 | 约定 |
|------|------|
| `status` | `success`、`skipped`、`failed` 或 `stopped` |
| `message` | 面向日志和用户的说明文字 |
| `state` | 下一阶段收到的业务私有 dict；控制层只透传 |

`prepare_item` 返回 `skipped` 或 `failed` 时，该条目的业务脚本不会执行，但
返回的 `state` 仍会传给下一条目。这使“账号已登录、角色不可用”等部分成功
状态能够被精确保留。

### 选择 wf 文件

点「浏览...」按钮选择 `.wf` 文件。默认打开 `config/system/workflows/` 目录。
也可以使用手动输入相对路径。

## 5.4 执行流程

点「开始批量执行 (F9)」后的完整流程：

```
1. 调用批次初始化 wf
2. 遍历勾选的行：
   - 调用条目准备 wf
   - session 切换（按用户名列值切换当前用户）
   - 顺序执行勾选的脚本
   - session 落盘（有脚本成功时保存）
   - 调用条目收尾 wf
3. setup 成功时，调用批次收尾 wf
```

### 执行中的行为

| 场景 | 行为 |
|------|------|
| 条目准备返回 `skipped` | 跳过该行所有脚本，继续下一行 |
| 条目准备返回 `failed` | 记录准备失败并跳过该行，继续下一行 |
| 批次初始化返回非 `success` | 现场准备失败，立即结束；不执行条目或批次收尾 |
| 条目阶段返回 `stopped` | 停止后续条目并进入批次收尾 |
| 脚本执行异常 | 记录失败，继续执行下一个脚本 |
| 按 F10 停止 | 当前条目完成后停止（不中断当前脚本） |
| 无启用行 | 日志提示「暂无启用的行，请到配置页勾选」 |
| 无勾选脚本 | 日志提示「请至少勾选一个脚本」 |

### 运行期间

- 脚本页和配置页被锁定（不可修改）
- 进度表实时更新状态
- 运行日志输出 `[批量]` 前缀的日志

---

## 5.5 脚本结果落盘

脚本执行后如果有返回值（dict 或 list），结果自动保存到：

```
config/session/output/{角色名}/{script_id}_{时间戳}.json
```
