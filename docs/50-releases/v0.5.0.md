# v0.5.0 — ProfileDB 线程安全、调律导航策略化

## 律匠 v0.5.0

本版本为 v0.5.0 正式版。修复 ProfileDB 多线程初始化竞态问题，调律回收路径完成策略化重构，消除工作流中的直接环境检查。

---

### 🔧 修复

- **ProfileDB 多线程初始化竞态**：多个线程首次打开数据库时可能并发执行同一迁移，导致 `duplicate column name` 错误。修复方案：`_migrate_v1` 从 `executescript` 改为 `execute` 以兼容 `BEGIN IMMEDIATE` 事务；`_ensure_schema` 整体包入写事务；WAL pragma 加锁串行化；单例加载改为 double-checked locking

---

### 📦 重构

- **调律回收路径策略化**：`auto_tuning` 和 `recycler` 中的 `load_env()` 环境分支全部收敛到 `TuningRouteStrategy`，新增 `open_recycle_dialog` / `close_recycle_entry_on_lock` / `grid_click_x_ratio` 策略方法；`TuningNavigator` 改为外部注入 routes
