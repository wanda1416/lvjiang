# 115 阶满养成基础属性基线

> 状态：部分实现（2026-10-06，基线 v0.13.12）。基础静态模型已实现，细分来源待后续补充。
>
> **数据基线**：`config/local/data/DIY计算器0.10.1.xlsx`

## 1. 目标

属性来源模型应能按流派、四门心法、武备、攻具套装和弓玦选择，推导南吕相和赛季
（角色等级 100、装备等级 115）的满养成静态属性。推导口径排除八件装备的 40 条
普通词条，但保留：

- 角色等级、基础天赋、突破和地图收集提供的属性；
- 八件 115 阶金装的固有基础属性；
- 装备叠音和所选攻具套装的静态属性；
- 所选心法、武学天赋、武备和弓玦的静态属性。

推导页直接从装备配置取得所选等级八件金装的固有基础值，并把它列为独立来源；弓玦
的类型与等级独立选择，因此 115 装备也可以搭配尚未升级的低等级弓玦。保存给毕业率使用时，
系统会扣回装备固有值和弓玦，继续由实际装备与方案弓玦公共链路叠加，避免重复计算。

## 2. 当前阶段边界

心法名册与满重属性以 DIY 计算器的「心法」表为准，共 38 门，统一维护在
`attr_model/inner_way.yaml`。旧社区名册不再作为依据，不创建以数据来源命名的心法组。
例如旧名称「苦四时」不再独立出现，应使用表格中的「四时无常」。

本阶段以表格能够证明的静态总量为准：

- 心法只保证选择六重时的累计结果与表格一致；表格没有提供各重归属，
  威猛歌、千山法、凝神章保留有依据的二、五重位置，数值取表格基线；
  其余累计集中在各自六重条目，显示“满重累计，重数归属待补”。低重数保持待填，
  不把未知归属标为无静态属性；
- 武学天赋按流派两门武学的累计结果建模，汇总贡献登记在主武学条目，副武学不重复
  计数；
- 牵丝·霖不在表格的武学天赋候选中，保持待建模，不套用其他牵丝流派；
- 表格未提供气血、外功防御、体/御转换等完整生存属性，本阶段不推测；
- 条件触发、叠层、持续时间和技能限定效果不进入静态基础属性。

## 3. 数值所有权

每类来源以哪份文件为准、以及聚合与置空规则，见

## 4. 验收基线

至少固定一组表格当前保存的选择作为回归靶子：破竹·鸢、扶摇直上、易水歌、
擒天势、断石之构、本系武备、撼天套、115 会心弓玦，八件 115 金装的普通词条为空。

验证时分别断言：

1. 属性来源推导值与表格对应来源相加一致；
2. 推导值包含 `380 / 757` 的固有最小/最大外功，不包含普通词条；
3. 叠音与撼天套只计算一次；
4. 基础穿透保留基础值口径，不把表格的最终抗性值反写为基础值。

实测对照可能尚未满叠音、混穿 110/115 装备或使用 110 弓玦，因此不要求与理论满值
直接相等。对照时应把这些差异作为明确的养成缺口，不能反写成公共模型补足。
