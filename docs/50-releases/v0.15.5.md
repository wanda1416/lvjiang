# v0.15.5 — 批量单任务停止、悬浮窗快捷关闭与安卓任务快照修复

发布日期 2026-10-27。

## ⚠️ 不兼容变动与升级指引

### 批量弹窗里的「停止任务」现在只结束当前这一条

- **现象：** 批量执行过程中，某个任务弹出询问窗时点「停止任务」，以前会把整批全部停掉；
  现在只结束当前这一条任务，批量继续跑同一条目的下一个任务（没有下一个任务就进下一个
  用户/单元），报表里这一条记为「已停止」。
- **原因：** 以前弹窗的「停止任务」和主界面停止按钮共用同一个整批停止信号，批量里一按就
  全部终止。
- **如何调整：** 想结束整批，请用主界面的停止按钮（F10）。无需其他操作。

### 改过 `daily_checkin.wf` 或 `page_action.wf` 本地覆盖的用户拿不到本次流程调整

- **现象：** 每日签到领奖后自动关闭物品获得提示，以及关闭提示最多点 10 次的兜底，在覆盖过
  `config/local` 同路径文件的用户那里不生效。
- **原因：** `config/local` 无条件优先于 `config/system`，工作流文件是整文件覆盖而不是合并。
- **如何调整：** 删除本地对应覆盖，或手动把系统新版改动同步进本地文件。

## ✨ 新增功能

### 手机悬浮窗支持快捷关闭

- 空闲态顶部由单个「启动任务」拆为「启动任务 | 关闭悬浮窗」；点「关闭悬浮窗」直接收起面板、
  移除悬浮图标并结束前台服务。
- 「用户：XXX / 任务：YYY」两行 label 与下面一排选择按钮压缩为两行：固定文案的
  「选择用户 / 选择任务」按钮 + 右侧展示当前值的纯文本，当前值超长自动省略。

### 批量脚本与单元列表支持 Shift 区间勾选

- 按住 Shift 点击某行的勾选框，以最近一次普通勾选行为锚点，把锚点到点击行之间的全部选项
  一并勾选（目标行原本已勾则一并取消）。无锚点、整表刷新或拖拽重排后退化为普通单行勾选。

## 🔧 修复

- **安卓批量/单任务报 `Read-only file system: '/.task'`**：任务配置快照此前固定写到工作目录
  下的 `.task`，安卓工作目录是只读根 `/`，一跑批量就失败。现在安卓端改用客户端自身根目录
  `$HOME/lvjiang/.task`，桌面端行为不变。
- **安卓升级后启动报「无法确认原始预置基底」**：预置安装校验拿旧代次归档比对同版本内的新
  预置内容，内容一变就误判损坏并打断启动。已移除该整树摘要硬校验，保留逐文件与清单自洽校验。
- **批量弹窗「停止任务」导致全部任务结束**：见上文不兼容变动；根因是弹窗停止与整批停止共用
  一个信号。
- **每日签到领奖后物品获得提示残留**：领奖成功后现在会自动点击空白处并关闭物品获得提示；
  关闭提示的公共子过程增加 10 次上限，点不掉时记 error 后结束，不再可能无限循环。

## 📦 重构

- **异常按「是否记录堆栈」分类并统一记账入口**：业务主动拒绝（`profile_reject`）、写入冲突、
  历史操作被拒、脚本可预期错误等只记一行原因（级别 WARNING/ERROR），不再打印引擎内部帧的
  完整堆栈；意外异常仍保留堆栈，并且同一异常穿透嵌套只记一次。运行线程、批量收尾、Profile
  回写与历史撤销/删除统一走同一入口。
