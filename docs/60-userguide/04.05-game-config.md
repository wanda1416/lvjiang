# 4.5 游戏配置

入口：「燕云 → 游戏配置」或按 **F5**。

游戏配置管理的是**游戏基础数据**——词条库、装备属性、武学与流派/玩法定义、等级与赛季规则。
这些数据被调律配置引用，但日常调律一般不需要修改。

> 游戏版本更新新增词条/武器时才需要动游戏配置。日常调律只需关注调律配置 (F6)。

## 词组配置

管理各词条在不同等级的最大值上限。

| 功能 | 说明 |
|------|------|
| 词条分类 | 普通词组 / 定音词组（定音词组不受承音限制） |
| 词条单位 | 空 / % |
| 词条分组 | 不分组 / 分组（如「指定技能增效」按十大流派分组） |
| 词条归属 | 普通词组可配置归属与可出现的装备部位 |
| 等级-上限表格 | 左侧选词组，右侧编辑各等级对应的最大值 |

> 双击词组类别 / 分组页签 / 词条名标签可重命名。

---

## 装备配置

管理装备基础属性规则（用于品阶推断）与武器类型注册表。

| 功能 | 说明 |
|------|------|
| 七个装备类型 | 主武器 / 副武器 / 环 / 佩 / 冠胄 / 胫甲 / 腕甲（固定不可增删） |
| 属性跟随 | 勾选后该部位复用目标部位的数值（如胫甲/腕甲跟随冠胄） |
| 基础属性说明 | 部位数值对应的属性名（区间型/离散型） |
| 武器类型注册表 | 每个武器可绑定一种武学增效词条 |

> 新增武器需重启后方可参与识别。被流派配置引用的武器不允许删除。

---

## 武学配置

管理**武学**（武器 + 属性的固定搭配，如「无名剑法」= 剑 + 鸣金），是流派配置和玩法配置的共同前置。

| 功能 | 说明 |
|------|------|
| 武学列表 | 左侧列出全部已注册武学，支持新增（＋ 武学）、删除（- 武学） |
| 武器 | 该武学固定使用的武器类型（下拉自装备配置的武器类型注册表） |
| 属性 | 该武学所属流派属性（鸣金 / 裂石 / 破竹 / 牵丝） |

> 流派配置和玩法配置只引用武学名称，武器由武学派生、不再各自录入——避免同一份数据在多处
> 各写各的，一处改动另一处忘改。仍被流派引用的武学不允许删除。

---

## 流派配置

管理流派：绑定主/副武学、所属属性、角色基础属性与毕业率方案。

| 配置项 | 说明 |
|--------|------|
| 属性 | 流派所属属性（鸣金 / 裂石 / 破竹 / 牵丝） |
| 主武学 | 从武学配置中选择，主武器随之自动填充（只读，标注「随武学」） |
| 副武学 | 同上，副武器随之自动填充 |
| 基础属性 | 查看、编辑、重命名或删除按流派保存的角色基础属性 |
| 方案管理 | 从 Excel 导入、重命名或删除毕业率计算方案，并校正 100% 基准 DPS |

基础属性用于角色面板反推和换装计算；毕业率方案用于把完整战斗属性换算成 DPS 与毕业率。日常操作见[5.4 角色基础属性与真实毕业率](05.04-base-attributes-and-graduation.md)。

---

## 玩法配置

管理**玩法**——调律要什么增伤、定什么音由玩法决定，与流派（决定毕业率算法）是两件事：
有玩法、无流派的混搭打法能调律但算不了毕业率，属于正常降级。

| 配置项 | 说明 |
|--------|------|
| 流派 | 绑定某个已有流派（属性/主副武学随流派锁定），或选「自定义」自行填写 |
| 属性 | 玩法所属属性（绑定流派时锁定） |
| 主武学 / 副武学 | 绑定流派时锁定；自定义玩法可从武学配置中任选 |
| 主武学增伤要求 / 副武学增伤要求 | 判定是否需要该武学的增伤词条 |
| 输出装备定音 / 防御装备定音 | 该玩法要求的定音词条 |
| 全武学增伤要求 | 是否需要全部武学通用的增伤词条（默认「需要」） |
| 奇术增伤要求 | 不需要 / 群体 / 单体 |
| 对单位增伤要求 | 不需要 / 首领 / 玩家 |

> 玩法以前内嵌在每条调律规则内部各写一份，现在统一收在此处，调律配置（F6）的规则只引用
> 玩法名称。仍被调律规则引用的玩法不允许删除。**从旧版本升级时，自己编辑过的玩法不会自动
> 迁移**，需要在此重新创建并核对，详见[发布记录](../50-releases/v0.10.0.md)。

## 等级配置

按等级区分装备能力、材料要求与抗性。

| 列 | 说明 |
|----|------|
| 等级 | 装备等级（1-999，不可重复） |
| 支持重置 | 该等级是否允许重置调律 |
| 支持承音 | 该等级装备是否可参与承音；也决定是否进入“承音装备”候选 |
| 无限转律 | 该等级的固定转律槽是否允许再次转律为其他词条 |
| 承音后转律 | 该原始等级的装备承音后是否仍可在固定转律槽上再次转律 |
| 最低材料数量 | 该等级要求的最低材料数量 |
| 判定抗性 | 判定抗性百分比（≥ 0） |
| 增益抗性 | 增益抗性百分比（≥ 0） |

> 系统配置中，91 级及以上支持承音，105 级及以上支持无限转律；目前仅 110 级支持承音后转律。原始等级只按装备名称的等阶名称识别，无法匹配时为 0。支持新增/删除/上移/下移，修改即时校验写盘。

## 赛季配置

管理游戏赛季的时间区间与对应装备等级，单表格结构。

| 列 | 说明 |
|----|------|
| 赛季编号 | 用于排序（1, 2, 3...），不可重复 |
| 赛季名称 | 如「黄钟长鸣」「夹钟并作」 |
| 开始日期 / 结束日期 | 赛季时间区间 |
| 上半赛季结束 | 用于区分上下半赛季 |
| 装备等级 | 该赛季对应的装备等级（从等级配置中选择，如 105、110） |

支持新增、删除选中行、上移/下移调整顺序。其他页面（毕业率计算、满等级假设开关的默认值、
匿名调律数据的赛季标注等）按今天的日期落在哪个赛季区间，取该赛季的装备等级为默认值。

## 字体设置

调整「其他装备」Tab 中装备卡片的外观参数，与 [3.1 通用配置](03.01-base-config.md#字体设置)
里用户总览/用户信息的字体设置是两处独立配置，互不影响。

| 配置项 | 说明 |
|--------|------|
| 装备名字号 / 等级字号 / 词条字号 | 卡片各文本区域的字号（px） |
| 卡片高度 | 卡片最小高度（px） |
| 网格列数 | 卡片网格每行显示的列数 |

点击「保存」后刷新页面即生效。

## 与调律配置的关系

```
游戏配置 (F5)                     调律配置 (F6)
┌───────────────┐                ┌─────────────┐
│ 词组配置       │ ← 词条库引用 ── │ 词条库设置    │
│ 装备配置       │ ← 品阶推断 ─── │ 基础配置      │
│ 武学/流派/玩法  │ ← 流派与玩法定义 │ 规则设置      │
│ 等级配置       │ ← 能力/材料 ─── │ 材料/结束处理  │
└───────────────┘                └─────────────┘
```

游戏配置是底层数据，调律配置是上层行为规则。修改游戏配置后，调律配置的判定逻辑会自动适配。
