# 燕云十六声伤害与治疗机制

## 一、三率判定机制

### 核心公式

| 结果 | 公式 |
|------|------|
| 会心 | = 判定精准 × (判定会心 + 直接会心) |
| 会意 | = 判定会意 + 直接会意 |
| 擦伤 | = (1 − 判定精准) × [1 − (判定会意 + 直接会意)] |
| 普伤 | = 判定精准 × [1 − 有效会意 − 有效会心] |

### 判定流程

```
攻击发起
    ↓
判定精准？
    ├─ 是 → 会意 / 会心 / 普伤
    └─ 否 → 会意 / 擦伤
```

### 关键机制

- **会意全局生效** — 无论精准与否，概率恒为 `判定会意 + 直接会意`
- **会心依赖精准** — 只有精准时才触发，未精准时转为擦伤
- **直接会心**只加精准分支，**直接会意**则是全局加成
- **普伤**只存在于精准分支，未精准分支没有普伤

### 上限约束

| 属性 | 上限 |
|------|------|
| 判定会心 | ≤ 80% |
| 判定会意 | ≤ 40% |

因此**会心与会意互斥**，无法同时堆到 100%。
