## 文档体系设计

### 目标

让 AI（或未来的自动化工具）能基于文档自动生成流派预设配置、词条权重、评分公式、顶级装备判定规则、转律策略。

---

### 文档分类

#### 第一类：游戏基础机制（不变的事实）

| 文档 | 内容 | 用途 |
|------|------|------|
| 装备系统概述 | 8个部位、品质分级、等级体系 | 基础数据模型 |
| 词条总表 | 所有可能出现的词条名称、类型、数值范围、出现部位限制 | OCR解析、规则校验 |
| 调律机制 | 初始词条固定、4条可调、不重复规则、最多2属攻 | 规则引擎核心逻辑 |
| 转律机制 | 三个库的定义、词条池、最多2属攻规则 | 转律策略生成 |
| 材料系统 | 律准石、转律石、品质对应关系 | 预算管理 |

#### 第二类：流派定义（玩家选择的玩法）

| 文档 | 内容 | 用途 |
|------|------|------|
| 流派总表 | 所有流派名称、定位、核心机制 | 用户选择列表 |
| 单流派详解 | 该流派各部位需要什么词条、优先级、取舍逻辑 | 生成 slot_rules |

#### 第三类：调律流程说明（操作层面的知识）

| 文档 | 内容 | 用途 |
|------|------|------|
| 调律界面说明 | 按钮位置、材料投入、动画时长 | UI自动化 |
| 转律界面说明 | 词条选择、库选择、确认流程 | UI自动化 |
| 回收流程 | 回收按钮、确认弹窗 | UI自动化 |
| 背包操作 | 翻页、筛选、排序 | 批量筛选流程 |
| 锁定机制 | 如何锁定词条、锁定后调律变化 | 精调策略 |

#### 第四类：顶级装备判定标准（跨流派共识）

| 文档 | 内容 | 用途 |
|------|------|------|
| T0词条定义 | 哪些词条在任何流派都有价值 | 自动保护逻辑 |
| 部位价值分析 | 各部位什么算"毕业" | 库存管理 |
| 稀有词条清单 | 武学增效、首领增伤等特殊词条 | 自动保护逻辑 |

#### 第五类：截图标注数据（视觉知识）

| 文档 | 内容 | 用途 |
|------|------|------|
| UI元素图鉴 | 各按钮、图标的截图模板 | 状态检测、点击定位 |
| 词条区域样本 | 不同词条的截图+OCR结果+正确标注 | OCR训练/校验 |
| 品质颜色定义 | 金/紫/蓝/绿的RGB范围 | 品质识别 |
