# v0.10.1 — 方案切换、Profile 快捷规则与五维换算修复

## 律匠 v0.10.1

> **发布状态：正式发布。发布日期：2026-09-03。** 本文以 v0.10.0
> 发布完成后的代码树为基线。

本版本增加机器级运行方案和 Profile 快捷规则可视化配置，并修正五维换算、
英文模式配置加载和用户总览字号持久化问题。

### ⚠️ 不兼容变动与升级指引

#### 五维换算修正后需重新采集角色基础属性

- **现象**：升级后，含劲、势或敏词条的装备会按正确系数计算；如果继续使用
  v0.10.0 或更早版本反推出的角色基础属性，换装后的毕业率绝对值可能出现偏差。
- **原因**：旧版使用了错误的五维换算系数，装备贡献被错误地扣进了已保存的
  角色基础属性。基础属性记录中没有保留当时的游戏面板值和装备快照，无法可靠
  自动还原。
- **如何调整**：升级后使用当前实际穿戴的装备和弓玦，按“新建属性”流程重新
  填写一次游戏内最终面板；可以使用原名称覆盖旧基础属性。程序不会添加版本字段、
  过期标记或界面提示。

除上述一次性操作外，本版本没有配置结构、存储位置、DSL 语法、场景键名、
快捷键或 Profile 数据格式的不兼容变动。方案功能默认保持“自定义”，升级后
无需创建方案即可继续使用原有图库、环境和布局选择方式。

### ✨ 新增功能

#### 机器级运行方案

- 新增“方案”选择器，可将图库、目标环境、布局和支持的连接方式保存为具名组合，
  在主窗口一次完成切换。
- 选中方案后锁定对应的图库、环境和布局；切回“自定义”时恢复进入方案前的组合。
- 方案可声明支持窗口模式、ADB 模式或两者。连接方式不匹配时，“开始执行”、F9
  和托盘启动入口都会阻止任务开始并说明原因。
- “通用 → 配置管理 → 方案设置”支持新建、从当前组合新建、编辑和删除方案。
- 方案保存在 `config/session/session.json`，属于机器级配置，不随用户切换。

#### Profile 快捷规则可视化

- 原来的“增减幅度”文本改为结构化变动规则，可直接选择“用途（减少）”或
  “来源（增加）”，并为同一来源或用途录入多个快捷数量。
- 来源、用途和快捷数量改为按 Enter 创建的可删除标签，避免中英文逗号、冒号
  混用导致解析失败。
- 变动规则与同步目标之间可纵向拉伸；标签超出一行时提供横向滚动。
- 快捷菜单按“快捷用途 → 快捷来源 → 增加/减少/覆写 → 历史记录”分组显示，
  仅在非空分组之间加入分隔线。
- 继续使用既有 `sources`、`uses` 和 `steps` 数据结构，旧 Profile 定义无需迁移。

### 🔧 修复

- **五维换算**：统一修正劲、势、敏到最小/最大外功攻击、会心率和会意率的固定
  换算系数。角色面板反推、战斗属性展示、词条边际收益、联合培养与最优组合均通过
  同一换算入口计算。
- **英文模式**：流派、部位、武器和装备词条等领域值不再随界面翻译后写入或参与
  规则校验，修复切换英文后基础规则组因“全部”等值无法识别而加载失败的问题。
- **用户总览字号**：编辑当前列并保存后不再把用户总览字体恢复为默认值，刷新后
  仍使用已保存的字号设置。

### 📦 重构

- Profile 来源/用途词表与绑定快捷数量的规则分开编辑，保存时自动合并为兼容的
  原有数据模型。
- 主窗口图库、环境和布局选择器改为按锁定原因统一管理，方案锁定不会干扰其他
  运行状态的禁用逻辑。
- 会话配置增加通用的 `actives.plan` 激活项，并将环境保存改为节点浅合并，避免
  并发保存时覆盖同一 `settings` 节点中的其他字段。

### 📚 文档
