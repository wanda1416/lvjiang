# 威威大王调律规则

公共规则见 [调律评价规则](README.md)，本文仅列威威大王（`huixin_modao`）专属规格。

- 规则键：`huixin_modao`，名称「威威大王」，`order: 70`。
- 必选配置：无；可选配置：无。
- 玩法：威威（裂石·威），主武器 陌刀（需要 陌刀武学增伤）、副武器 枪（不需要增伤）。
  裂石·威 只由本规则判定，会心大外不再包含它。

## 一、词条定位

| 词条 | 定位 | 顶级可参与 |
|------|------|------------|
| 对首领单位增伤 / 全武学增效 / 陌刀武学增伤 | 神力，部位必需，缺失即垃圾 | — |
| 最大外功攻击、劲 | 核心攻击 | 是（顶级硬要求） |
| 势 | 核心（会意流核心之一），但计入主武器/环/胫甲的「次要」密度 | 是 |
| 会心率 | 本命率 | 是 |
| 精准率 | 中性填充 | 是（见第二节组合限制） |
| 最大本属攻击 | 正常词条 | 是 |
| 会意率 | 次优率，价值低于精准率 | 是（见第二节组合限制） |
| 对玩家单位增效 | 仅 `keep_wanjia` 开关下有效 | 开关控制 |
| 敏、最小外功攻击 | 缺陷词条 | 否 |

- **最大本属攻击**在武器部位展开为 最大无相攻击，在非武器部位展开为玩法属性属攻
  （威威 = 最大裂石攻击）；武器部位没有外属。
- 池外词条直接判垃圾：最小属攻、未使用属性的属攻、会心伤害加成等。
- 敏、最小外功攻击 留在池内（池外会在第 1 条就判垃圾，拿不到「1 条一般」），
  但排在价值序最后。

## 二、转律优先级与可用词条库

- 转律优先级：最大外功攻击、劲、势、会心率、最大本属攻击。
- 可用词条库（价值序）：最大外功攻击、劲、势、会心率、精准率、最大本属攻击、
  会意率、对玩家单位增效、敏、最小外功攻击。

转律优先级只收本规则愿意主动转入的词条，因此和词条库有两类差异：

- 敏、最小外功攻击 不在其中——它们出现 1 条就一般封顶，转进来不可能提升评级；
- 会意率、精准率 也不在其中：本规则承认它们（在库内、不判垃圾），但转律不去凑。

词条库顺序本身是价值序，影响的是潜力判定填空槽的先后和模拟转律时「先转出谁」，
不参与评级：评级按合法转律上限穷举。敏、最小外功攻击 排在最末，即最先被转出、
最后才被填入。

## 三、通用判定

**垃圾档**
- 敏 + 最小外功攻击 合计 ≥ 2 条。

**一般档（优秀封顶）**
- 敏 + 最小外功攻击 ≥ 1 条；
- 非首词条没有 最大外功攻击（外功硬门槛）。

**顶级档（三条同时满足）**
- 非首词条含 最大外功攻击 + 劲；
- 会意率 与 精准率 不同现；
- 会意率 与 势 不同现。

> 「会意 + 精准」「会意 + 势」的组合限制写进顶级条件而不是垃圾条件：命中即封顶
> 优秀。冠胄首词条的 精准率 同样计入组合（`include_first`）。
>
> **垃圾档先于其他档判定**：敏/小外 的「1 条 → 一般」只在未命中任何垃圾条件时生效。
> 若该件同时命中下面的密度型垃圾，结果仍是垃圾——否则「再添一条缺陷反而从垃圾升到
> 一般」。

## 四、各部位：密度型垃圾与必需神力

**密度型垃圾**（组内 AND）：次要词条（率/势）≥ 2 条、且核心词条数不足阈值。

| 部位 | 次要词条 | 核心词条 | 核心阈值 |
|------|----------|----------|----------|
| 主武器 | 会意率 / 精准率 / 会心率 / 势 | 最大外功攻击 / 劲 / 最大本属攻击 | ≤ 0 |
| 副武器 | 精准率 / 会意率 / 会心率 | 最大外功攻击 / 劲 / 最大本属攻击 / 势 | ≤ 1 |
| 环 | 精准率 / 会心率 / 势 / 会意率 | 最大外功攻击 / 劲 / 全武学增效 / 最大本属攻击 | ≤ 1 |
| 胫甲 | 会心率 / 会意率 / 精准率 / 势 | 最大外功攻击 / 对首领单位增伤 / 对玩家单位增效 / 劲 / 最大本属攻击 | ≤ 1 |
| 冠胄 | 无密度型垃圾 | — | — |

- 势 在主武器/环/胫甲计入「次要」，只在副武器计入「核心」。
- 胫甲的核心集并入 对玩家单位增效，使「保留对玩家增效」打开时该词条照常算核心。

**部位必需神力**（缺失即垃圾）：主武器需要玩法给出的武学增伤；环需要 全武学增效；
胫甲按开关分流——关闭（默认）必须有 对首领单位增伤 且不得有 对玩家单位增效，
打开后两者有其一即可。
