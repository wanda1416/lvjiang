# v0.5.0b0 — DSL 键盘输入、布局体系重构、调律导航重构

## 律匠 v0.5.0b0

本版本为 v0.5.0 预览版。新增 DSL press/scroll 指令实现键盘与滚轮输入全链路，布局体系从场景级重构为布局级配置，调律导航策略拆分重构，UI 环境选择统一与日志筛选增强。

---

### ✨ 新增功能

- **DSL press 指令**：实现键盘输入全链路，包括 `KeyStateRegistry` 状态管理、`Win32Keyboard` 后台输入、`SendInput` 前台输入、安卓 `input` 指令
- **DSL scroll 指令**：实现鼠标滚轮全链路，支持桌面端与安卓端
- **DSL else if 支持**：条件分支链式写法，替代嵌套 if-else
- **DSL 系统函数扩展**：新增 `is_send` / `is_post` 系统函数
- **导航策略下沉**：`is_in_main_page` / `is_in_bag_page` 等检测函数下沉至 DSL 层，导航逻辑从 Python 硬编码迁移至工作流配置
- **桌面小屏布局**：全场景布局 JSON 支持小屏幕适配
- **布局 desc 描述字段**：布局配置新增描述字段，提升可读性
- **窗口扫描排除自身进程窗口**：桌面端窗口扫描自动过滤本进程窗口
- **场景编辑器增强**：POI 面板、区域面板交互优化
- **备战方案默认视图模式改为 half**
- **scan_wallet 工作流更新**
- **扫描同类型分组跳过**：自动调律扫描时同类型低等级武器跳过而非截止
- **导航 ESC 循环检测**：桌面端返回主页改为循环 ESC + 主页检测，最多 3 次后阻塞提示
- **登录页退出流程优化**
- **UI 环境选择统一**：环境选择上提至主窗口顶部，三个 tab 去重
- **运行日志级别筛选**：增加 WARNING / ERROR 级别筛选
- **布局坐标校准 + 新场景区域**：新增 status / func_area 区域
