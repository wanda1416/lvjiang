# 01-会意流派调律说明

公共规则（分级、品阶筛选、模式语法、定级骨架、转律熔断）见 `00-调律总说明.md`，
本文仅列会意流派专属规格。规格权威来源：04 文档「会意流派各部位词条要求」节。

- 适用流派：会意-通用（鸣金·虹 / 鸣金·影），主武器 剑，副武器 枪。
  注意：剑和枪可能在主武器槽位，也可能在副武器槽位，不受限制。
- 大本属 = 最大鸣金攻击（非武器部位的 大无相 即指它）。
- 可选配置：保留 PVP 装备（单体奇术增伤、对玩家增效 视作有效）。

## 一、神力词条要求

- 剑：必须有 剑武学增伤，没有视为不合格。
- 枪：不需要 枪武学增伤，有视为不合格。
- 首饰（环/佩）：必须有 全武学增伤，没有视为不合格。
- 冠胄和胸甲：不需要神力词条；但有 单体奇术增伤 可以留给 PVP 使用，姑且视作有效。
- 胫甲和腕甲：必须有 对首领增伤；如果是 对玩家增效，可以留给 PVP 和百业战使用，姑且视作有效。

增伤缺失直接判垃圾的部位：剑、首饰、胫甲/腕甲（见 00 第六节通用规则）。

## 二、转律优先级与可用词条库

- 转律优先级：大外、势、劲、会意、大无相（转律库中也会出现 会心，但视为废品词条）。
- 可用词条库：大外、势、劲、会意、大无相 + 会心、精准。
- 库外词条即废词条，直接判垃圾。典型：错位属攻（武器上的 最大鸣金攻击、
  非武器上的 最大无相攻击）、其他流派属攻（如 最大裂石攻击）、小属攻（如 最小鸣金攻击）。

## 三、各部位模式与顶级判定

| 部位 | 模式 | 顶级判定（均只看非首词条） |
|------|------|----------------------|
| 主武器（剑） | [大外(首) + 剑武学增伤 + 大外 + 劲/势] + 可用词条库 * 1 | 同时出现 大外+劲+势 → 顶级（3 自由槽即被占满），否则 优秀 |
| 副武器（枪） | [大外(首) + 大外 + 劲/势] + 可用词条库 * 2 | 同时出现 大外+劲+势 且 会意/大无相 ≥1 → 顶级，否则 优秀 |
| 环、佩 | [大外(首) + 大外 + 全武学增伤] + 可用词条库 * 2 | 同时出现 大外+劲+势 → 顶级（3 自由槽即被占满），否则 优秀 |
| 冠胄、胸甲 | [会意(首) + 大外 + 劲/势] + 可用词条库 * 2 | 出现 大外，且 劲/势 ≥1，且未出现 大鸣金 → 顶级，否则 优秀 |
| 胫甲、腕甲 | [劲(首) + 对首领增伤 + 大外] + 可用词条库 * 2 | 同时出现 大外+劲+势 → 顶级，否则 优秀 |

- 顶级判定**不计入首词条**，仅看非首 4 条
  （如 胫甲首词条=劲 时，非首词条仍须同时出现 大外、劲 和 势 才判顶级）。
- 有神力部位（主武器/环佩/胫腕甲）顶级要求核心三词条占满 3 自由槽，
  隐式排除了 会意/大无相 等其余词条；无神力部位（副武器/冠胄胸甲）
  4 自由槽凑不满核心词条，允许 1 条 会意（本命率）/大无相 参与顶级。
- 缺非增伤必选词条（如缺大外、缺劲/势）不构成缺陷，只要无废词条/缺陷词条
  即判 **优秀**（缺的词条可转律调出）。
- keep_pvp 开启时，对玩家增效 可顶替胫甲/腕甲模式中的 对首领增伤 槽位。

## 四、流派专属定级规则

会意流派目前不需要精准和会心：

- 出现 1 条 会心/精准，且取代的是可选槽 → 上限即为 **能用**。
- 出现 2 条及以上 会心/精准 → **垃圾**（本条为会意流派专属规则，已确认）。

## 五、顶级组合参考

04 给出的顶级装备示例（模式命中且满足顶级条件的一种典型取法）：

- 剑、环、佩：增伤 + 大外 + 大外 + 劲 + 势
- 枪：大外 + 大外 + 劲 + 势 + 会意
- 冠胄、胸甲：会意 + 会意 + 大外 + 劲 + 势
- 胫甲、腕甲：劲 + 对首领增伤 + 大外 + 劲 + 势

理论上全部顶级装备组合后将有 5 会意、8 势，这是会意流派的顶级组合。

## 六、判定例子

以下词条列表第 1 条均为首词条；大无相在非武器部位即 最大鸣金攻击（大本属）。

### 主武器（剑）

| 词条 | 判定 | 说明 |
|------|------|------|
| 大外 + 剑武学增伤 + 大外 + 劲 + 势 | 顶级 | 必选满足；可选槽=势，未出现会意/大无相 |
| 大外 + 剑武学增伤 + 大外 + 势 + 会意 | 优秀 | 可选槽=会意 |
| 大外 + 剑武学增伤 + 大外 + 会意 + 大无相 | 优秀 | 缺 劲/势 不算缺陷（可调出），无废词条 |
| 大外 + 大外 + 劲 + 势 + 会意 | 垃圾 | 剑明确需要 剑武学增伤，缺失直接判垃圾 |
| 大外 + 枪武学增伤 + 大外 + 劲 + 势 | 垃圾 | 剑上出现枪武学增伤，属废词条 |

### 副武器（枪）

| 词条 | 判定 | 说明 |
|------|------|------|
| 大外 + 大外 + 劲 + 势 + 大无相 | 顶级 | 同时出现 劲 + 势 |
| 大外 + 大外 + 劲 + 劲 + 会意 | 优秀 | 只有劲没有势（池内重复取劲合法） |
| 大外 + 大外 + 会意 + 大无相 + 大无相 | 优秀 | 缺 劲/势 不算缺陷（可调出） |
| 大外 + 大外 + 劲 + 势 + 鸣金 | 垃圾 | 武器上出现 最大鸣金攻击，属错位属攻 |
| 大外 + 枪武学增伤 + 大外 + 劲 + 势 | 垃圾 | 枪不需要枪武学增伤，有视为不合格 |

### 环、佩

| 词条 | 判定 | 说明 |
|------|------|------|
| 大外 + 大外 + 全武学增伤 + 劲 + 势 | 顶级 | 可选槽=劲+势，同时出现 劲 + 势 |
| 大外 + 大外 + 全武学增伤 + 劲 + 大无相 | 优秀 | 只有劲没有势（大无相即最大鸣金攻击） |
| 大外 + 大外 + 全武学增伤 + 劲 + 劲 | 优秀 | 池内重复取劲合法，但只有劲没有势 |
| 大外 + 大外 + 全武学增伤 + 劲 + 无相 | 垃圾 | 非武器上出现 最大无相攻击，属错位属攻 |
| 大外 + 大外 + 劲 + 势 + 劲 | 垃圾 | 首饰明确需要 全武学增伤，缺失直接判垃圾 |

### 冠胄、胸甲

| 词条 | 判定 | 说明 |
|------|------|------|
| 会意 + 大外 + 劲 + 势 + 会意 | 顶级 | 未出现大无相（可选槽再取会意合法） |
| 会意 + 大外 + 势 + 大无相 + 劲 | 优秀 | 出现大无相 |
| 会意 + 大外 + 劲 + 会心 + 势 | 能用 | 1 条会心顶替了可选槽 |
| 会意 + 大外 + 会心 + 精准 + 劲 | 垃圾 | 会心/精准 出现 2 条 |

### 胫甲、腕甲

| 词条 | 判定 | 说明 |
|------|------|------|
| 劲 + 对首领增伤 + 大外 + 劲 + 势 | 顶级 | 非首词条同时出现 劲 + 势 |
| 劲 + 对首领增伤 + 大外 + 劲 + 会意 | 优秀 | 没有势 |
| 劲 + 对玩家增效 + 大外 + 劲 + 势 | 顶级 | 对玩家增效视作有效（PVP/百业战保留，需开启 keep_pvp） |
| 劲 + 对首领增伤 + 大外 + 会意 + 大无相 | 优秀 | 可选槽=会意+大无相，命中模式但非首未同时出现 劲 + 势 |
| 劲 + 大外 + 劲 + 势 + 会意 | 垃圾 | 胫甲/腕甲明确需要 对首领增伤，缺失直接判垃圾 |
