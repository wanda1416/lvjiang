## 文档体系设计

### 目标
让AI（或未来的自动化工具）能基于这些文档，自动生成：
- 流派预设配置
- 词条权重
- 评分公式
- 顶级装备判定规则
- 转律策略

---

## 文档分类

### 第一类：游戏基础机制（不变的事实）

| 文档 | 内容 | 用途 |
|------|------|------|
| **装备系统概述** | 8个部位、品质分级、等级体系 | 基础数据模型 |
| **词条总表** | 所有可能出现的词条名称、类型、数值范围、出现部位限制 | OCR解析、规则校验 |
| **调律机制** | 初始词条固定、4条可调、不重复规则、最多2属攻 | 规则引擎核心逻辑 |
| **转律机制** | 三个库的定义、词条池、最多2属攻规则 | 转律策略生成 |
| **材料系统** | 律准石、转律石、品质对应关系 | 预算管理 |

**示例：词条总表**

```yaml
# data/affixes.yaml
affixes:
  - id: max_outer_attack
    name: 最大外功攻击
    aliases: [大外攻, 外功攻击]
    type: attack          # attack / rate / attribute / special / defense
    value_type: flat      # flat / percentage / range
    applicable_slots: [weapon, ring, pendant]
    quality_tiers:
      gold: {min: 80, max: 120}
      purple: {min: 50, max: 80}
      blue: {min: 30, max: 50}
    is_attribute_attack: true   # 是否属攻（用于最多2条规则）
    is_rare: false

  - id: crit_rate
    name: 会心率
    aliases: [会心]
    type: rate
    value_type: percentage
    applicable_slots: [weapon, head, chest, leg, wrist, ring, pendant]
    quality_tiers:
      gold: {min: 3.0, max: 5.0}
      purple: {min: 2.0, max: 3.0}
    is_attribute_attack: false
    is_rare: false

  - id: all_martial_boost
    name: 全武学增效
    aliases: []
    type: special
    value_type: percentage
    applicable_slots: [ring, pendant]
    quality_tiers:
      gold: {min: 6.0, max: 10.0}
    is_attribute_attack: false
    is_rare: true           # 稀有词条
```

### 第二类：流派定义（玩家选择的玩法）

| 文档 | 内容 | 用途 |
|------|------|------|
| **流派总表** | 所有流派名称、定位、核心机制 | 用户选择列表 |
| **单流派详解** | 该流派各部位需要什么词条、优先级、取舍逻辑 | 生成 slot_rules |

**示例：单流派文档**

```markdown
# docs/flows/会心双刀.md

## 流派概述
- 名称：会心双刀
- 定位：高会心高会意，爆发输出
- 核心机制：双刀攻击频率高，触发会心收益大
- 主属性：外功攻击、会心、会意

## 各部位需求

### 武器
- **初始词条T0**：最大外功攻击、敏、势
- **调律目标优先级**：
  1. 最大外功攻击（必须）
  2. 会心率
  3. 会意率
  4. 劲
  5. 敏
- **最低接受**：3条目标词条
- **必须包含**：最大外功攻击
- **组合加成**：大外攻+会心 同时存在时额外价值

### 头
- **初始词条T0**：会心率、会意率、精准率
- **调律目标优先级**：
  1. 会心率
  2. 会意率
  3. 精准率
  4. 劲
- **最低接受**：2条目标词条

### 胸
（同上，但可接受气血作为次选）

### 腿/腕
- **初始词条T0**：劲、会心率、会意率、精准率
- **调律目标优先级**：
  1. 劲
  2. 会心率
  3. 会意率
  4. 精准率
- **最低接受**：2条目标词条

### 环
- **初始词条T0**：最大外功攻击
- **调律目标优先级**：
  1. 最大外功攻击
  2. 全武学增效（稀有）
  3. 会心率
  4. 会意率
- **最低接受**：2条目标词条

### 佩
- 同环，但初始大外攻仅金装出现

## 转律策略
- 垃圾属攻词条 → 鸣金库（利用最多2属攻规则）
- 垃圾非属攻 → 其他库（追求三率/劲敏）
```

### 第四类：顶级装备判定标准（跨流派共识）

| 文档 | 内容 | 用途 |
|------|------|------|
| **T0词条定义** | 哪些词条在任何流派都有价值 | 自动保护逻辑 |
| **部位价值分析** | 各部位什么算"毕业" | 库存管理 |
| **稀有词条清单** | 武学增效、首领增伤等特殊词条 | 自动保护逻辑 |

```markdown
# docs/top_tier_criteria.md

## T0初始词条（任何流派都认）

| 部位 | T0初始词条 | 理由 |
|------|-----------|------|
| 武器 | 最大外功攻击、敏、势 | 攻击基础，全流派需要 |
| 环/佩 | 最大外功攻击 | 首饰唯一攻击来源 |
| 头/胸 | 会心率、会意率、精准率 | 三率全流派通用 |
| 腿/腕 | 劲、会心率、会意率、精准率 | 劲是通用攻击属性，三率通用 |

## T0调律词条组合

| 部位 | 什么组合算顶级 |
|------|--------------|
| 武器 | 大外攻 + 任意2条三率/劲敏势 |
| 头/胸 | 3条三率 |
| 腿/腕 | 劲 + 2条三率 |
| 环/佩 | 大外攻 + 全武学增效 + 会心/会意 |

## 稀有词条（自动保留）

- 武器：武学增效
- 首饰：全武学增效
- 头/胸：奇术增伤
- 腿/腕：首领增伤
```

## 文档 → 规则 的生成流程

```
用户选择"会心双刀"
    ↓
读取 docs/flows/会心双刀.md
    ↓
AI解析Markdown，提取结构化信息：
  - 各部位目标优先级
  - 最低接受条数
  - 必须包含词条
  - 转律策略描述
    ↓
读取 data/affixes.yaml，获取词条元数据：
  - 数值范围
  - 适用部位
  - 是否属攻
    ↓
读取 docs/top_tier_criteria.md
    ↓
生成规则配置：
  - slot_rules（各部位规则）
  - affix_weights（自动根据优先级分配权重）
  - transfer_strategy（根据描述生成）
  - top_tier_rules（跨流派保护规则）
    ↓
输出 YAML 到 config/presets/会心双刀.yaml
```
