# 04-治疗纯奶调律说明

公共规则见 `00-调律总说明.md`，本文仅列治疗纯奶专属规格。
规格权威来源：04 文档「治疗流派纯奶各部位词条要求」节。

- 治疗流派即 **牵丝·霖**：主武器为 扇，副武器为 伞。
- 必选配置：玩法（纯奶、火拳奶，可同时勾选）；可选配置：无（无 keep_pvp 配置）。
- 纯奶需要 **扇武学增效**；不需要伞武学增伤。
- 大本属 = 最大牵丝攻击，非武器部位的 大无相 即指它。

## 一、神力词条要求

- 主武器（扇）：必须有 扇武学增效，没有视为不合格（缺失直接判垃圾）。
- 副武器（伞）：不需要武学增伤，有视为不合格。
- 首饰（环/佩）：必须有 全武学增伤，没有视为不合格（缺失直接判垃圾）。
- 头盔和胸甲：不需要神力词条。
- 胫甲和腕甲：必须有 **对玩家增效**（缺失直接判垃圾）。
  注意：与输出流派不同，纯奶胫甲/腕甲必选的是对玩家增效，不是对首领增伤。

## 二、转律优先级与可用词条库

- 转律优先级：大外、劲、小外、敏、会心、大无相、大本属。
- 可用词条库：大外、劲、小外、敏、会心、大无相、大本属 + 势。
- 注意：会心、大无相、大本属、势 在库内**不判垃圾**（可命中可选槽），其中
  会心/大无相/大本属 会被部分部位的顶级条件排除；**势 → 优秀封顶**（见下节公共条件）。
- 库外词条即废词条，直接判垃圾。典型：会意、精准、**小无相**、非牵丝流派的属攻、
  错位属攻（武器上的大本属、非武器上的最大无相攻击）。
  注：04 原文顶级条件中提及的「小无相」属冗余表述——小无相不在词条库内，
  出现即已判垃圾，走不到顶级判定。

## 三、公共条件（heal_pure common，均只看非首词条）

按 垃圾 → 能用 → 优秀 → 顶级 顺序求值，首命中即终判：

1. 势、大无相、大本属 合计 ≥2 → **垃圾**；
2. 势 + 会心 同现 → **能用**；
3. 势 ≥1 → **优秀封顶**（不再参与顶级判定；该备注曾有争议，暂以实现现状为主）。

## 四、各部位模式与顶级判定

| 部位 | 模式 | 顶级判定（命中模式后） |
|------|------|----------------------|
| 主武器（扇） | [大外/小外(首) + 扇武学增效 + 大外/小外/劲] + 可用词条库 * 2 | 未出现 会心/大无相 → 顶级，否则 优秀 |
| 副武器（伞） | [大外/小外(首) + 大外/小外/劲 * 2] + 可用词条库 * 2 | 未出现 大无相，且（敏和会心未同时出现）→ 顶级，否则 优秀 |
| 环、佩 | [大外/小外(首) + 全武学增伤 + 大外/小外/劲] + 可用词条库 * 2 | 未出现 大本属，且（敏和会心未同时出现）→ 顶级，否则 优秀 |
| 头盔、胸甲 | [会心(首) + 大外/小外/劲 * 2] + 可用词条库 * 2 | 未出现 大本属 → 顶级，否则 优秀 |
| 胫甲、腕甲 | [劲(首) + 对玩家增效 + 大外/小外/劲] + 可用词条库 * 2 | 未出现 大本属，且（敏和会心未同时出现）→ 顶级，否则 优秀 |

- 首词条和必选槽多为 `大外/小外/劲` 多选一，同一模式的多个槽位可分别取不同候选。
- 主武器顶级排除会心；其余部位顶级只限制「敏+会心不同时出现」，单独出现敏或会心不影响顶级。
- 各部位另有**能用（一般）条件**（config 的 normal_conditions，非首词条）：
  主武器/环/胫甲 大外/小外/劲 全缺 → 能用；副武器/冠胄 大外/小外/劲 ≤1 → 能用。

## 五、判定例子

以下词条列表第 1 条均为首词条。

| 部位 | 词条 | 判定 | 说明 |
|------|------|------|------|
| 主武器（扇） | 大外 + 扇武学增效 + 小外 + 劲 + 势 | 优秀 | 势 ≥1 → 优秀封顶（公共条件） |
| 主武器（扇） | 小外 + 扇武学增效 + 大外 + 劲 + 会心 | 优秀 | 主武器顶级排除会心 |
| 副武器（伞） | 大外 + 小外 + 劲 + 敏 + 会心 | 优秀 | 敏和会心同时出现 |
| 副武器（伞） | 大外 + 大外 + 劲 + 小外 + 敏 | 顶级 | 必选槽 大外/小外/劲*2，可选槽 小外+敏 |
| 环 | 小外 + 全武学增伤 + 劲 + 大外 + 会心 | 顶级 | 只有会心没有敏，不触发同现限制 |
| 环 | 大外 + 全武学增伤 + 劲 + 敏 + 大本属 | 优秀 | 大本属即大无相，被顶级条件排除 |
| 头盔 | 会心 + 大外 + 劲 + 敏 + 会心 | 顶级 | 头盔顶级只排除大本属 |
| 胫甲 | 劲 + 对玩家增效 + 小外 + 大外 + 势 | 优秀 | 势 ≥1 → 优秀封顶（公共条件） |
| 胫甲 | 劲 + 对首领增伤 + 大外 + 劲 + 敏 | 垃圾 | 必选的对玩家增效缺失，且对首领增伤系纯奶不需要的神力词条 |
| 腕甲 | 劲 + 对玩家增效 + 大外 + 精准 + 敏 | 垃圾 | 精准为库外废词条 |
