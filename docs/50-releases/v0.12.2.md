# v0.12.2 — 赛季边界修正、不肝商店工作流与装备管理修复

日常使用装备管理、最优组合或安卓设备的用户建议升级；本版本不含新的自动化能力大改。

## 律匠 v0.12.2

> **发布状态：正式发布。发布日期：2026-09-18。** 本文以 v0.12.1 正式版为基线。

本次补丁版本修正了赛季生效边界与跨赛季装备等级的取值方式，新增不肝商店外观兑换
工作流与 `profile_declare` 内置函数，并集中修复了装备管理、最优组合、Profile 编辑和
安卓设备扫描中的若干问题。

### ⚠️ 不兼容变动与升级指引

**1. 赛季结束后不再回退到「最后一个赛季」的装备等级**

- **现象**：当前日期不在任何已配置赛季范围内时（例如系统随包的第 1 赛季于
  `2026-09-24` 结束，而你尚未录入第 2 赛季），配装页的当前赛季装备等级、最优组合
  的满级目标以及词条培养分析的目标等级会变为 0 / 空，而不是像以前那样沿用列表中最
  后一个赛季或最高一档的等级。
- **原因**：原先在赛季缺失时静默回退到旧赛季，跨赛季后会用错误的等级评估装备；现
  在统一由 `current_equip_level()` 按当前时间严格取值。
- **如何调整**：赛季更替后，到「游戏设置 → 赛季」添加新赛季（编号、起止日期、装
  备等级）。若你在 `config/local` 覆盖过 `yysls/game_config.yaml`，系统随包的赛季数
  据不会自动到达，需要自行维护该文件里的 `season_configs`。

**2. 赛季按 05:00 切换，起止日期必须首尾衔接**

- **现象**：赛季生效区间改为 `[start_date 05:00, end_date 05:00)`；上半赛季/下半
  赛季的切换也按 05:00 判定。在「游戏设置 → 赛季」保存时，新增校验：赛季编号唯一
  且为正整数、起止日期都必须填写且结束晚于开始、相邻赛季的结束日期必须等于下一赛季
  的开始日期。不满足时保存会被拒绝并提示原因。
- **原因**：燕云赛季固定在早上 5 点切换，原来按「整天包含」判断会在切换日产生一天
  的重叠或空洞。
- **如何调整**：已保存的旧配置仍可正常加载，不做迁移；下次在界面保存赛季时，按提
  示把相邻赛季的日期改成首尾衔接（旧赛季 `end_date` = 新赛季 `start_date`）即可。

**3. `bugan_detail`（不肝商店）布局区域 key 重命名**

- **现象**：不肝商店场景的布局 key 由 `cat_4`、`cat_5` 等重排为 `liebiao`、
  `cat_2`…`cat_7`，并新增 `current_tili`。引用旧 key（如 `[bugan_detail].[cat_5]`）
  的自定义工作流会在校验时报「区域不存在」。
- **原因**：不肝商店工作流扩展为支持外观兑换与体力同步，需要按实际页面重画区域。
- **如何调整**：系统随包的 `purchase_bugan.wf` 已同步更新，无需操作。若你在
  `config/local` 覆盖过 `bugan_detail` 布局、场景或该工作流，本地内容仍然优先生效，
  请手动同步或删除本地覆盖后重新获取。

**4. 装备「按筛选删除」默认保护备战方案引用的装备**

- **现象**：批量删除筛选出的背包装备时，任意现存备战方案正在引用的装备默认被保留，
  确认框会显示「筛选命中 / 备战保护 / 实际将删除」的件数；取消勾选「保留备战中的装
  备」才会连同它们一起删除，并提示将从相关方案中移除。
- **原因**：原先的筛选删除会顺带删掉备战方案里的装备，方案随之失效。
- **如何调整**：无需操作；如确实要删除备战中的装备，在确认框里取消保护勾选。

其余系统配置微调（主界面幻马/听风辩位入口的视图归属与激活键、`training_main` 布局
更新、心法购买任务更名为「自动购买心法心得」、batch 工作流参数文案）不改变语义。
若你在 `config/local` 保存过同路径覆盖，本地内容仍然优先生效，不会自动获得这些调
整；需要时请手动同步。本版本未提升任何 `content_version`，已下发的远端配置不受影响。

### ✨ 新增功能

- **不肝商店外观兑换与体力同步**：`purchase_bugan.wf` 新增外观类目的袅袅之音兑换
  （按 profile 前置条件跳过已购/库存不足），进店与购买宝钱后把当前体力同步到
  profile；配套重画 `bugan_detail` 的桌面与安卓布局。
- **`profile_declare` 内置函数**：工作流可在开头声明自身依赖的 profile key
  （`eval profile_declare("stock", "changmingyu", {"label": "长鸣玉"})`），未定义时
  按声明幂等创建，已定义则只做模型一致性校验；保存失败自动回滚，不阻断工作流。
- **配装摘要展示毕业率口径**：配装页摘要行直接显示 DPS 与毕业率所采用的「三满」假
  设开关，不再需要打开对话框才能看到评估前提。
- **黄字显示开关移入卡片菜单**：判定属性卡片右键即可在「仅黄字」与「白字 + 黄字」
  之间切换三率及增效的显示方式，增益效果与判定属性共用同一状态。
- **`extract_progress` 支持千分位逗号**：`1,950/2,500`、全角逗号等进度文本可正确解
  析；不满足每三位一组的逗号仍视为噪声。

### 🔧 修复

- 安卓设备扫描恢复可取消：无线扫描与 `adb devices` 枚举过程中点击取消会立即停止，
  不再等待所有探测超时。
- ADB 无线扫描只枚举私有网段并过滤 VPN/代理虚拟网段（如 198.18.x.x），改用 ping
  快速探测后再连接，大幅缩短局域网扫描时间。
- 赛季装备等级取值统一（见不兼容变动 1、2）：配装页、最优组合、词条培养分析在赛季
  切换日不再出现等级错位。
- 最优组合的玩法候选按「当前方案 / 同流派 / 同属性 / 其他」精确归类，不再把同流派
  的其他玩法混入当前方案分组。
- 装备词条顺序异常的日志级别由 error 降为 warning，不再在日志里被当作故障。
- Profile 设置对话框中按 Enter 添加词条时，只提交输入框内容，不再触发对话框默认按
  钮而丢失已有词条。
- 表单对话框中多行 JSON 值的 label 改为顶部对齐，不再超出 key 行。
