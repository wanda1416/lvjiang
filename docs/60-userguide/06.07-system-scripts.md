# 6.7 系统脚本与工作流清单

系统自带哪些脚本、每个脚本要什么参数，以及它们与你自己的副本是什么关系。

## 6.7.1 清单怎么读

以下为系统自带、可在日常 Tab 运行的工作流。每个工作流列出一句话说明、参数和前置条件
（游戏需要停在哪个页面）。

清单只收系统脚本；你自己放在本地的脚本不会在这里列出，也不要指望本页随你的改动同步。
想看当前机器上真实的全量，以下面三处为准：日常 Tab 的脚本下拉（受「脚本配置」勾选与排序
影响）、脚本编辑左侧的脚本树（区分系统与本地）、以及[附录 D](appendix-d-command-line.md)
的 `--list`。系统脚本随版本更新整份替换，你在本地的同路径副本优先，见
[6.7.3 系统脚本与你自己的脚本](#673-系统脚本与你自己的脚本)。

## 6.7.2 日常脚本清单

### 每日江湖号令

刷新并执行江湖号令任务（换装、合影、情境、看报、醉意）。

| 参数 | 说明 | 默认 |
|------|------|------|
| 单任务最大刷新次数 | 单个 label 未命中目标任务时最多刷新几次 | 50 |
| 领取奖励 | 任务完成且卡片显示待领取的金色光效时，点击标签领奖；已领奖卡片会跳过 | 否 |
| 黄泉酿置信度 | 背包中识别「黄泉酿」的置信度门槛，档位 0.65 / 0.6 / 0.55 / 0.5；反复匹配不上时可逐级下调，但不要低于 0.5——阈值过低会把其他道具误认成黄泉酿 | 0.65 |

**前置**：停在江湖号令活动页或游戏首页（自动识别）。

### 每日自动签到

自动进入活动列表，按配置依次查找活动并领取奖励。活动名称和领奖关键字按行对应；
例如活动名称填写“朝夕共赏”，同一行对应的领奖关键字填写“签到”。工作流逐屏滚动
活动列表，并在每个视口检查所有尚未处理的活动，因此配置顺序不受列表顺序限制。

| 参数 | 说明 | 默认 |
|------|------|------|
| 左侧活动名称 | 每行一个，名称不能重复 | 朝夕共赏 |
| 右侧领奖关键字 | 每行一个，与活动名称逐行对应，支持包含匹配 | 签到 |

**前置**：停在游戏首页。

### 购买不肝商店

从游戏首页进入菜单 → 不肝 → 商店，依次处理战斗养成、逐战商店、营生、赛季及外观兑换。

进入不肝后先领取奖励，再依次查看不肝和花蕊织的本周获取进度，最后进入商店。
花蕊织按周进度新增量更新库存，来源为“日常”；两项进度发生识别回退时记录错误
并保留已有数据，不把周进度直接当成库存余额覆盖。

| 参数 | 说明 | 默认 |
|------|------|------|
| 战斗养成购买项 | 逐项勾选要买的类目（心法/武学/奇术/振玉/生活/宝钱/短陌钱） | 全选 |
| 购买营生 | 是否购买营生类目 | 是 |

赛季类目始终全买，不做成参数。

逐战商店只检查首页，先兑换惊喜礼盒，再兑换袅袅之音·绑。花蕊织库存至少 1000
时补齐本周最多 5 个礼盒（每个 200）；之后按剩余花蕊织补齐本半赛季最多 2 个
袅袅之音（每个 3000），只够一个时只买一个。未找到对应商品或余额未知时跳过。
购买后的库存减少量用于记录配额并同步扣除花蕊织，未确认成交时不记录为成功。
礼盒使用 `zhuzhanbox_of_halfseason`，虽然 key 名含 halfseason，实际为每周配额。

**前置**：停在游戏首页。

### 购买袅袅之音·绑

菜单 → 商店 → 精选 → 道具，按物品文字定位「袅袅之音·绑」并购买。周额度上限 2 个，
每个 200 长鸣玉。

商店里同时存在付费版「袅袅之音」和游戏内货币兑换的「袅袅之音·绑」，脚本设了两道闸
防误买：只在物品文字含「绑」时点击；打开购买面板后再校验物品名同时含「袅袅」和「绑」，
不满足立即中止，绝不点「购买」。开头先读本周已购数量：已满 2 个直接跳过；再按长鸣玉
余额算出这次能买几个，只够 1 个时仍买 1 个。买成后按实际个数累加本周已购，周周期
自动清零。

| 参数 | 说明 | 默认 |
|------|------|------|
| 最大滚动查找次数 | 在道具网格中向下查找的次数上限，每步约半行 | 4 |

**前置**：停在游戏首页。

> 批量执行时，「本周已买满」只让该任务在该用户这一轮跳过，不会因此否掉整次登录——
> 同一轮里别的任务可能仍需要这个账号。

### 购买心法心得

可先打开背包普通道具中的全部心法心得，再进入商店购买心法。
进入循环购买前和循环结束后，任务会读取心得置换页的每周剩余库存，按
“600 - 剩余库存”同步 `xinfa_of_week` 本周已购买数量；识别失败不会覆盖已有值。
本周已购满 600 时任务直接结束，不再走一趟导航；批量执行也会在登录前跳过它。

| 参数 | 说明 | 默认 |
|------|------|------|
| 打开背包全部心法 | 扫描当前背包页及向上滚动一次后的普通道具，依次打开所有“心法心得” | 否 |

**前置**：停在游戏首页。

### 扫描备战装备

扫描当前已穿戴的八件装备，并写入任务启动时绑定的备战方案。

**前置**：停在游戏首页；先选择正确用户和目标备战方案。

| 参数 | 无 |
|------|---|

### 扫描全部备战方案

以游戏中当前可见的方案网格为准，依次切换有名称的方案、读取两门武学并扫描八件装备；
本地没有同名方案时自动新建。新建时按游戏里的方案名判断对战类型：名称含「PVP」记为
PVP，其余记为 PVE，认错了可以在方案管理里改回来。

| 参数 | 说明 | 默认 |
|------|------|------|
| 基础属性滚动次数 | 扫描角色页基础属性时向下滚动的次数 | 8 |
| 跳过已存在的备战方案 | 按任务启动时的本地方案名跳过，不再切换与扫描 | 否 |
| 跳过已存在的基础属性 | 方案照常切换、装备照常扫描，只在基础属性已保存过时跳过角色页 | 否 |

**前置**：停在游戏首页；先选择正确用户。

目前以当前可见的方案网格为准，不滚动，超出网格行数的方案暂不扫描。玩法匹配、
失败处理和写入规则见[5.1 装备数据总览](05.01-equipment-data-overview.md)。

### 扫描基础属性

进入角色详情页读取面板基础属性。默认只扫描并弹出创建面板，由你确认后写入；勾选静默
写入后自动写入指定方案，不再弹面板。

| 参数 | 说明 | 默认 |
|------|------|------|
| 滚动次数 | 角色页向下滚动的次数 | 8 |
| 静默写入备战方案 | 打开后自动写入，不再弹出确认面板 | 否 |
| 目标方案 | 仅在静默写入时出现；留空表示当前方案 | 空 |
| 主武学 / 副武学 | 仅在静默写入时出现；两门都留空表示按方案里记录的取值 | 空 |

要指定武学必须同时填写两门，且与本地方案的武学一致。

**前置**：停在游戏首页；先选择正确用户。

属性反推与写入规则见[5.4 角色基础属性与真实毕业率](05.04-base-attributes-and-graduation.md)。

### 扫描全部装备

按所选部位扫描背包装备，解析后写入当前用户的公共装备池。支持最低等级截止和
最少普通词条数过滤，主副武器共享武器背包且只扫描一次。

**前置**：停在游戏首页；先选择正确用户。

| 参数 | 说明 | 默认 |
|------|------|------|
| 扫描部位 | 武器、环、佩、冠胄、胸甲、胫甲、腕甲，可多选 | 全部 |
| 装备最小等级 | 低于该等级时结束当前部位的有序扫描 | 110 |
| 最少词条数 | 普通词条不足时仍扫描但不写入；0 表示不过滤，定音不计数 | 0 |

装备数据的产生、去重和核对方法见[5.2 装备数据如何产生](05.02-equipment-data-acquisition.md)。

### 扫描钱袋货币

进入包裹 → 钱袋，识别各货币数量并写入 Profile。支持容差校验，防止异常值覆盖。

| 参数 | 说明 | 默认 |
|------|------|------|
| 通宝允许差值(万) | 新值与旧值差超过此值则跳过写入 | 0（不限制） |
| 么玉允许差值 | 同上 | 0 |
| 宝钱允许差值(万) | 同上 | 0 |
| 长鸣玉允许差值 | 同上 | 0 |

**前置**：停在游戏首页。

### 太极炸鱼

自动执行炸鱼循环操作。

| 参数 | 说明 | 默认 |
|------|------|------|
| 最大循环次数 | 最多执行几轮 | 500 |
| 技能按键 | PC 端用于炸鱼的技能键，可选 1–4 | 1 |

**前置**：停在炸鱼活动入口。

> PC 端的技能按键不支持后台输入。运行前必须关闭「后台模式」，
> 否则工作流会在执行任何操作前直接中止并说明原因。

### 刷毒和膏

按图纸打一套固定循环（吐火 → 卸势 → 两次重击 → 后退 → 两次跳跃 → 前跳复位 → 武学技），
无限重复，每轮记一条 info 日志。全程没有页面判定与到位校验，起点或键位一变整套操作就
失效。

| 参数 | 说明 | 默认 |
|------|------|------|
| 奇术按键 | PC 端神龙吐火所在的奇术键位 | 4 |
| 多人挂机 | 多人场景下每个环节多等一拍 | 否 |

**前置**：角色位于图纸要求的起点，面向精英怪背后，并按图纸调整好奇术与武器。

> 需要「设备端手势」：前跳那段要一边推住前进摇杆一边点跳跃，注入式输入做不到。
> 能力不满足时启动即被拒绝并说明原因。
>
> PC 端必须关闭后台模式、让游戏窗口保持前台；安卓端把默认奇术键设为神龙吐火
> （脚本直接点奇术按钮）。卡脚、撞墙时先调朝向。

### 刷虎骨酒

面向精英怪背后，按固定节奏盲打：暗杀 → 拾取 → 前跳 → 后跳复位，无限循环。不识别
提示，靠随机等待吸收动画时长。无参数。

**前置**：角色站在精英怪背后并面向它；顶部背向的栅栏建议换成实体墙，否则容易后退
起跳时卡脚。

> 同样需要「设备端手势」：后跳那段是按住后退的同时连跳三次。PC 端目前更稳定。

### 鸣金虹木桩测伤

在木桩前按固定循环打一套技能，用于测伤害。PC 与安卓用不同参数表达各自的奇术位。

| 参数 | 说明 | 默认 |
|------|------|------|
| 阴阳迷踪步 / 萧吟千浪 | PC 端这两个奇术使用的按键 | 2 / 3 |
| 阴阳迷踪步 / 萧吟千浪（安卓） | 安卓端对应的奇术位 | 2 / 3 |

**前置**：切到枪，面向木桩并处于攻击范围。

> PC 端先把滚轮切武器绑到小键盘 8；默认 Q = 武学技、E = 卸势。要追极限伤害，需要
> 自己调每个环节的按键时间与等待。

### 破竹尘木桩测伤

破竹尘赛季的一套木桩循环，只有 PC 端可用。

| 参数 | 说明 | 默认 |
|------|------|------|
| 萧吟千浪 | 该奇术使用的按键 | 4 |

**前置**：开局切绳镖、面向木桩约 5 米并锁定视角；滚轮切武器绑小键盘 8；
Q = 武学技、E = 卸势、反引号 = 特殊技。

### 风沙酒肆·夜宿谜影

活动「风沙酒肆」的夜宿环节：触发一次「躺下」（重复触发会起身），守夜后连续接待
5 位访客，按策略决定给谁开门。分组为「活动」，**不可批量执行**。

| 参数 | 说明 | 默认 |
|------|------|------|
| 连刷轮数 | 连续跑几轮 | 3 |
| 判断策略 | 只开第 2、5 位 / 识别优先，认不出按序号 / 不看识别只按序号 / 只信识别，认不出就拒绝 | 只开第 2、5 位 |
| 保守放行序号 | 策略需要按序号放行时使用的序号表；「只开第 2、5 位」不受它影响 | 2,5 |
| 演练模式 | 走完整流程但不真的放人进来，用来先试跑 | 否 |
| 床位 | 1 / 2 / 3 号床；2、3 号床会先转向再走到床边 | 1 号床 |
| 开门 / 拒绝选项关键字（安卓） | 按词匹配选项文字，命中即认定该选项 | 内置词表 |

**前置**：角色在客栈房间内（不必站在从拾香旁）。

> PC 端用键盘位移扫房间找床边；安卓端推摇杆、每轮右转 45° 扫一圈。多人模式下要等
> 队友都躺下才开始守夜。目前只实机验证过「只开 2、5」这一策略，其余组合请先用演练
> 模式确认。

### 输入兑换码

主页 → 菜单 → 设置 → 其他 → 兑换码，处理完毕后退回主页。

| 参数 | 说明 | 默认 |
|------|------|------|
| 兑换码 | PC 每行一个，可一次填写多行；安卓端留空，由弹窗提示手动输入 | 空 |

**前置**：停在游戏首页或菜单页。

> PC 端逐行通过剪贴板粘贴，跳过空行并清理每行首尾空白。
> **全部为空会在进入游戏页面之前直接报错中止**。
> 每条确认或取消后，必须识别到“其他”页的兑换码标签，才重新打开入口处理下一条。
>
> 安卓端的输入通道发不了文本，脚本会在输入框打开后弹窗等待——请自己
> 输入或粘贴一个兑换码，选择「是」后由脚本处理确认；选择「否」结束兑换并
> 保留当前游戏页面。无人值守仍会显示这个确认框，不会跳过兑换任务。
> 也可自行确认并回到其他页后再继续，此时脚本不会重复点击确认。
> 安卓不循环处理参数中的多行；如需多个兑换码，请在等待确认期间自行逐条操作。
>
> 确认后若仍未回到其他页，且未识别到“兑换奖励”，脚本按已兑换提示处理，
> 记录一次 warn 并取消一次；如果仍无法回到其他页，则中止后续操作。

### 自动剧情跳过

自动推进对话；出现选项时查「剧情文案库」挑正确答案。仅安卓端可用，**不可批量执行**。

| 参数 | 说明 | 默认 |
|------|------|------|
| 最多推进轮数 | 单次运行的推进上限，到上限即结束 | 500 |

**前置**：停在剧情对话画面。

> 未收录的选项会暂停，等你手动选择后点继续，再到「工具 → 自动剧情」补充文案。
> 需要移动角色的剧情暂不支持：判定对话结束后提示你手动处理。

## 6.7.3 系统脚本与你自己的脚本

日常 Tab 里同时可能出现两类脚本，来源不同，处理方式也不同：

| | 系统脚本 | 你自己的脚本 |
|---|---|---|
| 来源 | 随安装包与在线更新下发 | 你新建，或从系统脚本复制到本地 |
| 可否编辑 | 只读；编辑前先复制一份到本地 | 可自由编辑、删除 |
| 版本更新后 | 整份被新版本替换 | 保持你的内容，不被覆盖 |
| 同路径同名时 | 让位给本地副本 | 生效 |

要点：

- **不想看到某个系统脚本**，不要试图删文件（系统脚本删不掉），到「工具 → 脚本编辑 →
  脚本配置」取消勾选即可，随时能勾回来。
- **想改某个系统脚本**，先复制一份到本地再改。本地副本按**整份文件**生效，不是逐行合并：
  系统版本后续新增的内容不会自动并进你的副本，需要你自己对照更新。
- **把自己改坏的副本删掉**，同路径的系统版本立刻重新生效。
- **更新后行为跟说明不一致**，先确认本地是不是还留着一份旧副本——同名时生效的是本地那份。
- 系统脚本里除了日常能看到这些，还有一批只被其他脚本调用的内部过程（导航、登录、页面
  判断、弹窗处理、结果摘要等）。它们不进入日常下拉，也不能单独运行；覆盖它们只影响你
  自己机器上那份副本，而所有调用它的脚本（包括系统脚本）都会改用你的版本。
- 各脚本支持哪些端、是否需要手机端手势、能不能排进批量，都以脚本自己的声明为准：
  不满足条件时它不会出现在对应候选里，或在启动前被拒绝并说明原因。
