# 4.7 使用外部 Agent 智能调律

> 最后更新：2026-10-09（基线 v0.13.14）。桌面入口与本机 MCP 已实现，WorkBuddy 界面接入和实际游戏过程待本机验收。

智能调律需要开通 Lv1，请先在设置的“功能激活”中激活。未开通时，页面显示提示，
不能开启接入或一键启动；所有 MCP 访问（包括发现、文档与数据读取）均返回 Lv1
激活提示。连接期间清除激活后，后续请求同样被拒绝。

启动律匠，连接游戏窗口或手机。在“调律管理”旁打开“智能调律”，选择执行用户
和授权目标，并在主界面选中该目标。勾选需要的权限，然后点击“开启 MCP 接入”。
这不需要设置律匠内置的 AI 模型；对话在外部 Agent 中完成。

点击“复制 WorkBuddy 配置”或“导出接入配置”，在 WorkBuddy 自定义 MCP 入口
粘贴或导入。具体入口名称以已安装版本为准。配置连接同一台电脑上的当前律匠，
含私人连接令牌，关闭/重新开启服务或重启后重新导出。

多个律匠实例可以同时开启 MCP，各自使用系统分配的空闲端口和独立令牌。
同时接入时，请在 Agent 配置中把默认的 lvjiang 连接名称改为不同名称；
每份配置只访问导出它的实例及该实例的数据，不会自动切换到其他安装目录。

可以在 Agent 中说：

> 先扫描我的备战方案，再和我讨论想玩的流派与玩法。看看现有装备怎么培养、哪些
> 部位需要替换，给我生成新的基础规则组和调律规则，保留我原有配置。

读取已有数据和触发采集是不同权限。扫描会切换游戏方案并更新装备与基础属性；
当前覆盖方案列表可见网格，列表外方案不保证被扫描。扫描结束后，Agent 应说明
成功、失败和数据不足，不能把部分结果说成全部完成。应用当前备战方案不随采集切换。

Agent 可分析真实毕业率、培养潜力、词条敏感度、转律建议和现有装备组合。建议
中应区分立即收益与培养假设，转律和培养不会自动执行。没有匹配模型或完整数据
时应先补齐，不能把估算写成可靠结论。

生成的配置是新的独立基础组和调律规则，不覆盖随包配置或已有用户定义。回到
智能调律页选择生成结果，阅读目标、调律部位和培养建议。允许启动及这套配置需要
且用户愿意授予的回收、重置、狗粮、锁定操作后，点击“一键启动调律”。如不愿
授权某项，让 Agent 重新生成不含该动作的配置。

启动不自动设为用户默认，也不执行培养建议。任务进度和历史仍在调律管理，可
使用原有暂停/停止入口。关闭 MCP 只断开 Agent 接入，已启动任务继续运行。
修改过生成规则时，启动会要求重新核对，避免执行与先前建议不一致的配置。

完整操作契约与对话示例见 [Agent 使用入口](../70-agent/README.md)。
