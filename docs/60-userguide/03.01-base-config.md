# 3.1 通用配置

入口：「通用 → 配置管理」。

修改后点「保存」生效。系统默认值随版本分发，你的修改保存为本地覆盖，
更新版本不会丢失。

---

### 基础配置

| 配置项 | 说明 |
|--------|------|
| 安卓截图方式 | `ADB screencap`（静态截图）或 `scrcpy`（视频流截图）。scrcpy 更流畅但需要额外依赖，不可用时自动回退 screencap。截图选择与输入选择相互独立 |
| 安卓输入方式 | 默认使用 `ADB shell input`，无需安装手机 App。`设备端手势`是 Beta 功能：只有用户明确选择，并在手机安装律匠 App、开启无障碍服务后才会尝试；App 不可达时自动回退 `ADB shell input`（运行日志提示一行）。该选项不改变截图方式，下次连接生效 |
| 窗口输入模式 | `PostMessage`（后台输入，不移动光标）或 `SendInput`（前台输入，真实移动光标）。仅投屏模式有效 |
| 默认窗口标题 | 填入窗口标题关键字（如「投屏」），「扫描窗口」时自动匹配并定位，免去每次手选 |

---

### 输入模拟

控制自动化操作中的拟人化参数。每项控件旁有 **「?」** 图标，悬停可查看说明。

| 参数 | 说明 |
|------|------|
| 点击前延迟 | 发出点击命令前的等待时长范围 |
| 点击后延迟 | 发出点击命令后的等待时长范围 |
| 鼠标移动时长 | 从当前位置移动到目标位置的耗时 |
| 坐标随机偏移 | 点击坐标的随机抖动范围（像素），模拟人手操作 |

> 这些参数影响自动化的「自然度」。如果操作过快导致游戏来不及响应，
> 可以适当增大延迟范围。

---

### 等待参数

命名等待参数表，供工作流按 key 引用。

| 操作 | 说明 |
|------|------|
| 新增 | 输入 key 名和等待范围（最小值~最大值，单位毫秒） |
| 编辑 | 双击行内修改值 |
| 删除 | 选中行后点「删除」 |

工作流中通过 key 引用等待参数，例如 `wait "短等待"`。
修改等待参数后，所有引用该 key 的工作流都会使用新值。

---

### 方案设置

分两块。

**连接方案** — 方案把图库、环境、布局绑成一个具名整体，并声明支持的连接
方式。内置「手游 / 端游 / 手游投屏」三个预置方案，完整用法见
[2.4 连接方案](02-main-interface.md#24-连接方案)。

| 操作 | 说明 |
|------|------|
| 新建 | 建一个空方案，默认两种连接方式都支持 |
| 从当前组合新建 | 把主界面当前的图库/环境/布局存成方案 |
| 删除 | 删除选中方案 |

右侧编辑名称、图库、环境、布局和「模式」勾选框。名称不能为空，模式至少勾
一个，否则保存会被拦下。

自建方案保存在 `config/session/session.json`，是**机器级**配置，不随用户切换；
随安装包分发的预置方案存在 `app.yaml` 里，选中时这五项和「删除」按钮都是灰的。

**系统参数** — 可用目标环境列表。目标环境决定 DSL 中 `env()` 的返回值，
用于区分 PC 游戏与手游的导航策略，指**游戏运行的目标环境，不是本机系统**。

| 操作 | 说明 |
|------|------|
| 添加环境 | 填环境 key（如 `ios`）和显示名称 |
| 删除 | 删掉一行 |

预置 `android`（安卓）和 `desktop`（桌面），保存在 `app.yaml`。新加的环境
要保存后重新打开对话框，才能在方案里选到。

---

### 字体设置

| 配置项 | 作用范围 |
|--------|----------|
| 用户总览字号 | 用户总览的分组页签、列表内容和列表表头 |
| 用户信息字号 | 用户信息中的便利贴和 Profile 信息分区 |

字号范围为 8~24 pt。点击「保存」后立即生效，无需重启。
两个页面顶部的刷新/用户切换工具栏保持原字号；用户总览底部的
「数据模型」按钮也不受影响。
