## 关键设计决策（用户确认）

1. **文档体系持续随功能同步拆分/重组**：用户指南、调律配置说明、需求文档架构均在功能收敛后同步拆分归档，避免文档与实现脱节。
2. **mypy 检查范围扩大至全量 src**：从局部清零转为全量门禁，防止后续退化。
3. **版本号按功能阶段密集发布**：12 个版本号在同一批次内产生，对应功能可通过各版本 commit 时间点在其余分篇中定位。
