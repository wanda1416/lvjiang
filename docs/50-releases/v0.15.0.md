# v0.15.0 — 手机端独立执行、官方在线配置与整体体验升级

发布日期：2026-10-17。以 v0.13.15 正式标签（`0ee0cea8`）为基线，跳过 0.14。

本版本是 0.15 系列的首个正式版，综合了 0.15.0 全部测试包（Beta1–Beta7）的内容。
推荐从 0.13.15 升级；更早版本请先升级并正常运行 0.13.15，在对应编辑器保存旧自定义配置后
再升级。手动安装过 0.15.0 测试包的用户可以直接升级到本正式版。

## ⚠️ 不兼容变动与升级指引

### 跳过 0.13.15 直接升级时旧格式不再自动转换

- **现象：** 由 0.13.14 及更早版本写入、又没有经 0.13.15 重新保存的配置文件会被跳过并记录
  文件路径：`app.yaml` 顶层 `android_apps`、`scenes.yaml` v1、布局里集中的 `disabled` 段、
  `levels_and_seasons.yaml`、`tune_config.yaml` 的 `tuning_rules`/`base_rules` 启停声明、
  `batch.json` 的 `selected_*`、`ocr_rules.yaml`、调律规则的 `max_pct`/`max_rating`、
  英文部位值与纯字符串武器类型、按等级猜测的承音能力。
- **原因：** 0.13.15 仍带着这些兼容转换，0.15.0 起一并移除；这些入口用户可自行重配，
  继续做启发式转换会反复改写用户文件。
- **如何调整：** 用 0.13.15 正常保存过的配置**无需任何处理**，本版本读取的正是该格式。
  只有当你的自定义配置来自 0.13.14 及更早版本时，才需要先在 0.13.15 打开对应编辑器重新
  保存，或按[配置升级调整](../60-userguide/appendix-a-config-upgrade.md)逐项手工修改。
  Profile、任务历史和调律历史数据库保留现有版本管理，不需要手工清理；不要删除整个 local 目录。

### 在线配置改为安装到 system

- **现象：** 旧 `config/remote` 不再作为加载层；官方内容按修订索引累计安装到 system，
  `config/local` 仍然优先。运行中的任务继续使用启动快照，更新影响后续新任务。
- **原因：** 在线更新改为与包内容一致的累计安装，不再单独维护一层远端目录。
- **如何调整：** 不删除 local 或 session；开启「接收在线配置更新」后重新获取即可。
  官方修正没有生效时先检查自己的本地覆盖。关闭在线更新或进入完全离线模式会恢复官方预置
  并撤下在线内容，不删除本地覆盖与数据库。确需人工恢复 system 时按
  [官方在线配置与会员内容](../60-userguide/appendix-b-online-config.md)使用当前版本的预置恢复，
  不要用其他版本的预置或自行伪造基底。

### 当前选择与界面状态分离

- **现象：** 当前用户、布局、方案以及日常脚本的选择改由 `interface.json` 保存；
  0.13.15 写在 `session.json` 里的这些选择不会被迁移，日常脚本上次选中的脚本与展示分组
  同样改由 `interface.json` 记录。
- **原因：** 运行选择与用户偏好分层存放，只读实例也可以临时切换而不落盘。
- **如何调整：** 升级后按需重新选择一次；脚本排序与显示名偏好仍保留在 `session.json`。
  燕云会话继续使用 `config/session/yysls` 独立文件，不再搬运 `session.json.yysls`。

### 手工修改场景或布局后需要刷新

- **现象：** 任务按配置修订索引复用配置，直接用文本编辑器改文件不会自动更新索引，
  改动可能不生效。
- **原因：** 修订索引由编辑器保存时维护，运行时快照以索引为准。
- **如何调整：** 在场景管理点击「刷新」或重启应用；未保存的编辑请先自行保存或撤销。
  正常通过编辑器保存会自动更新索引，无需额外操作。

### 备战方案管理改为显式保存

- **现象：** 备战方案的编辑、排序、新建与删除先进入草稿，点「保存」才写入。
- **原因：** 草稿与活动方案分离，避免浏览和排序静默改动正在使用的方案。
- **如何调整：** 无需操作。放弃未保存改动不会改变主页面的活动方案。

### 出装搭配不再绑定等级并改用无含义 ID

- **现象：** 搭配编辑器与玩法配置列表不再显示等级，导入备战方案时按你当前可用的世界等级
  生成八件模拟装备，「搭配等级高于世界等级」的拒绝提示一并取消；新搭配文件名形如
  `0cae52170e954021.yaml`，改名不再改文件名。
- **原因：** 等级是模拟计算器的运行参数，不是搭配内容；稳定 ID 与展示名必须分离。
- **如何调整：** 无需操作，旧搭配文件仍按原文件名读取，文件里遗留的等级字段会被忽略。
  系统预置搭配更新为 21 套、文件名有变化，安装器与 APK 自动替换，便携版解压到新目录即可。

### MCP 接入需要重新启用

- **现象：** 接入参数改为随客户端保存在 `config/session/mcp.json`，原用户主目录中的
  接入记录不再读取。
- **原因：** 接入配置跟随客户端目录，移动客户端时不再依赖原安装路径。
- **如何调整：** 在「燕云 → 智能调律」重新启用 MCP 服务并同步外部 Agent 配置；
  改过端口请重新填写。此后迁移客户端只要保留 `config/session` 即可保留接入参数。

### 好友送礼的红心判定相关布局变化

- **现象：** 系统布局 `chat_main` 缩小了情义值上限区域，并删除旧的满值红心模板。
- **原因：** 新界面下模板匹配不再稳定，判定不再依赖该模板。
- **如何调整：** 若你在 `config/local` 下覆盖过 `chat_main` 布局，需要自行同步新区域；
  升级不会覆盖或删除你本地已有的覆盖文件。

### 升级安装、两端同步与便携包

- **现象：** 沿用 0.13.15 的口径：PC 与 APK 版本不一致时不能同步；便携版就地覆盖会留下
  上一版已经删除或移动过的官方文件。
- **原因：** 同步是同版本单向快照；ZIP 由用户自行解压，没有任何一方能清理旧文件。
- **如何调整：** PC 与 APK 一起升级到 0.15.0，同步前核对覆盖提示。便携版解压到新目录后
  复制 `config/local` 与 `config/session`，但不要用旧目录的
  `config/session/baseline.json` 覆盖新包的同名文件——它是在线配置的官方基底身份，
  不是用户数据，客户端会自行维护。安装器与 APK 按通道更新官方内容并保留个人数据。

### Android 独立执行仍为 Beta

- **现象：** 手机可以执行单任务和批量任务，但复杂任务仍可能因设备内存不足导致游戏被系统
  结束，本轮未解决该问题。
- **原因：** 本版本扩大了手机端能力与页面，不代表已完成全部设备的稳定性验收。
- **如何调整：** 复杂任务优先在 PC 执行；出现游戏被系统结束时停止手机任务并保留诊断信息，
  按[移动设备与手机端](../60-userguide/07-mobile-device.md)说明处理。

## ✨ 新增功能

**PC 与通用**

- **官方在线配置**：开启「接收在线配置更新」后按修订索引累计更新，校验通过立即生效、
  无需重启；支持回退到较早修订，网络失败保留当前可用内容。
- **大地图管理**：地域目录、探查底图导入与预览，重叠截图可拼接。
- **场景管理**：顶部提供「刷新」从磁盘重载场景与布局，保存时遇到后台修改会提示是否覆盖；
  可按场景隐藏全部视图，配置来源只显示本地或系统。
- **备战方案**：草稿编辑与显式保存；扫描全部方案遇到历史定音提示时只选择「改用当前定音」，
  不会点击消耗玉的确认。
- **Profile 数据**：变更脚本可勾选「同步修改」，在写入前执行、失败时整条数据库变更回滚；
  历史记录可按来源与时间聚合，并支持确认后直接删除。
- **出装搭配**：等级解绑、无含义 ID、列表改用「词条搭配」列、右键可更改玩法类型；
  系统预置扩充到 21 套，含 20 条流派目标预置。
- **智能调律**：新增「查看生成方案并启动」，在对话框内查看生成结果并直接在当前设备启动，
  保留 AI 为该结果选择的目标与临时覆盖。
- **脚本**：日常页按元数据分组筛选与刷新，脚本编辑支持分组；新增内置函数
  `profile_reject` 与 `profile_history_aggregate`。
- **其他界面**：用户总览可按分组显示总和行；设备预览支持复制当前帧原图到剪贴板。
- **Android 连接恢复**：可在「高级设置」调整代理与 ADB 的重连次数、间隔以及是否允许
  普通输入降级到 ADB；重试后仍未恢复会等待你选择继续检查或停止对应任务。
- **游戏内容**：不肝商店支持逐战商店购买与配额记录；补充花蕊织查看与进度区域，
  以及百业活动页与活动推荐区域标定。

**手机端（Android）**

- **Material 工作台**：工作台、任务、用户、设置四个分区，首页提供悬浮控制入口。工作台显示
  运行用户、任务、耗时、实时日志与最近执行记录，可查看结束原因与结果摘要。
- **手机批量执行**：选择配置组并按本次需要勾选任务、用户与单元，支持拖动排序、轮数与
  无人值守（需要该组配置异常恢复工作流）；暂停、继续、结束控制整批，结果保留在手机侧。
- **用户页**：用户数据、备战方案与战斗属性。可扫描装备、查看毕业率与 DPS，
  「满等级」「满承音」「满定音」「模拟转律」四项假设可独立勾选；浏览与计算不改变执行用户。
- **与 PC 的同步**：下发配置与「保留手机任务参数」「保留手机批量配置」分离，两项默认勾选；
  手机任务历史、调律历史、日志与结果可单向回传 PC，不回写手机 Profile。
- **人工确认更明确**：需要确认的提示提供「确认」「拒绝」，普通「继续」不能代替选择，
  停止可以结束正在等待确认的任务；PC 旧控制入口遇到确认问题时在手机侧回答。

## 🔧 修复

- 修复启动更新检查、公告与内容同步不遵循网络开关与离线模式的问题。
- 修复缺少活动用户选择时备战方案无法自动加载的问题，当前用户统一按有效名册选择。
- 修复退出时战斗属性页面的延迟布局回调访问已销毁控件而报错。
- 修复打开菜单后首次未识别到菜单就立即中断的问题，改为保存截图并延迟二次确认。
- 修复部分有效配置包因内部登记遗漏被整包拒绝的问题。
- 修复参数输入频繁写盘造成的卡顿，切换编辑对象与启动任务时保留正确的参数归属。
- 修复用户档案直接变更的撤销依赖是否触发方向同步的问题。

## 📦 重构

- 配置分层重构：以 0.13.15 为基线清理旧入口，移除 `config/remote` 层，官方内容安装到
  system；按摘要归档并支持回退与累计删除；任务启动时冻结配置快照，执行中不重读配置。
- 配置解析与查询职责拆分，编辑冲突、修订索引与写权限收敛到公共层。
- Profile 与调律历史模块、公共后台服务与桌面线程适配解耦；插件宿主接口收敛为公共事件契约。
- 代理与 ADB 统一连接恢复流程，共用重试、降级与人工确认；桌面与手机复用批量调度能力，
  平台输入、截图与安全控制保留各自实现。
- 出装搭配的词条分配独立成模块，保存、模拟与导入共用白名单与总量规则，并移除搭配内的
  等级字段。
- 插件加载支持内置、`plugins/` 默认目录与显式路径三级，外置插件无需重新打包。
- 反馈二维码改为联网获取并缓存到会话目录，不再随安装包预置；刷新失败时保留已有缓存。
- 手机端界面改为底部「工作台／任务／用户／设置」四区导航，PC 侧「一键同步」更名为
  「下发配置」，批量任务改为先「准备批量执行」再从悬浮窗启动。
- 任务之间复用未变更脚本的解析结果，启动与检查不再重复解析同一文本。
- 人工查看的 JSON 写出收敛到公共模块，格式保持 UTF-8、两空格缩进与文件末尾换行；
  签名、摘要、JSONL 与传输协议仍走原有序列化路径。
