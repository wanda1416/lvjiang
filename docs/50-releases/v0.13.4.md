# v0.13.4 — 毕业率方案、批量调度与江湖号令识别更新

## ⚠️ 不兼容变动与升级指引

### 1. 自建毕业率模型需重新导入

- **现象：** 旧版自行导入的毕业率 JSON 不再出现在方案列表；内置方案仍可使用。
- **原因：** 模型改为按等级和版本登记，运行时只读取新格式；旧版模型没有这两个身份字段。
- **如何调整：** 在游戏配置中重新导入原 Excel，指定模型等级，生成新版本。旧 JSON 不会被自动改写；需要保留原文件时先自行备份。

### 2. 旧的基准 DPS 校正值需重新设置

- **现象：** 曾手动校正的毕业率基准 DPS 可能恢复为模型默认值，毕业率随之改变。
- **原因：** 校正值现在按“流派、方案、模型等级、模型版本”分别保存；旧值没有等级和版本，无法明确归属。会话文件迁移会保留旧数据，但新计算不会读取旧口径。
- **如何调整：** 升级后核对常用方案的基准 DPS，在对应等级和版本重新设置。旧记录仍留在会话文件中，升级前可备份 `config/session` 以便查阅原值。

### 3. 燕云会话数据改为分文件存储

- **现象：** `session.json` 内的 `yysls` 节点迁到 `config/session/yysls/` 下的独立 JSON 文件；迁移成功后旧节点消失。
- **原因：** 将基础属性、毕业率校正等状态拆开保存，避免同一节点持续膨胀。
- **如何调整：** 无需操作，首次启动自动迁移。若旧数据形状异常或与新文件冲突，程序会保留旧数据并报告错误；此时不要手工删除任一份数据。

### 4. 三项个人化工作流不再随系统打包

- **现象：** 旧版内置的 `weekly_huaruizhi`、`weekly_baiye_freight` 和 `profile/juezhang_reward` 不再作为系统脚本出现。
- **原因：** 这些任务的路线和领奖条件属于个人配置，已从系统层移出。
- **如何调整：** 仍需使用时，将自己维护的版本放入 `config/local/workflows/` 并检查批量配置中的脚本选择；升级不会自动复制或生成个人脚本。

### 5. 预置端游连接方案要求管理员权限

- **现象：** Windows 上使用预置端游方案启动自动化时，律匠未以管理员身份运行会明确报错并拒绝执行。
- **原因：** 该方案现已声明权限要求，避免游戏以管理员身份运行而律匠无法正常发送输入。
- **如何调整：** 以管理员身份启动律匠；若游戏无需提升权限，可新建不勾选“管理员权限”的自定义连接方案。

### 6. 两个字符串的 `==` / `!=` 改为精确比较

- **现象：** 自写工作流中，`"001" == "1"` 现在为假，`"1.0" == "1"` 也不再视为相等。
- **原因：** 数字外观的账号、编号等仍是字符串，旧行为先转数字会误把不同文本判为相同。
- **如何调整：** 比较字符串时直接使用 `==` / `!=`；确实需要数值比较时先用 `to_num()` 转换。旧式 `equals` 语法仍可解析，无需立即改写旧脚本。

本版修改了部分系统布局、模板和工作流。`config/local` 的同名覆盖仍优先于系统文件；若升级后江湖号令或签到识别仍使用旧配置，请在场景编辑器检查当前来源，并自行同步或移除对应本地覆盖。所有 `content_version` 保持原值，本次应用发布不触发新的远端配置下发代次。

## ✨ 新增功能

- 毕业率模型支持同一方案的多个等级与版本；个人世界等级决定抗性口径，并限制可选模型等级。补充 115 阶满养成来源与弓玦等级口径。
- 备战方案新增装备套装扫描与计算；同部位装备可互换普通定音。装备列表增加扫描时间筛选，便于核对长期未见的记录。
- 批量任务可按用户名或用户资料中的属性组织调度单元，并由准备工作流在单元成员中选择本次执行的角色；用户可继续在主页面勾选实际执行范围。
- Profile 定义支持类型内分组和批量更改分组，中文界面的初始分组为“默认”。
- 连接方案可声明 Windows 管理员权限要求；每日签到可配置多项活动及各自的领取关键字。
- “购买袅袅之音·绑”工作流扩展至桌面环境。

## 🔧 修复

- 修正江湖号令任务卡片模板错用父画布宽度计算缩放的问题。旧版本可能把六张卡片的刷新图标全部匹配失败，进而误判为已完成；本版按卡片子画布缩放，并改善浅色、深色图标的匹配。
- 自动调律在重置后或发现重置冷却时，会尝试开启装备详情的重置提醒，避免下次扫描仍看不到冷却状态。
- 修正江湖号令已领奖任务被重复点击的风险；完成状态与领奖状态分别判断。
- 工作流警告对话框不再把用户按下的 Esc 当作终止任务；最优组合缺少配置时会指出缺失项。
- 基础属性 OCR 对百分比文本的歧义增加拦截，避免错误数值进入角色基础属性。

## 📦 重构

- 燕云会话存储拆为独立文档，并在首次启动时迁移旧节点；批量属性调度沿用用户与角色的既有数据层级。
- 毕业率模型按等级分目录，方案、等级和版本写入模型身份；采集录制入口目前只在开发者模式显示。
