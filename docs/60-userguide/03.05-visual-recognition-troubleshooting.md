# 3.5 图像识别与模板匹配排查

> 最后更新：2026-10-09（基线 v0.13.14）。

## 先检查连接、布局与现场

确认选中的窗口或设备已经连接，布局符合当前画面。按 F3 打开场景管理，在实际出问题的页面刷新截图，选择对应区域，查看识别结果或测试匹配；随包旧截图不能证明当前现场可用。

## 模板分数低或跨设备不命中

1. 确认当前区域确实包住目标图标，模板中没有动画或大块动态背景。
2. 用当前布局的现场截图重新截取模板，测试匹配后保存布局。
3. 桌面与投屏的元素可能重排或改变字形，分别录制对应布局的模板。
4. 保持门槛与实际分数相符，分数明显低时先处理错布局、错区域和模板内容。

模板绑定、点击区域和网格标定的完整步骤见 [场景管理](03.02-scene-management.md#点击标定撤销模板与网格)。

## 编辑器通过而任务未命中

核对任务是否使用刚保存的布局、是否停在相同视图、画面是否出现动画或弹窗。保存后用实际任务重新验证；对比时尽量保留同一时刻截图和对应日志。确认配置一致仍能稳定复现时按 [反馈规范](08-feedback-and-issues.md) 提交现场与预期。

## 点击偏移、邻居误命中与文字乱码

- 整体偏移先查布局、画布与窗口形态，不逐个调整所有区域。
- 邻居被误识别时检查区域和模板边界，减少相邻按钮进入识别范围。
- 点击范围应标定在区域内部，不能为点击而任意扩大 OCR 范围。
- 装备词条乱码按 [装备词条解析失败排查](03.02-scene-management.md#自助排查装备词条解析失败) 区分截图、区域和 OCR 清洗问题。

## 脚本工作台

取点、取色和框区域可用于生成脚本参数。通过指令面板插入语句，再单步观察返回值与匹配画面；具体操作见 [脚本编写与调试](10-script-authoring.md)。
