# 6. 常见问题

## 连接问题

| 现象 | 处理 |
|------|------|
| 「未找到可见窗口」 | 确认投屏窗口未最小化；重新点「扫描窗口」 |
| 扫描后「未匹配到关键字」 | 配置管理里的「默认窗口标题」与实际窗口标题不符，改关键字或手动下拉选择 |
| 「未找到 ADB 设备」 | 检查数据线、手机上是否弹出并允许了 USB 调试授权；无线模式确认同一局域网 |
| 「连接设备失败 / 无法获取设备分辨率」 | 重插数据线、手机端撤销后重新授权 USB 调试 |
| 「scrcpy 截图后端不可用」 | 程序已自动回退 screencap，可继续使用；想用视频流可重启程序重试 |
| 预览「截屏失败」 | 投屏窗口被关闭或设备掉线，重新扫描并定位/连接 |
| 「请先停止当前任务」 | 运行中不能重新扫描窗口/设备，先按 F10 停止 |

## 识别问题

| 现象 | 处理 |
|------|------|
| 识别不准 / 点击位置偏移 | 见[场景管理](03.02-scene-management.md)坐标校准；用「工具 → 图像识别」确认 OCR 结果 |
| OCR 全部未识别到 | 确认截图是否正常（预览区查看）；检查场景区域坐标是否偏移 |
| 面板网格校准失败 | 面板区域可能不在当前画面内，检查场景编辑器中面板定义 |

## 调律问题

| 现象 | 处理 |
|------|------|
| 调律没反应就结束 | 查看运行日志：常见为未选规则/部位/玩法，或材料不足触发了「结束全部调律」 |
| 装备被意外回收 | 查看[调律说明文档](04.06-running-tuning.md#465-调律说明文档)中的判定依据，定位是哪条处置规则生效 |
| 装备没进调律 | 检查扫描处理的进入门槛是否设太高；用「装备调律验证」手动测试判定 |
| 重置调律没生效 | 每件装备单次运行只重置一次（受重置冷却期约束） |
| 规则判定结果不对 | 先在「装备调律验证」对话框手动输入词条测试，确认规则逻辑 |
| 「跳过实际调律」开关忘关 | 到调律 Tab → 更多页取消勾选，状态会随会话持久化 |

## 批量任务问题

| 现象 | 处理 |
|------|------|
| 「暂无启用的行」 | 到批量 Tab → 配置页勾选要执行的行 |
| 「请至少勾选一个脚本」 | 到批量 Tab → 脚本页勾选要执行的脚本 |
| 条目准备失败跳过整行 | 检查条目准备 wf 是否正确配置；查看运行日志中 `[批量]` 前缀的错误信息 |
| 脚本执行失败 | 查看运行日志定位具体脚本和异常信息；结果文件在 `config/session/output/` |
| 用户没有切换 | 确认批量配置中「用户名列」已正确设置，且列值与用户管理中的用户名匹配 |

## 其他

| 现象 | 处理 |
|------|------|
| 程序启动报错 | 确认 Python 版本 ≥ 3.10；确认已 `pip install -e ".[dev]"` |
| 插件未加载 | 启动命令需加 `-reg yysls` 参数加载燕云调律插件 |
| 崩溃 | 查看 `logs/crashes/` 下的崩溃日志，反馈时附带 |

## 工作流问题

| 现象 | 处理 |
|------|------|
| 日常下拉找不到某个工作流 | 「工具 → 脚本配置」中检查该脚本是否勾选「暴露」 |
| 工作流执行卡住 | 点击「暂停」查看运行日志定位卡在哪一步；必要时 F10 停止 |
| 工作流参数不生效 | 确认已点「加载」按钮刷新参数面板；部分参数由专属页面管理（如调律） |
| 江湖号令识别不到任务 | 检查是否停在正确的活动页；用「工具 → 图像识别」确认 OCR 结果 |

## 常见误操作

| 误操作 | 后果 | 解决 |
|--------|------|------|
| 源码版启动时忘记加 `-reg yysls` | 没有燕云调律插件，左侧没有调律 Tab | 重启时加上参数，或用 `dev.bat` / `dev.sh` 启动 |
| 布局选错 | 点击偏移、识别失败 | 顶部「当前布局」下拉切换，见 [1.4 布局适配](01-quick-start.md#14-运行前检查布局适配) |
| 游戏没停在正确页面就启动工作流 | 工作流第一步就失败 | 查看工作流清单中的「前置」要求，停在对应页面再启动 |
| 发行版 exe 被安全软件拦截 | 无法启动 | 将安装目录加入安全软件白名单，或重新安装时选「仅为当前用户」 |
| 调律 Tab「跳过实际调律」忘记关 | 只模拟不实际调律 | 调律 Tab → 更多页 → 取消勾选 |

## 术语速查

| 术语 | 含义 |
|------|------|
| **ADB** | Android Debug Bridge，安卓调试桥，用于电脑与手机通信的协议 |
| **USB 调试** | 手机开发者选项中的开关，允许电脑通过 ADB 控制手机 |
| **投屏** | 将手机画面实时显示到电脑窗口的技术 |
| **OCR** | 光学字符识别，从截图中读取文字的技术 |
| **布局** | 定义游戏界面各区域坐标的配置方案，不同分辨率可能需要不同布局 |
| **场景** | 游戏的一个界面（如背包页、调律页），包含多个区域定义 |
| **工作流 / 脚本** | 自动化流程定义，描述「扫描 → 识别 → 决策 → 点击」的步骤序列 |
| **DSL** | 领域特定语言，律匠自研的 `.wf` 工作流语法 |
| **Profile** | 用户数据档案，记录角色的货币、进度、调律历史等信息 |
| **调律** | 游戏中的装备重铸机制，消耗材料随机刷新词条 |
| **定音** | 调律的一种特殊形式，锁定特定词条进行重铸 |
| **品阶** | 装备评级，如鸣金、会意等，由词条组合决定 |
