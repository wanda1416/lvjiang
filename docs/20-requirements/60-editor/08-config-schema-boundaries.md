# 配置旧入口清理与读取边界

> 状态：已实现（2026-10-10，基线 v0.13.15）

以 0.13.15 正常保存的配置为升级基线，清理更早格式的读取与迁移入口。正式版本何时包含
这些变更，以发布说明为准。

## 范围与验收

1. 应用注册只从 app.yaml 的 apps 读取；旧顶层 android_apps 给出告警。
   当前 android/windows 绑定及内部 UserConfig.android_apps 模型不变。
2. scenes.yaml 仅接受当前结构。明确 v1 或旧 layout_scenes/group_names 报错；
   空覆盖、仅元数据、无版本号的 scenes 增量继续接受。保存前也验证旧覆盖，
   不以保存新结构为由静默覆盖旧文件。
3. 布局集中 disabled 段不再转换。磁盘加载报告路径并跳过该场景，
   其他场景继续加载；内存结构解析报错。实例自身的 disabled 与坐标不变。
4. 旧赛季文件只诊断，不自动改名。用户应备份后手工调整，不能覆盖已有新文件。
5. 调律旧启停声明只诊断，不改写规则和配置。当前规则排序、启停及 local 停用桩保留。
6. batch.json 仅接受 v2，旧 selected_* 告警且只读取 default_*；不自动转换 v1。
7. OCR 仅使用 ocr.yaml 的 normalization.default/groups；不读取 ocr_rules.yaml 或转换扁平规则。
8. 调律规则仅接受 pct_op/pct、ratings 和中文领域部位；旧条件字段明确报错，防止动作条件被忽略。
9. 武器类型与词条上限采用对象格式，等级能力必须显式填写布尔值；无效条目隔离并记录错误。
   普通词条承音上限缺省按游戏固定 94% 比例计算，不属于旧配置兼容；显式值优先，定音不受限。

读取旧文件不会删除、改名或重写用户文件。界面状态与燕云会话只读取独立文件，
不再从 session.json 搬运旧节点。多文档事务恢复、版本校验和数据库建表与版本管理保留。

定向回归保护当前配置可用、旧入口可诊断、读取不写文件和当前存储的事务恢复不退化。
操作指引见 [配置升级调整](../../60-userguide/12-config-upgrade.md)。

## 状态元信息

session.json、interface.json 不再生成无读取契约的顶层 version；公告缓存不再写入
last_checked_at。旧 server_config.remote_config 无消费者，不恢复、不迁移；已有残留
随其他未知字段原样保留。在线配置版本和安装时间以 UpdateStore 的 state.json 为准。
数据库 schema 版本、多文档 _meta.json 与事务日志版本仍用于真实校验，不受此清理影响。

## 网络开关

公告和版本更新分项只控制启动自动检查，跳过后继续执行启动链。手动检查不受分项
限制；用户离线设置或 LVJIANG_OFFLINE=1 同时阻止自动和手动网络请求，公告缓存仍可查看。
