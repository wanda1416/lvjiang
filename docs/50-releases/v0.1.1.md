# v0.1.1 — DSL 引擎增强 + OCR 清洗架构 + 批处理优化

## 律匠 v0.1.1

本版本聚焦 DSL 工作流引擎能力增强、OCR 通用清洗架构重构、以及批处理模块的架构优化。

---

### ✨ 新增功能

**DSL 工作流引擎**
- `screenshot` 截图指令：截取当前画面保存到 `logs/image/`
- `call $var = proc()` 返回值绑定语法：子过程可将结果赋值给变量
- 主流程 `return -1` 供批处理感知异常返回
- 子过程异常返回约定：`return < 0` 表示错误
- 整面板 `scan/recognize` 支持 `by` 子句指定识别器
- 捕获顶层 `return` 值

**OCR 通用清洗架构**
- 全局替换规则：文本级别的全局匹配替换
- 正则替换规则：支持正则表达式的模式匹配
- 噪声字符删除：可配置需要删除的噪声字符集
- 字段级规则：装备解析器集成字段级清洗规则
- OCR 测试对话框多 Tab 结构：图像识别 + 清洗规则管理

**OCR 画布可视化**
- 支持鼠标滚轮缩放（以鼠标位置为中心）
- 右键拖拽平移
- OCR 结果红色矩形标注 + 文字标签

**批处理模块**
- 三工作流槽位架构：预处理 / 切换 / 脚本
- 用户切换时联动更新主页面当前用户显示
- 账号切换逻辑修复：比较 `account` 字段而非 `tail`

**UI 增强**
- 帮助菜单新增：检查更新、文档、反馈入口
- 场景编辑器脚本测试结果格式化

---

### 🔧 修复

- DSL 引擎作用域隔离与 `default` 递归解析修复
- `call` 语句传递变量参数时值丢失
- 装备解析器 OCR 转律标记漏识别闭合括号时解析失败
- 调律报告 `resets` 字段始终初始化
- ruff 自动修复 import 排序和未使用导入

---

### 📦 重构

- OCR 清洗规则 `patterns` 改为 dict 格式
- 规则编辑改为表格内联编辑（移除弹窗）
- 批处理模块独立为 `batch` 包
- 心法购买工作流重构与场景重命名
- 装备分析冗余 `collect` 移除
