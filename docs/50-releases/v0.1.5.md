# v0.1.5 — 基础规则组多套切换 + 调律引擎稳定性增强

## 律匠 v0.1.5

本版本聚焦配置架构重构、调律引擎稳定性修复、工程治理与文档拆分。

---

### ✨ 新增功能

**工作流**
- 自动购买心法工作流：支持自动识别并购买指定心法
- 登录流程主页检测与活动弹窗自动关闭
- 江湖号令情境保存前衣柜页面检测：避免误操作导致保存失败

**调律引擎**
- 基础规则组多套切换：支持配置多套基础规则组，运行时动态切换
- 调律场景 OCR 区域细化与分组修正

---

### 🔧 修复

**调律引擎**
- 装备重置后狗粮规则失效：重置成功后刷新预期评级
- 冷却期误判为次数用尽：返回字符串强制跳过而非 False
- 回收阻断从格位级改为指纹级：同指纹装备锁态一致，简化阻断逻辑
- 材料数量解析修复：多段数字取最后一段（修复 "0/1 1092" 误取 0）

---

### 📦 重构

**配置架构**
- 配置读写全面收拢：SessionStore + ConfigResolver 统一咽喉
- 顶层 config.py 收拢至 core/config 包
- 层根常量收拢至 resolver，封堵 constants 旁路
- 移除 SessionStore 与 ReferenceDB 的懒加载

**模块结构**
- core 模块拆分：数据类独立建文件 + 模块重命名
- yysls 模块命名与结构优化
- rules_editor 目录重命名为 tune_config
- level_configs 从 tuning_base 迁移到 attributes.yaml
- 结束处理逻辑抽象为公共方法，消除初始判定代码重复

**调律配置**
- tuning_base.yaml → tune_config.yaml
- attributes.yaml → game_config.yaml
- 基础规则组配置文件独立至 tuning_groups/*.yaml

- 调律配置章节拆分为 5 个子文件

- 清理旧版配置文档
