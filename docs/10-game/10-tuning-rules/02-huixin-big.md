# 会心大外流调律规则

公共规则见 [调律评价规则](README.md)，本文仅列会心大外流专属规格。

- 必选配置：指定流派（裂石·钧、破竹·鸢、牵丝·霖，**可同时勾选**）和玩法。
- 可选配置：保留 PVP 装备（单体奇术增伤、对玩家增效 视作有效）。
- 主武器类型及所需武学增伤由勾选的流派/玩法决定（见总说明「流派与玩法配置」表，
  如 裂石·威→陌刀武学增伤、裂石·钧纯唐→横刀武学增伤、破竹·鸢→手甲武学增伤）。
- 大本属 = 勾选流派的最大属攻（如勾选牵丝即 最大牵丝攻击），非武器部位的 大无相 即指它；
  勾选多个流派时，任一勾选流派的属攻均视作大无相；**未勾选流派的属攻为废词条**。

## 一、神力词条要求

- 主武器：必须有对应的主武学增伤，没有视为不合格（缺失直接判垃圾）。
- 副武器：不需要武学增伤，有视为不合格。
- 首饰（环/佩）：必须有 全武学增伤，没有视为不合格（缺失直接判垃圾）。
- 头盔和胸甲：不需要神力词条；keep_pvp 开启时 单体奇术增伤 视作有效。
- 胫甲和腕甲：必须有 对首领增伤（缺失直接判垃圾）；keep_pvp 开启时
  对玩家增效 可顶替该槽位。

## 二、转律优先级与可用词条库

- 转律优先级：大外、劲、敏、会心、小外、大无相、大属攻。
- 可用词条库：大外、劲、敏、会心、小外、大无相 + 势、精准、对玩家增效。
- **缺陷词条（非首出现 → 能用封顶）**：势；精准+会心（非首）同现。
- 小外、大无相 在库内不判垃圾也非缺陷，但会被各部位顶级条件排除，上限优秀；
  会心（本命率）单独出现非缺陷：无神力部位（副武器/冠胄胸甲）可参与顶级，
  有神力部位（主武器/环佩/胫腕甲）优秀封顶。
- 库外词条即废词条，直接判垃圾。典型：会意、小无相、未勾选流派的属攻。
  「错位属攻」受部位约束不会出现，见 [调律评价规则](README.md) 第五节。

## 三、各部位模式与顶级判定

| 部位 | 模式 | 顶级判定（均只看非首词条） |
|------|------|----------------------|
| 主武器 | [大外(首) + 主武学增伤 + 大外] + 可用词条库 * 2 | 出现 大外+劲，且 会心/精准/敏 ≥1，且未出现 小外/大无相/势 → 顶级，否则 优秀 |
| 副武器 | [大外(首) + 大外 + 劲] + 可用词条库 * 2 | 出现 大外+劲，且 会心/精准/敏 ≥1，且未出现 小外/大无相/势 → 顶级，否则 优秀 |
| 环、佩 | [大外(首) + 全武学增伤 + 大外] + 可用词条库 * 2 | 出现 大外+劲，且 会心/精准/敏 ≥1，且未出现 小外/大无相/势 → 顶级，否则 优秀 |
| 头盔、胸甲 | [会心/精准(首) + 大外 + 劲] + 可用词条库 * 2 | 出现 大外+劲，且 会心/精准/敏 ≥2，且 精准 ≤1 条（含首词条），且未出现 小外/大无相/势 → 顶级，否则 优秀 |
| 胫甲、腕甲 | [劲(首) + 对首领增伤 + 大外] + 可用词条库 * 2 | 出现 大外+劲，且 会心/精准/敏 ≥1，且未出现 小外/大无相/势 → 顶级，否则 优秀 |

- 副武器/头盔胸甲（无神力部位）的顶级**不排除会心**（本命率可参与顶级）；
  有神力部位出现会心 → 优秀封顶。
- 主武器顶级可选槽实际只剩 劲/敏；胫甲/腕甲顶级可选槽实际只剩 劲/敏。
- 会心率、精准率 可参与顶级（作为「会心/精准/敏 ≥1」的满足项），但不会同时出现两条（否则触发缺陷）。
- 缺 劲 不构成缺陷，无废词条/缺陷词条即判 优秀；但**非首缺大外是硬门槛**，
  所有部位非首必须有 1 条大外，缺失即 **能用** 封顶。

## 四、判定例子

以下词条列表第 1 条均为首词条；示例假定勾选裂石（大本属=最大裂石攻击）。

| 部位 | 词条 | 判定 | 说明 |
|------|------|------|------|
| 主武器（陌刀） | 大外 + 陌刀武学增伤 + 大外 + 劲 + 敏 | 顶级 | 大外+劲 出现，敏 满足三率≥1，无排除词条 |
| 主武器（陌刀） | 大外 + 陌刀武学增伤 + 大外 + 劲 + 会心 | 顶级 | 会心率满足三率≥1，无排除词条 |
| 副武器 | 大外 + 大外 + 劲 + 敏 + 会心 | 顶级 | 副武器顶级不排除会心（本命率） |
| 副武器 | 大外 + 大外 + 劲 + 势 + 会心 | 能用 | 势 为缺陷词条，能用封顶 |
| 主武器（陌刀） | 大外 + 陌刀武学增伤 + 大外 + 会心 + 精准 | 能用 | 精准+会心（非首）同现，缺陷 |
| 主武器（陌刀） | 大外 + 陌刀武学增伤 + 劲 + 劲 + 敏 | 能用 | 非首缺大外，外功硬门槛封顶 |
| 环 | 大外 + 全武学增伤 + 大外 + 劲 + 敏 | 顶级 | 无排除词条 |
| 环 | 大外 + 全武学增伤 + 大外 + 敏 + 大本属 | 优秀 | 缺劲，顶级条件不满足 |
| 头盔 | 会心 + 大外 + 劲 + 敏 + 精准 | 顶级 | 精准仅 1 条（含首共 0+1） |
| 头盔 | 精准 + 大外 + 劲 + 敏 + 精准 | 优秀 | 精准两条（含首词条） |
| 胫甲 | 劲 + 对首领增伤 + 大外 + 劲 + 敏 | 顶级 | 可选槽=劲+敏 |
| 胫甲 | 劲 + 对首领增伤 + 大外 + 劲 + 会意 | 垃圾 | 会意为库外废词条（跨流派 OR 逻辑下会意流派可能保留） |
