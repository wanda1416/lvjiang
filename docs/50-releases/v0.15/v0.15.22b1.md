# v0.15.22b1 — Linux 与 macOS 安装包、预置基础属性与独立任务包（测试包）

本包是 0.15.22 的第一个测试版，供手动下载。它不替换当前正式版 0.15.21，也不会出现在
普通客户端的升级提示里。GitHub Release 会标成 Pre-release，且不是 Latest。

相对 0.15.21 的源码差异已按用户可见行为核对。Windows、Linux、macOS 与 Android
安装包本身要等本次发布流水线跑完才能核验，本文不代替那次产物检查。

## ⚠️ 不兼容变动与升级指引

### 1. 风沙酒肆改到独立任务包里

- **现象：** 任务列表里的脚本 id 仍是 `fengsha_jiushi_night`，按 id 引用的批量配置不用改。
  官方文件从 `workflows/standalone/fengsha_jiushi_night.wf` 和 `workflows/subcall/fengsha/`
  挪到 `workflows/standalone/fengshajiusi/`。识别改在包内场景区域内进行，不再整屏 OCR。
  场景和布局不出现在全局场景列表里。
- **原因：** 这套玩法的场景、布局和脚本收成一个可整目录复制的任务包。
- **如何调整：** 没改过这份官方脚本时无需操作。若在 `config/local` 里覆盖过旧路径下的脚本或子流程，
  把覆盖挪到 `workflows/standalone/fengshajiusi/` 里的对应文件，或删掉旧覆盖。换过窗口比例后，
  到场景管理顶栏「加载任务场景」里重新标定，再「退出任务场景」。便携版 ZIP 必须解压到新目录，
  否则旧的官方文件会留下来。

### 2. 同一套属性算出的毕业率可能和 0.15.21 不同

- **现象：** 鸣金·虹 115 级的满值基准改为 100%。武学天赋的五维增量和公共底子里的无相攻击
  按统一口径重算后，毕业率数字可能变化。毕业率模型上的 `source` 字段不再读取。
- **原因：** 模型按当前赛季满养成标准校正，并去掉不再使用的来源字段。
- **如何调整：** 个人基础属性和已保存方案不用迁移。若你在 `config/local` 里覆盖过毕业率模型，
  系统里的这次校正到不了那份覆盖，需要自行同步或删掉本地覆盖。

### 3. 测试包的配置更新状态单独存放

- **现象：** 本包不会沿用 0.15.21 或其他测试包已经下载的更新状态。
- **原因：** 在线配置仍按三段系列 `0.15.22` 匹配；测试包自己的更新状态放在
  `updates/v0.15.22b1`，与正式版目录分开。
- **如何调整：** 无需手工搬文件。装回正式版 0.15.21 时，仍使用正式版自己的更新状态。

### 4. 向手机下发改为整包，并按方案过滤布局

- **现象：** 手机同步不再按零散配置挑选内容。一次下发带上全部配置、脚本和用户资料，
  只按所选方案过滤布局与图库。默认仍保留手机上的任务参数和批量配置。
- **原因：** 离线包改成全量打包，同步入口改为选择方案。
- **如何调整：** 下发前确认选中的方案就是要装到手机上的那一套。若要连手机上的任务参数或
  批量配置一起换成电脑上的，取消对应的保留勾选。

### 5. 「用户属性」改名为「用户配置」

- **现象：** 用户管理右侧表格和按钮文案改为「用户配置」。已经保存的 Key（如 `account`、
  `role`、`role_index`、`tail`）和取值不变。
- **原因：** 这项数据是高隐私键值，名称与「基础属性」区分开。
- **如何调整：** 无需操作。

## ✨ 新增功能

- **Linux 与 macOS 安装包。** 发布产物增加 `lvjiang-v0.15.22b1-linux-x86_64.tar.gz` 和
  `lvjiang-v0.15.22b1-macos-arm64.dmg`。macOS 包是 Apple 芯片（arm64），没有 Intel 包。
  Windows 仍是便携 ZIP 和安装器。
- **十二个流派的 115 阶预置基础属性。** 「当前属性」下拉先列预置，再列当前用户，最后是其他用户。
  已经选中的个人属性不会被换成预置。
- **流派配置拆成两页。** 右区分为「流派方案」和「流派属性」，游戏配置窗口默认更高。
- **装备导出增加兵鉴格式。** 装备页「导出数据」可选 leoq7 文本或兵鉴 JSON，并可选导出后打开对应网站。
  模拟装备不导出。
- **独立任务包。** 风沙酒肆是第一份随包提供的实现。普通脚本不进入任务包作用域，行为与以前相同。
- **手机端应用内更新。** 可在应用内查看发布说明、后台下载并安装 APK；安装前校验包，进程被杀后可以续装。
- **本地控制面与 `lvjiang-cli`。** 桌面端可以无界面运行，并由本机命令行查看和控制任务。
  这是附加入口，不改变主窗口里开始任务的方式。
- **桌面端窗口图标。** 源码运行和打包使用同一份图标。
- **任务诊断增加「清空缓存」。** 用来丢掉已经留在内存里的历史帧，不影响默认关闭的落盘开关。

## 🔧 修复

- **手机端会长期显示离线。** 应用进后台时心跳计数被清掉，设备不再上报。现在后台暂停不再把
  已累计的心跳间隔清零。
- **备战方案里的增益效果被裁掉字。** 动态槽高度不够，半屏卡片纵向被压扁。现按内容留出高度。
- **编辑基础属性会丢掉未显示的字段。** 保存时隐藏字段不再从这份属性里消失。

## 📦 重构

- 毕业率计算模型不再使用 `stage`。阶段只属于预置基础属性；模型文件里残留的 `stage` 在读取时忽略。
- 用户管理里的属性表更名为用户配置，存储位置和键名不变。

  以及用户配置、便利贴不参与对外分享的说明。
