# 5.5 使用流派规则过滤装备

最优组合搜索可以直接尝试全部候选，也可以先复用自动调律的流派规则，把明确无效的装备取消勾选。这里的规则是候选预筛工具，不是毕业率计算公式。

---

## 流派规则与毕业率方案不是一回事

| 项目 | 流派规则 | 毕业率方案 |
|---|---|---|
| 输入 | 单件装备的部位、品阶和词条 | 一整套角色战斗属性 |
| 输出 | 顶级、优秀、一般、垃圾、跳过或不适用 | DPS、总伤害、毕业率 |
| 用途 | 自动调律判定、最优组合候选预筛 | 对完整装备组合做最终数值比较 |
| 是否能单独决定最优组合 | 不能 | 能对每个完整组合给出最终排序 |

一件规则评级“一般”的装备仍可能让整套毕业率更高；一件评级“顶级”的装备也不保证在当前基础属性和其他七件装备下最优。因此规则只减少明显无意义的组合，最终结果仍由毕业率公式计算。

## 规则选项从哪里来

打开 **「计算最优组合」** 后，“调律规则”下拉会显示：

```text
规则名-玩法名
```

系统只列出与当前流派匹配的规则玩法。匹配依据包括：

- 主、副武器类型集合；
- 流派所属属性；
- 规则中定义的玩法。

若没有合适规则，可以选择 **「不应用规则」**，手工勾选候选。

## 选择规则后的行为

规则会逐件计算实际评级并更新候选行：

| 判定结果 | 默认勾选状态 | 含义 |
|---|---|---|
| 顶级 | 保持勾选 | 高质量候选 |
| 优秀 | 保持勾选 | 无明显缺陷，可参与组合 |
| 一般 | 保持勾选 | 有瑕疵，但可能仍适合当前整套属性 |
| 垃圾 | 取消勾选 | 命中规则硬伤，默认排除 |
| 跳过 | 取消勾选 | 规则明确不参与判断或不建议进入候选 |
| 不适用 | 保持勾选 | 规则没有形成否决结论，交给最终公式判断 |

切回“不应用规则”会重新勾选全部候选。所有复选框都可以手工调整，规则不会禁止用户重新加入某件装备。

## 为什么“不适用”不自动排除

“不适用”通常表示该规则没有覆盖这件装备或当前部位，而不是已经证明它无效。把不适用当成垃圾会误删候选，因此系统保留它。

“跳过”与“不适用”也不同：当前最优组合界面会把跳过项取消勾选，但仍显示在列表中，用户可以根据实际需求重新选中。

## 推荐筛选流程

1. 先在装备面板选择合理的最低等级和词条条件；
2. 打开最优组合窗口；
3. 选择与当前流派和构筑目标一致的“规则名-玩法名”；
4. 查看每个槽位的评级；
5. 对垃圾和跳过项进行抽查；
6. 必要时手工恢复特殊装备；
7. 确认八个槽位至少各有一个候选后开始搜索。

## 修改规则还是修改基础属性

两者解决的问题不同：

- 当前角色面板不准、换号后属性不同：修改或重新创建角色基础属性；
- 某类词条被错误判成垃圾、玩法武器或属性不匹配：修改调律流派规则；
- DPS 权重、战斗时间或 100% 基准不正确：修改并重新导入毕业率方案；
- 某件 OCR 装备数据错误：修复识别，或复制为模拟装备校正。

不要通过修改角色基础属性来“过滤装备”。基础属性影响每个组合的最终 DPS；候选排除应通过装备筛选、流派规则或手工复选框完成。

## 与自动调律的关系

最优组合复用自动调律的同一套装备判定入口，所以同一规则、玩法和标准装备数据应得到相同实际评级。但两处用途不同：

- 自动调律根据行为配置决定继续、重置、回收或保留；
- 最优组合只用评级辅助勾选，不执行回收或调律动作。

流派规则详细定义见[4.4 流派规则详解](04.04-school-rules.md)。
