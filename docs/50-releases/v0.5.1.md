# v0.5.1 — 脚本工作台、图色原语、模板定位

## 律匠 v0.5.1

本版本新增脚本工作台（可视化调试）、图色原语 DSL、多尺度模板定位，并修复 session.json 多进程安全、批量暂停等关键问题。

---

### ✨ 新增功能

- **脚本工作台**：可视化脚本编辑与调试环境
  - 指令选择面板（action palette）
  - 截图取点 / 取色 / 取区域
  - 单步运行调试
  - 快捷键 F7 打开

- **图色原语 + DSL 内置函数**：工作流脚本可直接调用视觉能力
  - 取色、色占比、亮段、色心方位、同色图标、多点找色
  - 详见 `docs/30-architecture/32-grammar/06.4-vision-functions.md`

- **by image 模板定位**：`find_image` 语句支持多尺度匹配
  - 录制分辨率自适应，无需手动缩放模板
  - 详见 `docs/30-architecture/32-grammar/04.3-find.md`

- **设备端输入增强**
  - drag hold 改两段 stroke，真正停住
  - press ESC / HOME 映射系统 BACK / HOME

- **主题切换 + 本地化对话框**：支持亮/暗主题切换，系统对话框文本国际化

- **更新提示增强**：GitHub release 提示显示 changelog 摘要

- **批量任务有序选择**：批量脚本支持按顺序选择执行

---

### 🔧 修复

- **session.json 多进程安全**：原子持久化 + Windows 文件锁（`fasteners`），解决多实例并发写入导致的数据损坏
- **批量 Python 脚本暂停失效**：调律短路吞暂停信号，修复暂停/恢复状态机
- **暂停中结束确认序列化**：防止多次弹窗叠加
- **UI 选择器宽度**：装备过滤器保持单行显示，避免截断
- **模板缓存失效**：按文件 mtime 判断缓存有效性，修复修改模板后不生效的问题

---

### 📦 重构

- **调律职责解耦**：`auto_tuning` 拆分为 `tuning/` 模块（decisions / executor / judge / navigator / recorder / recycler / resetter / state）
- **工作流共享页面检测**：提取 `page_detection.wf` 子流程，江湖号令/百业/批量共用
- **导入解析确定性**：工作流 import 路径解析改为确定性算法
- **江湖号令活动恢复加固**：任务循环前校验页面，双模式导航（auto_nav）
- **毕业搜索性能**：缓存装备数据，避免重复解析
