# 燕云十六声流派系统介绍

## 一、流派总览

游戏共有**10大主流流派**（6大基础流派 + 4大进阶流派），按**属性攻击**分为四大类：**鸣金、裂石、牵丝、破竹**。每个流派由**两把武器+两套武学**组成，共享同一属性攻击类型。

| 属性 | 流派 | 武器组合 | 武学 | 定位 | 会心/会意 |
|------|------|----------|------|------|-----------|
| **鸣金** | 鸣金·虹 | 剑+枪 | 无名剑法+无名枪法 | 中远程输出 | **会意** |
| | 鸣金·影 | 剑+枪 | 积矩九剑+九曲惊神枪 | 近战爆发（流血） | **会意** |
| **裂石** | 裂石·威 | 陌刀+枪 | 嗟夫刀法+八方风雷枪 | 近战坦克 | 会心 |
| | 裂石·钧 | 唐横刀+陌刀 | 斩雪刀法+十方破阵 | 近战输出 | 会心 |
| **牵丝** | 牵丝·玉 | 扇+伞 | 青山执笔+九重春色 | 远程输出/控制 | 会心 |
| | 牵丝·霖 | 扇+伞 | 明川药典+千香引魂蛊 | 治疗辅助 | 会心 |
| | **牵丝·翊** | **舞绫鼓+扇** | **文动霓裳+杏游草野** | **控制/团队辅助/远近兼顾** | 会心 |
| **破竹** | 破竹·风 | 双刀+绳镖 | 泥犁三垢+栗子游尘 | 高机动持续输出 | 会心 |
| | 破竹·尘 | 伞+绳镖 | 醉梦游春+粟子行云 | 团队增伤/控制 | 会心 |
| | 破竹·鸢 | 拳甲+绳镖 | 天志垂象+千机索天 | 单体爆发/PVP | 会心 |

## 二、会心 vs 会意 两大体系

| | **会心流派** | **会意流派** |
|---|---|---|
| **包含流派** | 裂石威、裂石钧、牵丝玉、牵丝霖、牵丝翊、破竹风、破竹尘、破竹鸢 | 鸣金虹、鸣金影 |
| **判定条件** | 必须先精准命中 | 无需精准，直接判定 |
| **上限** | 80% | 40% |
| **伤害倍率** | 1.5倍（基于大小攻随机取值） | 1.35倍（基于最大攻） |
| **核心词条** | 会心率、劲、敏 | 会意率、势、劲 |

**关键规则**：当会心率+会意率 > 100%时，系统**优先判定会意**。因此会意流派需严格控制会意率不溢出，会心流派则需避免会意率过高挤占会心空间。

## 三、各流派详解

### 1. 鸣金·虹（初始自带）
- **武器**：剑（无名剑法）+ 枪（无名枪法）
- **特点**：角色初始自带，中远程输出，机动性强，PVP先手控制优秀
- **核心机制**：无名剑法蓄力剑气远程消耗，无名枪法近战突进
- **套装**：玉斗套 + 易相套
- **调律属性**：势 > 鸣金攻击（优先大）> 最大外功攻击 > 会意 > 劲 > 精准
- **心法**：易水歌、无名心法、威猛歌、千山法（日常）/ 断石之构（竞速）
- **词条价值**：大外=势=三率=100分，劲=85，敏=30，**小外=15**（不推荐）

### 2. 鸣金·影（九九）
- **武器**：剑（积矩九剑）+ 枪（九曲惊神枪）
- **特点**：近战输出，流血引爆机制，双武器联动
- **核心机制**：通过剑气纵横的爆发、移经易武的属性继承、飞隼套的会心叠加
- **套装**：飞隼套 + 鹰扬套
- **调律属性**：劲 > 最大鸣金 > 最大外功攻击、势 > 会意 > 精准
- **心法**：易水歌、剑气纵横、逐狼心经、凝神章（日常）/ 断石之构（竞速）

### 3. 裂石·威（坦克）
- **武器**：陌刀（嗟夫刀法）+ 枪（八方风雷枪）
- **特点**：近战坦克，护盾+减伤+嘲讽，团队副本必备主T
- **核心机制**：战意系统——攻击积累战意，释放高额AOE减伤
- **套装**：时雨套 + 桂月套
- **调律属性**：裂石攻击（优先小）> 体 > 御 > 会心 > 会意 > 气血 > 最大外功攻击 > 精准 > 最小外功攻击
- **心法**：易水歌、山河绝韵、抗造大法、磐石决（团本）

### 4. 裂石·钧（唐刀/陌刀）
- **武器**：唐横刀（斩雪刀法）+ 陌刀（十方破阵）
- **特点**：三种玩法方向——纯唐轴、双切轴、陌刀轴
- **核心机制**：斩雪刀法"卸势反击"，十方破阵"唤千军"召唤安西英魂
- **套装**：断岳套 + 玄甲套
- **调律属性**：最小外功攻击、最大外功攻击、会心率
- **心法**：易水歌、霜天白夜、穿喉决、极乐泣血（主唐刀）/ 孤忠不辞（双切）

### 5. 牵丝·玉（远程输出）
- **武器**：扇（青山执笔）+ 伞（九重春色）
- **特点**：远程持续输出+控制，有"飞天"和"走地"两种玩法
- **核心机制**：姿态切换与派生攻击，浮空连击
- **套装**：烟柳重重套 + 不知寒套
- **调律属性**：最小外功攻击、最大外功攻击、会心率
- **心法**：易水歌、花上月令、纵地摘星、明晦同尘（日常）/ 断石之构（竞速）

### 6. 牵丝·霖（奶妈）—— 两种玩法

**纯奶玩法**：
- **定位**：纯治疗辅助，不考虑输出
- **核心机制**：明川药典持续治疗，千香引魂蛊群体复活
- **套装**：浣花套 + 梨雪套
- **调律属性**：最小外功攻击、最大外功攻击、会心率（治疗会心）
- **词条特殊**：治疗没有擦伤和会意，只有会心/非会心；**会意、精准、外系属攻对奶量为0作用**
- **心法**：易水歌、君臣药、杏花不见、千丝蛊

**火拳奶玩法**：
- **定位**：按照**会心输出流派**考虑，主打奇术输出
- **核心机制**：利用奇术（如神龙吐火）进行输出，兼顾治疗
- **词条需求**：与会心输出流派一致，追求会心、最小外功攻击等

### 7. 牵丝·翊（新增流派，2026年4月）
- **武器**：舞绫鼓（文动霓裳）+ 扇（杏游草野）
- **特点**：控制、团队辅助、远近兼顾，融合汉唐袖舞与音游卡点机制
- **核心机制**：
  - 舞绫鼓：抽击、束缚敌人，限制行动，近战远程皆可输出；移动中持续释放，双侧光标交汇时按键触发范围伤害，连续精准判定激活强化状态
  - 扇（杏游草野）：以风场为核心机制，可推开敌人、增益友方，具备自我/队友回血能力
- **套装**：待定
- **调律属性**：最小外功攻击、最大外功攻击、会心率
- **心法**：霜天白夜等

### 8. 破竹·风（双刀/绳镖）
- **武器**：双刀（泥犁三垢）+ 绳镖（栗子游尘）
- **特点**：高机动性，召唤"鼠鼠"协同攻击，红刀（嗔焰）爆发
- **核心机制**：绳镖召唤鼠鼠→双刀高频攻击触发协同→红刀状态吸血+会心加成
- **套装**：燕归套 + 江凝套
- **调律属性**：最小外功攻击、最大外功攻击、会心率
- **心法**：易水歌、忘川绝响、心弥泥鱼、极乐泣血（日常）/ 断石之构（竞速）

### 9. 破竹·尘（伞/绳镖）
- **武器**：伞（醉梦游春）+ 绳镖（粟子行云）
- **特点**：团队增伤+控制，万金油辅助
- **核心机制**：绳镖"摄魂"状态→伞武学终结技"响指"收割
- **套装**：连星套 + 抱玉套
- **调律属性**：最小外功攻击、最大外功攻击、会心率
- **心法**：易水歌、忘川绝响、心弥泥鱼、断石之构

### 10. 破竹·鸢（拳甲/绳镖）
- **武器**：拳甲（天志垂象）+ 绳镖（千机索天）
- **特点**：单体爆发极高，PVP强势，版本T0
- **核心机制**：绳镖Q上BUFF→拳甲平A攒"天志"豆子→R蓄力一拳爆发
- **套装**：撼天套 + 尚义套
- **调律属性**：最小外功攻击、最大外功攻击、会心率
- **心法**：易水歌、忘川绝响、心弥泥鱼、断石之构

## 四、各流派词条优先级

以**大外攻为100分基准**：

| 词条 | 会心流派价值 | 会意流派价值 | 说明 |
|------|-------------|-------------|------|
| **大外攻** | 100 | 100 | 全流派第一优先 |
| **会心率** | 100 | 75 | 会心流派核心 |
| **会意率** | — | 100 | 会意流派核心 |
| **势** | 较低 | 100 | 会意流派专属 |
| **劲** | 100 | 85 | 会心流派核心，会意流派次选 |
| **敏** | 100 | 30 | 会心流派次选，会意流派收益低（不吃小攻） |
| **精准率** | 100 | 较低 | 会心前提，但上限100%易溢出 |
| **大无相（本属）** | 85 | 85 | 1.5倍本系加成 |
| **最小外功攻击** | **收益还行** | **不推荐** | 会心流派可用，会意流派鸡肋 |

**鸣金流派（会意）特殊说明**：
- **不推荐最小外功攻击**：会意伤害直接以最大外功乘以会意伤害系数结算，最小外功对会意流派几乎无收益
- 鸣金流派词条优先级：大外 > 势 > 会意 > 劲 > 精准 > **小外（不推荐）**

> 关于转律库、神力词条、调律规则等详细内容，参见 [装备系统介绍](equipment-system.md)。

## 五、小外流玩法（会心流派新玩法）

### 核心思路
- **不要最大外功攻击**和提供最大外功攻击的**劲、势**
- 只留**最小外功攻击**和**敏**
- 然后是**本系属性攻击（无相攻击）**
- **核心要求**：让角色属性的**最小外功攻击 > 最大外功攻击**

### 原理
- 会心伤害结算时，伤害在最小至最大外功间随机取值
- 当**最小外功 > 最大外功**时，会心伤害结算**固定取最小外功攻击**
- 这样可以实现会心伤害的**稳定高值**，避免随机波动

### 词条配置
- **保留**：最小外功攻击、敏、会心、大无相（本属）
- **排除**：最大外功攻击、劲、势
- **优势**：伤害稳定，不受大小攻随机波动影响

## 六、牵丝霖两种玩法的装备差异

| | **纯奶** | **火拳奶** |
|---|---|---|
| **定位** | 纯治疗辅助 | 会心输出+治疗兼顾 |
| **核心输出** | 无（纯治疗） | 奇术输出（神龙吐火等） |
| **词条需求** | 会心率、最小外功、最大外功 | 会心、最小外功、大外、劲、敏 |
| **不需要的词条** | **会意、精准、外系属攻**（对奶量0作用） | 无特殊排除 |
| **神力词条** | 全武学增效、群体奇术增伤 | 群体奇术增伤（优先） |
| **套装** | 浣花套 + 梨雪套 | 输出向套装 |

---

**总结**：当前110级版本流派体系已扩展至10大流派，新增牵丝·翊带来舞绫鼓+扇的全新战斗体验。会心流派中，最小外功攻击收益尚可，且衍生出"小外流"这一创新玩法。会意流派（鸣金）则不推荐最小外功攻击。牵丝霖分为纯奶和火拳奶两种截然不同的养成路线，装备需求差异显著。
