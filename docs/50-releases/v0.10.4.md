# v0.10.4 — PC 后台调律、角色扫描与场景编辑器修复

## 律匠 v0.10.4

> **发布状态：正式发布。发布日期：2026-09-06。** 本文以 v0.10.3
> 发布完成后的代码树为基线。

本版本为修复版本，重点解决新建场景导致布局管理白屏、编辑角色模型后总览字体
恢复默认值，以及 PC 后台模式无法拖拽的问题。

### ⚠️ 不兼容变动、已知限制与升级指引

#### 1. PC 后台滚轮模式不要与 `positional` 遍历策略同时启用

- 自动调律默认仍使用 `dedup` 遍历策略，并默认关闭「PC 端兼容后台模式」，正常
  用户不会遇到此限制。
- `positional` 不是默认策略，只会在主动勾选「启用位置校验遍历策略」后使用。它的
  位置校正依赖四分之一行的精准拖拽，而后台滚轮一次只能移动一个刻度；若同时启用
  两项，位置校正可能失准。
- 需要后台运行时请保持默认 `dedup`；需要 `positional` 时请关闭后台兼容模式，
  继续使用前台拖拽。

#### 2. 角色属性扫描工作流有本地覆盖时需手动同步

- 本版本修改了随包发布的
  `config/system/workflows/standalone/scan_role_base_attr.wf`，PC PostMessage 模式
  改用滚轮逐格翻动属性面板，Android 与其他模式仍走原有拖拽流程。
- 如果存在同路径的 `config/local` 工作流覆盖，系统修复不会替换本地文件。请删除
  本地覆盖以使用随包版本，或手动同步本次修改。

#### 3. Android `versionCode` 递增到 41

- 本版本修改了 `config/system` 工作流，Android 首次启动会重新解压配置。
- 无需手动操作。

> 本轮没有提升任何 `content_version`，不生成新一代远端配置。除上述说明外，
> 没有配置格式、快捷键或 Profile 落盘格式的不兼容变动。

### ✨ 新增功能

- 自动调律新增「PC 端兼容后台模式」。启用后，背包翻页使用
  `scroll [bag_equip_detail].[bag_grid] down 1` 等价能力代替拖拽，使 PostMessage
  后台输入可用；关闭时继续使用更精准的拖拽。Android 始终使用原有拖拽流程。
- 调律配置由「规则 / 部位 / 更多」整理为「规则 / 参数」两页。「参数」统一容纳
  调律部位、全局开关、调律设置和调试参数。
- 新增「启用位置校验遍历策略」复选框：默认不勾选并使用 `dedup`，勾选后改用
  `positional`。

### 🔧 修复

- 修复新建场景同时出现在「通用」与目标分组，继而导致布局管理的分组场景列表、
  画布和场景定义区域白屏的问题。场景归组现在会排除已被显式分组接管的场景。
- 修复编辑角色档案中的再生、体力等模型阈值后，用户总览整体恢复默认字体和字号的
  问题；重建总览控件时会保留当前字体设置。
- 修复 PC PostMessage 模式下角色基础属性扫描依赖拖拽、无法在后台稳定执行的问题，
  改为滚轮逐格滚动；Android 流程不变。

### 📦 重构

- 背包移动拆分为 `DragBagScroll` 与 `WheelBagScroll` 策略，自动调律只选择并调用
  策略，不在业务流程中散布环境判断。
- 将通用 `scroll` 能力下沉到基础工作流 action，DSL 引擎和 Python 业务工作流
  共享相同实现。

### 📚 文档

- 更新自动调律需求说明，记录两页参数结构、后台兼容开关与遍历策略默认值。
- 明确 PC 后台滚轮与非默认 `positional` 策略不能组合使用。
