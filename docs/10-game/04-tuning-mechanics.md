## 目前支持的调律流派

### 装备分级

    我们计划分装备为三个级别：顶级装备、优秀装备、一般装备、临时装备 和 垃圾装备
    注意，一般而言，除了小外流，并不是用户可以穿一身顶级装备，那样会出现三率不足的情况，会意和会心大外流一般需要一半顶级和一半优秀搭配。
    我们在调律的过程中，不论用户当前装备的装备是什么等级，优秀 和 顶级装备都需要保留。

    顶级装备：在符合增伤词条的要求下，外功攻击词条拉满，大外流没有小外词条
    优秀装备：在符合增伤词条的要求下，确保大外和劲拉满（非首词条）
    一般装备：在符合增伤词条的要求下，确保至少有一条大外或者劲（非首词条）
    临时装备：用户目前什么都没有，急需一件能用的


### 转律说明

    考虑到会心和会意流派都有一套好的装备共性，所以即使在调律过程中出现其他流派的好装备，也应该保留。
    比如 会心流派 一般不需要 会意，但是如果调 腿甲 的时候碰到 劲 + 对首领增伤 + 劲 + 大外 + 会意， 那么也应该自动保留。

    由于存在转律机制，即对 首词条 以外的词条可以选择一个进行无限次转律。
    这意味着，调律过程中，如果出现一条废词条，我们需要采取一种最优策略模拟其转律结果，再判定其可能。
    比如，对于 会意流派的 副武器，如果出现：  大外、劲、小鸣金。
        此时我们可以假定 小鸣金 按照转律优先级表，直接认定为 大外，然后判断 大外+劲+大外 算什么级别的。
        显然应该继续调律，并且这件装备有希望出 顶级装备。


### 调律配置

    会意流派-通用
        - 可选配置： 保留 PVP 装备（即 保留 单体奇术增伤 和 对玩家增效 词条）
        - 词条优先级：

    会心流派-小外流
        - 必选配置： 指定流派（裂石、破竹、牵丝） 和 玩法（可同时勾选）
        - 可选配置： 保留 PVP 装备（即 保留 单体奇术增伤 和 对玩家增效 词条）

    会心流派-大外流
        - 必选配置： 指定流派（裂石、破竹、牵丝） 和 玩法（可同时勾选）
        - 可选配置： 保留 PVP 装备（即 保留 单体奇术增伤 和 对玩家增效 词条）
        
    治疗流派（UI 上合并为一个流派条目）
        - 必选配置： 玩法（纯奶、火拳奶（输出），可同时勾选）
        - 可选配置： 无

    配置说明：
        玩法： 
                裂石均 区分 纯唐 还是 双切
                牵丝玉 区分 走地 还是 飞天
                牵丝霖 区分 纯奶 还是 火拳
            没有勾选指定流派（裂石 或者 牵丝），就不必出现玩法选项。

## 装备词条定义

    注意：以下强调的是 顶级装备 和 优秀装备， 对于 能用装备 的要求更低一些。
    注意：如果指定部位的明确了需要 增伤 词条，但是缺失，直接判定为 垃圾装备。
    注意：大无相 在 非武器的部位表达的含义是 大本属，即所在流派的的 最大属攻攻击。
    注意：所有的装备词条描述为 必选词条 + 可选词条 组合，你可以认为这是一种类似的正则语法。
    注意：[ ] 内框选的词条是必选词条，不符合但是也没有出现垃圾词条，就认为是 能用装备。
    注意：[ ] 之后后接的词条就属于可选词条，一般可选词条就是 能用词条 * 剩余词条数量。

    转律优先级： 描述当我们假定垃圾词条转律后，排除在 2-5 词条中出现过词条，应该假定会转为哪一条词条的优先级。
    可用词条库： 除 武学增效、奇术增效、对单位增效 这些词条后，当前流派能用的词条，出现这些以外的都算废词条。


### 会意流派各部位词条要求

    转律优先级： 大外、势、劲、会意、大无相   （转律库有会心，但是认为是废品词条）
    可用词条库： 上述转律词库 + 会心、精准

    主武器（剑）： [大外 + 剑武学增伤 + 大外 + 劲/势] + 可用词条库 * 1
        没有出现 会意 或 大无相，判定为 顶级；
    副武器（枪）： [大外 + 大外 + 劲/势] + 可用词条库 * 2
        同时出现 劲 + 势，判定为 顶级； 
    环+佩：  [大外 + 大外 + 全武学增伤] + 可用词条库 * 2
        同时出现 劲 + 势，判定为 顶级； 
    头盔+胸甲： [会意 + 大外 + 劲/势] + 可用词条库 * 2
        没有出现 大无相，判定为 顶级； 
    胫甲+腕甲： [劲 + 对首领增伤 + 大外] + 可用词条库 * 2
        除去首词条，同时出现 劲 + 势，判定为 顶级；

    会意流派目前最佳是不需要精准和会心，如果出现一条 精准 或者 会心，那么就认为是 能用 装备。
    鸣金流派顶级装备定义：
        对于 剑、环、佩 就是： 增伤 + 大外 + 大外 + 劲 + 势。
        对于 枪 就是： 大外 + 大外 + 劲 + 势 + 会意。  
        对于头盔和胸甲，就是 会意 + 会意 + 大外 + 劲 + 势。
        对于 胫甲、腕甲 就是： 劲 + 对首领增伤 + 大外 + 劲 + 势。
    理论上全部顶级装备组合后将有 5 会意，8 势。这的确是会意流派的顶级组合。 


### 会心大外流各部位词条要求

    转律优先级： 大外、劲、敏、会心、小外、大无相
    可用词条库： 上述转律词库 + 势、精准

    主武器： [大外 + 主武学增伤 + 大外] + 可用词条库 * 2
        没有出现 小外、大无相、会心、精准、势 判定为 顶级；  
    副武器： [大外 + 大外 + 劲] + 可用词条库 * 2
        没有出现 小外、大无相、精准 判定为 顶级； 
    环+佩：  [大外 + 全武学增伤 + 大外] + 可用词条库 * 2
        没有出现 小外、大无相、会心、精准、势 判定为 顶级；  
    头盔+胸甲： [会心/精准 + 大外 + 劲] + 可用词条库 * 2
        没有出现 小外、大无相、势 并且没有 两条精准（包含首词条） 判定为顶级；  
    胫甲+腕甲： [劲 + 对首领增伤 + 大外] + 可用词条库 * 2
        没有出现 小外、大无相、会心、精准、势 判定为 顶级；  


### 会心小外流各部位词条要求

    转律优先级： 小外、敏、大无相、会心
    可用词条库： 上述转律词库 + 精准、小无相、小外属（即非本流派的小属攻）

    主武器： [小外 + 主武学增伤 + 小外] + 可用词条库 * 2
        没有出现 小无相、小外属、精准 判定为顶级
    副武器： [小外 + 小外 + 敏] + 可用词条库 * 2
        没有出现 小无相、小外属、精准 判定为顶级
    环+佩：  [小外 + 全武学增伤 + 小外] + 可用词条库 * 2
        没有出现 小无相、小外属、精准 判定为顶级
    头盔+胸甲： [会心/精准 + 小外 + 敏/大无相] + 可用词条库 * 2
        没有出现 小无相、小外属 并且没有 两条精准（包含首词条） 判定为顶级
    胫甲+腕甲： [会心/精准 + 对首领增伤 + 小外] + 可用词条库 * 2
        没有出现 小无相、小外属 并且非首词条没有出现 会心/精准 判定为顶级

    会心流派小外流顶级装备定义：
        对于 主武器、环、佩 就是： 增伤 + 小外 + 小外 + 敏 + 大无相。
        对于 副武器 就是： 小外 + 小外 + 敏 + 大无相 + 会心。  
        对于头盔和胸甲，就是： 会心 + 小外 + 敏 + 大无相 + 精准/会心
        对于 胫甲、腕甲 就是： 会心/精准 + 对首领增伤 + 小外 + 敏 + 大无相。


### 治疗流派纯奶各部位词条要求

    治疗流派即 牵丝·霖：主武器为 扇，副武器为 伞。
    纯奶需要 扇武学增效，火拳奶不需要；两者均不需要伞武学增伤。

    转律优先级： 大外、劲、小外、敏、会心、大无相
    可用词条库： 上述转律词库 + 势

    主武器（扇）： [大外/小外 + 扇武学增效 + 大外/小外/劲]+ 可用词条库 * 2
        没有出现 会心/大无相/小无相 判定为 顶级，否则判定为 优秀
    副武器（伞）： [大外/小外 + 大外/小外/劲 * 2] + 可用词条库 * 2
        没有出现 大无相/小无相 并且 (敏和会心没有同时出现) 判定为 顶级，否则判定为 优秀
    环+佩：  [大外/小外 + 全武学增伤 + 大外/小外/劲] + 可用词条库 * 2
        没有出现 大无相/小无相 并且 (敏和会心没有同时出现) 判定为 顶级，否则判定为 优秀
    头盔+胸甲： [会心 + 大外/小外/劲 * 2] + 可用词条库 * 2
        没有出现 大无相/小无相 判定为 顶级，否则判定为 优秀
    胫甲+腕甲： [劲 + 对玩家增效 + 大外/小外/劲] + 可用词条库 * 2
        没有出现 大无相/小无相 并且 (敏和会心没有同时出现) 判定为 顶级，否则判定为 优秀


### 治疗流派火拳奶各部位词条要求
    
    火拳奶不需要 指定武学增效，和全部武学增效，但是需要 单体类奇术增伤 和 对首领增伤。

    转律优先级： 大外、劲、小外、敏、会心、大无相
    可用词条库： 上述转律词库 + 精准、势

    主武器（扇，无增伤要求）： [大外 + 大外 + 小外/劲]+ 可用词条库 * 2
        没有出现 大无相 并且 (敏和会心没有同时出现) 判定为 顶级，否则判定为 优秀
    副武器（伞）： [大外 + 大外 + 小外/劲]+ 可用词条库 * 2
        没有出现 大无相 并且 (敏和会心没有同时出现) 判定为 顶级，否则判定为 优秀
    环+佩：  [大外 + 大外 + 小外/劲] + 可用词条库 * 2
        没有出现 大无相 并且 (敏和会心没有同时出现) 判定为 顶级，否则判定为 优秀
    头盔+胸甲： [会心 + 单体奇术增伤 + 大外] + 可用词条库 * 2
        没有出现 大无相 判定为 顶级，否则判定为 优秀
    胫甲+腕甲： [劲 + 对首领增伤 + 大外] + 可用词条库 * 2
        没有出现 大无相/会心/精准 判定为 顶级，否则判定为 优秀



## 调律材料添加说明

    主要采用一键调律添加 律准石。
    备注：金色装备词条默认至少紫色以上，所以对于金色品阶装备添加紫狗粮是无效的多余行为。
    对于狗粮添加，取决于其初始词条。
        如果是 初始词条数值 >= 90%， 每一次都添加 金狗粮。
        如果是 初始词条数值 <  90%， 对于金色品阶装备，不用添加狗粮； 对于紫色品阶装备，添加 紫狗粮。
