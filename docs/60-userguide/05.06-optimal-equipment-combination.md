# 5.6 计算最优毕业率组合

最优组合搜索从八个槽位分别选择一件候选装备，对完整组合计算毕业率，返回当前输入条件下的前五名。它比较的是完整公式结果，而不是简单累加装备评分或单件评级。

---

## 搜索前置条件

开始前应确认：

1. 当前用户和备战方案正确；
2. 主副武学已经解析出流派；
3. 战斗属性区已经选择角色基础属性；
4. 已选择弓玦和毕业率方案；
5. 装备池已经扫描完整；
6. 装备页的等级、词条筛选符合本次搜索目标。

未选择流派或毕业率方案时，系统不会打开有效搜索上下文。

## 候选装备如何产生

点击 **「计算最优组合」** 时，系统读取当前装备页筛选快照，并按八个槽位建立候选：

```text
当前方案已穿戴装备 + 当前用户真实背包装备
  → 主副武器类型匹配
  → 最低等级过滤
  → 已定音/满调律过滤
  → 按指纹去重
  → 流派规则预筛（可选）
  → 用户最终勾选
```

主武器只接收当前流派主武器类型，副武器只接收副武器类型。环、佩和四件防具分别进入自己的槽位，不跨部位投放。

### 模拟装备说明

“排除模拟”默认开启，保证真实配装搜索不受假设数据影响。当前版本的候选加载以已穿戴装备和真实背包装备为主；未穿戴模拟装备不会自动进入候选。若要验证某件模拟装备，可以先把它穿到当前方案，并关闭“排除模拟”。

## 搜索窗口选项

| 选项 | 默认 | 作用 |
|---|---|---|
| 智能筛选 | 开 | 删除被同槽其他候选在相关属性上完全压制的装备 |
| 排除模拟 | 开 | 不让已穿戴的模拟装备进入本次搜索 |
| 满承音 | 关 | 搜索时把承音装备词条按承音上限计算 |
| 满定音 | 关 | 搜索时把定音按 100% 上限计算 |
| 满等级 | 关 | 搜索时把低等级装备基础属性提升到当前赛季最高等级 |
| 弓玦套装 | 继承当前选择 | 重新构造本次搜索使用的非装备属性 |
| 候选评级 | 本流派命中的全部玩法 | 按调律规则的评级预先取消无效候选 |
| 评级要求 | 一般 | 装备需至少有一条已选玩法给出该级别及以上 |

三个“满”开关只影响本次搜索中的假设变换，不会改写仓储里的装备原始数据。

### 候选评级：多选玩法

点击「候选评级」输入框打开玩法选择器，框内用 `/` 分隔显示已选项。

可选的是**全部调律规则下的全部玩法**，本流派命中的排在最前并标注「（本流派）」，
另有全选 / 全不选。打开窗口时默认选中本流派命中的那几条。

选多条是常态。一件装备通常只对得上其中一两套练法，判定因此取各条玩法给出的
**最高**评级——只能选一条规则时，能留下的装备极少。

「评级要求」只有顶级 / 优秀 / 一般三档（要求“至少是垃圾”等于没有要求），默认
一般。一条玩法都不勾选时整项不生效，候选全部保留。

评级取的是装备**当前**的实际评级，不是调律潜力。潜力判定会把空词条槽当万能牌
填满、还模拟一次转律，一件只有「最小外功攻击」的胚子照样算得出顶级——那种装备
现在一点用都没有，拿它筛候选只会让搜索围着一堆一词条装备打转。

已选玩法一条评级都给不出来的装备按**垃圾**算，会被取消勾选。规则内部的「跳过」
其实就是品阶无调律价值或没有词条数据，正是垃圾胚子；单独标成「不适用」的话，
一大片垃圾会顶着看不出好坏的标签留在候选里。

因此，如果只勾选了覆盖面很窄的玩法，某些部位可能整槽被清空——搜索会提示缺失
部位并拒绝开始。多勾几条玩法即可。

## 手工确认候选

窗口按八个槽位显示候选。每行包含：

- 勾选框；
- 装备名和等级；
- 已选玩法中给出的最高评级（一条都给不出时为「垃圾」）；
- **单击装备名**弹出详情，包括基础属性、普通词条、定音及上限占比（原为悬停，
  要等系统延迟，逐件比对时太慢）。

开始搜索前，每个槽位必须至少保留一件候选。任一槽位为空时系统会列出缺失部位并拒绝开始。

搜索空间约等于八个槽位候选数的乘积。例如每个槽位 10 件装备，理论组合数是 `10^8`。因此应先使用等级、词条和候选评级缩小候选。

## 智能筛选与组合计算

搜索分为四步：

1. 把每件装备转换为毕业率公式需要的属性增量；
2. 可选地执行支配剪枝，移除同槽位中被其他装备全面压制的候选；
3. 枚举剩余槽位组合，把角色基础属性、弓玦和八件装备合并；
4. 应用抗性规则并执行毕业率方案，维护最优结果榜。

智能筛选只移除在当前公式输入维度上没有优势的装备，用于降低组合数量。它不是调律规则，也不会修改装备池。

搜索在线程池中运行，窗口每秒更新已评估数量和搜索阶段。点击“取消”会请求停止，已经生成的旧结果会在新搜索开始时清空。

## 结果与应用

搜索完成后显示最多五组结果，每组包含：

- 排名；
- 毕业率；
- DPS；
- 八个槽位的装备摘要；
- “应用此组合”按钮。

点击应用后，结果中的装备引用写入当前备战方案。公共装备池和其他方案不变，战斗属性及顶部毕业率随后重新计算。

建议先新建一个专门的测试方案再应用最优组合，以便保留原方案作为对照。

## 如何搜索真实最优组合

使用以下设置：

- 角色基础属性来自当前角色同一套面板；
- 弓玦与游戏当前配置一致；
- 排除模拟开启；
- 满承音关闭；
- 满定音关闭；
- 满等级关闭；
- 候选池只包含游戏内仍然存在的真实装备。

此时结果表示已扫描装备池中、在当前毕业率方案下的真实最优组合。它不代表全游戏理论毕业上限，也不包含尚未扫描或已被错误筛掉的装备。

## 如何做养成上限模拟

可以复制当前方案或新建测试方案，然后按目标开启：

- 满等级：观察升级装备基础属性后的收益；
- 满承音：观察承音词条成长后的收益；
- 满定音：观察定音拉满后的收益；
- 关闭排除模拟：允许当前方案里已穿戴的模拟装备参与。

结果应标记为假设毕业率，不要与当前真实毕业率混用。

## 技能轴查看（实验性）

入口：「最优组合」对话框首行最右侧的**「技能轴」**按钮。

毕业率方案只给一个 DPS 数字，看不出伤害来自哪个技能——这些细节在导入 Excel 编译成方案时
就已经丢弃，只能回到原始的**毕业率计算器 Excel**（不是律匠自带的功能，需要你自备计算器
文件）重新读取。点「导入 Excel」选择该文件后，两个页签：

| 页签 | 内容 |
|------|------|
| 伤害来源 | 按技能汇总：类型、命中的轴行数、命中次数、总伤害、占比、单次均值 |
| 轴序 | 按顺序列出竞速轴每一行：技能、次数、类型、伤害 |

只读查看，数值直接取 Excel 已算好的结果，不重新计算、不修改表格内容；因此也**不支持**在
这里编辑技能顺序或倍率去反推毕业率变化。

## 常见问题

| 现象 | 排查 |
|---|---|
| 某部位没有候选 | 检查装备页部位、等级、词条筛选和流派武器类型 |
| 选择规则后候选骤减 | 多勾几条玩法，或把「评级要求」降到一般；也可手工重新勾选 |
| 模拟装备没有出现 | 当前未穿戴模拟装备不自动进入候选；先穿戴并关闭排除模拟 |
| 搜索空间过大 | 提高最低等级、限制已定音/满调律、应用流派规则并保持智能筛选开启 |
| 应用后毕业率与结果略有差异 | 检查搜索窗口与战斗属性页的弓玦和三个满值开关是否一致 |
| 结果不符合直觉 | 单件评级不是最终 DPS 权重，应核对基础属性、方案和公式基准 |
