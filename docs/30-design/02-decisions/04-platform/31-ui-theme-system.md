# 桌面端三主题系统与单一来源收敛

> 状态：已实现。

## 1. 背景与目标

桌面端此前仅提供冷灰「浅色」与「深色」二选一，且部分高密度界面（装备卡、调律进度/结果卡、用户管理、设置页等）散落了大量硬编码色值，切深色后局部对比度失调；同时网页端已落地「宣纸 / 玄墨」矿物色系统。桌面端作为高密度生产工具，需要在**保持原有排版、信息密度与操作肌肉记忆不变**的前提下，收敛主题来源并补全原生外观一致性。

## 2. 关键设计取舍

### 2.1 提供「纯白 / 宣纸 / 玄墨」三主题，不做“跟随系统”

- **保留纯白（`light`）作为默认主题**：老用户对原有冷灰 + 蓝强调色板已有明确习惯，直接替换会引起预期外改变。
- **新增宣纸（`paper`）与玄墨（`dark`）**：为偏好温润暖底或暗色护眼的场景提供独立调校后的选项，在菜单栏右上角通过互斥下拉菜单直选并持久化到 `settings.theme`（非法值安全回退 `light`）。
- **暂不做“跟随系统”自动切换**：用户常在白天游戏全屏或特定照明下固定使用某一套视觉模式，显式三选一并记住用户选择比跟随 OS 深浅色更可预期，也避免运行期被系统广播打断或出现局部闪烁。

### 2.2 固定 Qt `Fusion` 风格

- `ThemeManager` 在构造期统一 `app.setStyle("Fusion")`。Windows 原生样式（`windowsvista`）在多项控件上会忽略自定义 `QPalette`（例如按钮、表头与选中高亮），导致三套主题和深色模式在 Windows / Linux / macOS 上表现割裂；`Fusion` 是唯一能跨平台忠实响应完整调色板的内置风格。

### 2.3 宣纸 / 玄墨与 Web v2 令牌同源，但允许桌面端适度微调

- 「宣纸」（`#F5F3EE` 暖底、赤金 `#B45309` 强调、朱砂 `#C2410C` 警示、玉青/天青/绛红语义色）与「玄墨」（赤金 `#E5A93B` 强调、矿物语义色）和 `server/web` 的视觉令牌同源，保证跨端品牌气质一致。
- 桌面端高密度数据场景不做机械照搬，保留两处专门适配：
  1. **玄墨底色微抬半档**（`#141418` / `#1C1C22` / `#24242C`）：比 Web 纯炭黑更柔和，降低长时间盯宽表与日志时的明暗反差疲劳；
  2. **选中底色与高亮强调分离（方案 B）**：深色下 `Highlight` 采用沉稳琥珀棕 `#7A4C12` 配象牙白字 `#F5F2EA`，而聚焦描边、链接与重点文字保留亮赤金 `#E5A93B`，避免大面积表格/列表选中刺眼。

### 2.4 两层单一来源与 Windows 原生标题栏边界

- **通用主题层**：[theme.py](../../../../src/lvjiang/ui/widgets/theme.py)（仅源码检出） 独占 `ThemeSpec`、`THEME_SPECS`、基础色板、全局 QSS 与 `current_tokens()`；右上角菜单直接遍历 `THEME_SPECS` 生成，不再各自维护标签与顺序。
- **插件业务主题层**：[apps/yysls/ui/theme.py](../../../../src/lvjiang/apps/yysls/ui/theme.py)（仅源码检出） 基于通用 `ThemeTokens` 派生燕云专属语义色（装备品阶、词条上限档位、调律评级与结果胶囊、转律目标、黄字属性等），通用层不感知具体游戏业务概念，插件 UI 不再在控件内各自抄写色表。
- **Windows DWM 标题栏同步**：Qt 调色板与 QSS 不控制操作系统非客户区标题栏，因此在真实 Windows 桌面环境下（通过 `sys.platform == "win32"` 与非 `offscreen`/`minimal` 门控）使用 `dwmapi.DwmSetWindowAttribute` 同步沉浸式深浅模式（属性 `20` / 兼容旧版 Win10 `19`）、标题栏边框（`34`）、底色（`35`）与文字色（`36`）；Linux / macOS 及离屏测试在入口直接跳过，不触发原生句柄创建。
