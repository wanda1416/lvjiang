# 5.2 装备数据如何产生

真实装备不是在装备面板中手工录入的。系统通过工作流截图、OCR 和装备解析器生成标准装备数据，再写入当前用户的装备仓储。模拟装备则由用户在对话框中创建。

---

## 三个主要入口

| 入口 | 产生的数据 | 适用场景 |
|---|---|---|
| 扫描备战装备 | 当前方案八个已穿戴槽位 | 首次建立方案、游戏中换装后同步 |
| 扫描全部装备 | 未穿戴装备池 | 建立完整候选库、最优组合搜索 |
| 创建/复制模拟装备 | 用户手工定义的假设装备 | 校正识别、比较词条、模拟养成目标 |

工作流可以从「日常」Tab 运行。运行前应确认当前用户、游戏账号和备战方案正确，因为装备写入目标在任务开始时绑定。

## 扫描备战装备

「扫描备战装备」按固定顺序读取八个槽位：

```text
进入装备页
  → 主武器/副武器/环/佩
  → 冠胄/胸甲/胫甲/腕甲
  → 每个槽位截图与 OCR
  → 转换为标准装备字典
  → 写入本次绑定的备战方案
  → 返回主界面
```

扫描结果会同时进入公共装备池，并把当前方案对应槽位指向该装备。它不会为其他方案自动换装。

> 启动工作流后再切换备战方案，不会改变本次写入目标。这样可以避免扫描进行中 UI 切换导致八个槽位写入不同方案。

## 扫描全部装备

「扫描全部装备」用于读取未穿戴背包。可以选择部位，并设置最低装备等级。

| 参数 | 说明 |
|---|---|
| 扫描部位 | 武器、环、佩、冠胄、胸甲、胫甲、腕甲，可多选 |
| 装备最小等级 | 默认 110；背包按等级排列时用于提前结束低等级区间 |

主副武器共享武器背包，因此只扫描一次武器组。扫描器按物理行读取格子，用装备指纹识别已经访问过的行；滚动窗口再次遇到已知锚点或等级截止时结束当前部位。

同一件装备再次扫描时会按指纹更新，而不是无限追加重复卡片。

## 从画面到结构化装备

一件装备大致经过以下处理：

```text
装备详情画面
  → 场景字段 OCR
  → equip_type / equip_level / base_attr / affix_* / dingyin
  → to_equipment 清洗与标准化
  → 生成装备指纹 _fp
  → 写入用户公共装备池
```

标准数据包含：

| 字段 | 示例 | 用途 |
|---|---|---|
| 名称与类型 | `踏雪含光`、`剑` | 显示、武器槽位匹配 |
| 等级与品阶 | `110`、`gold` | 筛选、基础属性、上限计算 |
| 承音状态 | `true/false` | 承音上限与假设计算 |
| 装备基础属性 | 外功攻击、气血、防御 | 战斗属性聚合 |
| `affix_1`～`affix_5` | 词条名、值、单位、上限占比 | 评级与毕业率计算 |
| 定音 | 定音词条名和值 | 战斗属性和筛选 |
| `_fp` | 八位指纹或 `mock_` 前缀 | 去重、穿戴、删除、方案引用 |

OCR 原始文本不会直接保存为毕业率输入。解析器会统一装备类型、等级、品阶、词条名、数值和单位，后续功能只消费标准字段。

## 指纹与去重

真实装备的指纹由装备身份和词条内容生成。模拟装备使用 `mock_` 前缀，避免与真实装备混淆。

指纹承担三个职责：

1. 同一次或多次扫描之间去重；
2. 作为备战方案槽位的引用目标；
3. 装备编辑后判断它是否已经成为另一件数据对象。

词条、等级等参与指纹的内容发生变化时，指纹可能变化。因此自动调律后应重新运行装备扫描工作流，写入最新结果。

## 用户隔离与存储

装备仓储按用户保存：

```text
config/session/users/{用户名}.loadouts.json
```

文件中包含：

- 公共装备池；
- 多个备战方案；
- 当前激活方案；
- 装备页的筛选状态；
- 数据修订号。

写入采用临时文件替换，UI 操作和工作流共享同一仓储。工作流成功写入后会通知装备面板刷新。

## 如何确认扫描正确

扫描完成后建议检查：

1. 当前用户是否正确；
2. 八个槽位是否与游戏内穿戴一致；
3. 武器类型、等级、金/紫品阶是否正确；
4. 普通词条、定音和承音标记是否完整；
5. 切换来源筛选为“背包”，确认背包装备数量；
6. 对关键装备悬浮或查看卡片，核对数值与百分比。

若识别错误，不建议直接修改真实装备。应先检查场景布局、OCR 区域、图库和游戏配置；临时评估可以复制该装备并创建一件修正后的模拟装备。

> 自动调律会在运行中识别装备并生成调律报告，但当前版本不会把这些识别结果直接写入备战方案装备池。需要更新装备数据时，仍应运行“扫描备战装备”或“扫描全部装备”。

## 重新扫描与清理

- 重新扫描同一件装备：相同指纹会更新原记录；
- 游戏中装备已经不存在：扫描不会自动证明旧记录应删除，需要手动删除；
- “清空真实装备”：删除当前用户全部真实装备，保留模拟装备，同时清空所有方案中相关槽位；
- 删除和清空都不可撤销，操作前可先导出数据。
