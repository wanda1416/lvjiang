# v0.13.2 — 南吕赛季适配、装备假设视图与智能调律

## 律匠 v0.13.2

> **本地全量发布验证已通过。** 以 v0.13.1 正式版为基线；Windows ZIP、安装器、
> 校验和与 GitHub Release 仍以标签触发的公开发布工作流结果为准。

本版本完成南吕赛季和 115 阶装备规则适配，扩充备战方案、装备管理与 Profile 自动化，
并向普通用户开放跟随基础规则组配置的智能调律。

### ⚠️ 不兼容变动与升级指引

#### 1. 南吕赛季开始按 115 阶规则计算

- **现象：** 升级后，毕业率、最优组合、调律评级和假设预览会按南吕赛季的 115 阶、
  新抗性及词条规则计算；已有结果可能下降或发生变化。低于 105 级的装备不再参与满等级
  提升，也不会被假设为本赛季仍可承音。
- **原因：** 南吕赛季当前装备等级为 115，最低可承音等级为 105；115 阶冠胸使用
  “全奇术增伤”，并对首词条、调律词条和跨等级升级建立了等级范围。
- **如何调整：** 无需迁移装备数据，重新打开分析或重新计算即可。若曾在
  `config/local/yysls/game_config` 覆盖赛季、词条、装备或基础配置，请手动同步新版系统
  配置，或删除对应本地覆盖后重启；本地配置优先级更高，不会被系统配置自动替换。

#### 2. 智能调律改为按基础规则组启用和配置

- **现象：** 原“调律参数”中的智能调律设置不再作为全局真值；升级后每个用户、每个
  基础规则组的启用状态默认关闭，切换规则组时可分别启用。算法参数移到调律配置中当前
  规则组的智能调律页。
- **原因：** 智能调律现已向所有用户开放，并需要与扫描、材料和调律处理规则使用同一
  规则组边界，避免切换规则时仍沿用另一组参数。
- **如何调整：** 在主页面“调律 → 规则”中为需要的规则组重新勾选“启用智能调律”，
  再到“调律配置 → 智能调律”核对该组参数。若本地覆盖过 `base_groups/*.yaml`，需手动
  补充 `smart_tuning` 配置或删除覆盖以采用系统默认值。

#### 3. Profile 周进度公共子过程新增业务来源参数

- **现象：** 自定义工作流若直接调用 `sync_weekly_progress` 或
  `sync_weekly_remaining`，旧参数数量会导致调用失败；系统预置工作流不受影响。
- **原因：** Profile 写入现在记录真实业务来源，避免大量记录都显示为“DSL 写入”。
- **如何调整：** 分别在原参数末尾增加 `$source`，传入“日常”“宝钱”等实际来源文本。

#### 4. 默认扫描与冷却口径调整

- **现象：** 系统默认规则组只扫描 105 级及以上装备；新产生的调律重置和转律修正冷却
  按 3 天计算。已经记录的绝对到期时间不会被追溯修改。
- **原因：** 100 级装备已低于本赛季最低承音等级，游戏的新赛季冷却也由 5 天调整为
  3 天。
- **如何调整：** 希望继续扫描低阶装备时，在基础规则组中自行降低最低等级。若本地
  覆盖过基础规则组或 `game_config/basic.yaml`，需要手动同步对应数值。

其余用户数据无需迁移。旧备战方案缺少对战类型时按 PVE 读取；旧装备缺少扫描时间时
使用最后更新时间参与筛选。

### ✨ 南吕赛季与装备规则

- 新增南吕相和赛季、115 阶装备数值、抗性、调律消耗和回收返还配置；毕业率和战斗
  属性统一按当前赛季等级取值。
- 词条与首词条支持生效等级范围；115 阶冠胸用“全奇术增伤”替代单体/群体奇术增伤，
  110 阶旧装备和历史数据仍保留原词条。
- 承音跨越 115 阶时会把单体/群体奇术增伤升级为全奇术增伤，真实扫描结果仍以游戏
  画面为准；规则评级与毕业率兼容新旧毕业率表。
- 真实装备养成改由明确的“承音”操作完成等级、词条升级和数值截断；不会把自动词条
  升级误判为转律或错误触发冷却。

### ✨ 备战方案与装备管理

- 备战方案新增 PVE/PVP 对战类型；玩法支持名称关键字匹配，智能调律默认排除 PVP
  方案。方案管理改为逐列内联编辑并改善跨用户切换性能。
- 新增“假设视图”：备战方案装备栏和毕业率组合详情可在原始装备与应用满等级、满数值、
  满承音、满定音后的内存副本之间切换，不会回写真实装备。
- 背包装备支持按扫描时间筛选和删除，模拟装备自动排除；历史装备没有扫描时间时使用
  最后更新时间。删除操作继续保护穿戴、方案引用和模拟数据。
- 装备卡片和属性对话框统一双定音切换语义：装备槽只改变当前方案选择，背包区域才改变
  装备自身展示状态。
- 最优组合评级会对确实允许继续转律的装备模拟最佳合法转律，不再因当前可转律词条较差
  而提前丢弃可用装备。

### ✨ 智能调律与 Profile 自动化

- 智能调律向普通用户开放，启用状态按用户和基础规则组分别保存；配置页顶部展示当前
  规则组，运行时冻结该组参数。
- 调律规则与潜力评级理解 115 阶“全奇术增伤”，并按候选目标等级解析玩法必需词条，
  避免跨等级候选被错误判定。
- Profile 数据模型可关联变更脚本；数值落库后异步提交到独立串行队列，不占用用户任务
  锁，并向脚本传入原值、新值、变化量、来源和原始触发 key。
- 变更脚本采用工作流文件选择与语法校验；用户总览仅以状态灯显示队列忙碌状态，不触发
  全页面数据刷新。

### 🔧 修复

- 修复 PC 重启登录误把正常非重启流程带入启动页轮询，以及人工接手提示没有明确账号和
  角色的问题。
- 修复桌面端花蕊织缺少进度读取区域，导致任务无法同步周进度的问题。
- 修复江湖号令完成任务后卡片换位可能漏做任务的问题：识别刷新按钮并在必要时快速补扫
  一轮。
- 修复装备筛选未在启动时恢复、双定音切换目标不一致，以及最优组合忽略合法转律的问题。
- 提高 Android 包裹返回和通用关闭模板的匹配阈值，减少低置信度误点击。
