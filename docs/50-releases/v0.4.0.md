# v0.4.0 — 最优毕业率搜索 + 毕业评估模型升级 + ADB 断连恢复 + DSL 增强

## 律匠 v0.4.0

本版本新增最优毕业率组合搜索引擎，毕业评估模型全面升级（Excel 公式重构 + 满承音/满定音假设），ADB 断连暂停恢复机制，DSL 引擎增加全量匹配与面板范围索引，以及大量 UI 优化与架构重构。

---

### ✨ 新增功能

**毕业率系统**
- 最优毕业率组合搜索：自动搜索最佳装备搭配方案，支持多条件筛选
- 满承音 / 满定音 / 满等级假设选项：评估理想条件下的毕业率上限
- 攻击属性取整 + 装备筛选用户级隔离
- 毕业率 Excel 公式模型重构：穿透抗性转换精确对齐游戏算法
- 调律报告追加结构化 JSON 数据块 + 词条分布分析

**ADB 与设备管理**
- ADB 断连暂停恢复机制：设备断开连接时自动暂停任务，恢复连接后继续执行

**DSL 引擎增强**
- `recognize full by` 全量匹配模式 + `panel range by` 降级策略
- `scan` / `recognize` 支持 panel 范围索引
- 醉意动作实现

**UI 与交互**
- 战斗属性自适应布局优化 + 穿透类数值格式统一
- 脚本配置对话框列宽自适应，Profile 及装备 UI 优化
- 战斗属性展示模式规范化 + 跨线程信号修复
- 装备状态页 DPS / 毕业率状态行 + 配置面板 UI 优化
- 模拟装备功能与装备状态页交互增强
- 新增活动火云场景布局配置

**工作流**
- 登录流程抽离 `login_to_main_page` 并集成战令领奖
- 批处理账号切换解耦 + 导航函数抽取 + 新工作流
- 导航工作流加固与 Profile 系统增强

- 多备战方案架构重构
