# Android 独立任务工作台（0.15.0 目标）

> 状态：已实现（2026-10-11，基线 v0.13.15）

已完成定向回归；目标版本尚未发布。真机游戏流程仍待验收。
配置加载优化属于并行任务；本功能使用既有配置入口，不修改更新包、加载层或发布版本号。

## 交付计划

1. 文档与协议：明确页面、执行/编辑/浏览状态、确认回复和历史归属。
2. 导航与任务中心：工作台、任务、用户、设置；分组/搜索/任务详情，复用参数编辑器。
3. 运行闭环：显式选择执行用户；页面准备任务后回到游戏，由悬浮入口最终启动；
   工作台、悬浮窗、通知共用运行状态；确认与普通暂停使用不同操作。
4. 结果与历史：复用任务历史数据库，记录用户、任务、时间、终态和线程日志；
   进程退出遗留记录标记中断；结果未知时不推断领奖或业务完成。
5. 用户数据与维护：单用户 Profile 分组/数值/变更历史只读；权限、诊断、版本说明、
   公告、反馈联系入口；完成用户指南和定向回归、APK 编译及隔离 UI 验证。

本期不包含多用户队列、切换游戏角色、完整装备管理、规则编辑器、Profile 手动改值或
撤销、PC/手机双向数据合并。Android 独立执行继续保留 Beta 的复杂任务内存边界。

## 页面与状态边界

- 工作台展示实际运行用户、任务、耗时、暂停/确认问题、结束原因与日志；任务启动前
  选择的执行用户是明确操作，浏览其他资料及编辑参数不改变它。
  当前任务采用名称、状态和辅助信息的分层展示；实时日志按需展开。工作台提供并列的
  选择用户/选择任务入口和最新执行记录。选择用户显式修改活动执行用户，执行中禁用；
  工作台选择用户成功后同步任务页的参数用户，选择任务时也带入活动用户；
  不改变资料页的浏览用户。任务及资料页的用户选择和刷新操作在同一行对齐。
  选择入口下方保留启动悬浮窗的主按钮，已开启时提供关闭；执行中禁用关闭，
  暂停与结束仍由当前任务卡控制。首页与维护页共用原有悬浮控制入口。
- 任务列表包含无参数任务，分组/名称/说明来自发现元数据；搜索和分组只影响展示。
  显式准备任务仅选择任务、确保悬浮控制就绪，不自动点击游戏；用户返回游戏后点击启动。
  PC 正在控制、无权限、配置不完整时明确原因，保留修复入口。
- 参数编辑复用已有页面，保存只写当前用户/任务；运行期间保持既有只读和互斥语义。
  任务详情及结果使用带 dp 内边距的 Material 对话框，长内容可滚动；参数编辑页与
  主页面保持一致的水平边距，内容不能贴住窗口边缘。
- 用户页浏览 Profile 不建立虚构业务值；未采集与零值不同；按模型及分组展示，历史分页。
- 设置收纳权限、标定、自检、PC 同步说明、版本、公告和反馈联系；刷新内容不改变任务。

## 运行交互

确认问题有唯一请求 ID、问题文本、确认/拒绝操作；回复必须匹配当前待处理请求，
拒绝返回 False。普通继续不能代替确认，旧按钮/重复请求不能确认后一条问题。
停止始终可以打断等待；拒绝和停止是不同操作。普通暂停保持继续/结束语义。
界面重建从状态快照恢复问题，不另造请求、不自动回复。悬浮窗与工作台响应同一请求。

## 结果与持久化

复用 core.daily_history 的 TaskRunSession/TaskHistoryRepository，设备独立运行有明确来源。
执行用户在开始时冻结；历史归属不随之后的用户选择改变。日志与结果放任务记录自己的
输出目录。历史保存失败要显示原因，不能把失败误报成正常留存，也不妨碍停止任务。
只把本机独立执行的遗留 running 记录标记中断，不修改 PC 下发的历史。
