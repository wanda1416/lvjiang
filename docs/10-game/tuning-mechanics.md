## 燕云十六声调律流程说明

首先，明确当前版本不会支持自动开用户箱子，用户必须主动开箱子并且回收掉完全不需要的垃圾装备后才能执行该程序。


用户配置决定当前调律目标，八个装备部位的哪些部分（武器部位需要考虑勾选的流派）
1. 分别遍历 装备背包 的八个部位，根据传入参数决定是否执行该部位调律，如果不调，直接跳过。
2. 对于每个装备部位，根据传入的 cols 和 rows 来决定当前部位调律策略。（因为需要考虑到不同布局，可能并非固定 3*6）
3. 单个部位遍历策略：
    第一步：对于前 cols 行，直接采用双重 for 循环遍历即可，不需要考虑滚动。每次处理完写指纹到 滚动管理器， write col,row,hash
    第二步：当确定 (cols, rows) 还有装备，意味着装备还有，则需要开始进行滚动步骤。转 5。
4. 单件装备调律策略：
    单件装备需要评估是否需要调律和值得调律。
        对于不需要调律的装备（比如已经满词条，或者初始词条不符合要求的），直接跳过，或者后续决定是否自动回收。
        对于被回收的装备，下一件装备会自动前移到当前位置，前面装备不会变化，不用担心错乱。
    对于需要调律的装备，收集装备信息 和 调律要求 传入单件装备调律模块，执行。 执行完毕后重新读取装备，生成指纹。
5. 滚动策略：
    每次执行 drag grid up 1 滚动，滚动完毕后，通知滚动管理器滚动+1，执行滚动校验操作。
6. 滚动校验：
    读取 grid[1][1] 装备，询问 滚动管理器 滚动情况，根据结果执行 微调，微调后继续重复执行当前判断。 超过 4次 报错结束。
    确定滚动正常后，开始对 cols 行的装备继续进行调律，直到全部结束，将指纹写入 滚动管理器，通知其完成，需要更新状态。

7. 滚动状态判定说明：
1 2 3 4 5 6        实际序列
1 2 3              滚动管理器维护的指纹，下面为实际
  2 3 4        <-  正常情况                        返回 0
  3 4 5        <-  滚动过头，需要 down 0.2          返回 -1
  1 2 3        <-  没有滚动，需要 up 0.2            返回 1

备注：装备指纹生成方式：
    部位 + 等级 + 品阶 + 是否承音 +  ( 词条名 : 数值 )
    比如： 冠胄+110+purple+承音+会意率:6.6+势:72.2+最大外功攻击:114.1+会意率:6.6+劲:72.2:转
    然后对该字符串做 md5 取前8位16进制结果，解析装备信息时直接写入 _extra.hash 字段。









### 鸣金虹·无名 单件装备调律说明

对于一件装备装备，首先判断其品阶，如果是 武器和首饰，非金色的没有调律价值。对于 防具，只有紫色及金色装备有调律价值。
没有调律价值可以直接跳过。

装备判断：
    首先检查初始词条
    对于武器：主武器和副武器
        首选最大外功攻击，次选势。
    对于首饰：环和佩
        只考虑最大外功攻击。
    对于防具：冠胄和胸甲
        只考虑会意。
    对于防具：胫甲和腕甲
        只考虑劲。

当判断装备初始词条符合要求以后，开始进行下一步，进入调律详情页面
注意，对于剑和枪，可能在主武器位置，也可能在副武器槽位，这个不受限制。

装备要求：
    剑：必须有 剑武学增伤。 没有视为不合格
    枪：不需要 枪武学增伤。 有视为不合格
    首饰：必须有 全武学增伤。 没有视为不合格
    冠胄和胸甲：不需要神力词条，但是有 单体奇术增伤可以留着给 PVP 使用，姑且视作有效。
    胫甲和腕甲：必须有 对首领单位增伤，如果是 对玩家单位增效，可以留着给 PVP 和百业战使用，姑且视作有效。

词条选择：
    只考虑以下词条，出现以外词条视为不合格。
        神力词条：   参考上述 装备要求。
        五维类词条： 劲、势 
        攻击类词条： 最大外功攻击、最大无相攻击、最大鸣金攻击。
        三率类词条： 会意率、会心率、精准率
    其中 势 视作 = 0.5 最大外功攻击 + 0.5 会意率。

装备评分：
    势的扣分规则（势 = 0.5 最大外功攻击 + 0.5 会意率，存在价值重叠）：
        非首词条中同时出现势和会意率时，扣分 = 势的条数。
        例如：势+会意率扣1分，势+势+会意率扣2分。
        仅有势或仅有会意率不扣分。
    出现会心率或者精准率扣1分，出现两条直接不合格。
    出现最大无相攻击或者最大鸣金攻击 扣1分。

装备评级：
    对于五个词条，累计后采用扣分制
    传家宝：未扣分，
    合格装备：扣分小于等于1分。
    凑合装备：扣分小于等于2分。
    垃圾装备：出现不合格词条或者扣分大于2分。

调律熔断：
    转律词库（鸣金虹）：最大外功攻击、最大无相攻击（非武器则为最大鸣金攻击）、劲、势、会意率、会心率。
    转律约束：不会与已有非首词条重复，非首词条最多 2 个属性攻击（无相/鸣金）。
    熔断判定：将当前非首词条中最差的一条替换为词库中的最佳词条，重新评级。
    如果最佳替换后仍为垃圾装备，则停止调律。
