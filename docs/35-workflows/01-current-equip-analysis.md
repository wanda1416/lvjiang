# 流程：用户当前装备分析

> 编号：01
> 依赖场景：`bag_equip_detail`、`equip_weapon_detail`、`equip_armor_detail`

---

## 目标

收集用户当前穿戴的 8 种装备的完整数据，包括：
- 4 件武器类：主武器、副武器、环、佩
- 4 件防具类：冠胄、胸甲、胫甲、腕甲

---

## 依赖场景

| 场景 | 用途 |
|------|------|
| `bag_equip_detail` | 背包总览页，定位 10 个装备槽位 |
| `equip_weapon_detail` | 武器详情页，识别 8 个字段 |
| `equip_armor_detail` | 防具详情页，识别 9 个字段（含双基础属性） |

---

## 执行步骤

### 阶段一：扫描背包槽位

1. **截图背包页**
   - 使用 `bag_equip_detail` 场景的区域定义
   - 截图并识别 10 个槽位的状态（是否已装备）

2. **确定目标槽位**
   - 从 10 个槽位中选取前 8 个有装备的槽位
   - 槽位顺序：主武器 → 副武器 → 环 → 佩 → 冠胄 → 胸甲 → 胫甲 → 腕甲 → 弓箭 → 射玦

### 阶段二：逐一识别装备详情

对每个目标槽位执行以下循环：

#### 步骤 2.1：点击槽位进入详情页

```
对于槽位 i（i = 0 到 7）：
    获取槽位 i 在 bag_equip_detail 场景中的区域 (x, y, w, h)
    
    在区域中心附近随机取点击坐标：
        click_x = x + w * random(0.25, 0.75)
        click_y = y + h * random(0.25, 0.75)
    
    执行点击，等待页面加载（约 0.5-1 秒）
```

#### 步骤 2.2：截图并识别（武器类）

**适用槽位**：主武器、副武器、环、佩（i = 0, 1, 2, 3）

```
使用 equip_weapon_detail 场景的区域定义：
    截取当前画面
    识别以下字段：
        - equip_type（装备类型）
        - equip_level（装备等级）
        - base_attr（基础属性）
        - affix_gong/shang/jue/zhi/yu（五词条）
    
    记录到数据结构
```

#### 步骤 2.3：截图并识别（防具类）

**适用槽位**：冠胄、胸甲、胫甲、腕甲（i = 4, 5, 6, 7）

```
使用 equip_armor_detail 场景的区域定义：
    截取当前画面
    识别以下字段：
        - equip_type（装备类型）
        - equip_level（装备等级）
        - base_attr_1（基础属性1，如气血）
        - base_attr_2（基础属性2，如防御）
        - affix_gong/shang/jue/zhi/yu（五词条）
    
    记录到数据结构
```

#### 步骤 2.4：返回背包页

```
执行返回操作（ESC 或点击返回按钮）
等待背包页重新显示
```

### 阶段三：汇总输出

收集完 8 件装备数据后，汇总输出：

```
装备数据 = {
    "main_weapon": { equip_type, equip_level, base_attr, affixes... },
    "sub_weapon": { ... },
    "ring": { ... },
    "pendant": { ... },
    "head": { ... },
    "chest": { ... },
    "leg": { ... },
    "wrist": { ... },
}
```

## 注意事项

1. **随机点击范围**：0.25~0.75 确保点击在槽位中心区域，避免点到边缘或空白
2. **页面加载等待**：点击后需等待详情页完全加载（可通过图像稳定性检测）
3. **返回检测**：返回背包页后需确认已完全加载，再处理下一个槽位
4. **空槽位处理**：如果某槽位无装备，跳过该槽位
