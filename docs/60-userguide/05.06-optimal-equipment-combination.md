# 5.6 计算最优毕业率组合

最优组合搜索从八个槽位分别选择一件候选装备，对完整组合计算毕业率，返回当前输入条件下的前五名。它比较的是完整公式结果，而不是简单累加装备评分或单件评级。

它是 **「毕业率分析」对话框**的第一个页签；同一对话框还有转律建议、培养建议、词条收益率三页
（见 [5.4](05.04-base-attributes-and-graduation.md)）。主页面顶部的「最优组合」「转律建议」「培养建议」
三个按钮只是入口，分别打开对应页签。四页共用对话框顶部的一条**计算假设栏**：

- 假设栏是打开时从备战方案面板复制的副本，可以随意改动试算，**关闭对话框即丢弃，不会写回
  备战方案**；
- 各页只在点击本页的「开始搜索 / 计算」时读取假设并计算；切换页签或改动假设栏不触发计算；
- 假设栏改动后，已有结果会标注“计算假设已变化”，不会自动重算也不会清空；
- 上次的搜索结果按“用户 + 备战方案”各保留一份，再次打开对话框直接回填，重新计算时覆盖。

---

## 搜索前置条件

开始前应确认：

1. 当前用户和备战方案正确；
2. 主副武学已经解析出流派；
3. 战斗属性区已经选择角色基础属性；
4. 已选择弓玦和毕业率方案；
5. 装备池已经扫描完整；
6. 装备页的等级、词条筛选符合本次搜索目标。

未选择流派或毕业率方案时，系统不会打开有效搜索上下文。

## 候选装备如何产生

点击 **「计算最优组合」** 时，系统读取当前装备页筛选快照，并按八个槽位建立候选：

```text
当前方案已穿戴装备 + 当前用户真实背包装备
  → 主副武器类型匹配
  → 最低等级过滤
  → 已定音/满调律过滤
  → 按指纹去重
  → 流派规则预筛（可选）
  → 用户最终勾选
```

主武器只接收当前流派主武器类型，副武器只接收副武器类型。环、佩和四件防具分别进入自己的槽位，不跨部位投放。

### 模拟装备说明

“排除模拟装备”默认开启，保证真实配装搜索不受假设数据影响。关闭后，已穿戴和
模拟装备池中的模拟装备都会进入候选。

## 搜索窗口选项

页内选项分成“筛选设置”和“计算设置”：前者只决定哪些原始装备进入候选池，后者决定
搜索空间；计算假设不在页内，而在对话框顶部的共享假设栏。

| 选项 | 默认 | 作用 |
|---|---|---|
| 排除模拟装备 | 开 | 不让模拟装备进入本次搜索 |
| 候选评级 | 本流派命中的全部玩法 | 按调律规则的评级预先取消无效候选 |
| 评级 ≥ | 一般 | 装备需至少有一条已选玩法达到要求 |
| 智能分析 | 开 | 删除被同槽其他候选在相关属性上完全压制的装备 |
| 赛季装备假设承音 | 关 | 为本赛季等级的原生装备额外创建同等级承音分支（原装备保留，两个分支一起进搜索）；只将普通词条拉到承音上限，定音保持原值 |
| 弓玦套装 | 继承当前选择 | 可多选会意、精准、会心并分别计算；全不选表示无弓玦 |

「赛季装备假设承音」留在本页而不进共享假设栏：它会产生一个**平行的候选分支**，而共享
假设栏里的满等级／满承音／满定音／模拟转律都是对同一件装备的**原地提升**；备战方案面板
也不暴露它。

共享假设栏（打开时复制备战方案面板的勾选）：

| 假设 | 作用 |
|---|---|
| 满等级 | 把低等级装备基础属性提升到当前赛季最高等级并视为承音 |
| 满承音 | 承音装备词条按承音上限计算 |
| 满定音 | 按当前备战方案玩法把定音按目标满值计算 |
| 模拟转律 | 候选装备上已保存的转律目标按目标词条计算 |

这些假设只影响本次搜索中的虚拟候选，不会改写仓储里的装备原始数据——「应用此组合」
穿上身的始终是**原始装备**，而不是模拟出来的那份。虚拟候选仅参与算分，详情和应用仍
回溯到其对应的背包原装备。

### 候选评级：多选玩法

点击「候选评级」输入框打开玩法选择器，框内用 `/` 分隔显示已选项。

可选的是**全部调律规则下的全部玩法**，本流派命中的排在最前并标注「（本流派）」，
另有全选 / 全不选。打开窗口时默认选中本流派命中的那几条。

选多条是常态。一件装备通常只对得上其中一两套练法，判定因此取各条玩法给出的
**最高**评级——只能选一条规则时，能留下的装备极少。

「评级 ≥」只有顶级 / 优秀 / 一般三档（要求“至少是垃圾”等于没有要求），默认
一般。一条玩法都不勾选时整项不生效，候选全部保留。

评级取的是装备**当前**的实际评级，不是调律潜力。潜力判定会把空词条槽当万能牌
填满、还模拟一次转律，一件只有「最小外功攻击」的胚子照样算得出顶级——那种装备
现在一点用都没有，拿它筛候选只会让搜索围着一堆一词条装备打转。

已选玩法一条评级都给不出来的装备按**垃圾**算，会被取消勾选。规则内部的「跳过」
其实就是品阶无调律价值或没有词条数据，正是垃圾胚子；单独标成「不适用」的话，
一大片垃圾会顶着看不出好坏的标签留在候选里。

因此，如果只勾选了覆盖面很窄的玩法，某些部位可能整槽被清空——搜索会提示缺失
部位并拒绝开始。多勾几条玩法即可。

## 手工确认候选

窗口按八个槽位显示候选。每行包含：

- 勾选框；
- 装备名和等级；
- 已选玩法中给出的最高评级（一条都给不出时为「垃圾」）；
- **单击装备名**弹出详情，包括基础属性、普通词条、定音及上限占比（原为悬停，
  要等系统延迟，逐件比对时太慢）。

开始搜索前，每个槽位必须至少保留一件候选。任一槽位为空时系统会列出缺失部位并拒绝开始。

搜索空间约等于八个槽位候选数的乘积。例如每个槽位 10 件装备，理论组合数是 `10^8`。因此应先使用等级、词条和候选评级缩小候选。

## 智能分析与组合计算

搜索分为四步：

1. 无条件深拷贝每件原装备，构造只用于计算的虚拟候选；
2. 按需增加同等级承音分支，并对虚拟候选应用满值假设；
3. 可选地执行支配剪枝，移除同槽位中被其他装备全面压制的候选；
4. 枚举剩余槽位组合，把角色基础属性、弓玦和八件虚拟装备合并；
5. 应用抗性规则并执行毕业率方案，维护每种弓玦套装的最优结果榜。

智能筛选只移除在当前公式输入维度上没有优势的装备，用于降低组合数量。它不是调律规则，也不会修改装备池。

搜索在线程池中运行，窗口每秒更新已评估数量和搜索阶段。点击“取消”会请求停止：本次搜索的
半截结果**不会**被当成结果显示或写入缓存，上一次完成的结果原样保留；只有新一轮搜索完成才会
覆盖。

## 结果与应用

搜索完成后，每种选中的弓玦套装分别显示最多五组结果，每组包含：

- 排名；
- 毕业率；
- DPS；
- 本条结果使用的弓玦套装；
- 实际影响本条结果的计算假设（琥珀色标签，同一行紧跟弓玦套装）；
- 八个槽位的装备标签，以及相对当前备战方案的换装汇总；
- 同一行的三个动作：“应用此组合”“查看组合详情”“查看战斗属性”。

装备标签逐个部位列出“部位 · 装备名”。**与当前备战方案穿戴不同的部位用强调色
标出并带 ⇄ 前缀**，最前面的汇总标签写明“需更换 N 件”；鼠标悬停在某个强调标签上
会显示这个部位现在穿的是哪件。八件都与备战方案一致时汇总标签显示“与备战方案
一致”。不熟悉自己穿戴的人看这一行就知道应用这套组合后要动哪几件。

标签只有装备名，看不出这套组合凭什么排第一。点“查看组合详情”会跳到第三个
标签页「组合详情 (#N)」，按穿戴装备那套卡片以 4 列 × 2 行铺开八个槽位，词条、定音、
上限占比一览无余；页签标题里的 #N 就是结果列表里的方案编号（每种弓玦套装各自编号）。

点“查看战斗属性”会跳到第四个标签页「战斗属性 (#N)」：用角色详情那套战斗属性面板
（全屏 2×2 四张卡片：攻击 / 判定 / 增益 / 伤害）展示**穿上这套组合之后**的属性。
顶部一行注明方案编号、采用的弓玦套装和毕业率。数值按搜索时的计算假设与该弓玦套装
计算——只有标了“同等级承音假设”的部位才按承音投影——不是穿戴后的实测值；这个
预览面板不会改动备战方案，也不会影响顶部的当前毕业率。

**详情显示的是装备当前的真实数值**，不把虚拟装备伪装成真实装备。每张卡片上方有
固定两行的状态带：第一行是这个部位相对备战方案的变化——“需更换”并注明“当前：xxx”
（要换下的那件）、“新穿戴”（备战方案此部位为空）或弱化显示的“已穿戴”；第二行是
实际影响本条结果的“同等级承音假设”“满承音假设”“满定音假设”“满等级假设”
标签，已经达到目标值、没有发生属性变化的满值选项不会产生标签。两行都固定高度，
空着也占位，八张卡片始终对齐。需要更换的部位卡片边框同时改为强调色。详情顶部标明
本条结果使用的弓玦套装和需更换的部位清单。这一页的卡片只供查看，点击、悬停和右键
都不响应，不会触发备战方案页的部位筛选。

点击应用后，结果中的装备引用写入当前备战方案。写入的是每个虚拟候选关联的
**原始装备**：所有候选在进入计算前都会先复制，计算过程不接触、更不会改写背包
原始数据。公共装备池和其他方案不变，战斗属性及顶部毕业率随后重新计算。

建议先新建一个专门的测试方案再应用最优组合，以便保留原方案作为对照。

## 如何搜索真实最优组合

使用以下设置：

- 角色基础属性来自当前角色同一套面板；
- 弓玦与游戏当前配置一致；
- 排除模拟开启；
- 满承音关闭；
- 满定音关闭；
- 满等级关闭；
- 候选池只包含游戏内仍然存在的真实装备。

此时结果表示已扫描装备池中、在当前毕业率方案下的真实最优组合。它不代表全游戏理论毕业上限，也不包含尚未扫描或已被错误筛掉的装备。

## 如何做养成上限模拟

可以复制当前方案或新建测试方案，然后在假设栏按目标开启：

- 满等级：观察升级装备基础属性后的收益；
- 满承音：观察承音词条成长后的收益；
- 满定音：观察定音拉满后的收益；
- 模拟转律：观察已保存转律目标兑现后的收益；
- 关闭排除模拟装备：允许模拟装备池中的装备参与。

结果应标记为假设毕业率，不要与当前真实毕业率混用。

## 技能轴查看（实验性）

入口在「毕业率分析」对话框的右上角，与任何一页的计算无关。

入口：「毕业率分析」对话框首行最右侧的**「技能轴」**按钮。

毕业率方案只给一个 DPS 数字，看不出伤害来自哪个技能——这些细节在导入 Excel 编译成方案时
就已经丢弃，只能回到原始的**毕业率计算器 Excel**（不是律匠自带的功能，需要你自备计算器
文件）重新读取。点「导入 Excel」选择该文件后，两个页签：

| 页签 | 内容 |
|------|------|
| 伤害来源 | 按技能汇总：类型、命中的轴行数、命中次数、总伤害、占比、单次均值 |
| 轴序 | 按顺序列出竞速轴每一行：技能、次数、类型、伤害 |

只读查看，数值直接取 Excel 已算好的结果，不重新计算、不修改表格内容；因此也**不支持**在
这里编辑技能顺序或倍率去反推毕业率变化。

## 常见问题

| 现象 | 排查 |
|---|---|
| 某部位没有候选 | 检查装备页部位、等级、词条筛选和流派武器类型 |
| 选择规则后候选骤减 | 多勾几条玩法，或把「评级 ≥」降到一般；也可手工重新勾选 |
| 模拟装备没有出现 | 关闭“排除模拟装备”，再检查装备页的等级和词条筛选 |
| 搜索空间过大 | 提高最低等级、限制已定音/满调律、应用流派规则并保持智能分析开启 |
| 应用后毕业率与结果略有差异 | 检查搜索窗口与战斗属性页的弓玦和三个满值开关是否一致 |
| 结果不符合直觉 | 单件评级不是最终 DPS 权重，应核对基础属性、方案和公式基准 |
