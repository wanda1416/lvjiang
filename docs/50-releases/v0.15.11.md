# v0.15.11 — 鸣金·霆与双枪、风沙酒肆夜宿谜影、配置写入纠偏


这一版有两个重点：新增流派「鸣金·霆」与双枪玩法，并把新流派接进毕业率；新增独立脚本「风沙酒肆·夜宿谜影」，桌面端用键盘走位、安卓端推摇杆扫房间，同一个入口。

其余改动集中在「把静默失败改成当场报错」：脚本加载期检查作用域与参数元数据、字段赋值越界直接抛错、游戏配置保存只写真正变化的文件。

> **基线说明：** 本版相对 **v0.15.10**。v0.15.10 的代码已在 `master`，但该版本没有单独发布 Release（标签未推送），因此从 v0.15.9 升级的用户会在本版一并拿到 v0.15.10 的全部内容；逐条说明见 [v0.15.10](v0.15.10.md)，下面只重申会阻断升级的条目。

## ⚠️ 不兼容变动与升级指引

### 脚本里的 `add()` / `sub()` / `mul()` / `div()` 已移除

- **现象：** 升级后调用这四个函数的脚本在加载时报「未知内置函数」，脚本无法运行。
- **原因：** 它们与文法里的 `+ - * /` 完全重复，变参形式还容易让人误以为能一次连加多值。
- **如何调整：** 换成运算符，如 `$a = $b + $c`。`mod` / `min` / `max` / `abs` 保留（运算符表达不了）。内置函数从 103 个变为 99 个，语法文档已同步。

### 参数 `type` 写错会让脚本加载失败

- **现象：** 参数元数据里写了 `type: int` 之类的非法类型，脚本直接打不开，提示「未知类型 'int'，必须是 select / number / bool / checkgroup / text 之一」。
- **原因：** 过去非法类型被静默丢弃：参数在界面上不显示、批量不注入，脚本里的 `default` 继续生效，用户完全看不到「参数消失了」。
- **如何调整：** 按提示改成合法类型。整数与小数统一用 `number`；`int` / `float` / `string` 都不是合法值。

### 过程中读取未声明的变量会在加载期报错

- **现象：** 脚本加载失败，提示某个变量「没有在本过程赋值、不是形参、也没有 global 声明」。
- **原因：** 这类读取过去恒为 `null`，拼错变量名或漏写 `global` 都静默失效，要等运行到那一行才发现。
- **如何调整：** 按提示补 `global $name` 或在本过程内赋值。确实要从外部拿的变量，在用到它的过程里显式 `global`。

### 字段赋值失败改为报错

- **现象：** `eval $x.y = ...` 遇到非字典根、列表下标、非字符串动态 key 时，直接抛错中断，而不是像以前那样打一行日志、继续往下跑。
- **原因：** 旧值原地不动，脚本看起来像赋值成功，数据却在后面莫名其妙地不对。
- **如何调整：** 按报错提示改：给列表追加请用 `append()`；动态 key 先转成字符串；对非字典值不要做字段赋值。读取路径（`$list[0]`）行为不变。

### 任务不再使用配置快照，改为直接读磁盘

- **现象：** 任务运行期间在别处改了场景、脚本或游戏配置，下一个任务就会读到新内容（以前要重启）；任务里的写盘也真正落到 `config/system` 或 `config/local`，不再写进随任务销毁的临时副本。
- **原因：** 去掉「任务开始时复制整棵配置」的快照机制，避免同一份配置在任务内外出现两个版本。
- **如何调整：** 无需操作。若依赖「任务内改动只在本任务生效」，请改为显式判断后再写。

### 在线配置只在启动读盘前安装

- **现象：** 运行中不再下载或替换 `config/system`，设置里切换「在线配置」也要下次启动才生效。
- **原因：** 运行中替换系统配置会让正在跑的任务读到半新半旧的内容。
- **如何调整：** 切换后重启一次应用。

### 本版同时包含 v0.15.10 的不兼容变动

以下条目在 v0.15.9 上仍然成立，从 v0.15.9 升级的用户需要逐条确认（详细说明见 [v0.15.10](v0.15.10.md)）：

- **登录后不再自动同步**：需要先点一次「初始同步」，之后才恢复增量同步。无需其它操作。
- **初始同步在云端已有数据时会备份并替换本地三件套**：本地 `users/`、`profile.db`、`profile.yaml` 会移入 `config/session/_backup-initialsync-<时间戳>/`，可手工找回。
- **「清除同步」会清空云端**：需要密码确认；清空后回到未建立状态，点「初始同步」重新播种。
- **新实例不再自动创建 `default` 用户**：在「用户管理」创建，或登录后点「初始同步」把云端用户拉回。
- **只读实例禁用账户管理**：同一安装目录的第二个窗口里账户相关入口是灰的；只读实例的其它改动仍会被主实例同步发现。
- **手机端只拉不推定义与快照**：定义在 PC 端改，手机同步时拉取；云端没有快照时提示先在 PC 完成初始同步。
- **头像不再随常规同步自动上传/下载**：本版改为用户管理里的「同步全部头像」按钮，见下方新增功能。
- **会话文件改为首次使用时创建**：`config/session` 下部分文件不再启动即建空文件，无需操作。

## ✨ 新增功能

### 新增独立脚本「风沙酒肆·夜宿谜影」

- 「活动」分组新增可运行脚本：从客栈房间内部开始跑（不需要站在从拾香旁），看到「躺下」触发一次（重复触发会起身）。PC 用 W/A/S/D 扫房间找床边；安卓端推摇杆、每轮右转 45° 扫一圈。
- 多人模式躺下后会等队友都躺下再开始守夜，随后连续接待 5 位访客；默认只放第 2、第 5 位，另有「识别优先」「只看序号」「只信识别」三种判断策略，配合保守放行序号、演练模式、连刷轮数与床位设置。
- 找床、开门、关弹窗、开下一局四个能力按平台拆成 `_desktop` / `_android` 过程，其余逻辑只保留一份；旧的移动端专用入口并入 `android.wf`。
- 目前只实机验证过「只开 2、5」策略，其余策略建议先用演练模式确认。

### 新流派「鸣金·霆」与双枪玩法

- 流派、两门武学（决狱悬锋枪 / 拨山取月枪）、玩法「双枪」、定音词条、套装与会意规则同步登记；web 端与遥测词表已重新导出。
- 转律词条库按调律规则的 `transmute_priority` 排序，与鸣金·虹 / 鸣金·影 一致。
- 110 阶暂无毕业率模型，最优组合页会提示「未找到对应流派的毕业率方案」，不会算错。

### 毕业率支持新流派，不再有平行白名单

- 能否计算改由模型文件自身决定：导入一份模型即生效，不再需要在代码里另加流派名。
- 新增 115 阶「鸣金·霆」基础方案（33 个输入，满值回算 100%，基准 DPS 147337.30）。霆的两门武学暂不在 DIY 计算器天赋表中，按「未建模」登记，属性来源里可见，不会静默按零计入。
- 毕业率转换器不再把模板遗留、本流派用不到的武器增伤行当成导入错误；不认识的简称仍然报错。

### 9 个流派的 115 阶毕业率表格更新

- 新版表格补录未央城 P1 蹊跷（满值「最小外功 / 攻击」+12），基准 DPS 提升 0.08%–0.21%，公式、轴与环境参数未变。属性模型同步登记该地图收集，110 / 115 两条基线期望值随之更新。
- 旧表归档到「过期版本」，被取代的旧模型删除，每个流派每个等级仍只保留一份。鸣金·虹、鸣金·影 没有新版 115 阶表，保持原样。

### 游戏配置可以新增套装

- 攻具 / 防具套装表右上角新增「添加套装」：只填名称，稳定 key 由界面生成（`custom_N`）。名称是可改的展示 label，key 才是配装方案、装备记录与协议引用的身份。

### 帮助菜单新增「赞助」

- 帮助 → 赞助（反馈下方）：微信 / 支付宝收款码并排展示，可刷新、可直接打开站点赞助页。二维码按需下载并缓存在系统临时目录，换码不需要发版；一张都取不到时会直接给出「打开赞助页面」的出口。

### 头像同步改为手动按钮

- 用户管理对话框底部左侧新增「同步全部头像」，仅登录后可见，只读实例不显示。
- 双向合并：本地有云端无则上传、云端有本地无则下载、内容相同跳过、两边都不同按修改时间裁决；单张上限 1 MB，不做删除同步。

### 本版同时包含 v0.15.10 的新增功能

初始同步与数据同步页、账户自助服务（导出 / 清除 / 注销）、云端被清空后自动复位、文档增量同步（按修订号）、离线包可声明不携带总览数据。详见 [v0.15.10](v0.15.10.md)。

## 🔧 修复

- **赛季上半结束日期写错一天：** 南吕相和上半 42 天，最后一天是 11-05；原值写成 11-06（下半开始日），会让上半 / 下半判定整体晚一天。
- **游戏配置保存误报「磁盘配置已更新」：** 编辑基线只在进程首次读取时记录，对话框打开时虽已读到最新内容，保存却仍拿启动那一刻的字节比对。现在打开与撤销时对齐基线，打开之后发生的真实并发写入仍会被拦下。
- **只改一个领域却写七份配置：** 保存过去无条件写七份文件、每份单独做并发检查，改词条别名也会因另一个文件被别的窗口保存而整次失败。现在只写业务内容真正变化的文件。
- **扫描备战方案因形近字整条跳过：** OCR 把「拨」读成「拔」时，与本地武学的逐字比较失败，方案被跳过且日志看不出差异。现在按配置武学表做唯一匹配纠正，纠正不了会报出原始文本，真不一致时打印两边值。
- **定音词条漏识别：** 装备词条清洗组补「拔山取月 → 拨山取月」，并把方案名列表也纳入该清洗组，识别与写入使用同一份名字。
- **定音简称缺失：** 斩雪刀法 / 悬锋取月的「派生技定音」补进简称表。
- **空区间被当成错误：** `[10...5]` 过去记 error 日志，而 `range()` 同样情形返回空列表。现在两者一致空转；三个系统脚本改用区间语法。
- **安卓端找床冲过头：** 前进止点与右后斜移的偏移量收紧，并关掉拖拽端点随机抖动，走位距离可校准。
- **周期重置被计入上行：** reset 留在本地历史，不再进入上传与待上行计数；回放配额时上一周期的增量直接丢弃。
- **同步：旧账挡住新修改：** 早于快照的账本记录跳过并计入结果，其后的新修改照常入库；跟随必须带上用户确认的动作，未确认不剪切本地。
- **同步：初始同步播种 / 跟随不完整：** 没有快照时先占锁，空总览也能建立水位为 0 的第一份基线；已有快照时确认框写出来源、时间与条目数，失败会把本地文件搬回。
- **本版同时包含 v0.15.10 的修复清单：** 全新实例拉不到用户、本地 `profile.yaml` 缺失不拉取、名册缺文件时上传空资料、云端定义被旧版本回推、便利贴重复上传、总览快照落地慢、文档与头像逐份请求慢、桌面端凭据降级。详见 [v0.15.10](v0.15.10.md)。

## 📦 重构

- **任务配置快照整体移除：** 不再复制整棵配置、不再创建 `.task` 代次目录；`get_resolver()` 固定返回进程单例，引擎在任务起点清空读取缓存；批量任务与各配置单例不再按快照另建实例。
- **夜宿谜影按环境拆分：** 平台相关能力按 `_desktop` / `_android` 分发，其余过程只保留一份（细节见「新增功能」）。
- **二维码缓存移到临时目录：** 临时目录优先、`config/session` 兜底，两者都不可写时只在内存里用；下载、体积上限与图片头校验抽成共用模块，赞助收款码与交流群码共用一套规则。
- **游戏配置保存**：只写变化文件并返回写入列表，测试同时钉住「顶层键必须登记归属」。
