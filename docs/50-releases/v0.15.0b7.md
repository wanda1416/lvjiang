# v0.15.0b7 — 出装搭配等级解绑与设备重连修复（Beta7）

本版本是 0.15.0 的第七个测试包，在 [Beta6](v0.15.0b6.md) 基础上调整出装搭配的等级口径与
搭配标识，并修复设备重连后批量任务被中断的问题。供手动下载测试，不替换当前正式版 0.13.15，
不向普通客户端提示更新。

## ⚠️ 不兼容变动与升级指引

- **出装搭配不再绑定装备等级与弓玦等级。** 现象：搭配编辑器和玩法配置列表不再出现等级，
  导入备战方案时按你当前可用的世界等级生成八件模拟装备；同一套搭配在不同账号或不同
  世界等级下导入，装备等级不再相同，原来「搭配等级高于当前世界等级」的拒绝提示一并消失。
  原因：等级是模拟计算器的运行参数，不是搭配内容，搭配只描述词条、套装与弓玦套装。
  如何调整：无需操作，旧搭配文件里遗留的等级字段在读取时被忽略，文件照常加载。
  需要按固定等级评估同一套搭配时，在模拟计算器里选择装备等级即可。
- **新保存的搭配改用无含义 ID，文件名即 ID。** 现象：本地新搭配文件名形如
  `0cae52170e954021.yaml`，改名不再改文件名，文件名里也不再出现名称或拼音；
  已有文件保持原文件名。原因：稳定 ID 与展示名分离，路径不随展示名变化。
  如何调整：无需操作，旧文件继续按原文件名读取。注意本版保存过的搭配文件不再写等级字段，
  回退到 Beta6 或更早版本将无法加载这些文件，确需回退请先备份。
- **系统预置搭配由 1 套扩充为 21 套，文件名全部更换。** 现象：游戏配置「玩法配置」页新增
  20 条流派目标预置，原「满值搭配」按新格式重出，旧的预置文件名不再存在。
  原因：预置按新 ID 与格式重新生成。如何调整：安装器和 APK 升级会自动替换 `config/system`，
  无需操作；便携版必须解压到新目录。你若曾把旧系统预置另存为本地搭配，本地文件与名称
  不受影响，仍可继续使用。
- 便携包解压到新目录，再复制个人 config/local 和 config/session，保留新包 baseline.json，
  跳过旧 content.json 与 config.lock。在线配置按 0.15.0 系列匹配，
  本包更新状态独立位于 updates/v0.15.0b7，不复制其他 Beta 的更新状态。

## ✨ 新增功能

- 出装搭配编辑器明确分为两行：名称、保存位置、弓玦套装、承音数值属于写回搭配的数据；
  装备等级、弓玦等级与毕业率只影响本次计算，界面直接提示运行参数不会写进搭配。
- 新增 20 条流派目标预置搭配，导入与模拟按用户当前可用等级实例化，同一套搭配可跨等级复用。
- 玩法配置列表用「词条搭配」列替代原等级列，以简称压缩整套词条；名称、词条数、弓玦套装、
  保存位置按内容宽度排布，末列占剩余宽度。
- 玩法配置列表右键「更改玩法类型」可把搭配改挂到武器体系相同的另一玩法，武器不符的玩法
  在菜单中禁用并说明原因；编辑器的搭配下拉先列当前玩法的搭配，再列同流派其它玩法并标注玩法名。
- 词条别名词表补充大／小属攻、气血、外防、会心、会意等简称，用于「词条搭配」列的压缩描述。

## 🔧 修复

- 修复设备重连换绑后，正在执行的任务被误判失败、批量随即跳到下一个任务的问题。
  重连换绑后旧连接仍被在飞命令持有，其恢复回调指向已释放的界面对象，命令重试成功时
  这次正常恢复也被记成任务失败；现在重连后回调改指新连接，恢复与断线通知的异常不再冒泡
  成命令失败，断线通知只更新真正断线的设备，不会用旧设备状态覆盖换绑后的新连接。
  结果不确定的动作重连后仍需你点「继续」才会重放。

## 📦 重构

- 出装搭配的词条分配独立成模块，保存、模拟与导入共用同一份白名单与总量规则。
- 导入与模拟统一接收运行时等级：`materialize_build` / `equipment_for_plan` 不再读取搭配内的
  等级，搭配只保留词条与套装。
- 从搭配结构移除 `level` / `gongjue_level` 字段及相应校验路径。
