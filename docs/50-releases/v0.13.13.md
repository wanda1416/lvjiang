# v0.13.13 — Android 独立执行 Beta、属性来源与自动化稳定性

发布日期：2026-10-07。以 v0.13.12 正式标签（`64a85421`）为基线。

## ⚠️ 不兼容变动与升级指引

### Android APK 独立执行为 Beta，复杂任务仍可能导致游戏被系统 kill

- **现象：** 手机可以独立执行任务，但复杂任务可能使设备内存不足，游戏进程被系统 kill（结束）；独立执行目前不能保证复杂任务或长时间运行稳定。
- **原因：** 本轮已优化手机 OCR 和截图的内存占用，但**尚未解决复杂任务可能导致游戏因内存不足被系统 kill 的问题**。
- **如何调整：** Android APK 独立执行能力按 **Beta** 使用。出现游戏被系统结束时，请停止手机任务并保留诊断信息；需要稳定运行复杂任务时，优先使用 PC 执行。Beta 标记针对手机独立执行，不改变 PC 自动化与既有手机辅助通道的定位。

### PC 与手机请一起升级；配置同步为单向覆盖

- **现象：** PC 与 APK 版本不一致时无法同步；同步会替换手机数据库，手机结果不会回传电脑。
- **原因：** 手机新增独立参数和用户管理，运行配置与 PC 同步历史分开记录；同步包要求两端运行版本一致。
- **如何调整：** PC 与 APK 同时更新到 0.13.13。同步默认保留手机任务参数与手机独有用户，取消勾选才用 PC 覆盖这些内容；**手机数据库（含 Profile 和任务／调律历史）仍会被替换**，同名用户的其他资料仍取 PC 值。APK 升级仅更新官方预置，保留手机个人配置与数据库。电脑向手机下发配置需要 Lv1，手机使用已有配置独立执行不增加此限制。

### 心法模型改用实际心法名称与满重数据

- **现象：** 属性配置中部分旧心法名称不再出现，原先集中在“心法-diy计算器”的属性改为归属实际心法。
- **原因：** 名册与静态满重属性统一以 DIY 计算器为依据，移除重复来源配置。
- **如何调整：** 使用新名册重新核对四个心法槽，例如“苦四时”改选“四时无常”。当前模型保证六重累计口径；没有明确逐重依据的低重数仍为待填，不能把它当作零属性。已存用户基础属性不会自动重写，需要重新推导时请核对后保存。

### 威威大王规则评价与转律优先级调整

- **现象：** 使用威威大王规则时，一些装备的评价和转律建议会变化。
- **原因：** 规则补齐核心密度、无效词条与会意组合判定，收敛主动转入的词条优先级，并移除规则名称中的 Beta 标记。
- **如何调整：** 自动调律前重新核对规则和保留范围。自定义过 `huixin_modao` 的用户请手动同步对应本地覆盖；完整规则见 [威威大王调律规则](../10-game/10-tuning-rules/06-weiwei-dawang.md)。

### 日志与结果增加日期子目录

- **现象：** 新日志、批量报告、调律文档与结果 JSON 保存到原目录下的 `YYYY-MM/DD` 子目录。
- **原因：** 高频产出按任务启动日期归档，跨午夜任务仍属于启动当天。
- **如何调整：** 任务历史展示和打开无需调整，旧记录与旧文件保持原位。自行读取这些目录的脚本请改为递归查找。APK、图片和视频不纳入本轮日期归档。

### 升级安装与本地覆盖

- **现象：** 便携版就地解压可能留下移动或删除的旧脚本、旧模型；本地覆盖仍可能遮蔽系统修正。
- **原因：** ZIP 不主动清理旧系统文件，`config/local` 优先于系统配置。
- **如何调整：** Windows 便携版解压到新目录，再复制 `config/local`、`config/session`；安装器与 APK 自动更新官方系统配置。自定义过心法、调律规则或相关工作流时，请核对并手动同步本地覆盖。本轮未自动提升任何 `content_version`。

## ✨ 新增功能

- **Android 独立执行（Beta）**：APK 预置官方任务、场景、布局与参照图，首次初始化默认用户和空数据库，无需先从 PC 同步即可配置和启动任务；任务仍须满足自己的游戏数据与页面前置条件。
- 手机提供用户管理与按用户编辑的任务参数，包括自动调律候选设置。悬浮面板支持任务和用户选择、启动、暂停、继续、结束及有界日志；断开 PC 后手机任务可继续运行。
- PC 移动设备窗口默认打开离线任务页；同步下发全部用户资料与任务配置，只需选择一个布局，默认保留手机任务参数。远程启动自动准备悬浮控制，权限或准备失败会说明原因并拒绝启动。
- 战斗属性面板增加「属性来源」链接，逐项查看已存基础属性、弓玦、装备套装、普通词条、定音与装备固有数值，展开查看部位明细，并对照白字合计和黄字生效值；全零属性自动过滤。
- 数据历史支持安全撤销最新的操作或覆写记录，并留下撤销记录；带同步、变更脚本等不能单独撤销的记录明确说明原因。历史来源可单独修正。
- 新连接成功后自动选中新目标；当前方案不支持目标连接类型时自动选择配置完整的兼容方案。各目标保留独立草稿，后台重连不抢占选择，运行中的任务快照不变。
- 新增「刷毒和膏」「刷虎骨酒」任务，支持桌面和 Android 环境；请先阅读任务说明中的站位、技能与输入通道要求。
- 工作流支持 `from last` 显式复用最近截图，关联截图与识别记录；部分页面校验失败会在原有失败处理前保存现场图片，便于定位问题。

## 📦 重构

- 手机 OCR 使用原生识别管线，收紧图像与模型生命周期并补齐截图限流节拍；这些优化**不代表复杂任务内存问题已经解决**。
- 心法配置统一为 38 门实际心法，满重属性各自归属；属性推导中的百分比保留两位小数，其他数值保留一位，比较结果避免科学计数法和负零。
- 高频日志与结果按启动日期分目录保存，历史记录继续引用实际文件路径。
