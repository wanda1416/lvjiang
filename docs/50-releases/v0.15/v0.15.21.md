# v0.15.21 — 场景分组缺陷修复、制作天工道具新脚本与系统脚本分组筛选

本版本以缺陷修复和新脚本为主。修复集中在场景分组的写盘链路（换组、删除场景、分组元数据分层）
与 YAML 落盘口径；新增内容为「制作天工道具」脚本及配套的炼药页场景区域、系统脚本的展示分组
筛选、日常页参数一键恢复默认，以及九种语言的界面译文补全。

工程侧另有热键设置页排版调整与任务诊断落盘能力扩展，默认关闭，不影响既有任务的执行方式。
**仅运行既有任务、且不使用场景编辑器与手机端历史回传的用户，可以跳过本版本升级。**
升级前需确认的内容有五项：八音窍抢购场景换组后的本地覆盖路径（第 1 条）、历史回传的设备勾选
记忆不再沿用（第 2 条）、脚本列表新增分组筛选（第 3 条）、用户模式下系统场景的分组操作入口
禁用（第 4 条）、诊断落盘位置与开关（第 6 条）。

## ⚠️ 不兼容变动与升级指引

### 1. 八音窍抢购场景从资源组迁入活动组

- **现象：** 场景 key 与区域 key 全部不变，脚本、批量配置与任务顺序无需改动。但如果你在
  `config/local` 里覆盖过该场景的坐标或定义（文件放在 `scenes/resource/`、
  `layouts/<布局>/resource/` 下），升级后该覆盖不再生效，表现为坐标回到官方值，或场景读取不到区域。
- **原因：** 分层加载按「目录即归属」定位覆盖文件，该场景的目录已由 `resource/` 迁到 `activity/`，
  旧路径下的本地文件不再被读取。
- **如何调整：** 将 `config/local` 下的 `shop_bayinqiao` 覆盖文件移到对应的 `activity/` 目录；
  若不需要自定义坐标，删除旧覆盖文件即可。

### 2. 历史回传的设备勾选记忆不再沿用

- **现象：** 手机端「历史回传」中按设备记住的勾选项恢复为全选；`config/session/history-transfer`
  目录不再生成，旧目录残留可以安全删除。
- **原因：** 该目录此前只用于「写→读→删」的一次性传输件，长期驻留的只有一项界面勾选状态，
  现已并入 `interface.json` 的界面状态；旧 `preferences.json` 不做兼容读取。
- **如何调整：** 重新勾选一次即可，其余无需操作。

### 3. 脚本列表新增「展示分组」筛选

- **现象：** 日常页脚本下拉下方多出一个分组下拉，首次默认「全部分组」，重启后恢复上次选择；
  按分组筛选只影响列表展示，不改变批量配置、默认脚本与执行顺序。
- **原因：** 官方脚本数量增加后需要按用途筛选，脚本可在 `.wf` 头用 `#% group: <名称>` 声明分组。
- **如何调整：** 无需操作。自写脚本未声明 `group` 时归入「未分组」，照常出现在列表中；
  如需归组，在脚本头部补一行 `#% group: <名称>`。

### 4. 用户模式下系统场景的「更改分组」入口禁用

- **现象：** 用户模式下右键系统场景，「更改分组」子菜单置灰并提示「系统场景不可更改分组」。
- **原因：** 系统场景归属 `config/system`，该层在用户侧只读；此前的入口会在写盘阶段失败或被
  写进错误的分层。
- **如何调整：** 无需操作。需要调整分组时在开发模式的场景编辑器中进行，或把改动放在
  `config/local`。

### 5. 系统配置新增场景、区域与脚本

- **现象：** 新增「制造」场景与「炼药 → 天工道具」视图的三个可点击区域（数量上限、炼药、确定），
  并新增「制作天工道具」脚本；`config/system/scenes/_meta.json` 的内容随官方内容更新。
- **原因：** 为新脚本提供可寻址区域，同时移除此前误写进 system 的地图分组条目。
- **如何调整：** 无需操作。安装器与 APK 会整体清理并更新官方 `config/system`；便携版 ZIP 需按
  「已知限制」解压到新目录。地图分组仍由 `config/local` 提供，本机分组不受影响。

### 6. 任务诊断的落盘改为开关式，产物位置调整为 `logs/diagnostics/`

- **现象：** 诊断窗口新增实时帧轮播与「开始落盘 / 停止落盘」，落盘目录改为
  `logs/diagnostics/` 下按会话新建的独立目录；「同步落盘到 logs」这一单向操作不再存在。
- **原因：** 需要在不中断任务的前提下随时开始与停止采集，并把一次任务的帧固化成可单独取走的目录。
- **如何调整：** 无需操作。该功能仍属开发预览、默认关闭，重启后恢复关闭，仅对下次启动的任务生效。

### 7. 设置对话框关闭前提示未保存修改，保存界面语言后询问是否立即重启

- **现象：** 存在未保存的配置改动时关闭设置窗口，会先询问是否保存；保存界面语言后提示需要
  重启才生效，并提供「立即重启 / 稍后重启」两个选项。
- **原因：** 此前未保存的改动会被静默丢弃，语言修改也会静默延迟到下次启动。
- **如何调整：** 无需操作。选择「稍后重启」不会撤销已保存的语言设置，下次启动自动生效。

### 8. 热键设置页改为对齐网格，「字体设置」更名为「总览设置」

- **现象：** 热键设置页由单列改为多列对齐网格，分组间距与按钮宽度不再随文案长短错位；
  设置页中的「字体设置」入口更名为「总览设置」，字号项文案相应精简。
- **原因：** 热键项数增加后单列表过长，且同一页内混排不同宽度的控件。
- **如何调整：** 无需操作，已绑定的热键与字号取值均不变。

### 9. YAML 落盘口径统一

- **现象：** `config/session/*.yaml` 不再出现「整篇重排但内容未变」的差异。若这些文件此前被
  外部工具按其他风格写过，下一次在本机保存时会按本机口径重排一次，内容与定义不变。
- **原因：** 序列化收敛为单一入口，排版参数只有一处定义；云端定义与离线包仍按原始字节写入，
  检测到风格不一致时只记录一条提示，不改写来源。
- **如何调整：** 无需操作。需要核对时可在仓库内执行
  `python scripts/ci/check_yaml_style.py config/session`。

## ⚠️ 已知限制

- **任务诊断与全任务采集仍属开发预览。** 菜单「任务诊断」默认关闭、重启后恢复关闭，仅作用于下次
  启动的任务；离线工作流模拟只提供源码检出的命令行入口，不随可视化界面发布。
- **便携版 ZIP 升级必须解压到新目录**，再迁移 `config/local` 与 `config/session`（保留新包的
  `baseline.json`，跳过旧的 `content.json` 与 `config.lock`）。安装器与 APK 会自动清理官方内容，
  无需此步骤。
- **「制作天工道具」脚本不做页面判定。** 运行前需手动进入「炼药 → 天工道具」视图并选中目标道具；
  材料不足时脚本仅记录一条警告并结束任务，不会替用户确认「前往获取」。

## ✨ 新增功能

- **制作天工道具脚本。** 采集类单次运行任务：按设定次数（默认 10 次）重复「数量上限 → 炼药 →
  等待结果 → 确定」。点击炼药后先固定等待 5 秒，再最多轮询 20 次确认结果画面，不使用无限循环；
  桌面端的「炼药」与「确定」按界面提示绑定 Space，数量上限仍为鼠标点击。
- **日常页参数一键恢复默认。** 参数行最右侧新增「恢复默认参数」，仅在参数与脚本预置值不一致时
  可用：未使用独立参数时清除该脚本的全局参数（所有共用全局参数的用户一起回到预置值），使用独立
  参数时把预置值写入该用户的独立参数，其他用户与全局参数不受影响。
- **脚本展示分组与日常页筛选。** 系统脚本声明用途分组，日常页可按分组筛选脚本列表；分组只影响
  展示，不参与批量配置与执行顺序。
- **九种界面语言译文补全。** 德语、法语、西班牙语、巴西葡萄牙语、泰语、越南语、俄语、韩语、日语
  的核心界面与插件界面译文补全至与简体中文同量级。
- **设置对话框的保护性提示。** 未保存改动退出提醒、界面语言保存后重启询问，见升级指引第 7 条。
- **任务诊断能力扩展（开发预览）。** 实时帧轮播、临时区防淘汰保活、按会话落盘到
  `logs/diagnostics/`，见升级指引第 6 条。

## 🔧 修复

- **场景「更改分组」与「删除场景」会失败并留下半迁移状态。** 界面弹出「移动失败」或「删除失败」，
  场景定义已写入新分组而坐标仍留在旧分组，下次加载被判为坐标迁错，整个场景不可用；八音窍抢购
  场景曾因此读不到区域。现整段迁移（场景文件、坐标目录、分组元数据）在同一变更批次内提交，
  热重载与迁移守卫只看到终态，删除场景同样按当前状态收敛。
- **场景分组元数据会串层，把本机私有分组写进随包的 system 配置。** 保存分组配置时把「system
  与 local 的合并视图」整份写进 system 层，本机私有分组（例如「地图」）连同其场景被固化进
  `config/system/scenes/_meta.json`，并把这组顺序钉在 system 区间。现按磁盘归属分层落盘，system
  只写 system 归属的分组与场景、local 只写 local 归属的；已误写进 system 的地图分组条目连同其
  定义移除，地图分组继续由 `config/local` 提供。
- **用户模式下场景换组会把坐标写到 system 层，系统场景仍可点「更改分组」。** 坐标文件现按原归属层
  写入与删除，用户模式不再因跨层写盘失败；用户模式下系统场景的分组入口置灰，见升级指引第 4 条。
- **YAML 落盘会出现整篇重排的差异。** `config/session/profile.yaml` 曾出现新增删除各一千余条、
  实质变更仅数条的差异：应用内只有一条序列化路径，但该文件还会被云端定义下行与离线包以原始字节
  覆盖，外部风格写入后下一次本地保存即整篇重排。现收敛为单一序列化入口，并在写入云端定义前检测
  本地风格。
- **任务诊断落盘无法停止、方向键不切帧。** 「同步落盘」为单向操作，开始后无法停止；帧轮播中
  ←/→/Home/End 不生效，按钮样式与主界面不一致。现改为「开始落盘 / 停止落盘」双态开关，补齐帧
  导航与「回到最新」，按钮样式与主界面统一。
- **Android 自动化点击落在悬浮球上会误触暂停。** 手势命中悬浮球区域时，此前按点击下发，触发
  悬浮球的展开或暂停，任务被中断。现改为命中该区域时默认临时穿透悬浮窗。
- **Android 悬浮窗穿透的首次点击会被吞掉，超时后穿透状态泄漏。** 开启穿透后未等待首帧生效即下发
  手势，首次点击无效；穿透超时路径未复位，窗口长期处于穿透状态；展开的悬浮面板窗口不参与自动穿透，
  仍会挡住点击。现等待首帧后下发、显式构造手势包围盒、超时复位，并把悬浮面板窗口纳入自动穿透。
- **Android 执行通道断线重连后会持续提示「设备已被另一条 PC 执行连接占用」或「设备正在执行其他
  任务」，只能重启手机端应用。** 运行中重连会新建一条代理连接并接管执行租约，而卡在恢复等待中的旧
  通道醒来后用自己的连接私自重连、却没有重新申请租约，被设备端判为第二条 PC 连接；不换目标的纯传输
  重连同样不会重新取回租约。现在重连会重新取回租约，租约被占时按客户端身份接管并关闭旧连接。该修复
  需 PC 端与手机端升级到同一版本后生效。

## 📦 重构

- **历史回传的暂存区退出 `config/session`。** PC 端接收包改用系统临时目录，手机端冻结包改用项目根下
  的 `.history-stage-*`，用完即删；按设备的回传勾选并入 `interface.json` 的界面状态，见升级指引第 2 条。
- **YAML 序列化收敛为单一入口。** 新增 `dump_yaml()` 作为唯一排版来源，`save_yaml()` 复用它；新增
  `scripts/ci/check_yaml_style.py` 用于检查与按本机口径改写 `config/session` 下的 YAML。
- **热键设置页排版重构。** 由单列表改为按列对齐的网格布局，控件宽度按最长文案统一计算。
- **任务诊断落盘拆分为独立模块。** 落盘实现从界面抽出为 `task_diagnostics_dump`，与内存环形缓存
  解耦。
