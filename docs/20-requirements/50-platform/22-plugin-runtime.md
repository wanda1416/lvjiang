# 插件与宿主运行边界

> 状态：已实现（2026-10-13，基线 v0.15.0）。

## 需求与边界

- 插件通过类型化宿主运行接口查询目标、检查占用、切换目标、启动工作流与控制任务。
  草稿保存、后台就绪、目标恢复、人工提示与实际运行状态仍由宿主维护。
- 停止断开目标上的任务仍可执行；暂停、恢复要求目标就绪；人工提示未处理时不得恢复。
- AppEvent 是无 GUI 依赖的公共事件信封，业务主题由插件声明，Qt 路由由界面适配。
- 桌面接口由 UI 线程调用；MCP 请求先经队列信号进入 UI 线程。
- 当前接口统一宿主访问入口，不提供对象隔离：运行记录及其 engine/worker 仍是原对象，
  页面查询包含全部左栏控件，调用插件自行筛选自己的页面。

## 验证契约

目标切换不改变默认用户，忙碌目标不能启动新任务；人工提示与断线控制行为保持一致。
重复启动请求不再执行任务；公共契约能在没有 Qt 的执行端导入。
