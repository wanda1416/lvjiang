# 00-调律总说明

本目录按流派拆分调律判定规格，本文档汇总各流派**公共**的规则；流派专属规格见 01-05 各文档。

规格权威来源：`docs/10-game/04-tuning-mechanics.md`。
**该定义将持续频繁更新**，04 变更后须同步本目录文档与判定器代码。

词条简写与标准字段映射见 04 文档「简写与标准字段映射」节；
实现时必须映射为 `config/system/yysls/attributes.yaml` 中 `affix_caps._aliases`
定义的标准字段名，不得使用之外的词条名。

## 一、装备分级

装备分为：**顶级、优秀、一般（即代码中的「能用」）、临时、垃圾** 五档。

总原则：**在保证神力词条的基础上保外功**——攻击词条越多越好，三率尽可能少。
各流派核心攻击：会意 = 大外+势；会心大外 = 大外+劲；会心小外 = 小外+敏。

- 顶级装备：神力词条齐备，核心攻击词条占满自由槽、三率尽可能少
  （无神力槽部位允许 1 条本命率参与顶级，见下）。每个流派每个部位的
  顶级组合基本只有一两种。
- 优秀装备：能用且**无缺陷词条**，只是核心攻击词条未拉满、够不上顶级
  （缺的词条一般可通过转律调出来，**缺词条不算缺陷**——唯一例外见下条的
  外功硬门槛）。
- 一般装备（能用）：出现了**缺陷词条**（非首），或**非首缺外功攻击词条**
  （硬门槛：会意/会心大外流 = 非首必须有 1 条大外，小外流 = 非首必须有
  1 条小外，缺失即能用封顶），有瑕疵但仍非废品。
  缺陷词条按流派定义：会意流 = 会心/精准；会心流（大外/小外）= 势、
  精准+会心（非首）同现；小外流另有 小属攻（本属/外属）1 条。
- 临时装备：用户当前一无所有、急需一件能用的（特殊场景，暂未纳入自动判定）。
- 垃圾装备：硬伤——库外废词条、必须神力缺失、流派不要的神力出现、
  缺陷词条超限（如会意流会心/精准 ≥2、小外流小属攻 ≥2）。

**本命率的部位差异**（本命率：会意流=会意率，会心流=会心率）：

- 无神力槽的部位（如副武器、冠胄/胸甲）4 个自由槽凑不满核心攻击词条，
  非首出现 1 条本命率仍可判顶级；
- 有神力槽的部位（主武器、环佩、胫腕甲）出现本命率 → **优秀封顶**。

调律过程中，不论用户当前穿什么，**优秀和顶级装备一律保留**。
一般而言除小外流外，用户不会穿一身顶级（会出现三率不足），会意和会心大外流
通常需要一半顶级一半优秀搭配。

**跨流派共性保留**：会心和会意流派的好装备有共性，调律中即使当前流派判定为
垃圾，只要任一其他已实现流派判定有价值，也应自动保留（OR 逻辑）。

## 二、品阶筛选

- 武器（主/副）和环佩：非金色的没有调律价值。
- 防具（冠胄/胸甲/胫甲/腕甲）：只有紫色及金色装备有调律价值。

没有调律价值的装备直接跳过。

> 品阶门槛与 PVP 词条等价属于**全局基础配置**，落在
> `config/system/yysls/tune_config.yaml`（引擎读 `TuneConfig`）：
> `quality_thresholds` 按**七部位**（主武器/副武器/环/佩/冠胄/胫甲/腕甲）
> 配置允许品阶；全局默认：武器/环 = 仅金色，佩/冠胄/胸甲/胫甲/腕甲 = 金色+紫色，
> 规则文件可逐部位覆盖（如会意流环 额外放行紫色）；
> UI 在「调律配置 → 基础配置」页编辑。

## 三、首词条判断

各部位模式 `[ ]` 内的**第一个词条即首词条要求**（本目录表格中标注 `(首)`）。
首词条无法通过转律更改；首词条不符的装备由**扫描处置规则**接管
（`tuning_groups/*.yaml` 的 scan 规则表，自上而下首条命中即生效并阻断后续：
如金装可先调满词条再回收、紫装直接回收等；无命中则保留），
不再是早期的简单「跳过」。

注：早期会意流派武器有「次选势」的说法，现已废弃——暂不考虑势开头的武器。

## 四、模式匹配语法

- 一个模式描述一件装备的 5 条词条：第 1 条为首词条（标注 `(首)`），其余 4 条为非首词条。
- `[ ... ]` 框选的是**必选词条**：顶级要求全部出现。其中 **增伤类必选词条缺失 → 直接判垃圾**；
  **非首外功攻击词条（大外/小外）缺失 → 能用封顶**；其余必选词条缺失但无废词条/
  缺陷词条，判为**优秀**（缺的词条可转律调出，不构成缺陷）。
- `A/B` 表示该槽位可以是 A 或 B 中任意一个；`X * N` 表示 N 个相同候选的槽位。
- `可用词条库 * N` 表示从该流派可用词条库中任取 N 条填入 N 个槽位，**允许重复**。
  注意：可用词条库中的必选词条（如大外）必然被必选槽消耗，实际不会出现在可选槽。
- **大无相 在非武器部位表示 最大本属攻击**，即所选流派的最大属攻（各流派文档会指明）。
- 非首词条**不要求顺序**：只要装备的非首词条集合能与模式槽位一一对应，即视为命中。
- 匹配是精确穷举：装备的每一条词条都必须落入模式的某个槽位，不允许多余词条。

## 五、可用词条库与废词条

- **转律优先级**：假定垃圾词条转律后，排除已在 2-5 词条中出现过的词条，
  应假定转为的词条优先级顺序（各流派自有一张表）。列表**按价值降序**。
- **可用词条库** = 转律词库 + 流派补充词条。神力词条（武学增效、奇术增伤、
  对单位增效类）不计入词条库，单独按各流派「神力词条要求」处理。
- 出现可用词条库以外的普通词条即**废词条**，直接判为垃圾装备。典型废词条：
  错位属攻（武器上的属性攻击、非武器上的最大无相攻击）、未勾选流派的属攻、
  库外的小属攻/三率词条等。

### 玩法设定与动态属攻词条

- 规则文件的 `playstyles`（玩法设定）逐条携带 `attr` 字段（玩法属性，候选 =
  属性攻击词组名：通用/鸣金/牵丝/裂石/破竹），代码结构见 `Playstyle`。
- **动态词条（仅非武器部位）**：`最大本属攻击/最小本属攻击/最大外属攻击/
  最小外属攻击` 是规则层固定词汇（归属词条分类「动态类」，不入
  `attributes.yaml`）。判定非武器部位时，装备上的具体属攻以**双重身份**
  参与匹配：字面名 + 动态归类名任一命中即计入（至多计 1 次）。本属 =
  玩法 attr 的最大/最小属攻，外属 = 其余属性的最大/最小属攻（映射由
  `dynamic_affix_map()` 生成）。规则的非武器部位引用动态词条可泛化到各
  属性流派；两重身份均不在词条库的属攻仍按废词条判垃圾。
- **真实属攻词条合法可写**：8 个具体属攻词条在规则任何位置均可字面
  引用（单一流派精确锁属性、混搭流字面匹配均可），编辑器候选与校验
  均不排除；动态词条是泛化写法，两者可共存。
- **无相词条回归字面语义**：最大/最小无相攻击仅武器掉落，规则中只在武器
  部位引用，不再承担「属攻等价目标」角色。武器部位不做动态归类，字面
  无相与动态词条经部位过滤互不干扰（词条库/转律优先级可两者并存）。
- **attr=通用（混搭流）不做归类**：保持字面匹配语义，且含通用玩法的规则
  禁止引用动态词条（此时动态引用是死引用；校验拒绝、编辑器候选不提供）。

## 六、神力词条通用规则

- 部位模式明确需要的增伤词条缺失 → **直接判垃圾**（不走「必选缺失 → 能用」兜底）。
- 流派不需要的神力词条出现 → 按废词条判垃圾。
- PVP 词条（单体奇术增伤、对玩家增效）：勾选「保留 PVP 装备」（`keep_pvp`，
  运行期 session 开关）的流派中视作有效，具体等价处理来自基础配置
  `tune_config.yaml` 的 `pvp` 节（按部位的 `substitutions` 词条替换与
  `add_to_pool` 临时并库）；治疗流派本身即需要这类词条。

## 七、定级流程（通用骨架）

对通过品阶与首词条筛选的装备，按以下顺序判定：

1. 出现废词条（词条库以外的词条，或流派不需要的神力词条）→ **垃圾**。
2. 部位明确需要的增伤词条缺失 → **垃圾**。
3. 缺陷词条超限（流派专属，如会意流会心/精准 ≥2、小外流小属攻 ≥2）→ **垃圾**。
4. 出现缺陷词条（流派专属定义，见第一节），或非首缺外功攻击词条
   （会意/会心大外流=大外、小外流=小外）→ **能用**。
5. 命中部位顶级条件（核心攻击词条齐 + 排除词条未出现）→ **顶级**。
6. 其余 → **优秀**（含非增伤、非外功的必选词条缺失但无缺陷的情况）。

各流派可有专属附加规则（如会意流派的会心/精准数量限制），见各流派文档。

## 八、转律与熔断

- 转律机制：首词条以外的词条可以选择**一条**进行无限次转律。
- 转律约束：不会与已有非首词条重复；非首词条最多 2 个属性攻击；
  转律不产生神力词条。
- 模拟策略（转律优先级驱动的贪心，双向语义）：
  - **转入**：假定得到转律优先级列表中「当前缺失、排位最靠前」的词条后重跑判定；
  - **转出**：在持有的普通词条里转掉「排位最靠后」者（增伤/增效类词条不参与转出）。
  - 空槽同样按转律优先级填入缺失且不与现有 2-5 词条重复的最靠前词条。
- 增伤/增效类词条不进转律优先级：其逻辑固定——部位/玩法所需增伤勾选了即必选
  （缺失 = 垃圾），未勾选却出现 = 垃圾。
- 熔断判定：
  - 替换后可达到「能用」及以上级别 → 继续调律；
  - 替换后仍为垃圾 → 停止调律（熔断）。
