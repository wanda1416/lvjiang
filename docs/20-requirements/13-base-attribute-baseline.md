# 115 阶满养成基础属性基线

> **状态**：基础静态模型已实现，细分来源待后续补充
>
> **数据基线**：`config/local/data/DIY计算器0.10.1.xlsx`

## 1. 目标

属性来源模型应能按流派、四门心法、武备、输出套装和弓玦选择，推导南吕相和赛季
（角色等级 100、装备等级 115）的满养成静态属性。推导口径排除八件装备的 40 条
普通词条，但保留：

- 角色等级、基础天赋、突破和地图收集提供的属性；
- 八件 115 阶金装的固有基础属性；
- 装备叠音和所选输出套装的静态属性；
- 所选心法、武学天赋、武备和弓玦的静态属性。

推导页直接从装备配置取得所选等级八件金装的固有基础值，并把它列为独立来源；弓玦
的类型与等级独立选择，因此 115 装备可以搭配仍为 110 的弓玦。保存给毕业率使用时，
系统会扣回装备固有值和弓玦，继续由实际装备与方案弓玦公共链路叠加，避免重复计算。

## 2. 当前阶段边界

本阶段以表格能够证明的静态总量为准：

- 心法只保证选择六重时的累计结果与表格一致；表格没有提供各重归属，已有可靠重数
  数据继续保留，其余差额集中记为“满重补足”；
- 武学天赋按流派两门武学的累计结果建模，汇总贡献登记在主武学条目，副武学不重复
  计数；
- 牵丝·霖不在表格的武学天赋候选中，保持待建模，不套用其他牵丝流派；
- 表格未提供气血、外功防御、体/御转换等完整生存属性，本阶段不推测；
- 条件触发、叠层、持续时间和技能限定效果不进入静态基础属性。

## 3. 数值所有权

| 数据 | 权威来源 | 处理方式 |
|---|---|---|
| 115 装备基础值 | `game_config/equipment.yaml` | 推导页按八件金装自动聚合 |
| 40 条普通词条 | 实际装备或模拟装备 | 基线场景置空 |
| 角色满养成公共属性 | DIY 计算器 | `attr_model/base.yaml` |
| 突破 | DIY 计算器 | `attr_model/breakthrough.yaml`，单选 |
| 地图收集 | DIY 计算器 | `attr_model/oddity.yaml`，全部累计 |
| 叠音与输出套装 | DIY 计算器 | 合并为一个可选套装来源 |
| 武备 | DIY 计算器 | 通用或按本系选择 |
| 心法 | DIY 计算器 | 四槽选择，六重累计与表格一致 |
| 武学天赋 | DIY 计算器 | 由流派的两门武学自动派生 |
| 弓玦 | 对应等级词条上限 | 类型、等级独立选择；南吕相和实际仍按 110 |

## 4. 验收基线

至少固定一组表格当前保存的选择作为回归靶子：破竹·鸢、扶摇直上、易水歌、
擒天势、断石之构、本系武备、撼天套、110 会心弓玦，八件 115 金装的普通词条为空。

验证时分别断言：

1. 属性来源推导值与表格对应来源相加一致；
2. 推导值包含 `380 / 757` 的固有最小/最大外功，不包含普通词条；
3. 叠音与撼天套只计算一次；
4. 基础穿透保留基础值口径，不把表格的最终抗性值反写为基础值。

实测对照可能尚未满叠音、混穿 110/115 装备或使用 110 弓玦，因此不要求与理论满值
直接相等。对照时应把这些差异作为明确的养成缺口，不能反写成公共模型补足。
