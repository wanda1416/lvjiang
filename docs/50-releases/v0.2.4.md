# v0.2.4 — DSL recognize 富返回值 + 调律自动化增强 + 档案 regen 模型

## 律匠 v0.2.4

本版本重点：DSL recognize 语句新增 `as rich with` 语法支持插件化富返回值；调律流程全面增强（进度信号桥、材料缓存、wait_stable）；玩家档案 regen 模型拆分。

---

### ✨ 新增功能

**DSL 语法**
- `recognize ... as rich $var with func_name`：支持指定内置函数对 base dict 进行 dict→dict 转换
- `if $dict.field` / `if $dict.[key]`：条件语句支持 FieldAccess truthy 检查
- rich dict 扁平化：`label` / `group` / `confidence` / `level_text` / `count_text`

**调律自动化**
- 调律进度信号桥 + 浮动进度对话框
- 自动调律 `wait_delay` → `wait_stable` 替换，支持命名参数
- `wait_stable` 支持 `@命名延迟` 和 `\` 引用
- 调律启动校验失败底部状态栏提示 + 百业场景注册

**玩家档案**
- regen 模型拆分为 realtime / boundary 两种类型
- DSL 内置函数 `profile_get` / `profile_set` / `profile_inc`
- `updated_time` 迁移 v3
- 分钟级 regen 写入语义规范化

**告警与通知**
- 双阈值告警系统（橙色/红色）
- 公共告警通知系统 + DSL `notify` 双重通知
- 告警持久化下沉引擎侧

**场景编辑器**
- 点吸附对齐 + 分组删除修复 + CRUD 确认对话框
- DSL 函数文档拆分与脚本操作增强

**其他**
- 批量执行报告
- 局域网扫描支持取消
- 档案概览右键菜单允许右侧新增列
