# v0.13.15 — 智能调律 Agent 实验接入与自动化提速

发布日期：2026-10-10。以 v0.13.14 正式标签（`94f905cd`）为基线。

## ⚠️ 不兼容变动与升级指引

### 智能调律 Agent 为实验性功能

- **现象：** 「燕云」菜单新增「智能调律」入口，该 Agent 接入功能属于实验性功能，默认关闭，需要 Lv1 激活。
- **原因：** 本机 MCP 接入、分析与任务启动能力已实现，但 WorkBuddy／QoderWork 实际界面接入和真实游戏操作闭环仍待实机验收。
- **如何调整：** 按实验性功能使用，先核对 Agent 生成的配置和执行目标。只有主动启用后，主实例才会在后续启动时自动开启服务；其他实例不能启动同一安装的服务。无需使用时保持关闭，原有手动配置与自动调律入口继续可用。

### 脚本性质由脚本声明决定

- **现象：** 脚本配置分为「日常」「专用」两页，不再通过下拉框覆盖脚本性质；旧偏好中的性质覆盖不再生效。
- **原因：** 参数管理的归属统一由脚本元数据决定，避免展示偏好改变脚本执行语义。
- **如何调整：** 展示勾选、显示名与排序继续保留。确需改变自写脚本性质时，修改对应脚本的元数据声明，再重新加载；专用脚本仍由其专属页面管理参数。

### 手工填写的调律参数采用明确类型校验

- **现象：** 使用字符串代替开关、无效背包位置、不存在的部位、规则组或玩法的手工配置，会在启动前明确报错。
- **原因：** 界面与 Agent 共用任务准备逻辑，启动时冻结同一份有效配置。
- **如何调整：** 正常通过界面保存的配置无需操作。手工配置中的开关使用布尔值，等级与材料数量使用非负整数，背包位置使用两个正整数，并在调律配置中重新选择有效部位、规则组和玩法。

### 日志改为按天归档

- **现象：** 跨日的主日志归入 `logs/logs/YYYY-MM`，旧日志只保留最近 7 天。
- **原因：** 按日轮转和归档，避免主日志持续膨胀。
- **如何调整：** 普通用户无需操作。自行收集日志的脚本需同时检查归档目录；需要长期保留时请在清理前自行备份。

### 升级安装、两端版本与本地覆盖

- **现象：** PC/APK 版本不一致时不能同步；便携版覆盖旧目录可能保留已删除的文件，本地覆盖仍会遮蔽系统配置。
- **原因：** 同步要求两端版本一致，ZIP 不负责清理旧文件，`config/local` 优先于官方配置。
- **如何调整：** PC 与 APK 同时升级到 0.13.15。便携版解压到新目录，再复制 `config/local`、`config/session`；安装器与 APK 按现有升级流程处理官方内容。更新了相关场景或毕业率模型的用户，请自行核对本地覆盖。本轮未自动提升任何 `content_version`。

### Android 独立执行继续为 Beta

- **现象：** 复杂任务仍可能因设备内存不足导致游戏被系统结束。
- **原因：** 本版本未改变 Android 独立执行的稳定性边界。
- **如何调整：** 需要稳定运行复杂任务时优先使用 PC 执行。PC 同步仍会在确认后覆盖手机配置及数据库，不回传手机结果。

## ✨ 新增功能

- **智能调律 Agent（实验性）**：通过本机 MCP 查询用户、装备与方案，进行毕业率和养成分析，生成独立调律配置并启动扫描或调律。AI 设置支持多个外部 Agent、连接名称、导出路径及下载链接；支持 WorkBuddy／QoderWork 的 Streamable HTTP 接入，自动合并导出并保留其他 `mcpServers`。主动启用后主实例自动启动服务，默认端口 18765，可在停止服务后修改。
- **授权配置下发**：客户端支持清单与加密包，通过有效 Lv1 授权获取解密密钥，校验后安装到远端配置目录，保留本地覆盖。需要发布方提供内容服务地址、授权和实际内容；未配置服务时继续沿用公开配置更新。
- **脚本编辑跳转**：在内置脚本编辑器中按住 Ctrl 点击过程调用可跳到定义；外部工作流扩展增加 CodeBuddy 安装支持。
- **调满后回收提速**：按剩余词条数连续点击一键添加，再统一调律和回收，减少每个词条反复等待；原有逐次调律策略保持原行为。该优化已通过自动化回归，真实游戏速度与交互仍待实机复核。
- **工作流解析提速**：切换确定解析方式，并缓存编辑器缓冲区解析结果，减少大型脚本启动、检查、跳转与补全时的重复等待，保持既有 AST 契约。
- **登录更新恢复**：优先识别更新提示，确认后重新启动游戏，按 PC／Android 路径恢复登录页，保留原账号并继续选择角色。
- **毕业率基准更新**：更新 115 级裂石·威基础方案及对应源表。
