# v0.4.2 — 反馈对话框与导航增强

## 律匠 v0.4.2

本版本新增微信交流群反馈入口，增强导航失败处理机制，并扩展背包场景区域。

---

### ✨ 新增功能

- 帮助菜单新增「反馈与建议」入口，弹出对话框展示微信交流群二维码，并提供 GitHub Issue 跳转按钮
- 背包页导航新增二次确认机制：当 tab 识别失败时，通过「整理」按钮区域验证是否到达背包页；确认失败则返回 -1，上游调用方统一传播导航失败
- 背包详情页新增「整理」和「制造」两个可点击区域

---

### 🔧 修复

- 循环购买心法工作流页面校验放宽 OCR 匹配文本，修复因「心得置换」整词匹配失败导致误判未到达的问题（v0.4.1 已存在）

---

### 📦 重构

- 二维码图片统一存放至 `data/image/`，用户文档与应用程序共享同一份资源，消除重复文件
- 道具页导航移除冗余的尾部校验，由二次确认机制统一兜底

---

### 📚 文档

- 用户手册首页添加微信交流群二维码
