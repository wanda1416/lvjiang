# 03-会心小外流调律说明

公共规则见 `00-调律总说明.md`，本文仅列会心小外流专属规格。
规格权威来源：04 文档「会心小外流各部位词条要求」节。

- 必选配置：指定流派（裂石、破竹、牵丝，**可同时勾选**）和玩法。
- 可选配置：保留 PVP 装备（单体奇术增伤、对玩家增效 视作有效）。
- 主武器类型及所需武学增伤由勾选的流派/玩法决定（见 04「各流派需要的武学增伤说明」表）。
- 大本属 = 勾选流派的最大属攻，非武器部位的 大无相 即指它；勾选多个流派时，
  任一勾选流派的属攻均视作大无相；**未勾选流派的属攻为废词条**。
- 小外属 = **非本流派**的小属攻，在小外流中属可用词条（见下节）。

## 一、神力词条要求

- 主武器：必须有对应的主武学增伤，没有视为不合格（缺失直接判垃圾）。
- 副武器：不需要武学增伤，有视为不合格。
- 首饰（环/佩）：必须有 全武学增伤，没有视为不合格（缺失直接判垃圾）。
- 头盔和胸甲：不需要神力词条；keep_pvp 开启时 单体奇术增伤 视作有效。
- 胫甲和腕甲：必须有 对首领增伤（缺失直接判垃圾）；keep_pvp 开启时
  对玩家增效 可顶替该槽位。

## 二、转律优先级与可用词条库

- 转律优先级：小外、敏、大无相、会心。
- 可用词条库：小外、敏、大无相、会心 + 精准、小无相、小外属。
- 注意：小无相、小外属、精准 在库内**不判垃圾**（可命中可选槽），但会被多数部位的
  顶级条件排除，上限优秀。
- 库外词条即废词条，直接判垃圾。典型：**大外、劲、势**（大外系流派的核心词条在
  小外流全是废词条）、会意、未勾选流派的属攻、错位属攻（武器上的大本属、
  非武器上的最大无相攻击）。

## 三、各部位模式与顶级判定

| 部位 | 模式 | 顶级判定（命中模式后） |
|------|------|----------------------|
| 主武器 | [小外(首) + 主武学增伤 + 小外] + 可用词条库 * 2 | 未出现 小无相/小外属/精准 → 顶级，否则 优秀 |
| 副武器 | [小外(首) + 小外 + 敏] + 可用词条库 * 2 | 未出现 小无相/小外属/精准 → 顶级，否则 优秀 |
| 环、佩 | [小外(首) + 全武学增伤 + 小外] + 可用词条库 * 2 | 未出现 小无相/小外属/精准 → 顶级，否则 优秀 |
| 头盔、胸甲 | [会心/精准(首) + 小外 + 敏/大无相] + 可用词条库 * 2 | 未出现 小无相/小外属，且 精准不足两条（含首词条）→ 顶级，否则 优秀 |
| 胫甲、腕甲 | [会心/精准(首) + 对首领增伤 + 小外] + 可用词条库 * 2 | 未出现 小无相/小外属，且非首词条未出现 会心/精准 → 顶级，否则 优秀 |

- 主武器/副武器/环/佩 的顶级条件不排除 会心、大无相（敏、大无相、会心 均可留在顶级可选槽）。

## 四、顶级装备组合参考

- 主武器、环、佩：增伤 + 小外 + 小外 + 敏 + 大无相。
- 副武器：小外 + 小外 + 敏 + 大无相 + 会心。
- 头盔、胸甲：会心 + 小外 + 敏 + 大无相 + 精准/会心。
- 胫甲、腕甲：会心/精准 + 对首领增伤 + 小外 + 敏 + 大无相。

## 五、判定例子

以下词条列表第 1 条均为首词条；示例假定勾选裂石（大本属=最大裂石攻击）。

| 部位 | 词条 | 判定 | 说明 |
|------|------|------|------|
| 主武器（陌刀） | 小外 + 陌刀武学增伤 + 小外 + 敏 + 大无相 | 顶级 | 无排除词条 |
| 主武器（陌刀） | 小外 + 陌刀武学增伤 + 小外 + 敏 + 精准 | 优秀 | 顶级排除精准 |
| 副武器 | 小外 + 小外 + 敏 + 大无相 + 会心 | 顶级 | 顶级不排除会心 |
| 副武器 | 小外 + 小外 + 敏 + 会心 + 小无相 | 优秀 | 小无相被顶级条件排除 |
| 环 | 小外 + 全武学增伤 + 小外 + 敏 + 大外 | 垃圾 | 大外为库外废词条（会心大外流 OR 逻辑下可能保留） |
| 头盔 | 会心 + 小外 + 敏 + 大无相 + 会心 | 顶级 | 会心两条不受限（限制的是精准） |
| 头盔 | 精准 + 小外 + 大无相 + 会心 + 精准 | 优秀 | 精准两条（含首词条） |
| 胫甲 | 精准 + 对首领增伤 + 小外 + 敏 + 大本属 | 顶级 | 大本属即大无相；非首无会心/精准 |
| 胫甲 | 会心 + 对首领增伤 + 小外 + 敏 + 会心 | 优秀 | 非首词条出现会心 |
| 腕甲 | 会心 + 对首领增伤 + 小外 + 劲 + 敏 | 垃圾 | 劲为库外废词条（大外系流派 OR 逻辑下可能保留） |
