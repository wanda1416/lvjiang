# 实例并发与用户占用

> 状态：已实现（2026-11-03 收敛语义）。

## 边界

- 实例锁只回答两件事：
  1. **同一用户不被多实例同时执行或互相覆盖**：用户数据写入复用用户执行占用锁，
     被占用时必须持授权任务上下文；不为资料、装备、便签等文件另建锁。
  2. **只有主实例注册全局热键、启动 MCP 服务**：避免两个实例抢系统热键或端口。
- 只读实例有两个来源：抢占实例锁失败，或命令行显式声明 `--read-only`（后者
  不参与抢占，把主实例身份留给另一个窗口）。
- 除上述两点外，任何实例（含只读实例）都可以修改与保存所有功能：
  共享配置、场景、脚本、批量配置、用户资料、更新安装、离线导入、历史回传。
  并发安全由既有机制保证：`content_version` 基线、跨进程读写锁串行化、
  批量配置的基线检测与覆盖确认、用户 Session 的同字段冲突拒绝。
- 运行中的任务读启动时冻结的配置快照，运行中改配置只影响下一次任务。
- 只读实例的判断结果仅用于热键注册、MCP 启动门禁与标题栏提示，不进入任何
  数据写入路径。

## 验证

验证主实例/只读实例选举、同一用户跨进程占用互斥、崩溃后锁释放，以及
热键与 MCP 的主实例专属门禁。测试仅使用临时目录，不访问真实 Session/Profile。
