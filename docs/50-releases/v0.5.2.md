# v0.5.2 — 设备端代理、屏幕标定、宏录制

## 律匠 v0.5.2

本版本新增设备端代理通道（PC 经律匠 App 截图 + 手势输入）、屏幕标定系统、高精度宏录制，并统一导航流程与鼠标语义。

---

### ✨ 新增功能

- **设备端代理通道**：PC 经律匠 App 使用无障碍截图 + 手势输入，替代 adb shell
  - 无需 root，无需 scrcpy
  - 详见 `docs/30-architecture/04-device-agent-protocol.md`

- **屏幕标定系统**：App 内用参照图 + 地标对齐本机布局画布
  - 设备端屏幕映射 + 准星覆盖层
  - 详见 `docs/30-architecture/32-grammar/07-calibration.md`

- **悬浮球动态开关**：`float_icon` 截图/标定时自动隐藏，避免入画

- **高精度宏录制**：Raw Input 轨迹录制 + 按键/滚轮录制 + 对话框热键

- **F7-F12 可配置全局热键**：设置对话框可自定义快捷键

- **远程公告中心**：App 内可查看远程公告

- **红框标定开关**：可视化调试时显示/隐藏标定框

- **后台模式切换**：任务空闲时允许切换后台

- **click 鼠标按键**：支持指定左/右键点击

- **单点工作流**：新增单点触发型工作流

- **角色属性扫描**：新增角色基础属性扫描场景

- **修炼回收**：新增修炼回收场景与布局

- **装备词条硬约束**：模拟调律时实时红字提示不满足的词条

- **问题反馈入口**：完善反馈规范与二维码

---

### 🔧 修复

- **战斗属性卡片布局**：修复装备详情页布局偏移
- **VS Code 插件虚拟环境探测**：修复项目路径识别
- **滚轮数量语法**：统一 `scroll up/down N` 语义
