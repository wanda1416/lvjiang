# v0.11.1 — 用户级任务参数、批量华瑞制与视觉工作流增强

## 律匠 v0.11.1

> **发布状态：正式发布。发布日期：2026-09-12。** 本文以 v0.11.0
> 发布完成后的代码树为基线。

本版本是 0.11 系列的功能完善与稳定性更新，不包含架构升级，因此版本号按补丁版本
推进至 0.11.1。升级前请特别留意下述数据不兼容变动。

### ⚠️ 数据不兼容变动与升级指引

#### 1. 旧批量配置不会迁移到新的独立存储

- **现象：** 升级后，原先保存在 `session.json` 中的批量配置组、任务勾选和用户勾选
  不会出现在批量任务页面，需要重新配置。
- **原因：** 批量配置改为独立保存在 `config/session/batch.json`，新版只接受带有
  `document_type: lvjiang.batch` 和当前版本号的数据格式，不再读取旧的 Session 节点。
- **如何调整：** 升级前记录现有批量配置；升级后重新创建配置组，并重新选择任务、
  用户、轮次和四个生命周期工作流。旧 `session.json` 不会被自动删除，可用于人工核对。

#### 2. 旧自动调律参数不会迁移，需按用户重新设置

- **现象：** 升级后，自动调律的部位、规则组、开关、调律石检查和滚动策略等设置
  恢复为默认值；不同用户会各自保存一份设置。
- **原因：** 自动调律参数从共享的 `session.json.wf_configs.auto_tuning` 改为保存在
  `users/<用户名>.json` 的 `workflow_params.auto_tuning`，旧数据不再读取且不自动迁移。
- **如何调整：** 升级后逐个选择需要执行的用户，重新核对并保存自动调律设置，尤其
  是已选部位、规则、跳过调律、调律石缓存与最低数量。不要假定旧共享设置仍然生效。

#### 3. 普通任务参数改为按用户保存

- **现象：** 同一任务切换执行用户后会显示该用户自己的参数；未保存过参数的用户使用
  工作流默认值，不再沿用其他用户最后一次设置的值。
- **原因：** 任务参数现已写入各用户文件的 `workflow_params`，避免多账号共用一套参数。
- **如何调整：** 首次为每个用户执行日常等带参数任务前，分别核对并保存参数。

#### 4. 系统 OCR、场景和布局配置有更新

- **现象：** 修改过 OCR 规则、场景或布局的用户可能继续命中本地旧配置，看不到新版的
  模板绑定、区域定位和识别修正。
- **原因：** `config/local` 始终优先于随包的 `config/system`；本版本同时将系统 OCR
  配置由 `ocr_rules.yaml` 整合为 `ocr.yaml`。
- **如何调整：** 未修改过系统配置的用户无需操作。存在本地覆盖时，请手工同步对应
  配置，或备份后删除本地覆盖以采用随包版本。Android `versionCode` 已递增到 43，
  首次启动会重新解压设备端系统配置。

### ✨ 新增功能

- 日常任务与自动调律参数支持按用户独立保存，切换执行用户时自动加载对应设置。
- 批量任务新增独立配置文件、任务与用户勾选、执行轮次及生命周期参数持久化，并加入
  华瑞制准备、单轮收尾和周常工作流。
- DSL 表达式能力统一扩展到赋值、条件、循环、返回、函数参数和容器字面量；`scan` 与
  `find` 增加区域模板绑定、清洗规则和范围索引能力。
- 场景编辑器支持区域模板、引用位置、点击矩形和跨场景引用编辑，识别模板可跟随场景
  与布局解析。
- OCR 配置整合为通用规则，OCR 工具支持编辑、预览并保存清洗配置。
- 远程配置覆盖范围扩展到游戏配置与毕业方案，仍以 `content_version` 严格仲裁。
- 新增鸣金虹驻地独立工作流，并完善 Android 与桌面端的系统场景、布局和模板资源。

### 🔧 修复

- 同一用户被其他进程占用时，任务启动现在会明确拦截并提示。
- 只读实例禁用所有应用级快捷键，避免触发需要写权限的操作。
- 修复 OCR、装备识别、Android 弹窗处理和奖励领取流程中的稳定性问题。
- 修复 Windows 类型检查与跨进程测试的本地化编码问题。
- 修正鸣金虹驻地工作流的页面操作与执行细节。

### 📦 重构

- 批量编排数据从 `session.json` 拆分到独立的 `batch.json`，并增加跨进程写锁与原子写入。
- 自动调律配置、普通任务参数和装备相关运行设置按用户隔离。
- 工作流语法的条件、算术和字面量求值收口为统一表达式模型。
- 视觉识别统一场景区域、布局模板与点击范围的解析路径。

- 补充区域模板定位与图像查找说明。
