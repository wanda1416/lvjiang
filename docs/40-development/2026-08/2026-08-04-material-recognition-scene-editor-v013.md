1. **材料识别 panel grid**：从独立 region 迁移到 panel grid 统一架构。
2. **元数据输入/输出分离**：输入场景（OCR 源）与输出场景（调律目标）分开管理。
3. **DSL where 子句**：支持条件过滤语法。
4. **VS Code 插件分级**：Level 2 基础 → Level 3 语义智能。
5. **布局排序**：保存时按场景定义顺序排序，保证一致性。
