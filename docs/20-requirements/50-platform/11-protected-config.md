# 加密配置下发

> 状态：桌面同步和正式包发布链路已有实现；自动服务地址修正待安装包交付，Android 原生联网入口尚未开放。

有效 Lv1 及以上用户开启在线配置更新后，客户端自动通过现有签名激活码申请加密配置包密钥。
正式内容服务地址随客户端内置，不要求创建地址配置文件，不提供客户端地址覆盖入口。
非 Lv1、无激活码或本机授权已过期时不请求受保护清单或密钥接口，不出现相关提示。
激活码格式、既有离线功能及完全离线开关保持原样。

通用配置的“功能激活”分别展示本地激活与在线会员授权，不能用本地验签通过推断云端有效。
在线状态来自后台会员同步的本次进程检查结果；未检查、正在检查、检查失败、拒绝与通过分别展示。
换码后旧检查结果不得沿用，UI 不同步联网。会员服务拒绝保持 HTTP 403/forbidden，新增 reason
区分未登记、停用、过期、等级不足及包不可用；旧服务未返回 reason 时只能展示“云端拒绝”。
预期跳过在 DEBUG 日志说明原因，不输出激活码或密钥，也不改变原离线功能门禁。

管理工具登记激活码摘要、等级、有效期和启用状态，云端 Worker/D1 据此决定发放密钥；激活码不携带密钥。0.15.0 新协议通过 member/index.json 下发完整密文包，归档于 updates/member，校验后与公开配置合成 system 并即时应用。local 继续优先，当前任务保持快照；不再使用 remote 读取层或 content_version 仲裁。详见[官方配置增量更新需求](14-official-config-publication.md)。

公开与受保护来源共同管理清单，避免相互误删。授权失效或云端拒绝后，仅隔离受保护文件，不修改用户 local。受保护 WF 可按包版本更新，包括覆盖系统同名 WF；公开 WF 的只新增规则保持不变。

包校验覆盖摘要、AES-GCM 认证、云端包版本、客户端版本、路径和解压大小；验证未完成不得提交半包。临时联网失败保留已有内容；云端停用需要再次联网才能获知。已经交付的明文与密钥不可远程收回。

架构见 [受保护配置同步](../../30-architecture/38-platform/06-protected-config.md)，操作见 [用户配置](../../60-userguide/11-protected-config.md)。

验收要求：有效 Lv1 无需地址配置即可请求并下载受保护包；非 Lv1 无受保护网络请求；登记和发布失败可重试且不重新签发；公开清单 304 时受保护包仍可更新；授权失效保留 local；半包不生效；PC 到手机的离线快照保留受保护配置且不传输 PC 激活码。直接云端同步接入现有桌面入口，手机继续使用 PC 离线快照。

## 按客户端版本保留包

受保护清单保留多个完整包。客户端按清单顺序，选择第一个满足最低版本（含）及最高版本
（不含）的包；没有匹配包时不申请密钥。版本区间使用 `[min, max)`，无上限时 max 留空。
发布更高最低版本时，将上一版本包的上限封闭到新版本，保留旧密文、包 ID 和密钥；
同一最低版本更新时替换该区间的包；禁止用更低最低版本覆盖最新区间。
清单修订号与包修订号分离，新增包不会改变旧包的云端修订号。

管理控制台推送页分左右两栏，左栏从线上 site 拉取保护包清单，显示版本区间和包 ID，
提供独立刷新按钮、清单版本和获取时间；拉取失败明确显示失败及旧数据状态。
右栏保留 local 文件选择、最低客户端版本、准备和审核推送。发布成功仅表示 Git 推送成功，
左栏刷新反映实际部署的清单，不使用本地准备快照替代线上结果。

旧安装客户端仅支持单包清单，需要更新到支持版本选择的构建后才能读取多包清单；
本次不改动已发布安装包，也不执行线上包发布。
