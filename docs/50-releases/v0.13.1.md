# v0.13.1 — 备战方案管理、双定音与自动扫描

## 律匠 v0.13.1

> **发布验证进行中。** 以 v0.13.0 正式版为基线；本地全量检查与 Windows
> 发布工作流结果将在完成后更新。

本版本把备战方案提升为可跨用户管理、可从游戏批量扫描的完整数据入口，并让同一件
装备能够同时保存普通定音与止戈定音。批量用户排序、PC 重启登录、基础属性扫描和调律
规则配置也得到增强。

### ⚠️ 不兼容变动与升级指引

#### 1. 方案管理页从培养场景拆为独立场景

- **现象：** 自定义工作流或本地场景覆盖若仍引用 `training_main/fangan`、
  `training_main/fangan_fill`、`training_main/fangan_confirm` 及其方案页区域，升级后将
  无法定位方案管理页；系统预置工作流不受影响。
- **原因：** 方案管理的基底、填充和确认视图已迁入独立的 `training_plan` 场景，避免
  培养主页同时承担多个页面的区域定义。
- **如何调整：** 将自定义引用分别改为 `training_plan/base`、`training_plan/fill`、
  `training_plan/confirm`，并把方案名称、武学、方案列表、使用方案和智能填充等区域
  改为引用 `training_plan`。如果本地覆盖过培养或方案场景，请在场景管理中按新版系统
  定义重新标定；`config/local` 覆盖不会被系统配置自动替换。

其余持久化数据无需手工迁移。旧装备缺少 `dingyin_type` 时按普通定音读取；重新扫描后
会按实际来源写入双定音数据。

### ✨ 备战方案管理与扫描

- 主页面的方案入口收敛为“新建”和“管理”；新增跨用户备战方案管理对话框，可新建、
  删除、排序并编辑方案名称、流派、两门武学与玩法。
- 新建方案会根据流派自动带出两门武学，并按无序武学组合过滤玩法；自定义组合也能从
  方案名称匹配合适玩法，不再把“主/副”位置当成业务顺序。
- 新增“扫描全部备战方案”工作流：读取游戏方案列表，逐套切换并扫描八个装备部位、
  弓玦套装和基础属性，静默写入对应本地方案；可跳过已经存在的方案，便于增量补扫。
- 基础属性改为按“用户名_备战方案名”保存，允许同一玩法的多套方案保留各自属性；
  扫描过程补充右侧属性详情校验、重复文本提前结束和单套失败隔离。
- 方案面板重新整理当前属性、方案和弓玦入口；基础属性编辑器可直接新建属性，并改善
  流派数值区域滚动、输入框宽度和布局对齐。

### ✨ 普通定音与止戈定音

- 同一装备现在可同时保存普通定音和止戈定音，装备指纹保持不变；备战方案按部位记录
  当前使用哪种定音，扫描其他方案不会覆盖已保存的普通定音。
- 装备栏按当前方案显示定音，背包装备按自身展示状态显示；双槽齐全时可直接切换，属性
  对话框同时展示两种定音和当前生效状态。
- 所有装备写入路径统一合并两种定音与模拟转律目标，降低重复扫描造成已有数据丢失的
  风险；装备删除时同步清理方案中的定音选择。
- “养成扫描装备”更名为“养成真实装备”，编辑权限与真实养成规则统一：不可转律或
  不可提升的词条会明确置灰，定音仍可按装备实际状态切换。
- 装备属性对话框新增“引用方案”，可查看当前装备被哪些备战方案使用。

### ✨ 批量执行与登录

- 批量配置可指定一个 Profile 字段及升降序；用户列表新增“指定顺序排序”，按当前用户
  数据生成一次性的实际执行顺序，不改变配置组的初始顺序。
- PC 客户端重启登录改为复用账号选择流程：等待“进入游戏”，选择目标账号后登录，
  返回登录主页并选择角色；运行中的工作流会同步绑定重启后的新窗口。
- 花蕊织等批量任务可结合 Profile 排序优先处理进度较少的用户。

### ✨ 规则、DSL 与界面

- 扫描处理、材料处理和调律处理共用“校验规则”入口，按需展示部位与金/紫品阶的覆盖
  缺口；规则组按系统在前、本地在后排列，并正确保留开发模式选择的保存位置。
- DSL 条件支持字符串 `==` 与 `!=`，便于工作流精确核对 OCR 结果；方案、装备和基础
  属性子过程重新归拢，失败会隔离到当前方案并给出可行动提示。
- 调律规则页、流派配置页和备战方案页统一滚动、标题及表单布局，减少内容闪烁和局部
  滚动造成的窄小可视区域。

### 🔧 修复

- 修复桌面客户端重启后仍绑定旧窗口，导致后续后台输入或截图失效的问题。
- 修复基础属性扫描把百分比重复放大、外功攻击取错生效值、属攻与穿透详情错配，以及
  滚动拼接丢失后段属性的问题。
- 修复从角色页返回时菜单页被误判为主页，导致 Android 批量方案扫描提前结束的问题。
- 修复规则组选择“本地”后仍保存到系统目录，以及规则移动后“全部部位”显示丢失的问题。

### 📦 重构

- 装备写入建立统一合并契约，集中维护双定音、模拟转律目标和来源相关展示状态。
- 备战方案、装备扫描和角色属性扫描的工作流子过程按领域合并，减少单函数文件与重复
  页面导航。
- 角色基础属性解析统一左右区域命名和严格值来源，右侧详情缺失不再以未隔离异常中断
  整个多方案任务。
