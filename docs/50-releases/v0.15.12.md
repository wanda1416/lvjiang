# v0.15.12 — 在线配置后台下载、套装删除与说明更正

> **预发布草稿。** 当前正式版本为 **0.15.11**；本文件描述 0.15.12 的计划范围，尚未定稿，
> 下面的验证项均未开始，不得当作已完成的能力对外说明。

这一版的主体是把在线配置的联网下载从启动同步段移到后台，消除弱网时窗口出现前的等待；
其余是几处用户能直接感知的缺口与说明更正。

## ⚠️ 不兼容变动与升级指引

预计无。定稿前需按 `packaging/readme.md` 的八类来源，对照 `0.15.11..HEAD` 的最终差异逐项确认，
再决定此处写「本版本无不兼容变动」还是补条目。

## ✨ 新增功能

- **在线配置改为后台下载：** 启动不再等下载，窗口立刻出现；下载到的修订在下次启动、
  读取配置之前安装，本次运行不替换配置。设置页显示已下载待安装的修订号。
  边界见[在线配置后台下载与下次启动安装](../20-requirements/50-platform/26-online-config-background-download.md)。
- **游戏配置支持删除自建套装：** 表格上方新增「删除套装」，选中后二次确认；被同一份配置里
  的攻具套装登记为关联防具时，确认框会列出引用者，删除后自动解开这条关联。备战方案与装备
  记录里引用该套装的部位按未知套装处理，不会自动清空。
  新套装编号取当前最大序号加一，不补中间空号（删掉的 key 可能仍留在任务历史和装备记录里）；
  删掉最大编号后新建会复用它。

## 🔧 修复

- **无毕业率模型时不再抛异常：** 例如 110 阶的「鸣金·霆」没有模型，最优组合页过去直接抛
  「未找到对应流派的毕业率方案」，改为空状态提示并说明该流派/阶数暂无模型。

## 📦 重构

- **在线配置下载与安装解耦：** 同步段只保留本地回滚（`recover_installation()`），
  下载进后台线程，候选登记到更新暂存区；`prune_archives()` 把待安装候选算进保留集合，
  否则下次启动会把刚下载的内容当垃圾清掉。会员候选只暂存密文，安装时重新取一次授权
  解密，不把会员明文留在磁盘上。
  （实现细节与线程退出规则见上面链接的需求文档。）

## 📚 文档

- **更正 v0.15.11 说明里两处过宽的说法**（历史发布说明保持原样，以本节为准）：
  - 「下一个任务就会读到新的配置」：只有 `.wf` 脚本正文、YAML 缓存（按修改时间与大小失效）
    和每次开跑前读取的布局会立即生效。场景注册表、游戏配置、调律规则、OCR 清洗组是进程单例，
    不随任务重建；Git 拉取与外部编辑需要界面刷新或重启。
  - 「未建模来源不会静默按零计入」：数值上先按 0 参与求值，同时进入 `unmodeled` 清单并写日志，
    属性来源里可见，由 residual 兜底。
- **补一张刷新语义表**（用户指南）：立即生效 / 需界面刷新 / 需重启三类分别是哪些内容。
- **`AGENTS.md` 2.5 改正**：任务快照只覆盖环境、参数、用户、脚本与执行顺序；配置直接读磁盘，
  进程单例由程序内变更通知维护，并明确不得把任务配置快照重新引入。
