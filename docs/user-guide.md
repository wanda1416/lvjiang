# 律匠用户指南（User Guide）

面向普通用户的操作手册：如何启动程序、连接手机、完成配置并运行自动调律。
工作流 DSL 语法不在本文范围，见 [DSL 语法文档](30-architecture/32-grammar/README.md)。

---

## 1. 准备工作

### 1.1 环境要求

- **电脑**：Windows 系统（投屏模式依赖 Win32 API），Python 3.10 及以上
- **手机**：安装《燕云十六声》，并满足以下任一连接方式：
  - **投屏模式**：PC 端有可截屏、且支持鼠标点击转发到手机的投屏窗口（以 vivo 自带投屏为参考，不绑定特定品牌）
  - **ADB 模式**：手机开启开发者选项中的「USB 调试」（或无线调试）

### 1.2 安装与启动

```powershell
# 克隆仓库后，创建虚拟环境并安装依赖
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e ".[dev]"

# 启动（加载燕云调律插件）
python -m lvjiang -reg yysls

# 或直接用快捷脚本（自动处理 PYTHONPATH）
.\dev.bat
```

启动后进入主窗口「律匠 - 燕云十六声装备调律工具」。程序日志写入
`logs/lvjiang_日期.log`，崩溃现场写入 `logs/crashes/`，反馈问题时可附带。

## 2. 主界面速览

- **顶部菜单**：
  - 「通用」→ 配置管理、用户管理 (F2)、场景管理 (F3)、图库管理 (F4)
  - 「工具」→ 图像识别、脚本录制、脚本配置
  - 「燕云」→ 游戏配置 (F5)、调律配置 (F6)
- **顶部两行**：「当前用户」「当前布局」下拉；窗口/设备选择组（扫描窗口、
  扫描设备、目标下拉、定位/连接按钮、显示预览）
- **左侧 Tab**：「日常」（通用脚本执行）、「调律」（自动调律入口）
- **右侧 Tab**：「运行日志」（实时滚动）、「装备状态」
- **全局热键**：F9 开始执行、F10 停止、F8 脚本录制（须先完成定位/连接）

## 3. 连接手机

两种模式二选一，点哪个扫描按钮就切到哪个模式。

### 3.1 投屏模式（桌面窗口）

1. 用投屏软件把手机画面投到电脑上，确认投屏窗口可见。
2. 主窗口点 **「扫描窗口」**，下拉列出所有可见窗口（格式「标题 (宽x高)」）。
3. 选中投屏窗口，点 **「定位」**。成功后窗口信息变绿字，目标窗口四周出现
   红色边框；运行中边框变绿色。
4. **「后台模式」** 复选框：勾选 = 后台输入（点击不移动你的鼠标光标，
   投屏窗口可被遮挡）；取消 = 前台输入（会真实移动光标）。

> 提示：在「通用 → 配置管理 → 基础配置 → 默认窗口标题」填入窗口标题
> 关键字（如「投屏」）后，以后点「扫描窗口」会自动匹配并定位，无需手选。

### 3.2 ADB 模式（USB / 无线）

1. 手机开启「开发者选项 → USB 调试」，用数据线连接电脑，手机上允许调试授权。
2. 主窗口点 **「扫描设备」**，下拉列出已授权设备（格式「serial (型号)」）。
3. 选中设备，点 **「连接」**。成功后显示绿字「已连接: 序列号 | 分辨率 | 截图方式」。
4. **「流式截图」** 复选框：勾选 = scrcpy 视频流截图（流畅、预览为实时画面）；
   取消 = screencap 静态截图。持久默认值在「配置管理 → 基础配置 →
   ADB 截图方式」设置。scrcpy 不可用时会自动回退 screencap 并在日志提示。

> 想拔掉数据线改无线连接：运行 `python scripts/adb_wireless.py`，脚本会把
> USB 设备切到无线模式并自动连接（要求手机与电脑在同一局域网）。连好后
> 回到主窗口重新「扫描设备」即可。纯 USB 使用不需要这个脚本。

### 3.3 验证连接

定位/连接成功后会自动截取一帧画面。点 **「显示预览」** 展开预览区，能看到
手机画面即连接正常。看到「截屏失败」则检查投屏窗口是否被关闭 / 设备是否掉线。

## 4. 配置

### 4.1 通用配置（通用 → 配置管理）

| 页 | 内容 |
|----|------|
| 基础配置 | ADB 截图方式、窗口输入模式（后台 PostMessage / 光标 SendInput）、默认窗口标题 |
| 输入模拟 | 点击前/后延迟、鼠标移动时长、坐标随机偏移等拟人化参数（每项有「?」说明） |
| 等待参数 | 命名等待参数表（供工作流按 key 引用），可增删改等待范围 |

修改后点「保存」生效。系统默认值随版本分发，你的修改保存为本地覆盖，
更新版本不会丢失。

### 4.2 调律配置（燕云 → 调律配置，F6）

调律行为的核心配置入口。左侧导航：

- **基础配置**：装备等级/品阶等进入调律的全局门槛
- **扫描处理**：进调律前的处置规则表——预期评级达到进入门槛才进调律，
  未达标的装备按规则决定回收 / 保留 / 调满后回收（金装专用）
- **材料处理**：
  - 「大律准石数量检查」：启用检查 + 数量基准 + **「不足时」**下拉
    （跳过该装备 / 结束全部调律 / 询问是否继续——弹窗确认后本次运行不再检查）
  - 「狗粮添加规则」有序表：自上而下首条命中即生效，决定每轮是否加狗粮
- **结束处理**：每轮调律后的决策规则表——继续调律 / 重置调律 / 回收 /
  结束保留。重置调律会清空首词条以外的全部词条，每件装备单次运行只重置一次
- **各调律规则**（分割线以下）：每个规则一项，双击可重命名；内部含规则
  设置（流派 / 玩法）、词条库设置及各部位（主武器、副武器、环·佩等）的
  词条评级配置。左下「＋ 新增规则」创建新规则

> 本对话框**没有保存按钮**：任何改动即时校验，校验通过自动保存生效；
> 校验不通过会提示错误并拒绝保存。

左下「装备调律验证」可打开判定测试对话框，手动输入装备词条验证规则
判定结果，调规则时建议先在这里验证。

### 4.3 游戏配置（燕云 → 游戏配置，F5）

武器类型、词条库等游戏基础数据配置。游戏版本更新新增词条/武器时才需要动。

## 5. 运行自动调律

### 5.1 运行前检查

1. 已完成第 3 节的定位/连接；
2. 手机端游戏**停在背包装备页**（能看到装备列表的界面）；
3. 大律准石、狗粮等材料按需备足（或在材料处理页配好不足时的处置方式）。

### 5.2 选择与启动

切到左侧 **「调律」Tab**：

- **「规则」页**：勾选要启用的调律规则，及每个规则下的玩法（至少各选一个）
- **「部位」页**：勾选要处理的装备部位，支持「全选 / 取消全选」
- **「更多」页**：全局开关（如保留 PVP 装备）与测试选项

点顶部绿色 **「开始调律 (F9)」**。按钮变红色「停止 (F10)」表示运行中；
显示黄色「未就绪」说明还没完成定位/连接。

### 5.3 运行中与结束

- 右侧「运行日志」实时输出每件装备的判定与操作；预览区可看实时画面
- 随时按 **F10** 停止（等待中也能立即打断）
- 结束后生成叙事化的**调律说明文档**：`logs/tuning/调律说明_用户名_时间戳.md`，
  记录每件进入调律的装备的判定依据、每轮结果与最终处置，路径同时打印在日志里

## 6. 坐标校准（何时需要）

内置场景坐标按分辨率自适应缩放，正常情况无需校准。以下情况识别会偏移，
需要重新标注：

- 游戏版本更新导致界面布局变化
- 使用了与内置布局差异较大的分辨率/窗口比例

入口：「通用 → 场景管理 (F3)」打开场景编辑器，框选/调整各界面区域
（需要先完成定位/连接才能截图）。「通用 → 图库管理 (F4)」管理材料模板图。
怀疑识别有问题时，可用「工具 → 图像识别」对当前画面做 OCR 自查。

## 7. 常见问题

| 现象 | 处理 |
|------|------|
| 「未找到可见窗口」 | 确认投屏窗口未最小化；重新点「扫描窗口」 |
| 扫描后「未匹配到关键字」 | 配置管理里的「默认窗口标题」与实际窗口标题不符，改关键字或手动下拉选择 |
| 「未找到 ADB 设备」 | 检查数据线、手机上是否弹出并允许了 USB 调试授权；无线模式确认同一局域网 |
| 「连接设备失败 / 无法获取设备分辨率」 | 重插数据线、手机端撤销后重新授权 USB 调试 |
| 「scrcpy 截图后端不可用」 | 程序已自动回退 screencap，可继续使用；想用视频流可重启程序重试 |
| 预览「截屏失败」 | 投屏窗口被关闭或设备掉线，重新扫描并定位/连接 |
| 识别不准 / 点击位置偏移 | 见第 6 节坐标校准；用「工具 → 图像识别」确认 OCR 结果 |
| 「请先停止当前任务」 | 运行中不能重新扫描窗口/设备，先按 F10 停止 |
| 调律没反应就结束 | 查看运行日志：常见为未选规则/部位/玩法，或材料不足触发了「结束全部调律」 |
