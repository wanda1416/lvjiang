# v0.15.7 — 全局窗口热键、启动前占用预检与定音识别修复

发布日期 2026-10-31。

## ⚠️ 不兼容变动与升级指引

### 破竹·樽 防具定音「悬身断水·浓醺技能增伤」升级后毕业率可能变化

- **现象：** 破竹·樽 防具定音「悬身断水·浓醺技能增伤」此前因词条名带间隔号一直
  识别失败，装备上显示为 <止戈定音>，本版已修复。升级后相关装备的定音统计与
  毕业率会随之变化，并非计算口径变更。
- **原因：** 它是 60 条定音词条中唯一带间隔号的，旧版匹配不做去标点比对，
  整条定音判失败、收益从毕业率里消失。
- **如何调整：** 重扫相关装备即可恢复，无需其他操作。

其余变更均为向后兼容：定音词条更名为无间隔号写法后，识别端对带／不带间隔号的
旧名双向兼容，引用旧名的本地配置无需调整。本版本其余无不兼容变动。

## ✨ 新增功能

### 「最小化 / 恢复窗口」全局热键（默认 Alt+F8）

- 新增 `toggle_window` 热键动作：最小化主窗口后按组合键原地恢复；可在设置页更换修饰键，
  非法写法回退默认，与其余动作键整组查重，撞键则整组回退。
- 该键走 Windows `RegisterHotKey` 原生注册，不依赖 pynput 组合键状态机：Windows 上
  Alt 的释放事件会被系统菜单吞掉，组合键状态机残留一次后该组合永久不再触发，
  原生注册从根上规避。
- 热键设置页新增一行（候选含修饰键），提示按钮移到标题侧，五个下拉框统一宽度。

### 启动前预检设备执行占用

- 手机端仍在执行其它任务时，桌面端启动任务此前要到引擎 `control_begin` 才失败，
  用户看到的是「点下去一闪就结束 + 一行 ERROR 日志」。现在日常 Tab 与插件 Tab
  两条启动路径都在占用本地目标之前先试取一次设备占用（拿到即释放，判据与正式执行
  相同，不会预检放行、真跑被拒），被占用直接弹窗说明原因并中止启动。
- 窗口模式、纯 ADB 输入等无代理能力的后端直接放行。

### 悬浮窗任务列表行尾「⋮」直达参数设置

- 悬浮窗「选择任务」列表每行新增 `⋮` 入口，点开菜单直达该任务的参数设置页，
  无需先选中；底部原有「设置任务参数」按钮移除，选择视图底部只留「返回」，
  并隐藏与「返回」易混的常驻「收起」（返回主面板后恢复）。
- 面板日志由次要灰 10sp 改为主文字色 12sp，叠在游戏画面上可读。

## 🔧 修复

- **本机模拟器多开实例互相覆盖执行目标**：同一镜像克隆出的模拟器实例共享
  `android_id`、`ro.serialno` 甚至 `boot_id`，只按稳定身份算 `target_id` 会让后连接的
  实例覆盖先连接的实例，且旧目标被静默 dispose。现在本机回环地址
  （127.0.0.1 / localhost / ::1 / emulator-XXXX）并入身份哈希，多实例各成一个目标；
  真机不受影响，USB 与无线两条 transport 仍归并为同一目标。
- **定音词条一个间隔号导致整条定音判失败**：60 条定音词条中唯一带间隔号的
  「悬身断水·浓醺技能增伤」统一为无间隔号写法，playstyles、110/115 两份毕业方案
  与统计端词表同步重新导出；定音匹配增加去标点比对，游戏内文本带「·」、配置名不带
  两种写法都能识别。长词条（≥6 字）允许编辑距离 1 的模糊匹配，覆盖 OCR 整字丢失
  （悬身断水浓技能增伤 → 悬身断水浓醺技能增伤）；4~5 字短词条不启用，避免把
  止戈定音与乱码吞进普通定音槽。模糊纠正记 notice + warning 留痕，疑似误读在
  解析器层面立刻 warning，正常数据不再淹没日志。
- **源码安装可能装到不兼容的新版 PyQt6**：非 darwin 平台 PyQt6 约束加上界 `<6.12`，
  避免依赖解析选中尚未兼容的版本。
