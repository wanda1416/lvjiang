# 3.3 图库管理（F4）

入口：「通用 → 图库管理」或按 **F4**。

图库管理用于维护**参考图**（模板图），供图像匹配和 OCR 识别使用。

### 核心概念

| 概念 | 说明 |
|------|------|
| 空间 (Space) | 参考图的顶层分组，不同用途的参考图放在不同空间 |
| 分组 (Group) | 空间内的二级分类（如「装备」「材料」等） |
| 参考图 | 具体的模板图片 |
| 元数据 (Meta) | 参考图的附加信息（标签、备注、自定义字段等） |

### 操作说明

| 操作 | 说明 |
|------|------|
| 导入图片 | 从本地文件导入参考图 |
| 粘贴 (Ctrl+V) | 从剪贴板粘贴截图 |
| 截图 | 直接从当前连接的设备/窗口截取画面 |
| 编辑元数据 | 选中参考图后在编辑区修改 input 字段（标签、备注等） |
| 批量编辑 | 多选后统一修改元数据 |
| 筛选 | 按分组、标签等条件过滤显示 |

### 输入/输出字段

图库严格区分两类字段：

| 类型 | 说明 | 可编辑 |
|------|------|--------|
| input 字段 | 用户维护的元信息（标签、备注、自定义输入字段） | 可编辑 |
| output 字段 | 从图像中 OCR 识别的结果（如等级区域、数量区域） | **不可编辑** |

> output 字段是机器读取的结果，不应手动修改。

### 空间切换

顶部下拉框切换当前激活空间。不同空间可有不同 meta_schema（元数据字段定义），
切换后编辑区和筛选区会自动按新空间的 schema 重建。

### 预置空间说明

系统预置了两个空间，各自适用于不同场景：

| | 默认 | 手游 |
|---|---|---|
| **用途** | 通用参考图匹配 | 游戏内道具/货币识别 |
| **分组方式** | 语义分组（调律材料、货币资产、普通道具、增益道具、装备培养、定音转律） | 桶分组（bucket_0/4/8/C），按 group 字段筛选 |
| **图片来源** | 剪贴板粘贴为主 | 游戏截图为主 |
| **覆盖内容** | 核心调律材料、常见货币、基础道具 | 全量货币类型（含稀有货币）、更完整的道具覆盖 |

**共性：**

- 元数据结构相同：都有「等级」（input）、「等级文本区域」「数量文本区域」（output）
- 都支持按 group 字段进行语义筛选（手游空间虽然目录是桶名，但元数据中仍有 group 字段）
- 参考图格式一致，均可用于图像匹配和 OCR 识别

**如何选择：**

- 日常调律场景使用「默认」空间即可
- 如果需要识别更多货币类型或游戏内道具，切换到「手游」空间
- 两个空间可以共存，工作流中可按需引用不同空间的参考图

## 图像识别工具

入口：「工具 → 图像识别」。

对当前画面做 OCR 自查，验证识别结果是否符合预期。怀疑识别有问题时先用这个工具确认。
