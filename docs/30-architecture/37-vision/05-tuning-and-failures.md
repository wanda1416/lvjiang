# 视觉感知失败语义与能力边界

> 最后更新：2026-10-09（基线 v0.13.14）。

## 匹配与尺寸

模板适配按画布比例缩放，不保证跨布局的 UI 重排仍能匹配。模板阈值、录制画布和搜索区域共同决定命中；扩大搜索区可能纳入邻居。匹配算法见 [模板匹配](03-template-matching.md)。

## 图色与坐标

图色函数的面积、通道差、坐标归一化和方向约定见 [图色算法](02-color-ops-internals.md) 与 [坐标系](04-coordinate-system.md)。正常未命中与结构/配置错误分别处理；不能将低分结果当作已确认命中。

## 证据与一致性

编辑器预览与运行时必须使用同一语义；比较时固定帧、布局、搜索范围、阈值和画布口径。不同帧或配置下的结果不能直接当作算法矛盾。

操作排障见 [图像识别排查](../../60-userguide/03.05-visual-recognition-troubleshooting.md)；历史故障复现和修复笔记见 [开发归档](../../40-development/2026-10/2026-10-09-vision-failure-notes.md)。
