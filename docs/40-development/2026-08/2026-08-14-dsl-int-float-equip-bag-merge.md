## 一、DSL int/float 双类型改造（`5247f6c`）

### 1.1 类型系统

- `number_int` / `number_neg_int` 返回 `int`，不再统一 `float()`；
- 算术类型传播规则：`int + int → int`，`int + float → float`；
- `+` 运算符任一侧为 `str` 时走字符串拼接；
- 循环变量保持原始类型，不再强制 `str()`；
- dict 访问以 `int`/`float` 作 key 时先 `str()` 再查找；
- `_mod` 除 0 场景返回类型不一致问题修复；
- 公共类型转换逻辑提取到 `builtins/_coerce.py` 的 `to_number()`。

### 1.2 装备扫描修复

- 列 2 及以后为空时只 `break` 内层循环，继续扫描下一行；
- 仅第 1 列锚点为空才判定槽位结束（此前逻辑过早终止扫描）。

### 1.3 UI 微调

- 装备面板 `grid_container` 垂直策略改为 Maximum，内容贴顶显示。

### 1.4 文档同步

- `01-basics.md`：类型系统章节拆分 int/float 两种数值类型；
- `02-concepts.md`：Area 章节补充 Panel 简介；
- `06-functions.md` / `06-1-basic-functions.md`：函数签名更新为 `int|float`，运算函数保持双类型语义说明。

## 六、关键设计决策（用户确认）

1. **int/float 双类型**：整数运算保持整数，仅在混入 float 或除法时才转 float，避免精度语义混乱。
2. **装备扫描锚点判定**：以第 1 列锚点是否为空作为槽位结束标志，中间列为空不再提前终止。
3. **装备背包统一视图**：放弃当前/其他装备两个 Tab 的划分，改为顶部槽位 + 底部背包网格的单视图交互模型。
4. **感知指令文档拆分**：scan / recognize / find 拆为独立自包含篇章，概览篇只保留对比与速查。
