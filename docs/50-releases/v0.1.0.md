# v0.1.0 — 首个公开版本：通用视觉 RPA 引擎 + 燕云调律插件

## 律匠 v0.1.0 — 首个公开版本

通用视觉 RPA 引擎，基于「截图识别 + OCR + 模拟点击」实现桌面自动化。当前内置《燕云十六声》装备调律插件。

---

### ✨ 核心功能

**通用引擎**
- 双输入后端：桌面投屏窗口（PostMessage/SendInput）+ Android ADB（screencap/scrcpy）
- 视觉识别流水线：mss/scrcpy 截图 → RapidOCR → 词条解析 → 规则评分
- 声明式场景布局：YAML 定义 Scene/Area/Point，可视化编辑器标注，分辨率自适应
- 工作流 DSL 引擎：自研 `.wf` 语言，支持变量、条件、循环、子工作流、内置函数
- 可插拔识别器：OCR / 模板匹配 / 颜色特征

**燕云调律插件**
- 装备词条解析与品阶评分
- 自动调律工作流：背包滚动遍历 → 装备筛选 → 规则决策 → 模拟操作
- 调律规则配置化：品阶门槛、流派权重、词条上限可配置
- 重置调律冷却期检查

**安卓独立执行端（实验性）**
- 基于 Chaquopy 将核心引擎移植到设备端
- 无障碍服务完成截图与手势注入
- 无需 PC 即可运行（开发中）

---

### 📦 安装与使用

**Windows 用户**
1. 下载 `lvjiang-win64.zip`
2. 解压后运行 `lvjiang.exe`
3. 连接手机（投屏窗口或 ADB）
4. 选择场景、校准坐标、开始执行

**开发者**
```powershell
git clone git@github.com:wanda1416/lvjiang.git
cd lvjiang
pip install -e ".[dev]"
python -m lvjiang -reg yysls
```
