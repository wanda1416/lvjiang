# 5.1 装备数据总览

「备战方案」把游戏里的装备识别结果、手工构造的模拟装备、角色基础属性和毕业率计算放在同一个工作区。它解决的不是“展示背包截图”，而是把装备转换为可以保存、比较和组合计算的结构化数据。

入口：主窗口右侧 **「备战方案」Tab**。

---

## 页面结构

```text
┌──────────────────────────────────────────────────────────────┐
│ 刷新  用户切换  视图切换          最优组合/模拟装备/清空/导出 │
├──────────────────────────────────────────────────────────────┤
│ 备战方案  新建/重命名/删除  主武学  副武学  当前流派          │
├──────────────────────────────────────────────────────────────┤
│ DPS                                      毕业率               │
├────────────────────────────┬─────────────────────────────────┤
│ 战斗属性                    │ 当前方案的八个装备槽位           │
│ 流派/基础属性/弓玦/方案      │ 主武器、副武器、冠胄、胸甲……     │
│ 当前属性与显示选项           ├─────────────────────────────────┤
│                            │ 未穿戴装备网格与筛选器            │
└────────────────────────────┴─────────────────────────────────┘
```

顶部三个视图按钮可以切换为：

- 战斗属性全屏；
- 左右半屏，默认模式；
- 装备面板全屏。

视图只改变显示方式，不改变装备、方案或毕业率数据。

## 四类核心数据

| 数据 | 含义 | 归属 |
|---|---|---|
| 真实装备 | 由扫描工作流识别并写入的游戏装备 | 当前用户 |
| 模拟装备 | 用户手工创建或从现有装备复制出来的假设装备 | 当前用户 |
| 备战方案 | 主副武学、属性、弓玦、毕业率方案以及八个槽位引用的装备组合 | 当前用户下的各方案 |
| 角色基础属性 | 扣除装备和弓玦后的角色自身属性 | 按流派保存，当前会话共享 |

毕业率方案是第五类数据，但它不是角色数据。它来自流派配置中的计算模型，用来把当前战斗属性换算成 DPS 和毕业率。

## 装备池与备战方案的关系

系统为每个用户维护一个公共装备池。真实装备和模拟装备都只保存一份，每件装备通过指纹 `_fp` 唯一标识。备战方案不复制完整装备，而是保存八个槽位对装备指纹的引用。

```text
用户装备池
├── fp_A → 真实剑
├── fp_B → 真实枪
└── mock_C → 模拟环

方案「日常输出」
├── main_weapon → fp_A
├── sub_weapon  → fp_B
└── ring        → mock_C

方案「副本测试」
├── main_weapon → fp_A     ← 同一件装备可以被多个方案引用
└── ring        → 另一件装备
```

因此：

- 从当前方案卸下装备，只会清空该槽位，不会删除装备；
- 删除装备会从公共装备池移除它，并清空所有方案中对它的引用；
- 切换方案不会移动或复制背包装备；
- 其他方案正在使用的装备会在装备卡片上显示备战标记。

## 八个装备槽位

| 槽位 | 数据键 | 说明 |
|---|---|---|
| 主武器 | `main_weapon` | 必须与当前流派主武学对应的武器类型匹配 |
| 副武器 | `sub_weapon` | 必须与当前流派副武学对应的武器类型匹配 |
| 环 | `ring` | 独立候选组 |
| 佩 | `pendant` | 独立候选组 |
| 冠胄 | `head` | 独立候选组 |
| 胸甲 | `chest` | 独立候选组 |
| 胫甲 | `leg` | 独立候选组 |
| 腕甲 | `wrist` | 独立候选组 |

主、副武器共享游戏中的武器背包，但在备战方案中是两个不同槽位。当前流派能明确区分主副武器类型时，穿戴会自动路由；两种武学使用同型武器或流派尚未绑定时，系统会要求手工选择槽位。

## 备战方案与流派

新建方案时必须选择可以匹配现有流派的主武学和副武学组合。系统由这组武学解析流派，并据此确定：

- 主、副武器的合法类型；
- 可选择的角色基础属性；
- 可选择的毕业率方案；
- 最优组合窗口中可使用的调律规则与玩法。

方案支持新建、重命名、删除和切换，但至少保留一个方案。修改主副武学会重新解析流派，
并刷新战斗属性和毕业率。战斗属性区选择的属性、弓玦和毕业率方案分别保存在当前备战
方案中，切换方案会恢复各自选择；流派直接由该方案的主副武学派生。满承音、满定音、
满等级和仅黄字仍是当前用户共享的显示/计算偏好。

## 真实值与假设值

默认情况下，顶部显示的是当前方案的实际装备、当前角色基础属性和当前弓玦共同计算出的结果。

战斗属性区提供三个假设开关：

| 开关 | 作用 |
|---|---|
| 满承音 | 把承音装备的普通词条按承音上限参与计算 |
| 满定音 | 把定音词条按 100% 上限参与计算 |
| 满等级 | 把低于当前赛季最高等级的装备提升基础属性后参与计算 |

只要其中任一开关打开，结果就是养成假设值，不应称为当前真实毕业率。记录真实毕业率时应关闭三个开关。

## 推荐使用顺序

1. 选择正确用户并建立备战方案；
2. 扫描已穿戴装备和背包装备；
3. 在装备面板检查识别结果，必要时复制为模拟装备校正；
4. 选择流派、角色基础属性、弓玦和毕业率方案；
5. 关闭假设开关，确认当前真实 DPS 与毕业率；
6. 使用流派规则筛选候选装备；
7. 搜索并应用最优毕业率组合。
