# 6. 场景管理与图库管理

## 6.1 场景管理（F3）

入口：「通用 → 场景管理」或按 **F3**。

场景编辑器用于定义各界面在手机画面中的坐标区域。内置场景坐标按分辨率自适应缩放，正常情况无需校准。

### 何时需要校准

- 游戏版本更新导致界面布局变化
- 使用了与内置布局差异较大的分辨率/窗口比例

### 界面结构

```
┌──────────────────────────────────────────────┐
│  布局选择 + 截图按钮 + 识别按钮               │
├──────────────┬───────────────────────────────┤
│  场景分组     │  画布（截图底图 + 区域框）     │
│  · 背包       │  · 框选区域                   │
│  · 调律       │  · 拖拽/缩放区域              │
│  · ...        │  · 吸附对齐参考线             │
│              │                               │
├──────────────┴───────────────────────────────┤
│  区域列表：名称 / Key / 类型 / 含文本 / 可点击  │
│  [＋ 创建区域] [删除区域]                      │
└──────────────────────────────────────────────┘
```

### 基本操作

| 操作 | 说明 |
|------|------|
| 截图 | 从当前连接的设备/窗口截取画面作为底图（需先完成定位/连接） |
| 创建区域 | 在画布上框选矩形区域，填写名称、Key、类型 |
| 编辑区域 | 双击区域列表中的行，或拖拽画布上的区域框 |
| 删除区域 | 选中区域后点「删除区域」 |
| 识别 | 对当前画面做 OCR，验证区域坐标是否正确 |

### 区域类型

| 类型 | 说明 |
|------|------|
| text | 文本识别区域（OCR 读取文字） |
| click | 可点击区域（点击操作的目标） |
| 其他 | 由工作流定义的特殊用途区域 |

### 区域属性

| 属性 | 说明 |
|------|------|
| 名称 | 中文显示名 |
| Key | 英文标识符（不可与同场景下其他区域/点/面板重复） |
| 含文本 | 勾选后该区域参与 OCR 识别 |
| 可点击 | 勾选后该区域可作为点击目标 |

### 视图管理

同一页面可能有多个滚动态（如背包的不同页），场景编辑器支持**多视图**：

- 视图用于把同一页面的多个滚动态分屏排布，避免坐标叠在一起
- 入口：场景编辑器内的「管理视图」按钮
- 选定视图时只展示该视图自身的定义，选「全部」才展示所有视图

### 尺寸信息栏

编辑器底部显示当前截图尺寸/比例和画布相对截图的坐标尺寸/比例，
方便确认缩放关系。

## 6.2 图库管理（F4）

入口：「通用 → 图库管理」或按 **F4**。

图库管理用于维护**参考图**（模板图），供图像匹配和 OCR 识别使用。

### 核心概念

| 概念 | 说明 |
|------|------|
| 空间 (Space) | 参考图的顶层分组，不同用途的参考图放在不同空间 |
| 分组 (Group) | 空间内的二级分类（如「装备」「材料」等） |
| 参考图 | 具体的模板图片 |
| 元数据 (Meta) | 参考图的附加信息（标签、备注、自定义字段等） |

### 操作说明

| 操作 | 说明 |
|------|------|
| 导入图片 | 从本地文件导入参考图 |
| 粘贴 (Ctrl+V) | 从剪贴板粘贴截图 |
| 截图 | 直接从当前连接的设备/窗口截取画面 |
| 编辑元数据 | 选中参考图后在编辑区修改 input 字段（标签、备注等） |
| 批量编辑 | 多选后统一修改元数据 |
| 筛选 | 按分组、标签等条件过滤显示 |

### 输入/输出字段

图库严格区分两类字段：

| 类型 | 说明 | 可编辑 |
|------|------|--------|
| input 字段 | 用户维护的元信息（标签、备注、自定义输入字段） | 可编辑 |
| output 字段 | 从图像中 OCR 识别的结果（如等级区域、数量区域） | **不可编辑** |

> output 字段是机器读取的结果，不应手动修改。

### 空间切换

顶部下拉框切换当前激活空间。不同空间可有不同 meta_schema（元数据字段定义），
切换后编辑区和筛选区会自动按新空间的 schema 重建。

## 6.3 图像识别工具

入口：「工具 → 图像识别」。

对当前画面做 OCR 自查，验证识别结果是否符合预期。怀疑识别有问题时先用这个工具确认。
