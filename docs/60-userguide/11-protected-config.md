# 受保护配置

有效 Lv1 及以上授权开启在线配置更新后，会自动检查并获取作者发布的受保护配置。
内容服务地址由客户端内置，用户无需创建 JSON 文件、填写地址或配置 Token。
已有激活码无需更换，但需要作者已将其登记到内容服务。

下载成功后下次启动生效。自己的 local 配置保持优先。新场景和布局需与其工作流一同由作者发布。

未达到授权等级的用户不会请求受保护服务，也没有额外提示。未登记、已过期或被云端停用的码无法获取密钥；可联系作者检查登记状态。临时断网时保留此前下载且本机授权有效的内容；已停用授权需联网后才能确认。

离线激活原有功能保持不变。关闭在线配置更新会沿用现有行为，清除下发内容、回到系统配置；不会删除 local。作者撤回的受保护文件会在后续同步时移除。新下载与撤回结果仍按下次启动生效。

详情见 [需求边界](../20-requirements/50-platform/11-protected-config.md)。

旧版安装程序若仍要求手工配置服务地址，需要更新到包含此修正的客户端；本次修正尚未发布安装包。

发布方可以保留多个客户端版本的包。支持此功能的客户端按自身版本取第一个匹配包，
不会要求旧版本使用最新客户端才能执行的内容。版本范围包含最低版本、不包含最高版本。
目前只接受单包清单的旧安装版需要更新到包含版本选择能力的构建。
