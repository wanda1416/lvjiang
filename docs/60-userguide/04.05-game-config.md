# 4.5 游戏配置

入口：「燕云 → 游戏配置」或按 **F5**。

游戏配置管理的是**游戏基础数据**——词条库、装备属性、流派定义、等级规则。
这些数据被调律配置引用，但日常调律一般不需要修改。

> 游戏版本更新新增词条/武器时才需要动游戏配置。日常调律只需关注调律配置 (F6)。

---

## 四个页签

```
┌──────────────────────────────────────────┐
│  词组配置  │  装备配置  │  流派配置  │  等级配置  │
├──────────────────────────────────────────┤
│                                          │
│            （各页签内容区）                 │
│                                          │
└──────────────────────────────────────────┘
```

---

## 词组配置

管理各词条在不同等级的最大值上限。

| 功能 | 说明 |
|------|------|
| 词条分类 | 普通词组 / 定音词组（定音词组不受承音限制） |
| 词条单位 | 空 / % |
| 词条分组 | 不分组 / 分组（如「指定技能增效」按十大流派分组） |
| 词条归属 | 普通词组可配置归属与可出现的装备部位 |
| 等级-上限表格 | 左侧选词组，右侧编辑各等级对应的最大值 |

> 双击词组类别 / 分组页签 / 词条名标签可重命名。

---

## 装备配置

管理装备基础属性规则（用于品阶推断）与武器类型注册表。

| 功能 | 说明 |
|------|------|
| 七个装备类型 | 主武器 / 副武器 / 环 / 佩 / 冠胄 / 胫甲 / 腕甲（固定不可增删） |
| 属性跟随 | 勾选后该部位复用目标部位的数值（如胫甲/腕甲跟随冠胄） |
| 基础属性说明 | 部位数值对应的属性名（区间型/离散型） |
| 武器类型注册表 | 每个武器可绑定一种武学增效词条 |

> 新增武器需重启后方可参与识别。被流派配置引用的武器不允许删除。

---

## 流派配置

管理流派与武器的对应关系。

| 配置项 | 说明 |
|--------|------|
| 属性 | 流派所属属性（鸣金 / 裂石 / 破竹 / 牵丝） |
| 主武器 | 流派的主武器类型 |
| 主武学 | 主武器对应的武学增效名称 |
| 副武器 | 流派的副武器类型 |
| 副武学 | 副武器对应的武学增效名称 |
| 基础属性 | 查看、编辑、重命名或删除按流派保存的角色基础属性 |
| 方案管理 | 从 Excel 导入、重命名或删除毕业率计算方案，并校正 100% 基准 DPS |

> 武学增效已移至装备配置的武器类型中，每个武器绑定一种武学增效。

基础属性用于角色面板反推和换装计算；毕业率方案用于把完整战斗属性换算成 DPS 与毕业率。日常操作见[5.4 角色基础属性与真实毕业率](05.04-base-attributes-and-graduation.md)。

---

## 等级配置

按等级区分重置支持、材料要求与抗性。

| 列 | 说明 |
|----|------|
| 等级 | 装备等级（1-999，不可重复） |
| 支持重置 | 该等级是否允许重置调律 |
| 最低材料数量 | 该等级要求的最低材料数量 |
| 判定抗性 | 判定抗性百分比（≥ 0） |
| 增益抗性 | 增益抗性百分比（≥ 0） |

> 支持新增/删除/上移/下移。修改即时校验写盘。

---

## 与调律配置的关系

```
游戏配置 (F5)                    调律配置 (F6)
┌─────────────┐                 ┌─────────────┐
│ 词组配置     │ ← 词条库引用 ── │ 词条库设置    │
│ 装备配置     │ ← 品阶推断 ─── │ 基础配置      │
│ 流派配置     │ ← 流派定义 ─── │ 规则设置      │
│ 等级配置     │ ← 材料/重置 ── │ 材料/结束处理  │
└─────────────┘                 └─────────────┘
```

游戏配置是底层数据，调律配置是上层行为规则。修改游戏配置后，调律配置的判定逻辑会自动适配。
