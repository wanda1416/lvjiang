# 实验性采集录制

## 范围与边界

燕云专属功能。菜单「燕云 → 采集录制」编辑路线，第四个左侧页签「采集」
执行已保存路线。Python `BaseWorkflow` 专有任务接入现有执行租约、任务历史、
F9 启动、F10 停止、F11 暂停/恢复；使用用户实际配置的任务快捷键。

首版仅支持桌面标记模式、固定起点、固定缩放、不拖动地图、单轮执行。
用户负责提前传送、选择资源和地图单人/多人页。假设已具备采集马并绑定采集键。
智能扫描、全图覆盖、地图平移校正、自动传送和多人刷新循环尚未实现。

## 录制与执行

F1 读取当前系统鼠标位置，保存画布坐标及当时的地图视口摘要，并立即生成
「打开地图、点击坐标」序列。第一次 F2 主动按自动识途键（默认 V），短暂等待
提示后按确认键（默认 F），并从确认键发出后开始计时；用户到达后再次按 F2，
结束计时并生成「等待录制耗时、按采集键（默认 1）」序列。用户随后自行打开
地图、悬停下一目标并继续按 F1。

录制结果是结构化路线，并可确定性编译为 `press`、`click`、`wait` 组成的 WF。
录制器不保存鼠标轨迹、键盘原始事件、动画帧或等待期间的输入，避免普通脚本
录制产生的无业务意义状态。

回放逐点开图，核验录制视口，点击坐标，识途并采集。视口不匹配、无法识途、
到达超时均停止：后一点的屏幕坐标依赖前一点的实际到达位置，不能盲目跳步。
首版不能随意排序或删除中间点，只允许撤销末尾录制点。

到达使用地图退出、主页操作区恢复、实景连续稳定和最短行程等待的组合。
预计耗时仅作为等待下限的参考，超时绝不当作成功。该组合是实验性启发式，
不能证明世界位置；卡住、原地停留等仍需真机验证。采集按键后使用明确的
采集等待参数；当前没有采集产出成功检测，历史只能报告按键已执行。

## 状态所有权

- 持久化路线：稳定 ID、名称、起点说明、布局、步骤、行程及等待参数；
- 编辑器：独立草稿、当前待完成采集点和语义 WF 预览；保存只修改当前路线；
- 采集页：本实例选中的执行路线及执行用户，不随编辑对象切换；
- 运行：启动时冻结路线、参数、布局与用户；不读取正在编辑的路线，不回写耗时。

录制截图摘要只存用户会话；不把真实截图、用户信息或个人路线写入系统配置。
编辑器非模态，不阻断主界面停止/暂停。关闭编辑器释放全局热键和截图缓存；
任何其他任务启动都终止录制监听。

## 验证门禁

自动测试覆盖 F1 当前坐标记录、F2 计时边界、语义 WF 生成、保存合并、运行快照、
超时不采集、暂停/停止、视口失配不点击以及插件任务入口。
真机验收仍需重复固定起点回放、运动/到达/卡住样本和采集动画结束样本；
离线截图识别通过不等于真机回归通过。
