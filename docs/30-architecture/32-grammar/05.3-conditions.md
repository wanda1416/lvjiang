## 一、基础条件

| 形式 | 说明 |
|---|---|
| `$var.field contains "文本"` | 字段值包含子串 |
| `$var.field == "文本"` / `$var.field != "文本"` | 两侧都是字符串时精确比较 |
| `$var.field in ["文本1", "文本2", ...]` | 字段值等于列表中任一项（等价于多个 `==` 的 `or` 组合） |
| `$var in ["文本1", "文本2", ...]` | 变量值等于列表中任一项 |
| `$var.field is_empty` | 字段不存在或为空字符串 |
| `$var.field > N` / `< N` / `>= N` / `<= N` | 字段数值与 N 比较（N 为整数或浮点数） |
| `$var > N` / `< N` / `>= N` / `<= N` | 变量数值与 N 比较（变量值为数字或可转数字的字符串） |
| `$left == $right` / `$left != $right` | 按类型判等，见下文「相等比较的类型规则」 |
| `expr > expr` / `< / == / ...` | 算术表达式比较：两侧支持 `+` `-` `*` `/` 运算，如 `$a + 1 > $b * 2` |
| `$var` | truthy 检查：变量存在且非空时为 true，不存在或为空时为 false |
| `not <基础条件>` | 取反任意一种；字符串不等直接使用 `!=` |

### 相等比较的类型规则

`==` / `!=` 按两侧的类型决定怎么比，`!=` 始终是 `==` 的取反：

| 两侧类型 | 规则 | 例子 |
|---|---|---|
| 都是字符串 | 精确比较，不做数字换算 | `"001" == "1"` 为假 |
| 任一是布尔 | 只有布尔与布尔才可能相等 | `$flag == false` 可用；`$flag == 1` 为假 |
| 任一是 null | 只有 null 与 null 相等 | `$x == null` 可用；`null == 0`、`null == ""` 为假 |
| 其余可转数字 | 按容差比较（差值 < 1e-9） | `$ocr_text == 3` 中 `"3"` 与 `3` 相等 |
| 类型不可比 | 不相等 | `"abc" == 5` 为假 |

布尔与 null 必须先于数字规则判掉：`to_number` 刻意不把布尔当数字
（Python 里 bool ⊂ int），null 也没有数值形态。若让它们落到数字规则，
两者都会被判成「不可比」，于是 `==` 恒假、`!=` 恒真——`$x != null` 会永远成立。

`in` 与 `contains` 同理：只有 null 谈不上包含关系，`0` / `false` / `""` 是合法值，
`$zero in [0, 1]` 成立。

判定「有没有值」用 `is_empty` 或 `== null`：前者把 `0`、`false`、空串也算空，
后者只判 null。

工作流中的字符串相等与不等统一写 `==` / `!=`。条件语法仍可解析旧式 `equals`，
但新工作流不使用；`scan`、`find`、`recognize` 的 `by equals` 是匹配模式，继续保留。

**字段访问**：
- 静态字段：`$var.field`、`$var."field"`、`$var.[field]`（三者等价）
- 动态字段：`$var.$key`（用变量值作为 key）
- 列表索引：`$list[$i]`（直接 `[]` 表示索引）
- 链式嵌套：`$var.f1.f2.f3`，每层从上一层结果中取字段

`$var` 的 truthy 检查常用于判断子过程是否成功返回值：

```
call $result = my_proc()
if not $result
    log "子过程未返回 status，执行失败"
    return
end
```

## 二、组合条件

- `and`：逻辑与，优先级高于 `or`
- `or`：逻辑或
- **短路求值**：`and` 遇 false 停、`or` 遇 true 停

```
if $scan.affix_gong contains "会心" and not $scan.affix_shang is_empty
    log "命中目标词条"
end

if $scan.x is_empty or ($scan.y == "A" and $scan.z contains "B")
    click [scene].[field]
end
```

## 三、算术表达式条件

数值比较的两侧支持算术表达式（`+` `-` `*` `/`），可用括号改变优先级：

```
if $a + 1 > $b * 2
    log "a+1 大于 b*2"
end

if ($x + $y) / 2 >= 60
    log "平均值达标"
end

if $col + 1 == 6
    log "已是最后一列"
end
```

> 算术表达式的运算规则与 eval 赋值一致：浮点除法、除零返回 0。详见 [01-basics.md](01-basics.md#算术表达式)。
