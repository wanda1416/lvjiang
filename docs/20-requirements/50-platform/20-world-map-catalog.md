# 大世界地图目录与探查底图

> 状态：部分实现（2026-10-13，基线 v0.15.0）。地图目录、探查资料与预览工具已实现；地域选择和界碑传送运行时函数待实现。

用户确认按游戏大地图拆分现有占位地图“中原”，首批为清河、开封、开封皇宫、河西、不见山、青州、江南。地图下登记地域；地域不必相连，目录关系不能代替道路连通关系。

地图管理需展示大地图底图和地域定位后的探查截图。地域截图是屏幕观察记录，不能把截图点击坐标当作底图 POI 世界坐标。切换预览只改变编辑器展示，不写配置；只在底图上编辑 POI。

多次平移探查使用同一缩放的重叠截图，排除固定 UI 遮挡，以共同地图纹理计算平移并拼接。未覆盖部分保留为空白；没有足够重叠的截图不能强行拼接，更不能把尚未探查的地图声明为完整底图。原始探查资料留在客户端 config 内，真实账号信息不能进入生产源码、测试或公共文档。

第一轮交付：地图/地域目录、探查图片的保存与预览、重叠截图拼接工具，以及本地真机资料重建。地域选择和界碑传送的运行时函数另行实现。地图定位后的固定界碑布局点仍由场景/布局管理，不与底图 POI 混用。

验收：地域与探查图片可保存重载；复制地图保留图片；坏图片不影响其他地图；预览地域截图不改底图 POI；重叠截图能还原正确平移，不重叠或缩放不同的图片明确拒绝拼接。
