# 加密配置下发

> 状态：部分实现（2026-10-09，基线 v0.13.14）；本地和真实云端链路已验证，正式内容发布与原生移动端联网入口尚未开放。

Lv1 及以上用户可通过现有签名激活码申请加密配置包密钥。非 Lv1 不请求受保护清单或密钥接口，不出现相关提示。激活码格式和既有离线功能保持原样。

管理工具登记激活码摘要、等级、有效期和启用状态，云端 Worker/D1 据此决定发放密钥；激活码不携带密钥。完整包通过静态站点下发，客户端解密后仍使用 remote 层，保留 local 优先、暂存后下次启动生效和普通配置的 content_version 仲裁。

公开与受保护来源共同管理清单，避免相互误删。授权失效或云端拒绝后，仅隔离受保护文件，不修改用户 local。受保护 WF 可按包版本更新，包括覆盖系统同名 WF；公开 WF 的只新增规则保持不变。

包校验覆盖摘要、AES-GCM 认证、云端包版本、客户端版本、路径和解压大小；验证未完成不得提交半包。临时联网失败保留已有内容；云端停用需要再次联网才能获知。已经交付的明文与密钥不可远程收回。

架构见 [受保护配置同步](../../30-architecture/38-platform/06-protected-config.md)，操作见 [用户配置](../../60-userguide/11-protected-config.md)。

验收要求：非 Lv1 无受保护网络请求；登记和发布失败可重试且不重新签发；公开清单 304 时受保护包仍可更新；授权失效保留 local；半包不生效；PC 到手机的离线快照保留受保护配置且不传输 PC 激活码。直接云端同步接入现有桌面入口，手机继续使用 PC 离线快照。
