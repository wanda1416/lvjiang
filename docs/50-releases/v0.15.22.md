# v0.15.22 — Linux 与 macOS 安装包、独立任务包与预置基础属性

本版把发行范围扩到三个桌面平台：除 Windows 便携 ZIP 与安装器外，新增 Linux（`tar.gz`）与
macOS（`dmg`，Apple 芯片）安装包。功能侧的主线是「独立任务包」——风沙酒肆收进一个可整目录复制
的包，萌宠争锋与八音窍抢购的场景也一并从全局层移入各自的任务包；「预置基础属性」补到十二个流派的
115 阶，流派配置窗口随之拆成方案与属性两页。工程侧另有本地控制面与 `lvjiang-cli`、手机端应用内
更新。

升级前需要逐项确认的有八条：三个玩法的场景与布局不再出现在全局层（第 1 条）、十一个系统脚本
换了目录（第 2 条）、`packages` 成为保留名（第 3 条）、毕业率数值可能变化（第 4 条）、手机
下发改为整包（第 5 条）、用户属性改名（第 6 条）、编辑器草稿位置（第 7 条），以及装过测试包
0.15.22b1 时的两处遗留（第 8 条）。

本文按相对 0.15.21 的净差异编写。Windows、Linux、macOS 与 Android 安装包本身要等本次发布
流水线跑完才能核验，本文不代替那次产物检查。

## ⚠️ 不兼容变动与升级指引

### 1. 三个玩法的场景与布局收进任务包，全局场景层不再内置

- **现象：** 全局场景从 45 个减到 43 个。「萌宠争锋」（场景 key `activity_mengzhu`）与
  「八音窍抢购」（场景 key `shop_bayinqiao`）的场景和布局不再随全局层提供：场景列表、布局列表
  里都看不到它们，按旧路径（`scenes/activity/`、`layouts/<布局>/activity/`）放在 `config/local`
  的覆盖不再被读取，引用这两个场景 key 的自建脚本会报找不到场景。官方脚本的 id、批量配置引用与
  任务顺序都不变；风沙酒肆只是从 `workflows/standalone/` 内部改成了任务包目录，场景同样不再进全局层。
- **原因：** 这几套场景只被各自的玩法使用，没有复用价值，改成随任务包分发，不再占用全局命名空间。
- **如何调整：** 不用自建脚本、也没写过这几项覆盖时无需操作。覆盖过的话，把文件挪进对应任务包
  目录，或直接删掉旧覆盖；自建脚本需要的话，把场景与布局放回 `config/local` 并重新标定。
  注意这两套玩法的任务包（`mengchong_zhengfeng`、`bayinqiao_snap`）只在本机 `config/local` 里，
  不随安装包分发——随包提供的第一份任务是风沙酒肆。
  便携版 ZIP 必须解压到新目录，否则旧目录里的全局场景会继续被加载（见「已知限制」）。

### 2. 十一个系统脚本移入 `workflows/daily/` 与 `workflows/scan/`

- **现象：** `daily_checkin`、`daily_jianghu`、`redeem_code`、`purchase_bugan`、
  `purchase_niaoniao`、`purchase_xinfa` 的官方文件从 `config/system/workflows/` 根层移到
  `daily/`；`scan_all_loadouts`、`scan_equipped`、`scan_role_base_attr`、`scan_unequipped`、
  `scan_wallet` 移到 `scan/`。脚本 id、界面分组、可见性与批量配置全部不变。
- **原因：** `workflows/` 根层不再放可运行脚本，只保留目录，避免「这里可以随手放脚本」的先例。
- **如何调整：** 没有覆盖过官方脚本时无需操作。本地覆盖按相对路径生效，若你在 `config/local`
  里覆盖过其中某个脚本，要把它从 `workflows/xxx.wf` 挪到 `workflows/daily/xxx.wf` 或
  `workflows/scan/xxx.wf`，否则覆盖不再命中。

### 3. `packages` 成为保留名

- **现象：** 新建或重命名布局、环境时，key 用 `packages`（大小写不敏感）会被拒绝并给出原因；
  解析已有同名布局的截图目录时同样被拒。
- **原因：** 任务包的标定底图固定落在 `config/session/screenshots/packages/<任务包 id>/`，
  而普通截图按布局 key 建目录；同名布局会和所有任务包共用一棵目录树，互相覆盖底图，报错只以
  「截图不见了」的形式出现。
- **如何调整：** 换一个名字。已经有名为 `packages` 的布局或环境时要改名，改名后该布局的截图
  需要重新标定。

### 4. 同一套属性算出的毕业率可能和 0.15.21 不同

- **现象：** 鸣金·虹 115 级的满值基准改为 100%；武学天赋的五维增量与公共底子里的无相攻击按
  统一口径重算后，毕业率数字可能变化。毕业率模型上的 `source` 字段不再读取。
- **原因：** 模型按当前赛季满养成标准校正，并去掉不再使用的来源字段。
- **如何调整：** 个人基础属性与已保存方案不用迁移。若你在 `config/local` 里覆盖过毕业率模型，
  系统里的这次校正到不了那份覆盖，需要自行同步或删掉本地覆盖。

### 5. 向手机下发改为整包，并按方案过滤布局

- **现象：** 手机同步不再按零散配置挑选内容。一次下发带上全部配置、脚本与用户资料，只按所选
  方案过滤布局与图库。默认仍保留手机上的任务参数与批量配置。
- **原因：** 离线包改成全量打包，同步入口改为选择方案。
- **如何调整：** 下发前确认选中的方案就是要装到手机上的那一套。若要连手机上的任务参数或批量配置
  一起换成电脑上的，取消对应的保留勾选。

### 6. 「用户属性」改名为「用户配置」

- **现象：** 用户管理右侧表格与按钮文案改为「用户配置」。已保存的 Key（如 `account`、`role`、
  `role_index`、`tail`）与取值不变。
- **原因：** 这项数据是高隐私键值，名称要与「基础属性」区分开。
- **如何调整：** 无需操作。

### 7. 编辑器草稿与试运行临时文件移到 `workflows/_scratch/`

- **现象：** 编辑器上次的运行草稿由 `workflows/_editor_run.wf` 变为
  `workflows/_scratch/editor_run.wf`，试运行用的临时文件也落在该目录。旧位置的草稿不会被读取。
- **原因：** `workflows/` 根层不再出现 `.wf`；带下划线的目录既让发现层跳过，也天然落在 local 层
  被忽略的 `workflows/_*` 规则里。
- **如何调整：** 无需操作。想找回上次未保存的草稿，把旧文件内容重新粘进编辑器即可，旧文件可以删掉。

### 8. 装过测试包 0.15.22b1 时的两处遗留

- **现象：** 在线配置的更新状态落在正式版目录 `updates/v0.15.22`，测试包用的
  `updates/v0.15.22b1` 不会沿用，首次启动会重新下载一次在线配置；任务包底图目录由
  `screenshots/_packages/<id>/` 改为 `screenshots/packages/<id>/`，b1 期间标定的底图在新位置
  找不到。
- **原因：** 正式版与测试包的更新状态分开存放；原来的下划线目录被 `config/session/.gitignore`
  的备份忽略规则连坐，任务包底图因此进不了库，换机就得重拍。
- **如何调整：** 更新状态无需动手（自动重下）。底图把 `config/session/screenshots/_packages/`
  下的目录整体搬到 `config/session/screenshots/packages/` 即可。

## ⚠️ 已知限制

- **便携版 ZIP 升级必须解压到新目录**，再迁移 `config/local` 与 `config/session`（保留新包的
  `baseline.json`，跳过旧的 `content.json` 与 `config.lock`）。安装器与 APK 会自动清理官方内容，
  不需要这一步。
- **macOS 包只有 Apple 芯片（arm64）版本**，没有 Intel 包；Windows 仍是便携 ZIP 与安装器。
- **Linux 包的任务栏图标依赖包内 `install-desktop.sh`。** 未执行它时窗口能开，但任务栏与
  应用菜单只显示通用图标（Wayland 按窗口 app_id 匹配同名 `.desktop` 文件，`setWindowIcon` 不够）。
- **任务诊断与全任务采集仍属开发预览。** 菜单「任务诊断」默认关闭、重启后恢复关闭，仅作用于下次
  启动的任务。

## ✨ 新增功能

- **Linux 与 macOS 安装包。** 发布产物增加 `lvjiang-v0.15.22-linux-x86_64.tar.gz` 与
  `lvjiang-v0.15.22-macos-arm64.dmg`。Linux 包内含 `install-desktop.sh`，用于把图标装进
  hicolor 主题并生成 `lvjiang.desktop`。
- **十二个流派的 115 阶预置基础属性。** 「当前属性」下拉先列预置，再列当前用户，最后是其他用户；
  已经选中的个人属性不会被换成预置。
- **流派配置拆成两页。** 右区分为「流派方案」与「流派属性」，游戏配置窗口默认更高。
- **独立任务包。** 风沙酒肆是第一份随包提供的实现，它的场景、布局与脚本收进一个可整目录复制的
  包，普通脚本不进入任务包作用域，行为与以前相同。萌宠争锋与八音窍抢购的场景与布局也一并从全局层
  移入各自的任务包（这两份包随本机 `config/local` 提供，不随安装包分发），见升级指引第 1 条。
- **装备导出增加兵鉴格式。** 装备页「导出数据」可选 leoq7 文本或兵鉴 JSON，并可选导出后打开对应
  网站；模拟装备不导出。
- **手机端应用内更新。** 可在应用内查看发布说明、后台下载并安装 APK；安装前校验包，进程被杀后
  可以续装。
- **本地控制面与 `lvjiang-cli`。** 桌面端可以无界面运行，并由本机命令行查看和控制任务。这是附加
  入口，不改变主窗口里开始任务的方式。
- **桌面端窗口图标。** 源码运行与打包使用同一份图标资产。
- **任务诊断增加「清空缓存」。** 用来丢掉已经留在内存里的历史帧，不影响默认关闭的落盘开关。

## 🔧 修复

- **手机端会长期显示离线。** 应用进后台时心跳计数被清掉，设备不再上报。现在后台暂停不再把已累计
  的心跳间隔清零。
- **备战方案里的增益效果被裁掉字。** 动态槽高度不够，半屏卡片纵向被压扁。现按内容留出高度。
- **编辑基础属性会丢掉未显示的字段。** 保存时隐藏字段不再从这份属性里消失。

## 📦 重构

- **工作流引用改为按脚本 id 解析，目录不再是契约。** 解析顺序为「相对路径 → 脚本 id → 文件名」，
  绝对路径不参与 id 回退；同名候选多于一个时直接报错并列出候选，而不是先找到谁用谁。存量调用
  行为等价。
- **系统脚本按用途收进 `daily/` 与 `scan/`**，`workflows/` 根层只留目录，见升级指引第 2 条。
- **编辑器草稿与试运行临时文件收进 `workflows/_scratch/`**，见升级指引第 7 条。
- **任务包截图目录改用 `screenshots/packages/<id>/`**，脱离 session 备份忽略规则的连坐。
- **毕业率计算模型不再使用 `stage`。** 阶段只属于预置基础属性；模型文件里残留的 `stage` 在读取时
  忽略。
- **用户管理里的属性表更名为用户配置**，存储位置与键名不变。
