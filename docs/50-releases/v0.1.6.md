# v0.1.6 — 玩家档案系统 + 工作流配置治理

## 律匠 v0.1.6

本版本新增玩家档案管理系统、工作流配置统一存储、调律引擎职责收拢与多项稳定性修复。

---

### ✨ 新增功能

**玩家档案系统**
- 玩家信息元数据定义：profiles.yaml 重构为纯元数据 schema，定义 user.json 字段属性
- 档案总览交互式列配置：右键列头新增/删除列，双击列头选择字段，列配置存储到 session.json
- 元数据定义对话框增强：支持分组列、修改 key、调整排序，新建字段同时输入 key 和标签
- 所有元数据编辑操作实时保存

**调律引擎**
- 扫描处理新增最大连续回收次数配置：避免无限回收循环
