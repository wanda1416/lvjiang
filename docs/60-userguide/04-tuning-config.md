# 4. 调律配置

入口：「燕云 → 调律配置」或按 **F6**。

这是调律行为的核心配置，决定了哪些装备进调律、怎么判定好坏、调律后怎么处理。

> 本对话框**没有保存按钮**：任何改动即时校验，校验通过自动保存生效；
> 校验不通过会提示错误并拒绝保存。

---

## 4.1 界面结构

对话框左侧为一级导航，右侧为对应的配置内容区：

```
┌──────────────┬──────────────────────────────┐
│  基础配置     │                              │
│  扫描处理     │    （右侧内容区）              │
│  材料处理     │                              │
│  结束处理     │                              │
│  ─────────   │                              │
│  规则A        │                              │
│  规则B        │                              │
│  规则C        │                              │
│              │                              │
│ [＋ 新增规则] │                              │
│ [装备调律验证] │                              │
├──────────────┴──────────────────────────────┤
│  状态栏：校验结果 / 最后保存时间                │
└─────────────────────────────────────────────┘
```

导航分为两组：
- **上方全局配置**（4 项）：基础配置、扫描处理、材料处理、结束处理
- **下方调律规则**（分割线以下）：每个规则一项，双击可重命名

---

## 4.2 基础配置

设定进入调律的**全局门槛**和全局开关。

### 品阶门槛

定义各品阶装备进入调律的最低要求。只有预期评级达到门槛的装备才会进入调律流程。

| 品阶 | 说明 |
|------|------|
| 金装 (gold) | 金色品质装备 |
| 金装限定 (gold_only) | 仅限金装的特殊门槛 |
| 紫装 (purple) | 紫色品质装备 |
| 紫装限定 (purple_only) | 仅限紫装的特殊门槛 |
| 蓝装 (blue) | 蓝色品质装备 |

### 全局开关

基础配置区还包含若干全局开关复选框（由 `tuning_base.yaml` 的 `switches` 注册表动态生成），例如：

- **保留 PVP 装备** — 勾选后跳过带有 PVP 标记的装备
- **初始判定** — 启用后，首次调律前强制执行一次结束处理（用于垃圾金装复用重置）

> 开关数量可能随版本更新变化，以实际界面为准。

---

## 4.3 扫描处理

控制**进调律前**的进入门槛与处置逻辑。

### 进入门槛

传入规则预期评级 ≥ 进入门槛 → 进入调律；未达门槛 → 走处置表。

### 处置规则表

有序规则表，自上而下首条命中即生效。每行定义：

| 列 | 含义 |
|----|------|
| 条件 | 品阶范围 + 判定语义（传入规则 / 全部规则 / 自选规则 / 自选词条） |
| 处置 | 回收 / 保留 / 调满后回收（金装专用） |

**判定语义**（四选一）：
- **传入规则** — 使用当前调律规则的评级结果
- **全部规则** — 综合所有规则的评级
- **自选规则** — 弹窗勾选参与判定的规则
- **自选词条** — 按装备词条名直接匹配（不跑潜力判定）

> 无命中时默认**保留**装备（不进调律也不回收）。

### 「仅首词条」选项

扫描处理可勾选「仅首词条」：取评级时只注入首词条，用于只看首词条的判定场景。

---

## 4.4 材料处理

每轮调律开始前的材料准备逻辑。

### 大律准石数量检查

| 配置项 | 说明 |
|--------|------|
| 启用检查 | 勾选后在每轮调律前检查大律准石数量 |
| 数量基准 | 低于此值触发「不足时」动作 |
| 不足时 | 三选一：**跳过该装备** / **结束全部调律** / **询问是否继续**（弹窗确认后本次运行不再检查） |

### 狗粮添加规则

有序规则表，自上而下**首条命中即生效**，决定每轮调律是否加狗粮。

每行定义条件（如词条数、品阶等）和对应动作（加 / 不加）。

> 规则顺序很重要：排在前面的优先匹配。可以用上移/下移调整顺序。

---

## 4.5 结束处理

每轮调律**结束后**的决策规则表。

### 行为规则表

有序规则表，自上而下首条命中即生效。每行定义：

| 列 | 含义 |
|----|------|
| 条件 | 品阶范围 + 词条状态（已满/未满）+ 判定语义 |
| 处置 | 继续调律 / 重置调律 / 回收 / 结束保留 |

**处置动作说明**：

| 处置 | 行为 |
|------|------|
| 继续调律 | 词条未满，继续下一轮调律 |
| 重置调律 | 清空首词条以外的全部词条，重新开始调律。**每件装备单次运行只重置一次** |
| 回收 | 将装备回收 |
| 结束保留 | 停止对该装备的调律，保留当前状态 |

> 词条已满时为边界条件：「继续调律」不可达，无命中默认**结束保留**。
> 词条未满时无命中默认也是**结束保留**。

### 重置设置

| 配置项 | 说明 |
|--------|------|
| 重置冷却期 | 同一件装备两次重置之间的最小间隔轮数，防止反复重置 |

---

## 4.6 调律规则

分割线以下的每个规则项代表一套完整的调律评判标准。

### 规则内部结构

点击规则后，右侧内容区显示该规则的**二级导航**（共 9 项）：

```
规则设置        ← 流派、玩法等基础设定
词条库设置      ← 该规则可用的词条池
通用判定        ← 跨部位的通用判定条件
───────────     ← 分割线
主武器          ← 主武器各词条评级
副武器          ← 副武器各词条评级
环 · 佩         ← 环和佩的词条评级
冠胄 · 胸甲     ← 冠胄和胸甲的词条评级
胫甲 · 腕甲     ← 胫甲和腕甲的词条评级
```

### 规则设置

| 配置项 | 说明 |
|--------|------|
| 流派 | 该规则适用的武器流派（如「会意」「会心」等） |
| 玩法 | 可选多个玩法（如「大外攻流」「小外攻流」），调律 Tab 中按规则勾选玩法 |

### 词条库设置

定义该规则可用的词条池。词条池决定了扫描处理、结束处理中「传入规则」判定
能看到哪些词条，也是各部位评级页的候选来源。

### 通用判定

跨部位的通用判定条件，如首词条要求等。

### 各部位评级页（5 个）

每个部位页独立配置该部位下各词条的评级（如 S / A / B / C / 垃圾）。
评级结果直接影响扫描处理和结束处理的判定。

---

## 4.7 新增与管理规则

### 新增规则

点左下 **「＋ 新增规则」**，弹出对话框：

| 字段 | 要求 |
|------|------|
| 标识 key | 小写英文标识（字母开头，可含数字/下划线），作文件名 |
| 规则名称 | 中文显示名（如「治疗-纯奶」） |

### 重命名规则

在左侧导航中**双击**规则项，弹出重命名对话框。注意：配置页（基础配置等）不可改名。

### 删除规则

在规则内部的「规则设置」页底部有删除按钮。删除后不可恢复。

---

## 4.8 装备调律验证

左下 **「装备调律验证」** 按钮打开判定测试对话框。

功能：手动输入装备词条，验证当前规则的判定结果。

> 调规则时建议先在这里验证，确认判定逻辑符合预期后再实际运行。

---

## 4.9 游戏配置（F5）

入口：「燕云 → 游戏配置」或按 **F5**。

与调律配置不同，游戏配置管理的是**游戏基础数据**：

| 页签 | 内容 |
|------|------|
| 词组配置 | 词条库定义（词条名、别名、分组） |
| 装备配置 | 基础属性数值、武器类型定义 |
| 流派配置 | 流派与武器的对应关系 |
| 等级配置 | 按等级区分重置支持与材料要求 |

> 游戏版本更新新增词条/武器时才需要动游戏配置。日常调律只需关注调律配置 (F6)。
