## AI接入场景

| 场景 | AI做什么 | 输入 | 输出 |
|------|---------|------|------|
| **初始规则生成** | 根据文档生成流派配置 | 流派文档+词条总表 | YAML规则文件 |
| **装备评估建议** | 分析单件装备，给出调律/保留/回收建议 | 装备词条+当前库存 | 决策+理由 |
| **库存优化建议** | 对比全身装备，指出优先提升部位 | 全身7件装备数据 | 优先级排序+目标词条 |
| **调律策略建议** | 精调过程中，每一步给出最优操作 | 当前4条词条+剩余材料 | 调律/转律/锁定/放弃 |
| **流派转型建议** | 用户想换流派，分析哪些装备可复用 | 当前库存+目标流派 | 保留清单+需重新调律清单 |

---

## 对需求文档的影响

文档需要让AI能**理解**、**推理**、**生成建议**。

### 新增文档类型

| 文档 | 用途 |
|------|------|
| **装备价值模型** | 定义"为什么某词条好"，让AI能推理而非死记 |
| **部位优先级分析** | 各部位对整体输出的贡献度，AI据此给出提升建议 |
| **词条协同效应** | 哪些词条组合有1+1>2效果 |
| **边际收益分析** | 从2条目标词条提升到3条，收益多大 |
| **转型成本模型** | 换流派时，哪些部位必须换，哪些可保留 |

## 文档格式设计（AI友好）

### 1. 词条文档：增加"价值维度"

```yaml
# data/affixes.yaml
affixes:
  - id: crit_rate
    name: 会心率
    # ... 基础信息 ...
    
    # 新增：AI推理用
    value_dimensions:
      - dimension: dps_contribution
        description: "直接提升暴击概率，增加期望伤害"
        formula: "crit_rate * crit_dmg_multiplier"
        applicable_flows: [会心双刀, 九剑, 无名]  # 对哪些流派有价值
      
      - dimension: synergy
        description: "与会意率协同，高会心+高会意=稳定爆发"
        pairs_with: [crit_dmg_rate]
        synergy_bonus: 1.5  # 同时存在时价值提升50%
      
      - dimension: slot_efficiency
        description: "头部是获取三率的最佳部位，其他部位难替代"
        best_slots: [head, chest]
        fallback_slots: [weapon, ring]
```

### 2. 流派文档：增加"决策逻辑"

```markdown
## 核心公式（AI可解析）
```
期望DPS = 基础攻击 * (1 + 会心 * 会意) * 技能系数
```

## 部位价值分析（AI给出优先建议时用）

| 部位 | 对DPS贡献占比 | 提升难度 | 建议优先级 |
|------|------------|---------|-----------|
| 武器 | 35% | 高（初始词条决定） | P0（最先调）|
| 环 | 20% | 中 | P1 |
| 头 | 15% | 低 | P2 |
| ... | ... | ... | ... |

## 词条边际收益

| 当前状态 | 操作 | 期望收益 | 建议 |
|---------|------|---------|------|
| 武器0条目标 | 调律到2条 | +30% DPS | 必须做 |
| 武器2条目标 | 调律到3条 | +15% DPS | 优先做 |
| 武器3条目标 | 调律到4条 | +5% DPS | 材料充裕时做 |
| 头2条三率 | 转律优化数值 | +3% DPS | 后期优化 |

## AI建议模板

当用户问"优先调什么"时，AI按以下逻辑回答：

1. 检查各部位当前词条数
2. 找出"初始词条合格但调律词条<2条"的部位
3. 按部位贡献占比排序
4. 考虑材料成本，给出性价比最高的方案
```

### 3. 新增：AI提示词模板文档

```yaml
# ai/prompts/equipment_advice.yaml

system_prompt: |
  你是燕云十六声装备调律专家。用户会提供当前装备情况，你需要给出专业建议。
  
  你的建议原则：
  1. 优先保证各部位初始词条合格
  2. 优先调律武器和首饰（DPS贡献大）
  3. 保留跨流派通用的顶级装备
  4. 材料有限时，追求"2条目标词条"的性价比最高
  
  输出格式：
  - 优先级排序（P0/P1/P2）
  - 每件装备：当前状态 → 目标状态 → 操作建议
  - 理由（引用具体数值）

user_prompt_template: |
  我当前穿戴的装备如下：
  {equipment_list}
  
  我的目标流派是：{target_flow}
  当前材料：律准石{x}个，转律石{y}个
  
  请告诉我：
  1. 优先调律哪些部位？
  2. 每件装备的目标词条是什么？
  3. 是否需要换流派保留某些装备？
```

## 你现在需要整理文档的优先级（含AI预留）

| 优先级 | 文档 | 内容要点 | AI用途 |
|--------|------|---------|--------|
| P0 | **词条总表** | 名称、数值范围、适用部位、是否属攻、是否稀有 | 基础数据、OCR校验 |
| P0 | **调律/转律机制** | 规则、材料、界面流程 | UI自动化 |
| P1 | **2-3个流派详解** | 优先级、必须词条、组合加成、**边际收益分析** | 规则生成、AI建议 |
| P1 | **部位价值分析** | 各部位对输出/生存的贡献占比 | AI优先建议 |
| P1 | **顶级装备判定** | T0词条、跨流派共识 | 自动保护 |
| P2 | **词条协同效应** | 哪些词条组合有加成 | AI深度建议 |
| P2 | **转型成本模型** | 换流派时保留/更换策略 | AI转型建议 |
| P2 | **AI提示词模板** | 建议格式、推理逻辑 | LLM调用 |

## 关键设计决策

| 问题 | 选项 | 建议 |
|------|------|------|
| AI本地还是云端？ | 本地LLM / 云端API | 先云端（GPT-4/Claude），后期可切本地 |
| AI建议是否阻塞操作？ | 同步等待 / 异步提示 | 异步，AI建议显示在侧边栏，用户参考 |
| AI是否自动执行？ | 只建议 / 建议+确认 / 全自动 | 建议+确认，用户始终有最终决定权 |
| 历史数据是否给AI？ | 当前状态 only / 历史调律记录 | 给历史记录，AI学习用户偏好 |
