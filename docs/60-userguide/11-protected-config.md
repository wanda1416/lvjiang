# 受保护配置

当前功能已完成本地开发验证，云端服务和隔离链路已验证，正式业务内容尚未发布。服务开放后，作者登记到云端的有效 Lv1 及以上激活码可获取受保护配置，不需要更换已有激活码。

按照作者提供的实际 HTTPS 服务地址，在用户配置目录建立 `config/local/remote_service.json`：

```json
{"service_url": "https://content.example.invalid"}
```

不要填写管理 Token。打开在线配置更新，客户端会检查公开配置与受保护包；下载成功后下次启动生效。自己的 local 配置保持优先。新场景和布局需与其工作流一同由作者发布。

未达到授权等级的用户不会请求受保护服务，也没有额外提示。未登记、已过期或被云端停用的码无法获取密钥；可联系作者检查登记状态。临时断网时保留此前下载且本机授权有效的内容；已停用授权需联网后才能确认。

离线激活原有功能保持不变。关闭在线配置更新会沿用现有行为，清除下发内容、回到系统配置；不会删除 local。作者撤回的受保护文件会在后续同步时移除。新下载与撤回结果仍按下次启动生效。

详情见 [需求边界](../20-requirements/50-platform/11-protected-config.md)。
