# 货币追踪 — 子需求文档

## 1. 需求概述

自动识别游戏内货币页面中各类货币的数值，按账号持久化存储，支持历史趋势查询，并在主页面装备状态 Tab 中展示货币资产概览面板。

---

## 2. 核心流程

```
导航到货币页面（nav_to_currency.wf）
    ↓
截屏 → OCR 识别各货币图标与数值
    ↓
结构化数据：{货币名: 数值}
    ↓
追加写入 currencies.jsonl（带时间戳）
    ↓
UI 面板展示最新快照
    ↓
支持历史趋势查询（折线图）
```

---

## 3. 数据模型

### 3.1 货币快照（CurrencySnapshot）

```python
class CurrencySnapshot:
    account: str              # 账号名
    timestamp: datetime       # 采集时间
    currencies: dict[str, int]  # 货币名 → 数值
    
    # 示例:
    # {
    #     "宝钱": 12345,
    #     "长鸣玉": 567,
    #     "不肝": 89,
    #     "长鸣珠": 12,
    #     "宋元通宝": 3456,
    #     "河西通宝": 789,
    #     "周元通宝": 234,
    #     "不见山墨筹": 56
    # }
```

### 3.2 货币类型

| 货币名 | 分组 | 说明 |
|--------|------|------|
| 不肝 | 货币资产 | 活动货币 |
| 长鸣珠 | 货币资产 | 高级货币 |
| 宝钱 | 货币资产 | 基础货币 |
| 长鸣玉 | 货币资产 | 付费货币 |
| 宋元通宝 | 货币资产 | 通用货币 |
| 河西通宝 | 货币资产 | 区域货币 |
| 周元通宝 | 货币资产 | 区域货币 |
| 不见山墨筹 | 货币资产 | 活动货币 |
| 袅袅 | 货币资产 | 袅袅货币 |

## 4. 存储方案

### 4.1 文件结构

```
config/session/users/{account}/
    currencies.jsonl
```

### 4.2 JSONL 格式

每行一条快照记录，追加写入：

```json
{"timestamp": "2026-08-04T10:30:00", "currencies": {"宝钱": 12345, "长鸣玉": 567, ...}}
{"timestamp": "2026-08-04T18:45:00", "currencies": {"宝钱": 11200, "长鸣玉": 600, ...}}
{"timestamp": "2026-08-05T09:15:00", "currencies": {"宝钱": 13500, "长鸣玉": 580, ...}}
```

### 4.3 数据清理

- 保留最近 90 天的数据
- 超过 90 天的记录自动归档或删除

## 5. 场景定义

### 5.1 新增场景

| 场景 key | 名称 | 说明 |
|----------|------|------|
| `currency_page` | 货币页面 | 货币资产展示页面 |

### 5.2 新增区域

| 区域 key | 名称 | 类型 | 说明 |
|----------|------|------|------|
| `currency_bugan` | 不肝 | text | 不肝数值 |
| `currency_changmingzhu` | 长鸣珠 | text | 长鸣珠数值 |
| `currency_baoqian` | 宝钱 | text | 宝钱数值 |
| `currency_changmingyu` | 长鸣玉 | text | 长鸣玉数值 |
| `currency_songyuan` | 宋元通宝 | text | 宋元通宝数值 |
| `currency_hexi` | 河西通宝 | text | 河西通宝数值 |
| `currency_zhouyuan` | 周元通宝 | text | 周元通宝数值 |
| `currency_bujianshan` | 不见山墨筹 | text | 不见山墨筹数值 |

### 5.3 识别方案

两种方案可选：

**方案 A：模板匹配 + OCR**
- 先用参考图库匹配货币图标位置
- 再对图标右侧区域 OCR 读取数字

**方案 B：整页 OCR + 文本匹配**
- 整页 OCR 获取所有文本
- 按货币名关键词匹配对应数值

> 建议先用方案 B 快速实现，准确率不足时再切换方案 A

## 7. DSL 工作流

### 7.1 nav_to_currency.wf

```
# 从主页面导航到货币页面
call $ok = nav_main_to_equip()
if $ok < 0
    return -1
click "more_func"
wait "page_refresh_wait"
# 找到货币按钮（需要确认具体位置）
click "sub_func_3"  # 待确认
wait "page_refresh_wait"
return 0
```

### 7.2 read_currencies.wf

```
# 读取货币页面所有货币数值
scan $bugan = currency_bugan by ocr
scan $changmingzhu = currency_changmingzhu by ocr
scan $baoqian = currency_baoqian by ocr
# ... 读取所有货币
return 0
```

## 9. 风险与待确认

### 9.1 风险

1. **货币页面导航路径**：需要确认从主页面到货币页面的具体路径
2. **OCR 数字准确率**：千分位分隔符、单位（万/千）可能影响识别
3. **货币种类变化**：游戏更新可能新增货币类型

### 9.2 待确认

1. 货币页面的导航路径是什么？
2. 需要追踪哪些货币？（完整列表）
3. 是否需要历史趋势图？
4. 货币数据是否需要导出功能（CSV）？
5. 是否需要货币变化提醒（如宝钱减少）？
