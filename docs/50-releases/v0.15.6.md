# v0.15.6 — 自动剧情文案库、命令行执行入口与悬浮窗贴边吸附

发布日期 2026-10-30。

## ⚠️ 不兼容变动与升级指引

### 改过 `daily_checkin.wf` 或 `activity_main` 场景／布局本地覆盖的用户拿不到页签适配

- **现象：** 游戏 UI 改造后活动页左侧新增「活动 / 新内容 / 推荐」页签，进入时若停留在
  非「活动」页签，每日签到的列表扫描会落空。本版本为 `activity_main` 场景新增
  `tab_activity` / `tab_new` 页签区域并按实机标定坐标，签到流程进活动页后先切回
  「活动」页签，点击前还会先确认区域内识别到「活动」二字，识别不到时截图提醒并跳过，
  不在未确认的位置上盲点。覆盖过 `config/local` 同路径文件的用户那里这些修正不生效。
- **原因：** `config/local` 无条件优先于 `config/system`，场景、布局与工作流文件是
  整文件覆盖而不是合并。
- **如何调整：** 删除本地对应覆盖，或手动把系统新版改动同步进本地文件。

其余变更均为向后兼容的新增能力与内部修正；`SyncTargetDef` 新增的 `lock_on_cap`
字段默认保持原有满值锁定行为，旧配置无需调整。本版本其余无不兼容变动。

## ✨ 新增功能

### 自动剧情文案库（通用工具）

- 新入口「工具 → 自动剧情」：维护剧情选项文案库，任务运行时按 OCR 相似度自动选择
  匹配的答案。
- 文案库按配置组管理（`config` 下 `tools/auto_plot/<组名>.json`，一组一个文件），
  可新建、删除、保存到本地或系统层；同名组本地条目覆盖系统条目，激活时合并全部组。
- 匹配阈值可在对话框顶部调整，单独存于全局参数文件。
- DSL 新增 `story_options` / `story_pick` / `story_learn` 内置函数与
  `ocr_region_blocks` 块级 OCR 匹配原语，内置 `auto_skip.wf` 提供可直接调度的
  自动跳过剧情工作流。

### 命令行执行入口 lvjiang-cli

- 不开界面即可列出与执行任务，用于计划任务与外部编排；与 GUI 共用同一套引擎、
  配置快照与用户锁。
- 动作采用扁平参数：`--list` 列出全部脚本或配合 `--id` / `--name` 查看参数，
  `--exec` 执行任务；脚本选择统一为 `--id` / `--name` / `--file` 三选一。
- 插件严格按 `-reg` / `--all` 显式加载，不再默认全量；`--list` 纯查询不装配插件与
  崩溃防护。单任务执行日志自动落盘。
- `python -m lvjiang` 与打包的 `lvjiang-cli.exe` 行为一致，详见新增
  「附录 D：命令行」用户文档。

### 手机悬浮窗贴边吸附与 Material 3 视觉

- 悬浮球拖到屏幕边缘后动画收起为细把手，拖出或点击恢复；「悬浮控制」卡片底部新增
  「悬浮球贴边吸附」开关。
- 悬浮球与面板按 Material 3 重构：三级状态色、Filled/Tonal/Text 分级按钮、统一
  文字层级，并跟随系统深浅色；面板按钮缩小，「回到最新」并入收起行，移除已完成
  状态行。

### 同步目标逐条满值锁定

- 同步目标达硬上限时是否把源 key 锁成 `—` 并禁止编辑，改为按边配置
  （新增「满值锁定」列，默认勾选保持原行为）。
- 取消锁定后目标满只表示增量不再写入该目标，源 key 仍照常展示和记账——适用于
  心力等真实资源与每周消耗等派生计数器等多源场景。
- 锁定时总览单元格与右键菜单行为一致，只保留只读的历史入口。

### 同步目标编辑改为级联 key 选择

- 新建同步目标时目标 key 改为级联下拉选择，不再手填。

### 移动端用户数据页全用户视图与分组筛选

- 每个 key 行右侧新增「全部」入口，进入单 key 的全用户视图，按「模型·分组」组织
  所有用户实时值，可累加模型附合计。
- 用户数据页新增分组下拉筛选，局部刷新、不反写配置；全用户视图返回改用固定
  AppBar 导航。

## 📦 重构

- **命令行动作扁平化**：移除 `run` / `list` / `schema` 子命令，统一为 `--exec` /
  `--list` 动作开关，`--list` 纯查询最高优先级截断（该重构发生在 CLI 入口同一
  发布周期内，无旧参数用户）。
- **悬浮窗视觉重构**：Material 3 卡片与分级按钮替换旧样式，符号重绘后改为代码
  染色；拆分启动图标 `ic_launcher`，修复重绘符号后桌面图标丢失。
