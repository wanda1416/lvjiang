# 任务入口状态与启动反馈

> 状态：已实现（2026-10-12，基线 v0.15.0）。

第一轮仅统一日常、批量、调律、采集的启动展示和就地反馈，不改变参数保存、
运行快照、平台限制或任务调度规则。

- 公共连接状态统一显示「未连接」或「未定位」，使用黄色样式；方案或权限
  不允许启动时使用灰色样式。原因显示在执行按钮下方，不只依赖日志或悬停。
- 空脚本、空执行用户、批量未选择脚本或单元、采集缺路线或平台不支持，
  由各页面进行廉价预检。不得为了刷新 UI 进行 OCR、截图或重型启动检查。
- 非运行状态的不可启动按钮允许点击解释原因，但不能启动任务。其他页面
  占用当前目标、暂停中和停止中仍沿用原有禁用规则，停止和恢复不被预检拦截。
- 启动过程中才发现的错误显示在同一个提示区域，并保留原有日志与必要确认。
  修改选择、再次启动或成功运行后清除旧错误；可执行性提示与失败提示不混为日志。
- 公共层只复用展示和反馈，不维护另一份运行状态，不接管页面业务判断。

验证须覆盖四页共同状态、空选择及恢复、启动失败的可见反馈、其他页面占用
与停止/暂停操作，并在明暗主题和窄面板中检查提示换行及按钮可达性。
