# v0.7.0 — 匿名统计与调律数据回收、承音装备合并、系统托盘

## 律匠 v0.7.0

本版本新增可选的匿名使用统计与调律数据回收（默认关闭，首启询问，随时可退出并删除），用于改进内置调律规则；新增承音装备合并，把承音或再次转律产生的同件装备历史版本归并为一件；支持最小化到系统托盘并以图标反映运行状态。同时大幅改进按键与鼠标事件录制的保真度，并重构 UI 模块归档结构。

---

### ✨ 新增功能

- **匿名使用统计与调律数据回收**：可选参与，**默认关闭**，首次启动询问。仅上报匿名安装标识与调律过程数据（部位、材料、逐轮词条、结束原因），不含账号、角色名、装备名与截图。设置页可随时查看待上报数据、退出参与、重置标识或请求删除服务端记录
- **承音装备合并**：识别承音或再次转律产生的同件装备历史版本，确认后原子迁移引用并删除旧快照，避免同一件装备在配装中重复占位
- **最小化到系统托盘**：主窗口可最小化到托盘，托盘图标随工作流运行状态变化
- **按键与鼠标事件录制完善**：补齐修饰键组合与鼠标事件的录制覆盖
- **交流群二维码在线刷新**：二维码支持从 github.io 刷新，群变更后无需重新发版
- **鸣金·虹毕业方案更新**：更新鸣金·虹毕业基础方案与阡陌属性汇总数据

---

### 🔧 修复

- **低精度录制丢失非左键**：右键、中键与侧键在低精度录制中被忽略，现改由 Raw Input 捕获，五种鼠标键全部录制
- **录制事件时序错乱**：低精度录制会把成对的按下/抬起提前压缩成 `click`，与键盘事件交叠时破坏全局顺序，现保留原始事件序列并固定每个事件的指针坐标
- **滚轮重复脉冲**：部分 Windows 鼠标驱动把一次物理滚轮动作拆成数个相邻回调，回放时表现为反复切换，现将同方向短脉冲折叠为同一手势

---

### 📦 重构

- **UI 模块按业务域归档**：整理 `ui/` 下的平铺模块，录制引擎回到 `core`
- **主窗口拆分**：`main_window` 及其混入收进 `ui/main/`
- **参照管理子包更名**：`reference_manager` 更名为 `reference`
