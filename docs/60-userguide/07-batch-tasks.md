# 7. 批量任务

批量任务用于**多账号/多角色**场景：自动遍历条目表中的每一行，切换账号后执行指定脚本。

入口：主窗口左侧 **「批量」Tab**。

---

## 7.1 批量 Tab 三页

```
┌──────────────────────────────────────┐
│  [开始批量执行 (F9)]                  │
├──────────────────────────────────────┤
│  进度 │ 脚本 │ 配置                    │
│  ─────────────────────────────────── │
│  （子页内容）                         │
│                                      │
└──────────────────────────────────────┘
```

### 「进度」页

执行进度表，显示 **条目 × 脚本** 的矩阵状态：

| 列 | 说明 |
|----|------|
| 条目 | 行数据的显示标签（各列值用 `/` 连接） |
| 脚本 | 脚本名称 |
| 状态 | 待执行 / 运行中 / 成功 / 失败 / 跳过 |

状态用颜色区分：
- 灰底 = 待执行
- 蓝底 = 运行中
- 绿底 = 成功
- 红底 = 失败
- 黄底 = 跳过

### 「脚本」页

勾选要执行的脚本。脚本列表与「日常」Tab 下拉框中的脚本一致
（由工作流发现层自动扫描，通过「工具 → 脚本配置」管理暴露和排序）。

### 「配置」页

| 操作 | 说明 |
|------|------|
| 当前配置 | 下拉框选择批量配置（可多配置） |
| 选择要执行的行 | 勾选条目表中的行，支持「全选 / 全不选」 |

---

## 7.2 批量配置

入口：「工具 → 批量配置」。

批量配置对话框管理多个命名配置，每个配置定义一套条目表和关联工作流。

### 界面结构

```
┌──────────────────────────────────────────────┐
│  配置：[下拉选择] [新建] [删除]                │
│  列名（逗号分隔）：[col1, col2, col3, ...]    │
│  用户名列：[可选]                              │
│  ┌──────────────────────────────────────┐    │
│  │  条目表（双击编辑单元格）               │    │
│  │  col1  │ col2  │ col3  │ ...         │    │
│  │  ...   │ ...   │ ...   │ ...         │    │
│  └──────────────────────────────────────┘    │
│  [添加行] [删除行]           [↑ 上移] [↓ 下移]│
│  预处理 wf：[____________] [浏览...]          │
│  切换 wf：  [____________] [浏览...]          │
│  后处理 wf：[____________] [浏览...]          │
│                              [保存] [取消]    │
└──────────────────────────────────────────────┘
```

### 配置管理

| 操作 | 说明 |
|------|------|
| 新建 | 输入配置名，创建空配置（默认两列） |
| 删除 | 删除当前配置（不可恢复） |
| 切换 | 下拉框切换不同配置 |

### 列名定义

在「列名」输入框中用逗号分隔定义列，如：

```
account, role, tail
```

修改列名后表格列头立即更新，已有数据保留。

### 条目表

每行代表一个待执行的条目。双击单元格编辑值。

| 操作 | 说明 |
|------|------|
| 添加行 | 在末尾添加空行 |
| 删除行 | 删除选中行 |
| 复制为新行 | 右键菜单，复制当前行数据到新行 |
| 上移/下移 | 调整行顺序 |

### 用户名列

指定哪一列的值作为**角色名**（对应用户管理中的用户）。

执行时，批量运行器会：
1. 读取该行「用户名列」的值
2. 自动切换到对应用户的 session
3. 脚本执行完毕后落盘 session

> 如果不设置用户名列，则不切换用户（所有条目共享当前 session）。

### 字段语义约定

在燕云调律场景中，常用列名约定：

| 字段 | 含义 |
|------|------|
| account | 游戏账号（用于判断是否需要重新登录） |
| role | 游戏角色名（对应应用中的「用户」概念，填入用户名列） |
| tail | 尾号（仅用于 UI 列表中匹配账号） |

## 7.3 工作流槽位

每个配置有三个 wf 槽位：

| 槽位 | 调用时机 |
|------|---------|
| **预处理 wf** | 仅在**首行**执行前调用（如初始化环境） |
| **切换 wf** | 在**后续每行**执行前调用（如切换账号、切换角色） |
| **后处理 wf** | **全部行执行完毕**后调用（如清理环境） |

### 切换 wf 的变量传递

预处理/切换 wf 接收以下变量：

| 变量 | 说明 |
|------|------|
| `batch_table` | 启用行列表（不含禁用行） |
| `batch_index` | 当前行在启用行中的序号（从 0 开始） |
| `batch_row` | 当前行数据（dict） |
| 各列值 | 行数据各列直接展开为同名变量 |

### 选择 wf 文件

点「浏览...」按钮选择 `.wf` 文件。默认打开 `config/system/workflows/` 目录。
也可以使用手动输入相对路径。

---

## 7.4 执行流程

点「开始批量执行 (F9)」后的完整流程：

```
遍历勾选的行：
  ├── 1. 调用 wf（首行→预处理，后续→切换）
  ├── 2. session 切换（按用户名列值切换当前用户）
  ├── 3. 顺序执行勾选的脚本
  └── 4. session 落盘（有脚本成功时保存）
全部结束后：
  └── 5. 调用后处理 wf
```

### 执行中的行为

| 场景 | 行为 |
|------|------|
| 切换 wf 失败 | 跳过该行所有脚本，继续下一行 |
| 脚本执行异常 | 记录失败，继续执行下一个脚本 |
| 按 F10 停止 | 当前条目完成后停止（不中断当前脚本） |
| 无启用行 | 日志提示「暂无启用的行，请到配置页勾选」 |
| 无勾选脚本 | 日志提示「请至少勾选一个脚本」 |

### 运行期间

- 脚本页和配置页被锁定（不可修改）
- 进度表实时更新状态
- 运行日志输出 `[批量]` 前缀的日志

---

## 7.5 脚本结果落盘

脚本执行后如果有返回值（dict 或 list），结果自动保存到：

```
config/session/output/{角色名}/{script_id}_{时间戳}.json
```
