# 附录 C. 功能激活与恢复

> 适用：支持一次性码的 0.15.0 预发布客户端；新正式安装包尚未交付。

在“配置管理 → 功能激活”粘贴一张码并点击“激活”。首次激活必须联网；完全离线模式下会提示先关闭该模式。激活在后台执行，完成前请等待，不重复点击或关闭窗口。

成功后自动绑定本机，并显示到期时间。再次填写同一码只恢复原授权，到期时间不会延长。如果首次请求成功但网络回复或本地保存失败，在同一台机器重试即可恢复；其他机器无法再次认领。

首次成功后可离线使用至到期。服务器停用只有再次联网才能确认，不能立即撤销已经离线的认证。没有适用会员包时不会进行包授权检查，可以重新填写同一码查询并恢复。

清除本机激活不释放服务器绑定；重装后只要设备序列号不变，仍可用原码恢复。更换设备或主板导致序列号变化时，需联系签发者处理，当前没有自动换绑功能。

预绑定码保留给不能联网的机器，仍按原方式离线激活。既有免绑定码和预绑定码无需重发。

若本地激活记录损坏，日志会提示恢复方法，“清除激活”仍可使用；清除后在原设备重新联网激活即可恢复既有绑定和期限。

在线会员内容状态与本地激活不同，见[附录 B 官方在线配置与会员内容](appendix-b-online-config.md)。
