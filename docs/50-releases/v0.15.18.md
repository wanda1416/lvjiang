# v0.15.18 — 模板跨分辨率匹配、图库空间 key 化与总览账本收敛

这一版主要修三处「升级后才发现不对」的地方：模板按名引用换分辨率后静默失配、
参考图库拿中文名当文件名导致改名困难、总览配额在每个读路径上刷重置行。前两项
会动到磁盘上的文件与键名，**如果你改过图库，请先看第 1 条**。

## ⚠️ 不兼容变动与升级指引

### 1. 图库空间名改为稳定 key（`手游` / `端游` → `android` / `desktop`）

- **现象：** 升级后图库显示的内容回到官方版本，自己加过或改过的参考图看不见了；
  图库空间下拉里会多出一项旧的「手游」（端游是「端游」）；主页面当前空间被切回默认。
- **原因：** 以前空间名直接拿中文展示名当文件名，改名就得连文件一起改。现在空间名是
  环境 key（`android` / `desktop`），中文只由空间 yaml 里的 `name` 字段展示；空间列表
  改为扫描目录得出，所以旧名的 yaml 变成一个**独立的用户空间**，不再叠加到系统空间上。
- **如何调整：** 从没改过图库 → 无需操作。改过的 → 你的图没有丢，仍在
  `config/local/references/手游/`（端游同理）。在图库管理里选中那个旧空间，把需要的图
  重新录入默认空间；确认无误后删除旧的用户空间。最后在图库下拉里重新选一次空间
  （旧的激活空间名已失效，会自动回落到默认空间）。

### 2. 参考图目录由 `bucket_*` 改为分组中文名（系统层）

- **现象：** 安装目录下 `config/system/references/android/` 里不再是 `bucket_0`、
  `bucket_C`，而是「装备培养」「调音材料」这类分组名。
- **原因：** 分组名即目录名，人工翻图和迁移本地覆盖时不用再对着编号猜属于哪一组。
- **如何调整：** 无需操作，安装器与 APK 会整目录替换。若你手工往
  `config/local/references/` 拷过系统参考图，或自己写过依赖 `bucket_*` 路径的脚本，
  需要按新分组名放回。

### 3. 总览配额跨周期归零改为「首次真实写入」时固化

- **现象：** 跨周期后总览照样显示 0，但历史页里的「重置」行不再自动刷出来——它会等到
  你下一次真实写入该条目时才补上，并在账本里呈现「重置 + 更新」两行。
- **原因：** 归零收敛为读时派生，写库只记录真实发生的机制行，避免每台设备每个 key
  各刷一批重置。
- **如何调整：** 无需操作，自动生效。

### 4. 自定义「关联目标」指向再生型条目时的写入口径

- **现象：** 如果你给再生型条目配过关联目标（`sync_targets`），升级后这类写入会先把
  恢复量固化再落业务行，账本上因此多一条「恢复」行，数值比之前更准。
- **原因：** 补齐自定义 regen 关联目标：以前这条路径不固化恢复量，会少算。系统自带的
  关联目标原本都是库存类，不受影响。
- **如何调整：** 无需操作。

### 5. 配置文件文本改为固定 LF 行尾

- **现象：** 程序保存过的 `config/system` / `config/local` 文本文件行尾统一为 LF；
  如果你把配置纳入了 git，会看到整个文件的 diff。
- **原因：** Windows 上按 CRLF 写会让跨端内容摘要漂移、diff 全是噪音。
- **如何调整：** 无需操作，不影响读取。

### 6. 按名引用模板改为按录制尺寸归一

- **现象：** `find … by image "名字"` 在**非录制分辨率**下以前会静默失配（分数掉到阈值
  以下，或缩放后模板比搜索区还大），现在会按录制宽高归一；同一分辨率下行为不变。
- **原因：** 以前固定按原始像素匹配，换分辨率必然失配。
- **如何调整：** 无需操作。未在索引里登记的模板仍按原始像素匹配，保持旧行为。

### 7. 安装目录与 Agent 包里的文档路径整体改为编号体系

- **现象：** `docs/10-game/…` → `docs/10-domain/01-yysls/…` 这类路径整体变化，文件名
  也带上了序号。
- **原因：** 文档 ID 与磁盘路径解耦，路径可以重排而 ID 保持稳定，Agent 侧按 ID 取文，
  不再依赖目录名。
- **如何调整：** 通过 MCP 读文档的 Agent 不受影响（旧 ID 仍能解析，新 ID 见包内
  manifest）。若你把文档路径写进了笔记或脚本，按新路径更新。

### 8. 新建图库空间必须填中文与英文名

- **现象：** 新建空空间时名称对话框要求简中与英文两个名字。
- **原因：** 空间名已是稳定 key，展示名要能随界面语言切换。
- **如何调整：** 只影响新建；已有空间可以随时改名，不影响数据。

## ✨ 新增功能

- **模板图管理与跨分辨率匹配。** 新增 `config/system|local/templates/templates.yaml`
  索引与「模板图管理页」：按分组管理模板、引用扫描（布局绑定 + 脚本 `by image`
  字面量）、改名与删除，新增图像可选择写入目标；布局分组归场景管理维护，在库层直接
  拒绝改名/删除。
- **图库空间支持稳定 key 与可编辑展示名。** 空间改名不再动数据文件，展示名可改中文
  与英文，管理界面里的切换只影响自己看的那一份，不改主页面运行空间。
- **参考图按分组目录存放。** 看图、搬图、备份都能按分组名直接操作。
- **网页端模拟计算器按玩法过滤词条。** 玩法推荐词条表随资产导出，网页按玩法收敛候选。
- **Agent 文档：脚本开发任务书与编写指南。** 新增 `.wf` 脚本开发的现状说明与待实现
  契约、Profile 读写操作指引，以及文档身份与磁盘路径解耦后的发行包校验门禁。
- 「帮助 → 反馈」改为可直接提交的表单（截图、脱敏日志、提交前预览），回复走填写的邮箱。

## 🔧 修复

- **再生型条目的自定义关联目标不再少算恢复量。** 以前这条路径不固化恢复量就直接落业务
  行，恢复量被漏掉；现在与直接写入该项同构（先固化恢复、再落业务行，失败一起回滚）。
- **配置文本被 Windows 写成 CRLF。** 统一按 LF 写，跨端 diff 与内容摘要不再漂移。
- **按名引用的模板换分辨率后静默失配。** 见不兼容第 6 条。
- **图库空间文案残留。** 补齐图库空间相关中英文文案，清掉已废弃的「激活空间」措辞。

## 📦 重构

- **总览配额归零收敛为读时派生**（写入时固化 `reset` + `set`），删掉了读路径上的自动
  刷盘，账本只留真实变更。
- **参考图库目录按分组重建**，写入侧跟随分组，键名与目录一一对应。
- **文档体系编号化**：顶层目录与子目录、文件全量编号，历史与发布组迁入稳定路径，
  发布解析与 Agent 文档兼容层同步更新。
- **图库空间从「名册 + 中文名」改为「目录即事实 + 稳定 key」**，管理界面只读切换。

## 📚 文档

- 新增四份权威契约（文档标准、领域事实、数据模型、发布规范）并纠正 Profile 同步的
  旧描述；AGENTS 里的领域事实改为引用文档。
- 用户指南附录按现役内容重组为 A/B/C，配置升级调整归档；反馈相关说明同步更新。
- 隐私说明补账户注册登录与多端同步章节，并新增反馈提交一条（含上传范围、脱敏与保留期）。
