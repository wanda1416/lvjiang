# 律匠需求文档 v5

## 1. 运行环境

| 项目 | 说明 |
|------|------|
| 游戏运行 | 手机端燕云十六声手游 |
| 投屏方式 | 手机投屏到 PC 端（以 vivo 自带投屏为蓝本，不绑定特定品牌） |
| 投屏要求 | 必须支持反向控制（PC 端操作可转发到手机） |
| 控制方式 | Python 模拟鼠标点击 PC 端投屏窗口 |
| 输入特性 | 只有点击事件被转发到手机，移动轨迹无关 |
| 反作弊策略 | 模拟操作发生在 PC 端，不直接注入手机端，规避手游反作弊检测 |

### 1.1 架构链路

```
手机运行游戏
    ↓ 投屏（视频流 + 反向控制通道）
PC 端投屏窗口（画面显示 + 鼠标事件注入）
    ↓
律匠工具（截屏识别 → 决策 → 模拟点击投屏窗口）
    ↓ 点击事件经投屏协议转发
手机端执行操作
```

### 1.2 投屏方案说明

- 以 vivo 系统自带投屏为参考实现（USB/WiFi 投屏，支持反向操控）
- 工具本身不依赖特定投屏品牌/协议，只要求：
  1. PC 端存在一个可截屏的窗口（显示手机画面）
  2. 该窗口支持鼠标点击事件转发到手机
- 用户自行完成投屏连接，律匠只负责找到并控制投屏窗口

### 1.3 工具形态

- **PyQt6 图形界面应用**，提供完整的可视化交互
- 主窗口：投屏窗口定位、流派选择、模式选择、执行状态展示
- 坐标校准工具：内嵌于主界面，支持截图+框选区域+生成坐标配置
- 实时日志面板：显示每步决策信息
- 统计报表：处理装备数量、保留/回收/精调汇总

## 2. 用户操作流程

GUI 交互流程：

```
启动律匠（python -m lvjiang）
    ↓
【主窗口】
    - 左侧：投屏窗口选择/刷新、流派选择（下拉框）、模式选择
    - 右侧：实时画面预览 + 识别结果叠加
    - 底部：日志面板 + 操作按钮（开始/暂停/停止）
    ↓
【步骤1】用户在 GUI 中选择投屏窗口、勾选目标流派
    ↓
【步骤2】点击"扫描装备"按钮，自动扫描当前穿戴装备
    - 截屏 → OCR 识别当前穿戴的 7 件装备
    - 判定每件是否为"顶级装备"（跨流派通用标准）
    - GUI 展示扫描结果：
      [保留] 武器 - 最大外功攻击+敏+势 (T0)
      [保留] 头部 - 三率×3 (T0)
      [优化] 腿部 - 劲+精准 (非T0)
    - 顶级装备自动标记为"保留"，不参与后续调律
    - 非顶级装备进入待处理池
    ↓
【步骤3】用户选择处理模式（批量筛选 / 精调）
    ↓
【步骤4】点击"开始执行"，实时查看进度和日志
```

## 3. 配置与持久化

```yaml
# 用户配置
user_config:
  target_flow: "会心双刀"  # 当前目标流派
  
  # 顶级判定开关
  auto_protect_top_tier: true
  
  # 保留策略
  keep_strategy: "top2"  # top1 / top2 / top3
  
  # 调律预算
  budget:
    max_tunes_per_equip: 20
    material_threshold: 10  # 低于此数量暂停
  
  # 延迟参数（模拟人类）
  delay:
    before_click_wait: [0.1, 0.3]  # 点击前延迟（引擎级）
    after_click_wait: [0.1, 0.2]   # 点击后延迟（引擎级）
    custom:                        # 命名等待参数（供工作流 wait 按 key 引用）
      page_refresh_wait: [2.0, 3.0]  # 页面切换/刷新、调律结果出现等待
```
