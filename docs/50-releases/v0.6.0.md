# v0.6.0 — 技能轴查看器、词条培养分析、配置分层

## 律匠 v0.6.0

本版本新增技能轴查看器（导入 Excel 查看竞速轴与伤害来源）、词条培养影响分析、图库空间目录化管理，并重构配置分层体系与出厂内容保护机制，全面提升 UI 稳定性和交互体验。

---

### ✨ 新增功能

- **技能轴查看器**：导入 Excel 查看竞速轴与伤害来源，支持多套配装对比
- **词条培养影响分析**：量化各词条对毕业属性的影响，辅助培养决策
- **装备合法性校验**：新增装备合法性验证，不合法装备卡片显示角标提示
- **图库空间目录化**：图库参照按空间目录化管理，支持新增/删除空间
- **统一工具栏布局**：工具栏与脚本展示区域统一布局风格
- **统一按钮与批量列表**：批量任务列表与按钮样式统一管理
- **简化低精度录制**：低精度输入录制输出格式简化

---

### 🔧 修复

- **最优组合「排除模拟」**：修复排除模拟装备选项无效的问题
- **装备卡片交互**：修复装备卡片交互中嵌套事件循环导致的卡顿与异常
- **批量登录与角色切换**：提升批量任务中登录和角色切换的稳健性
- **脚本配置移动**：修复脚本配置对话框移动时复用单元格控件导致的显示异常
- **退出崩溃**：修复解释器退出时 Qt 对象释放顺序导致的崩溃
- **工作流退出**：等待工作流线程完全退出后再释放资源，避免悬挂线程
- **会心调律规则**：修正会心调律规则中的武器配置错误

---

### 📦 重构

- **配置分层与出厂保护**：重构配置解析器，完善配置分层机制与出厂内容保护，防止用户误删系统配置
- **批量子过程合并**：将三个 `_` 前缀子过程合并并入 `prepare_item.wf`，简化批量流程结构
- **工作流运行环境锁定**：固定工作流运行环境并锁定批量上下文，避免状态污染

- **配置分层架构文档**：新增配置分层架构说明
