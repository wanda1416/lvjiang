# v0.8.0 — 江湖号令 PC 端可用、配置在线下发、批量执行可靠性

## 律匠 v0.8.0

**「江湖号令」日常现已完整支持 PC 端游窗口**——此前该流程只能在手机投屏 / 模拟器上跑，端游因为菜单项位置不固定、无法用坐标点击而缺失。本版本补齐了端游适配：`press` 支持变量按键名，扫出「看报」在第几列就按第几个数字键；导航改走统一的子过程（端游按 ESC、安卓才点菜单）；相关场景布局同步更新。端游的装备回收也一并修好——确认改按空格，此前点击「确认」区域在端游无效，回收弹窗滞留会让后续操作接连错位。

**后台模式也真正回到了「后台」**：不再抢占焦点，副屏挂机、主屏干活的用法恢复可用。

此外新增配置在线下发层（场景/布局/调律规则可不发版热修）、批量执行的顺序与状态修正、工作流文件头参数化与严格校验，并恢复了 52 条被遮蔽的英文译文。

**升级前请先读下面的「不兼容变动与升级指引」**——本版本有若干需要你动手确认的变化。

### ⚠️ 不兼容变动与升级指引

#### 1. 默认暂停热键由 F8 改为 F11

- **现象**：全新安装的暂停/恢复热键是 **F11**；而**曾经打开过「配置管理」并保存过任何设置的老用户，暂停键仍是 F8**，按 F11 不会有任何反应。
- **原因**：默认值变更不会覆盖你已保存的按键配置。
- **如何调整**：想统一到 F11 的，到 **配置管理 → 热键设置** 手动改；想继续用 F8 的无需操作。文档已按新默认值 F11 描述，与你的实际按键不一致时以「热键设置」页显示的为准。

#### 2. 会心小外的「翊翊(不推荐)」更名为「翊翊」

- **现象**：升级后打开调律配置，会心小外的 **翊翊** 玩法可能变成**未勾选**状态。
- **原因**：玩法勾选按**名字**保存，旧名「翊翊(不推荐)」与新名对不上。
- **如何调整**：在调律配置里**重新勾选「翊翊」并保存**。其他玩法不受影响。

#### 3. 系统调律规则收严，回收会变多

- **现象**：同样的装备，本版本判「回收」的比 0.7.1 多。影响全部 7 个内置规则，其中**威威大王(beta) 的胫甲/腕甲**变化最大——0.7.1 时该部位没有任何垃圾条件（几乎全保留），现在关闭「保留对玩家增效」时必须带「对首领单位增伤」，否则回收。
- **原因**：补齐了环/佩的「全武学增效」门槛、各部位属攻封顶，并与会心大外/小外的判定口径对齐。
- **如何调整**：**回收不可逆**。首次运行前建议先用少量装备试跑，确认判定符合预期；或在调律配置里按需打开「保留对玩家增效 / 保留单体奇术增」等开关。

#### 4. 批量：配置里新增的行现在会真的执行

- **现象**：如果你在「批量配置」里加过行，这些行此前在勾选页**显示为打勾、执行时却被跳过**；本版本它们会**真的参与执行**。
- **原因**：勾选页与执行侧对「历史勾选记录短于当前行数」的兜底规则不一致，现已统一为「缺失位视为启用」。
- **如何调整**：**升级后首次运行批量前，请到「配置」页核对一遍行勾选状态**——尤其是按游戏账号分行的配置，避免多跑了不想跑的号。

#### 5. 批量：行的禁用状态改为随行搬运

- **现象**：在「批量配置」里增删、上下移动行之后，禁用状态不再错位到别的行上。
- **原因**：此前禁用状态是按行号索引的独立数组，配置里一动行就张冠李戴——被禁用的账号照跑、启用的反而被跳过。
- **如何调整**：无需操作。但因为历史数据是按旧的行号语义存的，**首次打开「配置」页时请核对一遍禁用状态**是否落在你预期的行上。

#### 6. 批量：单条目默认跳过生命周期工作流

- **现象**：只启用 1 行时，`batch_setup` / `prepare_item` / `finish_item` / `batch_teardown` 默认**不再执行**（0.7.1 总是执行）。
- **原因**：新增配置项 `skip_lifecycle_for_single_item`，默认开启——单条目直接使用当前现场，省掉一轮切换。
- **如何调整**：需要单条目也跑完整生命周期的，在「批量配置」里**取消勾选「单条目直通」**。

#### 7. 插件配置 `yysls.json` 并入 `session.json`

- **现象**：无可见变化。
- **原因**：yysls 插件数据收进 `session.json` 的 `yysls` 节点，统一存储位置。
- **如何调整**：**无需操作，自动迁移**——首次写入时以旧文件内容为基底完成迁移，且旧的 `yysls.json` 不会被改动，降级回 0.7.1 仍能读到自己的数据。

#### 8. 后台模式不再激活目标窗口（投屏用户请注意）

- **现象**：窗口模式勾选「后台模式」时，程序不再把目标窗口切到前台——你的焦点不会被抢走，可以一边挂机一边用电脑。**代价是 scrcpy 投屏窗这类 SDL 窗口在后台模式下可能收不到点击。**
- **原因**：此前每次点击/移动/滚动/拖拽都会先 `SetForegroundWindow` 把目标窗口拉到前台再还原焦点，于是「后台」只剩下「不移动光标」。该行为是当年排查一个投递问题时在根因未明的情况下加入的猜测性改动，真正的修复是同批的 DPI 坐标转换。
- **如何调整**：端游窗口、多数普通窗口无需任何操作。**若你用手机投屏且发现点击不生效，改用前台模式**；确需窗口在前台时，正确做法是自己点一下窗口激活、再用热键启动任务。

#### 9. 新增 `config/remote` 在线下发层（⚠️ 本地改过配置的用户请注意）

- **现象**：系统配置（场景、布局、调律规则）今后可以不发版直接下发修正。**但如果你自己改过、或在场景编辑器里重画过某份配置，系统的修正对你不会生效。**
- **原因**：配置优先级是 `local > remote > system`，其中 **`local` 无条件最高**——你的本地覆盖会一直遮住系统内容和在线下发内容。
- **如何调整**：本版本修正了**桌面端调律详情布局**（`equip_tune_detail`，收紧了 `auto_add` / `reset_confirm` 等 4 个区域）。**如果你自己调整过这个布局，需要手动同步，或删除本地覆盖以回到系统值。**其余配置同理。

#### 10. Android：`versionCode` 34 → 35，设备上的配置会重新解压

- **现象**：升级后首次启动 App 会重新解压系统配置。
- **原因**：本版本改动了 86 个 `config/system` 文件，`versionCode` 是配置解压的判据。
- **如何调整**：无需操作。

#### 11. 新建用户名增加字符校验

- **现象**：新建用户时，只接受中文、字母、数字、下划线、连字符，长度 1~32。
- **原因**：用户名会直接作为文件名使用，`../`、`/`、`:` 等字符会造成路径逃逸、凭空建目录，或在 Windows 下存不了盘。
- **如何调整**：**存量用户不受影响**，仅约束新建。

> 其余变化均向后兼容。特别地，`.wf` 文件头元数据虽然加了严格校验，但**未知字段一律忽略**，0.7 时代写的脚本无需修改即可继续使用；单个脚本的元数据错误也只影响它自己，不会中断整个脚本列表。

### ✨ 新增功能

- **「江湖号令」支持 PC 端游**：端游菜单项位置不固定，此前只能靠坐标点击、PC 端因而无法跑通。现改为扫描动作列表定位「看报」等项，再按对应数字键进入；导航统一走子过程（端游按 ESC、安卓才点菜单），配套更新江湖号令相关场景布局
- **`press` 支持变量按键名**：`press $key` —— 键名可来自扫描结果，四种模式（完整 / hold / down / up）与等待子句均可用；取值后统一标准化，扫出来的数字列号可直接按
- **配置在线下发层**：实体配置加 `content_version`，新增 `config/remote` 层（`remote` 需版本严格更高才顶替 `system`，`local` 恒最高）——场景、布局、调律规则可在不发版的前提下热修
- **工作流文件头参数化**：自动购买脚本的购买类目与营生开放为参数，可在运行前直接选择
- **文件头元数据严格校验**：`.wf` 的 `#%` 声明按类型校验（select/number/bool/checkgroup），写错立刻报出具体位置；未知字段忽略，向后兼容
- **批量表头管理列**：直接在表头增删、重命名批量配置的列
- **批量单条目直通**：只有一个条目时跳过批量生命周期工作流，省掉一轮现场切换（新增配置项，默认开启）
- **用户数据模型上限开关**：note 模型的「显示上限」开关真正生效，数值型 note 按 `X/Y` 展示并按上限截断
- **默认暂停热键调整为 F11**

### 🔧 修复

- **端游回收装备不生效**：回收确认此前统一点击「确认」区域，但端游那里不是可点按钮，点了没反应——回收弹窗滞留会让后续操作全部错位。现改为按空格确认（与 X 触发回收成对），安卓端仍点击确认区域
- **英文界面下调律找不到材料**：大律准石与狗粮的 label 被当成界面文案送进了翻译，英文界面下变成 `Gold Fodder` 等，与参考图库的中文 label 永远匹配不上——库存查不到、狗粮必然「材料槽位定位失败」。这类 label 属于数据键，已不再经翻译
- **后台模式抢占焦点**：窗口模式的后台投递每次操作都会把目标窗口切到前台再还原，焦点被反复抢走，「后台」实际只剩下「不移动光标」——现已不再激活目标窗口（投屏用户注意事项见上）
- **Windows 下按钮文字被截断**：数据模型对话框的工具栏按钮写死固定宽度，Segoe UI 下装不下「新增 / 上移 / 下移」，现改为按字体度量自适应
- **批量执行顺序与实际不符**：脚本页的「上移/下移」只改了序号数字、不移动行，且执行顺序实际等于勾选复选框的先后——现已改为可见行顺序即执行顺序
- **批量行禁用状态错位**：配置里增删/移动行后，禁用状态会落到别的行上（按账号分行时等于跑错号）
- **批量进度表状态错行**：同名条目会互相顶掉状态，条目标签算法不一致时状态一行都刷不到，看起来像卡死
- **批量报告统计**：非中文界面下条目收尾失败被算成「全部成功」
- **调律结束重复输出报告**：自动调律结束时把整份报告重复转储进日志面板
- **桌面端退出调律后未回收**：按 X 退出后回收动作可能被跳过
- **桌面端调律详情布局**：修正 `auto_add`、`reset_confirm` 等区域的识别范围
- **会心流派调律规则**：补齐 keep_wanjia 分档条件，与会心大外/小外口径对齐
- **会心小外玩法名称**：「翊翊(不推荐)」统一为「翊翊」
- **材料数量识别失败**：识别不到数量时不再中断，改为容错处理
- **工作流访问禁用布局**：运行时引用已禁用的布局对象会取到零坐标，现直接拒绝并报错
- **工作流静态校验误报**：执行前校验会被无关页面的过程挡住，现只检查可达过程
- **工作流对话框无法立即停止**：弹窗阻塞时 F10 停止不生效
- **OCR 清洗规则误写盘**：打开对话框即触发多次写盘，改为显式保存/取消
- **场景编辑器手抖误判修改**：画布加拖拽死区，单纯点击不再算作修改
- **退出时段错误**：关闭场景编辑器时析构顺序导致的崩溃
- **英文界面 52 条译文被遮蔽**：占位段覆盖了正式译文，英文覆盖 879 → 930，并新增一致性门禁
- **用户名无校验**：`../`、`/`、`:` 等字符会造成路径逃逸或存盘失败
- **下拉框选项被截断**：弹出列表改为按最长选项自适应
- **调律导航栏不可拖宽**、**紧凑战斗属性定音重叠**、**复选参数组换行高度错误**、**配置类按钮样式不统一**

### 📦 重构

- **core 与插件解耦**：通用层不再认识 yysls 的具体路径与业务文案，配置合并策略改由插件自行注册
- **通用层业务文案改由插件提供**：解析路径不再经过 `tr()`，避免非中文界面下匹配失效

### 📚 文档

- **DSL 语法文档**：控制流拆分为 05.1–05.3，`default` 移回基础指令一节
- **文档与实现对齐**：修正多处进度落后或与实现不符的描述
