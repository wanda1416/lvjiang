# 5. 运行自动调律

## 5.1 运行前检查

1. 已完成[连接手机](01-quick-start.md#13-连接手机)（定位/连接成功）
2. 手机端游戏**停在背包装备页**（能看到装备列表的界面）
3. 大律准石、狗粮等材料按需备足（或在[材料处理](04-03-behavior-config.md#材料处理)页配好不足时的处置方式）
4. 已在[调律配置 (F6)](04-01-tuning-config-overview.md)中设置好规则和门槛

---

## 5.2 调律 Tab 三页

切到左侧 **「调律」Tab**，有三个子页：

### 「规则」页

- 勾选要启用的**调律规则**（对应调律配置中定义的规则）
- 每个规则下可勾选具体**玩法**（至少各选一个）
- 规则显示名来自调律配置中的规则名称

### 「部位」页

- 勾选要处理的装备部位：主武器、副武器、环、佩、冠胄、胸甲、胫甲、腕甲
- 支持 **「全选 / 取消全选」** 快捷按钮
- 某些部位可能因规则配置而不可选（如副武器在某些流派中锁定）

### 「更多」页

全局开关和测试选项：

| 配置项 | 说明 |
|--------|------|
| 保留 PVP 装备 | 勾选后跳过带 PVP 标记的装备 |
| 跳过实际调律 | 仅模拟进出调律页面，不执行实际调律操作（测试滚动用） |
| 初始跳过 | 跳过背包中前 N 行 M 列的装备（从指定位置开始） |
| 指定调律 | 只调律指定位置的装备（与初始跳过互斥） |

> **初始跳过** 与 **指定调律** 互斥：勾一个另一个置灰。

---

## 5.3 启动与停止

点顶部绿色 **「开始调律 (F9)」** 启动。

| 按钮状态 | 含义 |
|----------|------|
| 绿色「开始调律 (F9)」 | 就绪，可以启动 |
| 红色「停止 (F10)」 | 运行中，点击或按 F10 停止 |
| 黄色「未连接」 | 尚未完成定位/连接，请先连接手机 |

运行中随时按 **F10** 停止（等待中也能立即打断）。

---

## 5.4 运行中行为

- 右侧「运行日志」实时输出每件装备的判定与操作
- 预览区可看实时画面（需先点「显示预览」展开）
- 自动化流程：遍历选中部位 → 扫描装备 → 判定 → 进调律/跳过 → 调律/回收/保留 → 下一件

---

## 5.5 调律说明文档

结束后自动生成叙事化的**调律说明文档**：

```
logs/tuning/调律说明_用户名_时间戳.md
```

路径同时打印在日志里。

### 文档内容

文档记录每件进入调律的装备的完整决策过程：

| 内容 | 说明 |
|------|------|
| 装备标识 | 部位 + 位置 |
| 判定依据 | 为什么决定调律/跳过/回收 |
| 每轮结果 | 每轮调律后的词条变化和评级 |
| 最终处置 | 最终状态（调成/调废/回收/保留） |

> 调律说明文档是排查问题的最佳入口。如果某件装备的处置结果不符合预期，
> 查看文档中的判定依据可以定位是哪条规则生效。
