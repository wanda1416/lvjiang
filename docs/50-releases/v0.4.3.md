# v0.4.3 — 暂停/恢复机制、热键分离与工作环境配置

## 律匠 v0.4.3

本版本新增 DSL/Python 工作流暂停/恢复机制，修复 F8 双触发问题并将脚本录制改绑 F12，新增工作环境配置与 DSL 内置函数。

---

### ✨ 新增功能

- **工作流暂停/恢复机制**：DSL 工作流支持 F8 暂停、F8 恢复；`BaseWorkflow.is_stopped` 嵌入暂停检查点，所有 Python 工作流（如自动调律）自动获得暂停支持；批量引擎 `BatchContext` 注入 `pause_event` 支持暂停
- **工作环境配置**：新增 `env` 概念，支持桌面/模拟器等多环境切换；新增 `load_available_envs()` / `load_env()` / `save_env()` 配置 API
- **secondary_confirm 延迟参数**：新增配置化二次确认等待参数，替换硬编码等待
- **daily_jianghu 看报独立化**：看报操作独立为 `do_kanbao` 子工作流，增加主页判断防止未解锁时误操作

---

### 🔧 修复

- **F8 双触发导致暂停/恢复互相抵消**：全局热键与 `keyPressEvent` 同时响应 F8，两次调用 `_on_pause_resume()` 互相抵消；修复为全局热键激活时 `keyPressEvent` 跳过 F8 处理
- **脚本录制热键改绑 F12**：F8 现在仅用于暂停/恢复，脚本录制移至 F12
- **PostMessage 后台投递回归标记**：窗口模式的后台 PostMessage 投递出现严重回归问题，代码与 README 均标记为暂不可用，详见 `docs/desktop_input_blocker.md`

---

### 📦 重构

- **战斗属性布局策略模式重构**：`CardLayoutStrategy` 策略模式抽取，`CombatLayoutMixin` 声明 `_strategy` 类型注解
- **页面检测公共方法抽取**：`is_in_main_page` / `is_in_menu_page` 从内联检测中抽取为公共方法，消除重复
