# 出装搭配与模拟计算器

> 状态：已实现（2026-10-06，基线 v0.13.11）。不含自动调律联动。
>
> 实现结构（数据文件、总词条分配算法）、界面分栏与卡片口径见
> [39-runtime/04-build-calculator.md](../../30-architecture/39-runtime/04-build-calculator.md)。

## 范围

备战方案原「模拟装备」入口改为独立「模拟计算器」；「创建模拟装备」移到删除筛选
装备／批量复制装备左侧，继续只创建当前用户的单件模拟装备。

出装搭配独立于玩法配置：新建、编辑、复制与删除都不嵌入 playstyles，也不纳入整份
游戏配置保存；稳定 ID 与显示名称分离，每次保存重读文件，仅合并当前搭配，冲突时
提示重载。

## 搭配内容与边界

- 搭配保存玩法、PVE/PVP、装备等级、承音／普通数值口径、八件装备词条和套装、
  弓玦套装与等级、强制／最佳／推荐要求；总词条分布由八件装备派生。
- PVE 默认公共要求为首领增伤两条；其他要求由搭配编辑，不改变旧调律规则。
- 模拟器冻结打开时当前方案的基础属性、毕业率模型、用户及真实装备作为对照。写回
  只保存搭配，不保存私人基础属性、最终面板、用户信息或真实装备指纹。
- 加载另一搭配不改变活动备战方案；修改未保存的草稿切换／关闭时必须确认。
- 弓玦归搭配定义所有：计算时使用不含弓玦的方案基础属性，再叠加目标弓玦；真实方案
  的弓玦不随模拟编辑改动。
- 装备套装复用现有公共属性计算链。

## 验收

- 每次调整都显示总数、要求满足情况、推荐八件分布、战斗属性与毕业率；无法分配时
  清空过期结果，不写入非法组合。
- 未满 40 条允许保存合法草稿；强制要求未满足要明确标记，不作为合格完整目标。
- 只提供总量到合法装备位置的推荐，不宣称 DPS 全局最优，也不接入自动调律运行流程。
