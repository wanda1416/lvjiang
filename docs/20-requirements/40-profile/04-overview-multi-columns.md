# 数据总览批量新增列

> 状态：已实现（2026-10-07，基线 v0.13.13）。已通过多选、批量保存与单选边界回归。

表头右键「右侧新增列」打开字段多选窗口，按数据模型已有的类型、定义分组和字段顺序
展示复选框树；仅排除当前总览分组已经配置的字段，其他总览分组仍可使用同一字段。
搜索匹配字段名称或 key，不丢弃已勾选项；整组勾选与「全选当前结果」只作用于当前
搜索可见候选，「清空选择」清除全部选择。底部「添加（N）」无选择时禁用，取消不落盘。

确认后按树中的字段顺序连续插到右键列的右侧；用户名列右侧从第一列开始。
插入位置用原列的稳定 key 定位，保存时读取最新分组并去重，保留其他列（含失效字段）
和其他分组。原列在编辑期间被移除时提示重新选择，不悄悄换位置。
批量插入一次更新列配置，一次更新列宽，一次刷新所属表格；保留原列宽和用户名列宽。
「替换当前列」及批量配置「指定排序」仍使用原单选选择器。不改数据库或配置结构。

回归保护：搜索保留选择、筛选后的整组/全选范围、显示顺序、取消不写入、并发去重与
原列定位、失效字段保留、多列插入的列宽与单次刷新，以及现有单选入口。
