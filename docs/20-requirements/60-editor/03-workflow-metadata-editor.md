# 工作流元数据表单与保存位置
> 状态：已实现（2026-10-06，基线 v0.13.11）。

## 范围

脚本编辑器的「元数据」页管理文件第一行起连续的整个 `#%` 区块。表单覆盖当前
运行时支持的全部顶层字段和五种参数类型，参数的环境、显示条件、选项和默认值
均可编辑。未知参数类型原样保留并在类型控件中提示，可改选受支持类型；
其他无法解释的声明显示原因并禁用表单应用，代码页仍可修正原文。

`#%` 是脚本内容；保存位置是文件所属的配置层，不写入 `#%`。普通用户只能在
`local` 新建和编辑；`system` 与远程脚本只读，修改前须显式复制到本地。
开发者可选 `local` 或 `system`，编辑现有文件时默认显示实际来源层。

## 编辑与保存边界

- 长文本平时占一行，右侧按钮展开为多行输入；收起不丢失换行。
- 参数顺序、选项的稳定值与显示名分别维护；缺省字段不因打开表单而写入。
- 切换页签保留未应用的表单草稿；代码和表单同时变更时，重新加载前先提示。
- 「应用到代码」只更新编辑缓冲区；「保存」才写文件。跨层保存成功后移除旧层
  文件，目标同路径文件存在时先确认。
- 跨层迁移还要复制脚本引用的相对录制轨迹；旧轨迹可能被其他脚本共用，不删除。
- 保存后沿用脚本编辑器现有的语法与布局引用校验。
