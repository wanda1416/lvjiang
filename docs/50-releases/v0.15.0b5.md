# v0.15.0b5 — 手机同步与模板编辑（Beta5）

本版本是 0.15.0 的第五个测试包，供手动下载测试，不替换当前正式版 0.13.15，
不向普通客户端提示更新。此前测试包的调整见 [Beta1](v0.15.0b1.md)、
[Beta3](v0.15.0b3.md) 和 [Beta4](v0.15.0b4.md)。

## ⚠️ 不兼容变动与升级指引

- **旧配置格式不再自动转换。** 0.15.0 以 0.13.15 正常保存的配置为基线，
  不再读取旧批量配置、旧 OCR 文件、旧调律字段或旧插件会话节点。
  更早版本请先升级并正常运行 0.13.15，在对应编辑器保存配置；
  具体格式及手工调整见[配置升级调整](../60-userguide/12-config-upgrade.md)。
  Profile、任务历史和调律历史数据库仍保留版本管理，不要清理个人数据库。
- **活动选择与界面状态分离。** 当前用户、布局、方案及日常脚本选择读取 interface.json，
  不迁移 session.json 中残留的旧选择；升级后必要时重新选择。
  日常脚本展示分组会随选择保存，脚本排序与显示名偏好仍保留在 session.json。
- **PC 与手机须一起升级到 Beta5 才能下发配置。** 同步协议支持独立保留手机任务参数和
  批量配置，旧 APK 不接受新协议。下发仍单向覆盖配置与 Profile，不合并手机 Profile；
  手机历史、日志和执行结果保留，历史回传需用户另行操作。
- **好友送礼红心判定不再使用模板。** 系统缩小情义值上限区域并删除旧红心模板，
  相关脚本需更新到红色占比判定；脚本位于独立 local 仓库，不随本公开包预置。
  若 local 覆盖了 chat_main 布局，请自行同步新区域；不会覆盖或删除用户 local。
- 便携包解压到新目录，再复制个人 config/local 和 config/session，保留新包 baseline.json，
  跳过旧 content.json 与 config.lock。在线配置按 0.15.0 系列匹配，
  本包更新状态独立位于 updates/v0.15.0b5，不复制其他 Beta 的更新状态。

## ✨ 新增功能

- 移动设备支持独立回传手机任务历史、日志及插件声明的历史数据，不回写手机 Profile。
- 手机配置下发分别提供「保留手机任务参数」「保留手机批量配置」，默认勾选。
- 大世界地图管理支持地域目录、探查底图导入与预览，以及重叠截图拼接工具。

## 🔧 修复

- 启动更新检查、公告与在线配置同步遵循网络开关及离线模式；
  用户拒绝匿名统计后不再因缺少选择记录反复询问。
- 初始化时缺少活动用户选择，不再导致备战方案无法自动加载；当前用户统一按有效名册选择。
- 日常脚本展示分组能够保存并在下次启动恢复，不再总是回到全部分组。
- 收敛配置写权限及锁，避免配置安装与任务快照准备之间因重复获取文件锁而等待。

## 📦 重构

- 模板编辑只保留整区域截取，需要更小模板时缩小区域；操作栏合为一行：
  截取模版、测试、解除、兼容反色、阈值与绑定状态。反色匹配继续保留。

更新手机同步、历史回传、配置升级、日常脚本分组及模板编辑指南。
