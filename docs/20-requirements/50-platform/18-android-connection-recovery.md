# Android 连接恢复与输入降级

> 状态：已实现（2026-10-12，基线 v0.15.0）；连接重试、ADB 输入降级及停止边界有定向回归，实机断线场景需单独验收。
> 2026-11-08 增补「画面流故障」：设置页改名 Android 连接设置，新增建立流式传输尝试次数，
> 代理／ADB／流式三类恢复次数默认统一为 5 次。

## 需求与边界

代理进程退出或 ADB 断开不能直接中断后续任务。配置管理以“基础设置、高级设置、
应用注册……”排列；高级设置 →「Android 连接设置」维护本机连接策略，保存在
session.json 的 settings。默认允许 ADB 输入降级，**建立流式传输 5 次、代理重连
5 次、ADB 重连 5 次**，重试间隔 2 秒。建立流式传输次数同时用于首次连接与断连后
的自动恢复。默认值只影响未显式保存过该字段的用户；老用户请在设置页确认当前值。
任务启动固定策略；运行态降级不修改用户选定的输入方式。

代理重连重新建立转发、协议握手与执行占用，不只复用旧 socket。代理恢复失败后，
恢复当前设备 ADB；普通点击、滑动、推住和按键可降级，不能把并发、多指手势改成顺序操作。
不关闭全局 ADB 服务，不影响其他设备；不自动启动游戏或修改手机权限。

全部尝试失败进入等待连接状态，发起非模态是／否询问，主页面仍可停止、暂停和操作其他目标。
选择是重新检查连接，选择否停止对应执行链；无人值守不能跳过此询问或继续后续任务。
未发出的输入可在连接恢复后继续；已发出而未取得响应的输入不自动重放，先等待用户确认。
用户确认继续表示允许重新尝试当前动作。停止请求必须打断重试间隔与人工等待。

直接 ADB 与代理使用同一个设备级恢复协调器及运行策略。截图、设备属性等明确的
只读操作超时可自动重试；输入超时或响应丢失仍需确认，不通过命令字符串猜测安全性。
只读请求连续失败达到 ADB 重试次数后也需人工确认，不能因连接探测正常而无限重试。
代理明确拒绝执行占用等业务操作时直接向调用方报告，不作为传输故障降级绕过。
连接探测成功不直接宣告任务恢复；请求重试成功后才更新展示，保留用户主动暂停状态。
「重新检查」只唤醒对应执行链，不提前隐藏恢复提示或显示任务已继续。

长按与普通单指操作可按已有 ADB 能力降级，多指或并发手势不得顺序模拟。
截图方式不随输入降级改变；代理截图断线等待恢复，而不是当作空白 OCR 结果。
没有运行任务的预览失败只报告连接问题，不进入无人接收的永久人工等待。
重试间隔和人工等待可停止；正在执行的 socket 或 ADB 子进程仍受单次超时约束。

## 画面流故障（推送式视频流）

视频流是常驻通道：帧不再更新时，画面看起来仍然"正常"，识别与点击却全在旧帧上进行。
因此流健康必须独立判定，并接入上面同一套恢复编排。

判定按四条独立事实组合，缺一不可（阈值均为真机实测值）：

| 事实 | 判定 | 处置 |
|---|---|---|
| socket EOF / 读异常 | 立即（实测 0.1s） | 通道断开，重建会话 |
| 收字节数连续 3 秒为零（无 EOF） | 半开连接 | 关 socket → 重建会话 |
| 帧计数连续 5 秒不推进 | 需先查设备屏幕状态 | 亮屏 → 采集停摆；息屏 → 正常空转 |
| 连续 30 个包无法解码 | 数据在流但画面出不来 | 先重建解码器，再重建会话 |

**息屏必须豁免**：实测该机型息屏后编码器 0 帧 0 字节，与"编码器停摆"在客户端完全
同构，只有 `mWakefulness` 这类设备侧状态能区分；亮屏静止时仍会持续出帧（实测
2–4 帧/秒、最长间隔 2.03 秒），所以 5 秒阈值不会误报。尺寸／方向切换期间没有帧属正常，
单独豁免并有 10 秒上限。

恢复阶梯：`建立流式传输次数` 次重建会话 → 代理／ADB 重连 → 仍失败则**无限等待人工**
（不做超时：通道停下后任务已无法推进，自动放弃只会把可恢复的故障变成失败）。人工等待
期间任务停在原地、不下发任何输入；选择「重新检查」开始新一轮（计数重置），选择
「停止该任务」才结束；**关闭提示弹窗不等于停止**，顶部横幅保留，F10 随时可用。

失败必须分四类记账，彼此不可混同：

| 类别 | 触发 | 后果 |
|---|---|---|
| 任务内异常 | 脚本/识别/业务报错 | 该条目失败，继续下一项 |
| 无人值守中断 | 撞到弹窗 | 跑恢复 wf 收回登录页，继续下一项 |
| **通道故障** | 上述恢复放弃后 | **中止整批**，不跑无人值守恢复 wf |
| 用户停止 | F10 | 停止 |

通道故障在中止时写入 `channel_fault` 状态与详细原因（归因、重试次数、耗时、条目、
用户、脚本），日志按 ERROR 记录；批量报告写「执行通道中断，整批中止」，
「脚本执行 0 次」不得再写成「正常完成」。纯输入脚本（只点击不截图）同样受闸门保护：
每条语句执行前校验通道，健康时只是一次布尔判断。

## 验收契约

- 代理被关闭后仍重新建立转发并握手，不能因旧端口为空永远无法恢复。
- 代理重试耗尽后 ADB 可用则普通输入继续；不支持的手势仍等待恢复代理。
- ADB 不可用时完成重试后等待是／否，无人值守行为一致；停止只作用于对应目标。
- 响应丢失不能自动重放输入；修改设置不能改变正在运行的恢复策略。
