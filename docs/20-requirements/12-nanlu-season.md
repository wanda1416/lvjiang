# 南吕相和赛季适配

> **状态**：部分实现，待完成业务闭环与回归验证
>
> **适用赛季**：南吕相和（115 阶）
>
> **相关系统**：游戏配置、装备解析与校验、调律评级、真实养成、毕业率分析

---

## 1. 背景与目标

南吕相和赛季把当前装备等阶从 110 提升到 115，并修改了部分装备产出、承音、
词条和冷却规则。项目不能只增加一组 115 数值；所有依赖装备等级、词条候选和承音
资格的消费者，都必须读取同一份配置并遵守相同语义。

本需求的目标是：

1. 用配置准确表达不同等级下的词条产出范围和首词条范围；
2. 表达装备跨等级承音时发生的词条名称升级；
3. 用赛季配置表达低阶装备作废线，并让所有承音相关功能共同执行；
4. 让调律评级、最大预期评级和毕业率分析正确处理 115 阶规则；
5. 在社区毕业率表格仍为 110 阶口径时提供明确、可退出的兼容层；
6. 保留旧装备的识别和存储能力，不因词条停止产出而把历史装备判为非法。

---

## 2. 已确认的游戏规则

### 2.1 赛季与等级

| 项目 | 蕤宾叠奏 | 南吕相和 |
|------|----------|----------|
| 赛季装备等级 | 110 | 115 |
| 最低可承音装备等级 | 100 | 105 |
| 开始日期 | 2026-06-26 | 2026-09-24 |
| 结束日期 | 2026-09-24 | 2026-12-25 |
| 上半赛季结束 | 2026-08-07 | 2026-11-04 |

南吕相和从周四开始，到周五结束，时间跨度为 13 周加 1 天；上半赛季持续 6 周，
下半赛季持续 7 周加 1 天。

### 2.2 赛季最低承音等级

`min_chengyin_level` 是当前赛季对低阶装备设置的作废线：

- 南吕相和中，低于 105 级的装备不能再承音；
- 该限制既包括原地应用承音数值，也包括承音到下一装备等级；
- 满等级、满承音、智能分析和最优组合等假设不得绕过这条限制；
- 低阶装备仍可保存、展示和参与不依赖承音的真实值计算。

它与等级配置中的 `allow_chengyin` 不是同一概念：

- `min_chengyin_level` 描述**当前赛季是否仍接受这个等级的装备**；
- `allow_chengyin` 描述**该装备等级在其所属时代是否具有承音能力**。

一次承音行为必须同时满足两者。不能因为 100 级装备的历史等级配置允许承音，就在
南吕相和继续对它应用承音或满等级假设。

### 2.3 普通词条的等级产出范围

词条注册与词条产出必须分离：

- 注册表保留所有历史词条，供 OCR、旧装备加载、展示和真实值计算使用；
- 生效等级范围只控制该词条能否在指定等级被调律产出或作为相应候选；
- 未配置起始等级表示向更低等级开放；
- 未配置截止等级表示向更高等级开放；
- 两端都未配置表示所有已注册等级均可产出。

南吕相和的奇术类词条范围为：

| 词条 | 起始等级 | 截止等级 | 部位 |
|------|----------|----------|------|
| 单体类奇术增伤 | 不限 | 110 | 冠胄、胸甲 |
| 群体类奇术增伤 | 不限 | 110 | 冠胄、胸甲 |
| 全奇术增伤 | 115 | 不限 | 冠胄、胸甲 |

停止产出不等于历史装备非法。110 级装备上的单体、群体奇术增伤必须继续被识别和计算。

### 2.4 首词条的等级产出范围

装备配置中的首词条不再是只有名称的单行列表。每个首词条都是独立记录，并支持起始、
截止等级：

| 部位 | 词条 | 起始等级 | 截止等级 |
|------|------|----------|----------|
| 武器 | 最小无相攻击 | 不限 | 110 |
| 胫甲 | 体 | 不限 | 110 |
| 腕甲 | 体 | 不限 | 110 |

其他未配置范围的首词条默认对所有已注册等级开放。等级未知的历史装备不因缺少等级信息
被拒绝；严格的产出校验只在等级明确时执行。

### 2.5 跨等级词条升级

装备承音跨过 115 等级边界时：

```text
单体类奇术增伤 ─┐
                  ├─> 全奇术增伤
群体类奇术增伤 ─┘
```

规则语义是“跨过某个等级边界”，而不是只允许固定的 110→115 路径。只要来源等级低于
115、目标等级达到或超过 115，就应执行升级；没有跨过边界则保持原词条。

升级规则只改派生副本或用户明确执行的真实养成结果：

- OCR 扫描永远保存画面实际识别到的名称；
- 满等级等计算假设在副本上执行升级，不修改原装备；
- “养成真实装备”在确认承音后应用升级并写回真实装备；
- 多个来源词条升级为同一名称后形成重复词条时，不能静默叠加。真实编辑应拒绝保存并
  给出可行动提示，计算任务应隔离该异常候选。

### 2.6 冷却时间

装备调律重置和转律修正的冷却时间由 5 天调整为 3 天。

冷却中的历史装备保存的是绝对到期时间，不追溯重算；新发生的操作按 3 天计算。

### 2.7 115 等级抗性

毕业率、战斗属性和最优组合必须使用**当前赛季装备等级**对应的判定抗性与增益抗性。
南吕相和生效后应读取 115 等级配置，不能继续使用 110 等级抗性。

抗性提高后，即使社区毕业率方案的装备目标值仍基于 110 阶数据，现有用户的实时毕业率
也可能整体下降。这是口径变化的合理结果，不能为维持旧百分比而继续套用 110 抗性。

## 3. 配置模型需求

### 3.1 词条等级范围

每个具体词条名称可配置：

```yaml
_alias_levels:
  单体类奇术增伤:
    through_level: 110
  全奇术增伤:
    from_level: 115
```

等级范围属于具体词条，而不是整个词组。词组仍负责公共数值上限、单位和归类。

配置读取应提供以下稳定能力：

- 查询词条是否已注册；
- 查询词条在给定等级是否可由调律产出；
- 查询词条可出现的装备部位；
- 在未传等级时返回完整历史词条集合，不擅自过滤旧数据。

### 3.2 首词条等级范围

首词条列表兼容无范围的简写和带范围的完整写法：

```yaml
_first_affixes:
- 最大外功攻击
- name: 最小无相攻击
  through_level: 110
```

配置加载后统一为“名称 + 等级范围”的领域对象；保存时，无范围项可以继续使用简写，
避免制造无意义配置噪声。

### 3.3 跨等级升级规则

词组可以声明多来源到单目标的升级：

```yaml
_upgrades:
- operation: chengyin
  from_level: 110
  to_level: 115
  from:
  - 单体类奇术增伤
  - 群体类奇术增伤
  to: 全奇术增伤
```

配置必须拒绝或阻止保存以下状态：

- 来源或目标词条未注册；
- 起始等级大于目标等级；
- 升级规则形成循环；
- 同一来源和等级边界存在互相冲突的目标。

词条重命名或删除时，必须同步维护等级范围、升级规则、部位限制和外部别名，不能留下
悬空引用。

### 3.4 赛季配置

每个赛季增加可选的 `min_chengyin_level`：

```yaml
- name: 南吕相和
  equip_level: 115
  min_chengyin_level: 105
```

未配置或配置为 0 表示不施加赛季作废线。配置 UI 必须保证最低承音等级不高于赛季装备
等级，并且只能选择已注册的装备等级。

### 3.5 转律池保持独立

本次等级范围描述的是调律和首词条产出变化，不修改现有流派转律池。

候选能力应拆成三个明确接口：

1. 装备部位和武器类型允许出现的物理词条；
2. 指定等级可由调律产出的词条；
3. 流派配置声明的转律池。

调律候选使用第 1、2 项交集；转律候选使用第 1、3 项交集。禁止让调律等级范围隐式
收窄转律池。

## 4. 配置界面需求

### 4.1 词组配置

词条名称区域中，每个具体词条一行，展示并允许编辑：

- 词条名称；
- 生效起始等级；
- 生效截止等级；
- 可出现部位。

起始与截止均使用等级配置中的已注册等级；“不限”代表开放区间。界面不得把空值展示成
疑似漏填的空白项。

跨等级升级规则与词条名称放在同一词组上下文中管理，支持多选来源词条、目标词条和等级
边界。保存前执行循环、冲突和悬空引用校验。

### 4.2 装备配置

原有首词条单行展示改为表格，每个首词条独占一行：

- 词条名称；
- 生效起始等级；
- 生效截止等级。

重新选择、排序首词条时，已有词条的等级范围必须按词条名保留，不能因重排被重置。

### 4.3 赛季配置

赛季表增加“最低承音等级”列。提示文案必须明确：

- 这是当前赛季对旧装备的作废线；
- 它不同于等级配置中的“支持承音”；
- 低于该等级的装备不参与满等级和满承音假设。

## 5. 装备识别、校验与真实养成

### 5.1 OCR 与旧装备

- OCR 识别层不应用预期升级，不把单体、群体自动改成全奇术；
- 识别出的退役词条仍可保存；
- 已注册但在当前等级不再产出的词条，只在“新产出是否合法”的场景被限制；
- 历史装备缺少原始等级时，首词条范围校验放行，不产生阻断性告警。

### 5.2 装备合法性

需要分别校验：

- 首词条是否符合 `original_level` 对应的首词条范围；
- 后续词条是否为已注册词条且部位合法；
- 新调律结果是否符合当前装备等级的产出范围；
- 承音后的派生装备是否应用了跨等级升级规则；
- 升级后是否产生不允许的重复词条。

不能使用当前等级的产出范围否定旧装备已经持有的退役词条。

### 5.3 养成真实装备

用户在“养成真实装备”中执行承音时，必须统一检查：

1. 当前赛季最低承音等级；
2. 当前等级的历史承音能力；
3. 是否存在下一已注册装备等级；
4. 跨等级词条升级；
5. 升级后的完整装备合法性。

UI 的启用状态和仓储写入校验必须使用同一公共判断，不能只在界面禁用、却允许其他入口
写入非法结果。

## 6. 调律评级需求

### 6.1 规则词库

现有调律规则中，所有把“单体类奇术增伤”作为可用词条或优质词条的规则，同时加入
“全奇术增伤”。两者在规则文件中共存，以便同一规则覆盖 110 与 115 装备。

现有 `keep_danti` 名称和 key 保持不变，其业务含义扩展为：

```text
110 及以下：保留单体类奇术增伤
115 及以上：保留全奇术增伤
```

不要求迁移用户配置或修改展示名称。

### 6.2 最终评级

最终评级只评价当前已经存在的完整词条：

- 使用装备当前等级过滤规则词库；
- 110 级允许单体、群体，不允许全奇术；
- 115 级允许全奇术，不允许新产出单体、群体；
- 退役词条出现在历史装备上时仍可识别，但不能作为该等级新增候选。

### 6.3 最大预期评级

最大预期评级需要明确区分“当前等级调满”和“承音到赛季等级后的预期”：

- 在当前等级填充时，按当前等级过滤候选；
- 假设承音到 115 时，先按升级规则转换已有词条，再使用 115 候选补全；
- 允许转律时继续复用统一转律资格判断，不因词条升级放宽转律限制；
- 110 的单体奇术增伤升级到 115 后，应与原生 115 全奇术增伤得到一致的规则语义。

词条填充、跨等级升级和模拟转律必须只修改派生副本。

## 7. 毕业率与战斗属性需求

### 7.1 当前赛季抗性

所有毕业率入口统一使用当前赛季等级的抗性，包括：

- 备战方案战斗属性；
- 最优组合；
- 转律建议；
- 智能分析内部的方案比较；
- 单件词条收益率分析。

切换到南吕相和后应使用 115 等级的判定抗性和增益抗性。测试不得继续把旧毕业率百分比
当作固定结果，应按 115 抗性更新期望值，或者验证抗性来源和单调变化。

### 7.2 全奇术增伤的领域字段

战斗属性模型应保留三种真实语义：

- `single_qs_bonus`：单体类奇术增伤；
- `group_qs_bonus`：群体类奇术增伤；
- `all_qs_bonus`：全奇术增伤。

装备解析、属性汇总和 UI 展示先写入真实字段，不得在公共层永久把全奇术伪装成单体
奇术。否则新版毕业率表格到来后无法区分原始数据。

### 7.3 旧毕业率模型兼容

当前社区毕业率表格仍以 110 阶为基础，只提供单体、群体奇术输入。临时兼容应发生在
毕业率模型适配边界：

- 若模型没有 `all_qs_bonus` 输入，把全奇术贡献叠加到该模型的
  `single_qs_bonus` 输入；
- 若模型已经声明 `all_qs_bonus` 输入，三个字段分别传入，自动停止旧兼容；
- 兼容只影响该次模型输入，不修改装备、基础属性或公共战斗属性对象；
- 日志或模型信息应能确认本次使用的是旧模型兼容口径。

这条兼容是对旧表格的临时适配，不代表游戏中全奇术等同于单体奇术。

### 7.4 未来表格兼容

毕业率转换器当前依赖固定单元格位置。未来表格加入全奇术字段后可能导致行号变化，因此
转换器需要：

- 支持从表格标签定位奇术输入，或明确支持旧、新两种 schema；
- 在生成的模型中保留输入能力信息；
- 对“全奇术增伤”等新标签提供唯一、可校验的配置别名；
- 新模型启用后不再走旧模型的单体奇术回退。

### 7.5 计算假设

- 满等级只升级本赛季仍可承音的装备；
- 满承音只提升符合赛季承音资格且真实已经承音的装备；
- 跨到 115 时，在派生副本中执行词条名称升级；
- 假设没有造成实际变化时，不显示“已应用”标记；
- 原装备和其他备战方案引用不得被计算假设修改。

## 8. 不在本次范围内

以下更新不纳入本需求：

- 通宝快捷兑换及其优先级；
- 传律材料装备找回；
- 套装解锁、免费切换及备战方案套装记录；
- 历史定音启用费用；
- 115 装备各词条的随机概率权重；
- 根据概率调整调律搜索策略；
- 社区尚未提供的新版毕业率公式和目标装备表。

装备套装与定音是不同系统，项目当前不支持设置装备套装，不能把公告中的套装变化合并
到现有普通定音/止戈定音模型。

---

## 9. 失败边界与可观测性

- 单件历史装备不符合新产出范围时，不得阻止用户数据加载；
- 配置冲突应在保存配置时提示，不能等到调律或毕业率计算中无限循环；
- 某件装备跨等级升级后发生冲突，只隔离该装备或该组合，不终止整个用户任务；
- 因赛季作废线跳过承音假设时，应能在详情或调试日志中看到原因；
- 使用旧毕业率模型兼容时不得伪装成新版 115 模型，必须保留可追踪口径。

## 10. 验收矩阵

### 10.1 配置与 UI

- [ ] 单体、群体奇术增伤在 110 可用，在 115 不作为调律候选；
- [ ] 全奇术增伤只在 115 及以上可用，且仅限冠胄、胸甲；
- [ ] 武器最小无相、胫腕的体在 115 不作为首词条候选；
- [ ] 未配置范围的词条在所有已注册等级可用；
- [ ] 起始等级大于截止等级时不能保存；
- [ ] 升级规则循环、冲突或引用不存在词条时不能保存；
- [ ] 词条重命名、删除同步维护所有引用；
- [ ] 赛季最低承音等级不能高于赛季装备等级。

### 10.2 装备与养成

- [ ] 110 历史装备上的单体、群体奇术可以加载、展示和计算；
- [ ] 115 新调律候选不再出现单体、群体奇术；
