# AI 连接基础能力

> 状态：已实现（2026-10-08，基线 v0.13.13）；桌面端配置与连接测试，尚未接入答题、调律分析或 Android 独立执行。

## 范围与状态边界

通用 → 配置管理 → AI 设置，配置单个 OpenAI 兼容 Chat Completions 连接。
接口根地址、模型和超时独立保存到 config/session/ai.json；API Key 仅保存在
系统凭据库，按配置文件路径与接口地址隔离，不写入 JSON、日志或手机同步包。
系统凭据库不可用时可以临时填写 Key 测试，但不能保存 Key。无需鉴权的服务可留空。

编辑表单是草稿；只有「保存 AI 配置」写入 AI 配置，不调用其他设置页的保存逻辑。
连接测试冻结当前草稿，实际向所选模型发出简短文本请求，不隐式保存，也不上传游戏数据。
更改接口地址清空表单 Key 和旧测试结果，防止向另一个服务发送旧凭据。

## 模型获取

模型字段支持下拉选择和手动输入。首次打开已配置的 AI 页，以及 Key 输入完成离开
输入框时，按当前草稿自动查询接口的模型列表；同一地址/Key 不重复自动请求。
可点击「获取模型」重新查询。不支持列举模型的服务仍可手动填写并测试。
凭据读取失败时不自动查询，用户重填 Key 或显式点击后再请求。

列表刷新保留当前填写的模型，不自动选中第一个候选，不保存草稿。
接口地址或 Key 变化清空旧候选；候选列表本身只在页面内存中保存。
获取列表与测试调用使用同一后台取消、超时与鉴权错误处理。
列表可获取不表示其中每个模型都支持文本对话，仍需测试所选模型。

## 测试行为

后台请求期间禁用表单和保存、测试按钮，保留取消按钮；关闭配置窗口时取消测试。
非空有效文本回复才算连接成功，不能用端口可达或模型列表查询代替。
测试可能产生少量费用，页面明确提示。成功不保证图片、结构化输出或工具调用可用。
服务限流、鉴权失败、接口/模型不存在、超时、无效响应分别提示；不展示原始响应或 Key。
总超时 1–300 秒，不自动重试或跟随重定向。

## 后续边界

游戏知识、答题执行、调律计算与工具调用不属于本次范围。
