# 动态识别区域

> 状态：已实现（2026-10-08，基线 v0.13.14）。

工作流需要对移动标记识图，并在命中位置附近读取文字。该位置不属于固定场景，
不应为它维护虚构的场景和静态布局。

- `find $area` 接受四元组构造的画布归一化矩形，复用既有文字和模板搜索引擎。
- 范围外的图标与文字不参与匹配；非法或零宽高矩形不得退回全画布搜索。
- 命中结果只读暴露 `x_ratio`、`y_ratio`、`w_ratio`、`h_ratio`、`text`，供构造相邻搜索框。
- 原有场景、Region、Panel、模板绑定及 `from last` 行为保持不变。
- 新能力属于识别原语，不包含寻路、物品、轮次或其他业务规则。

已通过合成帧验证范围排除、相邻文字读取及复用同一帧；平台场景标定和业务验证由调用方负责。
