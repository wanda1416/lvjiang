# 连接目标与执行目标分离
> 状态：已实现（2026-10-07，基线 v0.13.13）。

> 本文描述连接层与目标选择边界。不同目标同时运行任务的已实现能力见
> [多执行目标并发任务](05-concurrent-target-execution.md)。

## 目标

主窗口可以同时保留一个 Windows 窗口和多台 Android 设备连接。扫描和连接只
维护可用目标；新连接成功后自动选中新目标，自动化启动时使用当前选中的执行目标。
连接新目标不得断开或覆盖其他目标，也不改变已经启动的任务。

## 状态边界

1. **连接草稿**：右侧控件中为下一次定位/连接选择的参数。Windows 与 Android 各自
   保留一份草稿；切换候选类型、执行目标或连接新目标不得拿已连接目标反写草稿。
2. **候选目标**：一次扫描得到的窗口或设备，只供用户选择，不参与执行。
3. **已连接目标**：一个窗口目标与按 ADB serial 区分的多台设备。窗口连接记录
   hwnd 和实时坐标区域；设备连接分别拥有 capture、input、Agent 与断连状态。
4. **当前执行目标**：已连接目标中的一个稳定 ID。新连接成功后自动选中；已有设备的后台重连
   不改变选择。
5. **运行目标**：任务启动时冻结的目标 ID，并通过稳定句柄访问可重绑后端资源。不同目标
   可以分别运行任务；切换列表只改变观察与控制视角。

扫描不改变后三项；新连接切换当前选择但不改变已有任务；切换执行目标不重建连接。

「工具 → 移动设备 → 设备扫描」常驻提供局域网无线 ADB 和本机模拟器端口扫描，
不以当前是否已有 `adb devices` 结果为前提。它只发现并建立 ADB transport、刷新移动
设备工具中的设备列表，不创建主窗口连接目标，也不切换当前执行目标。主窗口在普通设备
枚举为空时弹出的扫描入口复用同一面板与扫描后端。

## 数量与身份

- Windows 窗口为单例，新定位替换旧窗口目标。
- Android 设备为多实例，稳定 ID 为 `android:<serial>`。
- 窗口稳定 ID 为 `window`，实际身份与坐标记录在目标内容中。
- 方案只约束 `windows` / `adb` 连接种类，不绑定具体 hwnd 或 serial。

## UI

主界面的连接区域分成候选选择和执行目标列表。列表同时展示所有已连接目标的名称、
连接状态、连接信息和运行状态信息。名称就是该执行端的唯一标识：Android 用 transport
serial，Windows 用 `WINDOWS:<pid>`；不用型号、窗口标题或 HWND——型号是 serial 之上的重复，
窗口标题会在运行期变化。连接信息只补名称没有的部分（设备是尺寸，窗口是坐标和尺寸），
输入方式、截图方式与设备端执行等内容独立显示在状态信息列。当前行就是下一次执行使用的目标。设备掉线只更新自己的行；非运行
目标掉线不得打断任务或弹出阻塞提示。

候选区复选框只定义下一次连接参数；已连接目标的实际输入、截图和执行方式显示在目标
摘要中，并通过该行右键菜单修改。窗口菜单提供前台/后台模式、前台/后台截图、红框标定、
刷新位置和断开定位；设备菜单提供流式截图、设备端执行、重新连接和断开连接。
刷新窗口位置时必须重新验证 HWND 仍存在且仍属于原 PID；验证失败后目标进入离线状态，
不得继续沿用旧坐标并报告刷新成功。
候选区参数是当前会话的连接草稿，重启后重新取“配置管理 → 基础配置”中的持久化默认值；
主页面调整草稿或已连接目标状态均不反写基础配置。

## 当前边界

- 预览跟随当前执行目标。
- 快捷键控制当前选中目标的运行任务。
- 未激活用户一次运行一个目标；Lv1 用户可以让窗口与设备或多台设备并发运行。
- 游戏环境与连接目标保持独立：模拟器窗口仍可以搭配 Android 环境和布局。

## 验收

- 定位窗口后连接多台设备，窗口和所有设备均保留。
- 新连接自动成为当前执行目标，原目标的会话草稿与运行任务保持独立；后台重连不抢占选择。
- 切换目标不重建 capture/input。
- 修改候选区连接参数不改变任何已连接目标；修改目标右键菜单不反写候选区参数。
- 扫描任意类型不清理已连接目标。
- 启动任务只读取当前执行目标，运行中目标选择被锁定。
- 非运行目标掉线不改变当前任务和运行按钮状态。
- 闲置目标被选中或首次连接时，当前方案不支持其连接类型则按列表顺序选择第一个支持该类型、且图库／环境／布局引用完整的方案；支持当前类型的方案和自定义组合保留。
- 自动适配只更新当前目标的会话草稿，不改持久化默认方案或运行快照；没有匹配方案时保留原选择并提示，原有启动门禁继续生效。
