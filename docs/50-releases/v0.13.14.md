# v0.13.14 — AI 设置、任务历史预览与批量配置优化

发布日期：2026-10-08。以 v0.13.13 正式标签（`f84bc300`）为基线。

## ⚠️ 不兼容变动与升级指引

### 界面状态独立保存，首次启动自动迁移

- **现象：** 窗口、分栏、总览展示、告警与服务器状态不再保存在 session.json 的旧节点中。
- **原因：** 这些界面与辅助状态统一存入 interface.json，告警历史改为根节点。
- **如何调整：** 普通用户无需操作；interface.json 不存在时首次启动自动迁移并清除 session.json 对应旧节点。备份运行配置时保留整个 config/session 目录。自行读取旧节点的脚本需改读 interface.json；已有新文件时不会再次导入旧文件。

### 图库网格参数需要重新设置

- **现象：** 升级后参考图切割的行列数、间隔和单格宽高恢复默认值。
- **原因：** 网格参数改为图库工具自身的界面状态，不读取旧 settings.reference_grid，也不做迁移。
- **如何调整：** 在图库管理的网格切割区重新设置所需参数；窗口大小等同页状态不会被网格保存覆盖。

### 自定义拖拽的显式零保持时长不再接受

- **现象：** 自写脚本中的 `drag ... hold 0` 会报时长校验错误，timeline 内同样如此。
- **原因：** 拖拽保持时长与按键保持统一校验，显式时长必须是有限正数。
- **如何调整：** 不需要到位后保持时，删除 `hold 0`，直接省略 hold。已有官方任务使用的正数保持时长无需调整。

### 自动任务结果采用精简摘要

- **现象：** 江湖号令和部分日常任务开始记录逐项状态；日志不再重复打印完整结果 JSON。
- **原因：** 结果保留最终状态与必要数据，识别过程和操作细节继续写日志。
- **如何调整：** 在任务历史中查看结果与对应日志。自行解析结果或依赖日志 JSON 的脚本，请改读结果文件，不把“已尝试”当作“已确认成功”；本轮新增的详细结果不补写旧历史。

### 升级安装、两端版本与本地覆盖

- **现象：** PC/APK 版本不一致时不能同步；便携版覆盖旧目录可能留下旧文件，本地覆盖仍可能遮蔽系统配置更新。
- **原因：** 同步要求两端版本一致，ZIP 不负责清理旧文件，config/local 优先于 system。
- **如何调整：** PC 与 APK 同时升级到 0.13.14。便携版解压到新目录，再复制 config/local、config/session；安装器与 APK 自动更新官方配置。改过相关场景、布局或工作流的用户请自行核对本地覆盖。本轮没有自动提升任何 content_version。

### Android 独立执行继续为 Beta

- **现象：** 复杂任务仍可能因设备内存不足导致游戏被系统 kill（结束）。
- **原因：** 该问题尚未解决，本版本没有改变独立执行的稳定性边界。
- **如何调整：** 按 Beta 使用；需要稳定运行复杂任务时优先使用 PC 执行。PC 同步仍为单向覆盖，手机数据库会被替换，手机结果不回传电脑。

## ✨ 新增功能

- **AI 设置与连接验证**：在「通用 → 配置管理 → AI 设置」配置 OpenAI 兼容接口、模型和超时，自动获取模型列表，支持下拉选择或手动填写，实际调用所选模型测试连接，后台请求可以取消。API Key 存系统凭据库，不写入 JSON；连接参数随普通配置同步。当前提供连接基础能力，答题和调律 AI 分析尚未开放。
- **任务历史内嵌预览**：左侧筛选和记录列表，右侧直接阅读对应日志与 JSON，无需打开外部阅读器；增加状态过滤和日志级别过滤，记住窗口大小以及两页分栏比例，改善用户、任务和执行目标的展示。
- **数据总览批量新增列**：新增列支持搜索、多选与批量添加，按现有定义分组组织候选，保留原列宽和已有列。
- **自动任务结果记录**：江湖号令按稳定任务类型记录结果；每日签到、购买不肝、购买袅袅、购买心法、兑换码和钱袋扫描补充精简结果。已有完成、跳过、未实现、执行尝试及确认成功分别记录，保持原有游戏操作流程。
- **工作流识别与输入能力**：find 支持变量矩形搜索区域，命中结果可读取坐标和文字并复用截图；drag hold 支持数值变量与随机区间，timeline 同样支持。

## 🔧 修复

- 移动设备体检的连接数排除当前体检窗口，避免误报多台电脑，同时明确其他连接可能来自同机窗口或其他电脑。
- Profile 的只读 key 支持选择与复制，便于核对和引用。

## 📦 重构

- 配置管理把常规、字体、热键归入「基础配置」，输入与等待归入「执行参数」，分块展示并支持滚动；AI 设置位于功能激活前，对话框扩大。
- 批量设置采用更紧凑的双列分块，异常恢复工作流与单个执行单元同排，参数区域不会持续挤压任务、用户列表；失效任务明确标记，便于重新选择。
- 界面状态与机器级运行配置分开保存；图库网格不再属于通用设置。
