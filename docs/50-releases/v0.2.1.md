# v0.2.1 — Stock 模型增强 + 每日签到 + DSL log 级别 + Inno Setup 安装包

## 律匠 v0.2.1

本版本为 v0.2.0 的增量更新，新增 Stock 模型增减幅度支持、每日自动签到工作流、DSL log 级别指令，并引入 Inno Setup 安装包构建。

---

### ✨ 新增功能

**玩家档案**
- Stock 模型支持自定义增减幅度（steps）：与 Quota/Regen 模型对齐
- 右键菜单支持 Stock 自定义增减幅度
- 定义面板 Stock 编辑对话框新增增减幅度输入
- 提醒阈值备注修正：`>` → `>=`（代码逻辑本身正确）
- Stock 无详情时摘要留空，不再强行展示 key 名称

**工作流**
- 新增每日自动签到工作流 `daily_checkin.wf`
- 重命名 `activity_jianghu.wf` → `daily_jianghu.wf`

**DSL 引擎**
- `log` 指令增加级别支持：debug / info / warn / error

**打包**
- 新增 Inno Setup 安装包构建（`.exe`）
- 产物文件名采用标准命名格式：`lvjiang-vX.Y.Z-win64.zip` / `lvjiang-vX.Y.Z-win64-setup.exe`
