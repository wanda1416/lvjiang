# 4.1 调律配置 — 页面结构

入口：「燕云 → 调律配置」或按 **F6**。

这是调律行为的核心配置，决定了哪些装备进调律、怎么判定好坏、调律后怎么处理。

> 本对话框**没有保存按钮**：任何改动即时校验，校验通过自动保存生效；
> 校验不通过会提示错误并拒绝保存。

---

## 界面布局

对话框左侧为一级导航，右侧为对应的配置内容区：

```
┌──────────────┬──────────────────────────────┐
│  基础配置     │                              │
│  扫描处理     │    （右侧内容区）              │
│  材料处理     │                              │
│  调律处理     │                              │
│  智能调律     │                              │
│  ─────────   │                              │
│  流派规则     │                              │
│  规则A        │                              │
│  规则B        │                              │
│  规则C        │                              │
│              │                              │
│ [＋ 新增规则] │                              │
│ [装备调律验证] │                              │
├──────────────┴──────────────────────────────┤
│  状态栏：校验结果 / 最后保存时间                │
└─────────────────────────────────────────────┘
```

导航分为两组：

| 区域 | 包含项 | 说明 |
|------|--------|------|
| **全局配置** | 基础配置、扫描处理、材料处理、调律处理、智能调律 | 控制调律的整体行为；智能调律基于备战方案毕业率进行二次判断 |
| **调律规则**（分割线以下） | 每个规则一项 | 定义各流派的评判标准 |

---

## 调律规则内部结构

点击分割线以下的任一规则，右侧显示该规则的**二级导航**（共 9 项）：

```
规则设置        ← 流派、玩法等基础设定
词条库设置      ← 该规则可用的词条池
通用判定        ← 跨部位的通用判定条件
───────────     ← 分割线
主武器          ← 主武器各词条评级
副武器          ← 副武器各词条评级
环 · 佩         ← 环和佩的词条评级
冠胄 · 胸甲     ← 冠胄和胸甲的词条评级
胫甲 · 腕甲     ← 胫甲和腕甲的词条评级
```

### 规则设置

| 配置项 | 说明 |
|--------|------|
| 流派 | 该规则适用的武器流派 |
| 玩法 | 可选多个玩法，调律 Tab 中按规则勾选玩法 |
| 品阶门槛（覆盖） | 可选，按部位覆盖全局默认品阶门槛 |

### 词条库设置

定义该规则可用的词条池。词条池决定了扫描处理、调律处理中「传入规则」判定能看到哪些词条，也是各部位评级页的候选来源。

### 通用判定

跨部位的通用判定条件（如通用垃圾条件、通用一般条件等）。

### 各部位评级页（5 个）

每个部位页独立配置该部位下各词条的评级模式。评级结果直接影响扫描处理和调律处理的判定。

---

## 规则管理

### 新增规则

点左下 **「＋ 新增规则」**，弹出对话框：

| 字段 | 要求 |
|------|------|
| 标识 key | 小写英文标识（字母开头，可含数字/下划线），作文件名 |
| 规则名称 | 中文显示名（如「治疗-纯奶」） |

### 重命名规则

在左侧导航中**双击**规则项，弹出重命名对话框。注意：全局配置页（基础配置等）不可改名。

### 删除规则

在规则内部的「规则设置」页底部有删除按钮。删除后不可恢复。

---

## 装备调律验证

左下 **「装备调律验证」** 按钮打开判定测试对话框。

功能：手动输入装备词条，验证当前规则的判定结果。

> 调规则时建议先在这里验证，确认判定逻辑符合预期后再实际运行。

---

## 智能调律

智能调律位于「调律处理」之后，与调律处理之间无分割线，与后续流派规则用分割线隔开。
它不会替代现有扫描处理或调律处理：只有原有规则决定“继续调律”后，才会根据
备战方案推演当前装备补满后的最大可能毕业率。比较双方采用完全相同的口径：
原备战方案和替换候选后的方案都会按**满等级、满承音、满定音**计算极限，
当前八件装备的实际毕业率只用于展示，不参与是否提升的判定。

公共页面中的「启用智能调律」只是功能总开关。实际运行前，还必须到主页
「调律 → 参数」底部，为当前执行用户再次勾选「启用智能调律」。双重开关用于
避免不需要毕业率推演的用户被意外影响。

### 使用前必须准备

1. 为要参与判断的每种玩法建立备战方案；
2. 为方案选择正确的武学、玩法、基础属性及毕业率计算方案；
3. **尽可能为每个方案执行一次“扫描已穿戴装备”**，保证主副武器和其余六个
   部位共八件装备齐全；
4. 在主页调律 Tab 只勾选本次确实要培养的规则和玩法。

毕业率属于流派计算模型，玩法可以覆盖更大的调律目标范围。因此，勾选某个
规则玩法并不保证一定存在可用毕业率方案。运行开始时，律匠会逐项检查：

- 没有匹配备战方案：该「规则－玩法」不执行智能调律并打印警告；
- 没有流派、基础属性或毕业率方案：忽略对应方案并打印警告；
- 八件穿戴装备不完整：忽略对应方案，并提示先扫描已穿戴装备；
- 只要仍有其他完整且可计算的方案，智能调律会继续使用这些方案；
- 所有方案都不可用时，本轮智能调律整体放行，不执行回收、跳过等失败动作。

毕业率精度决定比较前的向下取整粒度。默认 `0.1%`，例如 `94.59%` 按
`94.5%` 比较；选择 `1%` 时按 `94%` 比较。候选方案极限和原方案极限使用
相同精度，之后再执行“大于”或“大于等于”。
