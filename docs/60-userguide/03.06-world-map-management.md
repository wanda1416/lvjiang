# 大世界地图管理

地图按游戏中的大地图分别管理，如清河、开封、青州；在“地域与探查”页登记各自
地域。这里的地域目录不代表地域之间有道路连接。

在“地域与探查”页选择截图所属地域，再添加图片文件或保存当前画面。点击保存后，
图片和地域资料一同保存。在“底图与 POI”页的“展示”下拉框中可切换大地图底图
和探查截图；切换预览不会修改配置，探查截图只能查看，POI 在底图上编辑。

底图可从多次移动地图视口后的截图拼接生成。每次保持相同缩放，让前后图片有
较多重叠，并排除任务面板、按钮等固定遮挡。未覆盖部分显示为空白；必须补拍
后才能补齐，不能把局部截图当成完整地图。

开发探查工具的 UTF-8 清单示例（坐标为图片像素，exclude 为 x/y/宽/高）：

```json
{
  "exclude": [[0, 0, 1600, 90], [0, 630, 1600, 90]],
  "frames": [{"image": "view_a.png"}, {"image": "view_b.png"}]
}
```

```bash
python scripts/stitch_map.py survey.json --output config/local/diagnostics/map-mosaic
```

按实际截图补全所有固定遮挡的 exclude。结果中的 base.png 可在地图管理中导入；
coverage.png 和 registration.json 用于检查缺口和原始图片位置。工具无法匹配时，
补拍中间视口，或者分别保留不同地域的截图。

地域定位与界碑传送的自动运行流程尚未接入。

地图标题会显示底图是“局部探查，待补齐”还是“整图探查已完成”。补齐并核对整张
地图后，可在基本信息中勾选“底图已完成整图探查”；拼接成功不会自动勾选。
