# v0.2.0 — 玩家档案 SQLite 迁移 + 设备无线连接 + DSL 增强

## 律匠 v0.2.0

本版本完成玩家档案系统从 JSON 到 SQLite 的全面迁移，引入三模型体系（配额/再生/存量）与后台引擎，新增 ADB 无线扫描、DSL 语法增强、装备等级组件统一等多项功能与稳定性改进。

---

### ✨ 新增功能

**玩家档案系统**
- Profile 数据迁移到 SQLite：替代原有 JSON 存储，支持历史记录查询与变更追踪
- 三模型体系重构：配额（Quota）/ 再生（Regen）/ 存量（Stock），各自独立的定义与计算逻辑
- 后台 ProfileEngine：自动 tick 驱动再生值累计，整数部分变化时才写入 DB
- 总览交互增强：
  - 双击 cell 编辑走 action 路径，自动触发 Quota→Stock 同步
  - 右键菜单「增加/减少/覆写...」三条写入路径
  - 右键「查看历史记录」弹出 QDialog 展示最近 50 条变更记录
  - Quota sync_to 目标达硬上限时显示 "—" 并禁止编辑
- 总览分组增强：拖拽排序、列宽持久化、重置日/活动模型简化
- 其他信息 tab 三模型横向并列展示（配额 | 存量 | 再生），纯数值取整

**设备连接**
- ADB 无线扫描集成：局域网设备发现与自动连接

**DSL 工作流引擎**
- `wait stable` 语法扩展：新增 `least` 参数（最低等待期）
- 命名延迟 `@` 前缀语法

**调律引擎**
- 脚本性质（daily/dedicated）+ 批量引擎参数加载重构
- 装备等级输入统一为 LevelCombo 下拉选择组件

**其他**
- UI 精简与赛季配置支持
- 新增活动场景配置

### 📦 重构

**架构**
- SessionManager 并发安全改造与 ProfileEngine 写入优化
- 模块合并与重命名 + mypy 清理
- profile_store 统一接口 + material_grid 合并入 settings

- 三模型重命名：daily→quota / realtime→regen / resource→stock
