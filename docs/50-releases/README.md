# 发布说明

每个版本一份，记录该版本的新增能力、修复和已知问题。发布日期以各版本发布说明为准；未写明确发布日期的版本取本文件索引表日期。当前版本 **0.15.7**。

0.15.0 推荐从 **0.13.15** 升级。更早版本请先升级并正常运行 0.13.15，
在对应编辑器保存旧自定义配置；具体调整见[配置升级调整](../60-userguide/appendix-a-config-upgrade.md)。

惯例口径：「不兼容变动与升级指引」（含「如何调整」）段自 v0.8.0 起出现，更早的 v0.4.0~v0.7.1 没有此段；「变更统计」段各版本均有，其标题层级自 v0.13.4 起由 `### 📝 变更统计` 改为 `## 📝 变更统计`。
