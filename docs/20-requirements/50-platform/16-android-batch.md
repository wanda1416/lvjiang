# Android 批量执行

> 状态：已实现（2026-10-12，基线 v0.15.0）；真机验收范围按本文验证章节确认，不代表所有游戏任务均已实测。

## 目标与交互

任务页提供日常任务、批量执行两个入口，沿用四项底部导航。批量页选择配置组，编辑本次任务、用户或属性单元的勾选和顺序，以及轮数和无人值守。准备后回到游戏，从悬浮窗启动；工作台和悬浮窗统一显示整批状态并控制暂停、继续和结束。批次详情按条目列出任务结果及原因。

手机可使用电脑同步的配置组，也可在任务页菜单「批量配置」中新建、重命名和编辑定义。手机运行草稿与定义分离，按稳定组 ID 保存；参数浏览用户独立于执行用户与批量勾选。

## 执行边界

单任务、批量、电脑控制共用执行占用；手机任务暂停后不再驱动设备，电脑可以接管，接管期间拒绝继续手机任务。启动冻结配置组、实际顺序、全部成员资料、任务及生命周期参数和目标环境；运行期仅业务 Profile 可动态读取。继承公共调度器的 batch_check、属性选人、五个生命周期及异常恢复协议。没有恢复工作流不得开启无人值守。手机目前支持 pause、confirm、notify，其他交互明确失败。

同步补齐 batch.json，保留手机批量草稿并按新定义协调；不将电脑的本次执行顺序覆盖手机。配置变化使准备令牌失效，启动前重新准备。进程中断后的批次记为中断，不自动恢复未知游戏现场。

## 重启与方向变化

重启期间可能经过横屏、竖屏桌面、启动页再回横屏。清除旧截图与识别结果，等待注册方向的连续稳定新帧，再由工作流确认业务页面。截图与手势之间方向变化必须拦截旧坐标，交由任务失败/恢复处理，禁止误点。等待支持停止和超时；悬浮图标及面板旋转后重新限制到屏幕边界。

## 验证

保护运行草稿不反写定义、准备后参数变化拦截、执行快照不回读、单任务与批量互斥、属性单元协议、停止与异常恢复、方向过渡与旧坐标拦截。真机验证页面、悬浮启动、重启方向切换与整批结果；未执行的场景不得声称通过。

日常任务沿用电脑端名称，任务次级说明缩进一个字宽；设置页「关于与反馈」分组在「反馈联系」下方提供与电脑共用文案的关于入口。

配置组编辑器与本次运行草稿独立；保存单个配置组以最新定义令牌校验并合并，不覆盖其他组。删除只清除所属草稿，并修复指向该组的活动引用。同步选中「保留手机批量配置」（默认勾选，独立于任务参数开关）时保留手机整份批量定义；取消则使用电脑定义，本次运行草稿仍保留并按新定义协调。
