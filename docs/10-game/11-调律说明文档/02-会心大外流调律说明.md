# 02-会心大外流调律说明

公共规则见 `00-调律总说明.md`，本文仅列会心大外流专属规格。
规格权威来源：04 文档「会心大外流各部位词条要求」节。

- 必选配置：指定流派（裂石、破竹、牵丝，**可同时勾选**）和玩法。
- 可选配置：保留 PVP 装备（单体奇术增伤、对玩家增效 视作有效）。
- 主武器类型及所需武学增伤由勾选的流派/玩法决定（见 04「各流派需要的武学增伤说明」表，
  如 裂石·威→陌刀武学增伤、裂石·钧纯唐→唐横刀武学增伤、破竹·鸢→手甲武学增伤）。
- 大本属 = 勾选流派的最大属攻（如勾选牵丝即 最大牵丝攻击），非武器部位的 大无相 即指它；
  勾选多个流派时，任一勾选流派的属攻均视作大无相；**未勾选流派的属攻为废词条**。

## 一、神力词条要求

- 主武器：必须有对应的主武学增伤，没有视为不合格（缺失直接判垃圾）。
- 副武器：不需要武学增伤，有视为不合格。
- 首饰（环/佩）：必须有 全武学增伤，没有视为不合格（缺失直接判垃圾）。
- 头盔和胸甲：不需要神力词条；keep_pvp 开启时 单体奇术增伤 视作有效。
- 胫甲和腕甲：必须有 对首领增伤（缺失直接判垃圾）；keep_pvp 开启时
  对玩家增效 可顶替该槽位。

## 二、转律优先级与可用词条库

- 转律优先级：大外、劲、敏、会心、小外、大无相。
- 可用词条库：大外、劲、敏、会心、小外、大无相 + 势、精准。
- 注意：小外、大无相、势 在库内**不判垃圾**（可命中可选槽），但会被多数部位的
  顶级条件排除，上限优秀。
- 库外词条即废词条，直接判垃圾。典型：会意、小无相、未勾选流派的属攻、
  错位属攻（武器上的大本属、非武器上的最大无相攻击）。

## 三、各部位模式与顶级判定

| 部位 | 模式 | 顶级判定（命中模式后） |
|------|------|----------------------|
| 主武器 | [大外(首) + 主武学增伤 + 大外] + 可用词条库 * 2 | 未出现 小外/大无相/会心/精准/势 → 顶级，否则 优秀 |
| 副武器 | [大外(首) + 大外 + 劲] + 可用词条库 * 2 | 未出现 小外/大无相/精准 → 顶级，否则 优秀 |
| 环、佩 | [大外(首) + 全武学增伤 + 大外] + 可用词条库 * 2 | 未出现 小外/大无相/会心/精准/势 → 顶级，否则 优秀 |
| 头盔、胸甲 | [会心/精准(首) + 大外 + 劲] + 可用词条库 * 2 | 未出现 小外/大无相/势，且 精准不足两条（含首词条）→ 顶级，否则 优秀 |
| 胫甲、腕甲 | [劲(首) + 对首领增伤 + 大外] + 可用词条库 * 2 | 未出现 小外/大无相/会心/精准/势 → 顶级，否则 优秀 |

- 副武器的顶级条件**不排除 势 和 会心**（已确认系故意）：副武器顶级可含 势/会心。
- 主武器顶级可选槽实际只剩 劲/敏；胫甲/腕甲顶级可选槽实际只剩 劲/敏。

## 四、判定例子

以下词条列表第 1 条均为首词条；示例假定勾选裂石（大本属=最大裂石攻击）。

| 部位 | 词条 | 判定 | 说明 |
|------|------|------|------|
| 主武器（陌刀） | 大外 + 陌刀武学增伤 + 大外 + 劲 + 敏 | 顶级 | 可选槽=劲+敏，无排除词条 |
| 主武器（陌刀） | 大外 + 陌刀武学增伤 + 大外 + 劲 + 会心 | 优秀 | 主武器顶级排除会心 |
| 副武器 | 大外 + 大外 + 劲 + 敏 + 会心 | 顶级 | 副武器顶级不排除会心 |
| 副武器 | 大外 + 大外 + 劲 + 势 + 会心 | 顶级 | 副武器顶级不排除势 |
| 环 | 大外 + 全武学增伤 + 大外 + 劲 + 敏 | 顶级 | 无排除词条 |
| 环 | 大外 + 全武学增伤 + 大外 + 敏 + 大本属 | 优秀 | 大本属即大无相，被顶级条件排除 |
| 头盔 | 会心 + 大外 + 劲 + 敏 + 精准 | 顶级 | 精准仅 1 条（含首共 0+1） |
| 头盔 | 精准 + 大外 + 劲 + 敏 + 精准 | 优秀 | 精准两条（含首词条） |
| 胫甲 | 劲 + 对首领增伤 + 大外 + 劲 + 敏 | 顶级 | 可选槽=劲+敏 |
| 胫甲 | 劲 + 对首领增伤 + 大外 + 劲 + 会意 | 垃圾 | 会意为库外废词条（跨流派 OR 逻辑下会意流派可能保留） |
