# v0.15.0b6 — 手机授权与应用控制修复（Beta6）

本版本是 0.15.0 的第六个测试包，在 [Beta5](v0.15.0b5.md) 基础上修复两个手机端问题。
供手动下载测试，不替换当前正式版 0.13.15，不向普通客户端提示更新。

## ⚠️ 不兼容变动与升级指引

相对 Beta5，本版本无不兼容变动。手机直接覆盖安装新版 APK，保留个人配置和历史记录。
首次进入 0.15.0 测试系列时，推荐从 0.13.15 升级，先阅读
[Beta5 升级指引](v0.15.0b5.md)和[配置升级调整](../60-userguide/12-config-upgrade.md)。

便携包解压到新目录，再复制个人 config/local 和 config/session，保留新包 baseline.json，
跳过旧 content.json 与 config.lock。在线配置按 0.15.0 系列匹配，
本包更新状态独立位于 updates/v0.15.0b6，不复制其他 Beta 的更新状态。

## ✨ 新增功能

无新增功能。

## 🔧 修复

- 修复 APK 缺少密码学依赖导致手机授权校验、会员配置解密及相关在线配置模块无法加载的问题。
  手机运行环境检查同时覆盖这些依赖，便于提前发现异常。
- 修复 Shizuku 已启动且已授权，批量任务仍提示 `ShellService not ready`、无法查询或控制应用的问题。
  新版保留应用控制服务的完整实现；使用手机自动启停应用仍需启动 Shizuku 并授权律匠。
