# 5.7 出装搭配与模拟计算器

在备战方案顶部点击「模拟计算器」。请先选择当前用户，并为备战方案选好玩法、
角色基础属性和毕业率方案。窗口会固定打开时的用户、方案和基础属性，不随外部切换变化。

顶部集中显示角色与基础属性、搭配选择、计算设置及毕业率对比。流派与模型等级／版本等详情
可通过悬停查看；词条总数仅在左侧标题显示，要求未满足或无法分配时显示原因。

## 调整与比较

1. 从当前方案装备开始，或加载当前玩法的一套出装搭配。
2. 选择装备等级、承音数值或普通数值、弓玦类型及等级。八件装备的套装在推荐分布表中选择。
3. 左侧每条词条以「词条名 · 满值　− 数量 +」单行展示，点击减加按钮调整数量；数量包含八个首词条，设为零表示不选用。初始候选合并该玩法调律规则中的词条，还可添加当前等级其他合法词条。
4. 左侧可在「装备词条」「词条约束」之间切换；右侧直接查看八件装备分配、毕业率变化及完整战斗属性面板，不需要切换页签。装备按主武器、副武器、环、佩、冠胄、胸甲、胫甲、腕甲排列，宫、商、角、徵、羽分别显示实际分配词条。可获取位置仅供程序内部使用，不在界面展示。

分配会遵守首词条候选、普通词条去重、属攻和神力数量限制。例如 9 势需要占用一个武器首词条，
不能同时保留 12 大外。武器上的本属攻击会落为无相攻击，其他部位落为玩法的属性攻击。
旧装备上的单体、群体奇术增伤会统一计入战斗属性中的「全奇术增伤」。
无法分配时会清空旧的推荐结果并说明限制，不会用非法装备继续显示毕业率。

战斗属性是抗性扣减前的面板值；毕业率沿用备战方案选定的模型和公共计算口径。
装备基础数值、装备套装与满值定音计入模拟；定音类型来自玩法定义。
推荐分布优先保持合法和原位置，**不是自动搜索毕业率最高的词条组合**。

## 要求与保存

「词条约束」可配置强制、最佳、推荐三级词条数量范围；PVE 公共强制要求为两条对首领单位增伤。
调整词条数量不会自动改掉这些目标。合法但未满 40 条、或未满足强制要求的搭配可以保存为草稿，
界面会明确标记，不代表合格的完整目标。

「保存出装搭配」更新所选搭配；「另存为新搭配」保留原搭配，创建一套新的。
只保存装备词条组合、套装、弓玦、等级与要求，不保存用户基础属性、评分结果或原装备指纹，
也不会创建或穿戴八件模拟装备。单件模拟装备仍通过筛选行的「创建模拟装备」创建。

游戏配置的「玩法配置」页中同样可以新建、编辑、复制和删除出装搭配；该入口不带角色上下文，
只编辑组合和要求。搭配单独保存，不嵌在玩法定义内。系统预设不可直接删除，可复制使用。
多窗口修改同一搭配时，后保存的窗口会提示冲突并保留草稿，不静默覆盖。

此功能目前不改变自动调律行为，分配引擎为后续智能分析提供可复用的合法位置结果。
