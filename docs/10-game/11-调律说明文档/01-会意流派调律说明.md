# 会意流派（鸣金虹·无名）单件装备调律说明

装备评级不采用打分制，改为**穷举匹配**（本质是正则匹配）。每个部位定义**一个统一模式**，
模式由「必选词条」（`[ ]` 框选）和「可选组合词条」（候选池）构成，按以下顺序定级：

1. 完整命中模式 → 按该部位的**顶级判定条件**区分 顶级 / 优秀；
2. 必选词条不满足，但没有出现垃圾词条 → **能用**；
3. 出现垃圾词条 → **垃圾**。

## 一、品阶筛选

对于一件装备，首先判断其品阶：

- 武器和首饰：非金色的没有调律价值。
- 防具：只有紫色及金色装备有调律价值。

没有调律价值的装备直接跳过。

## 二、首词条判断

首先检查初始词条（首词条）：

- 武器（主武器和副武器）：首选最大外功攻击，次选势。
- 首饰（环和佩）：只考虑最大外功攻击。
- 防具（冠胄和胸甲）：只考虑会意。
- 防具（胫甲和腕甲）：只考虑劲。

首词条符合要求后，进入调律详情页面继续判断。
注意：对于剑和枪，可能在主武器槽位，也可能在副武器槽位，不受限制。

## 三、神力词条要求

- 剑：必须有 剑武学增伤，没有视为不合格。
- 枪：不需要 枪武学增伤，有视为不合格。
- 首饰：必须有 全武学增伤，没有视为不合格。
- 冠胄和胸甲：不需要神力词条；但有 单体奇术增伤 可以留给 PVP 使用，姑且视作有效。
- 胫甲和腕甲：必须有 对首领单位增伤；如果是 对玩家单位增效，可以留给 PVP 和百业战使用，姑且视作有效。

注意：**如果指定部位明确了需要 增伤 词条，但是缺失，直接判定为垃圾装备**。
（即：剑缺 剑武学增伤、首饰缺 全武学增伤、胫甲/腕甲缺 对首领增伤（或对玩家增效），均直接判垃圾，
不走「必选缺失 → 能用」的兜底。）

## 四、词条池

只考虑以下词条，出现池外词条即为垃圾词条（直接判为垃圾装备）：

- 神力词条：参考上述「神力词条要求」。
- 五维类词条：劲、势
- 攻击类词条：最大外功攻击、最大无相攻击、最大鸣金攻击
- 三率类词条：会意率、会心率、精准率

## 五、模式匹配语法说明

- 一个模式描述一件装备的 5 条词条：第 1 条为首词条（标注 `(首)`），其余 4 条为非首词条。
- `[ ... ]` 框选的是**必选词条**：必须全部出现。其中 **增伤类必选词条缺失 → 直接判垃圾**；
  其余必选词条（如 大外、劲/势）缺失但没有出现垃圾词条，判为**能用**。
- `A/B` 表示该槽位可以是 A 或 B 中任意一个。
- `(A/B/C) * N` 表示从候选池中任取 N 条填入 N 个槽位，**允许重复**（如取两条相同的 A）。
- **大无相 在非武器部位表示 大本属**，即所在流派的最大属攻攻击（鸣金虹即 最大鸣金攻击）。
- 非首词条**不要求顺序**：只要装备的非首词条集合能与模式槽位一一对应，即视为命中。
- 匹配是精确穷举：装备的每一条词条都必须落入模式的某个槽位，不允许多余词条。
- 例：`[大外(首) + 大外 + 劲/势] + (劲/势/会意/大无相) * 2`
  表示非首词条中**必须至少出现一条 劲 或 势**（占据必选的 `劲/势` 槽位），
  剩余两条在 劲/势/会意/大无相 中任取，允许与已有词条重复（如再取一条劲）。

## 六、各部位模式与顶级判定

转律优先级表：大外、势、劲、会意、大无相

| 部位 | 模式 | 顶级判定（命中模式后） |
|------|------|----------------------|
| 主武器（剑） | [大外(首) + 剑武学增伤 + 大外 + 劲/势] + (劲/势/会意/大无相) * 1 | 未出现 会意/大无相 → 顶级，否则 优秀 |
| 副武器（枪） | [大外(首) + 大外 + 劲/势] + (劲/势/会意/大无相) * 2 | 同时出现 劲 + 势 → 顶级，否则 优秀 |
| 环、佩 | [大外(首) + 大外 + 全武学增伤] + (劲/势/会意/大无相) * 2 | 未出现 会意/大无相 → 顶级，否则 优秀 |
| 冠胄、胸甲 | [会意(首) + 大外 + 劲/势] + (劲/势/会意/大无相) * 2 | 未出现 大无相 → 顶级，否则 优秀 |
| 胫甲、腕甲 | [劲(首) + 对首领增伤 + 大外 + 劲/势] + (劲/势/会意/大无相) * 1 | 同时出现 劲 + 势 → 顶级，否则 优秀 |

注：04 文档中仅武器部位标注了 `[ ]`，本文将各部位模式的固定槽位统一视为必选词条。

## 七、定级流程

对通过品阶与首词条筛选的装备，按以下顺序判定：

1. 出现垃圾词条（词条池以外的词条，或明确禁止的神力词条，如枪上的枪武学增伤）→ **垃圾**。
2. 指定部位明确需要的 增伤 词条缺失（剑缺剑武学增伤、首饰缺全武学增伤、胫甲/腕甲缺对首领增伤）→ **垃圾**。
3. 必选词条全部满足，且可选槽位全部落在候选池内 → 按部位的顶级判定条件区分 **顶级 / 优秀**。
4. 非增伤类必选词条不完全满足，或可选槽位被 1 条 会心/精准 顶替，但无垃圾词条 → **能用**
   （会意流派目前不需要精准和会心，出现 1 条且取代的是可选组合词条时，上限即为能用）。
5. 会心/精准 出现 2 条及以上 → **垃圾**（沿用旧打分制规则，待确认）。

## 八、调律熔断

- 转律词库（鸣金虹）：最大外功攻击、最大无相攻击（非武器则为最大鸣金攻击）、劲、势、会意率、会心率。
- 转律约束：不会与已有非首词条重复；非首词条最多 2 个属性攻击（无相/鸣金）。
- 熔断判定：假设将当前非首词条中最差的一条替换为词库中的最佳词条，对替换后的词条集合重新定级：
  - 替换后可达到「能用」及以上级别 → 继续调律；
  - 替换后仍为垃圾 → 停止调律（熔断）。

## 九、判定例子

以下词条列表第 1 条均为首词条；大无相在非武器部位即 最大鸣金攻击（大本属）。

### 主武器（剑）

| 词条 | 判定 | 说明 |
|------|------|------|
| 大外 + 剑武学增伤 + 大外 + 劲 + 势 | 顶级 | 必选满足；可选槽=势，未出现会意/大无相 |
| 大外 + 剑武学增伤 + 大外 + 势 + 会意 | 优秀 | 可选槽=会意 |
| 大外 + 剑武学增伤 + 大外 + 会意 + 大无相 | 能用 | 必选的 劲/势 缺失，但无垃圾词条 |
| 大外 + 大外 + 劲 + 势 + 会意 | 垃圾 | 剑明确需要 剑武学增伤，缺失直接判垃圾 |
| 大外 + 枪武学增伤 + 大外 + 劲 + 势 | 垃圾 | 剑上出现枪武学增伤，属垃圾词条 |

### 副武器（枪）

| 词条 | 判定 | 说明 |
|------|------|------|
| 大外 + 大外 + 劲 + 势 + 大无相 | 顶级 | 同时出现 劲 + 势 |
| 大外 + 大外 + 劲 + 劲 + 会意 | 优秀 | 只有劲没有势（池内重复取劲合法） |
| 大外 + 大外 + 会意 + 大无相 + 大无相 | 能用 | 必选的 劲/势 缺失 |
| 大外 + 枪武学增伤 + 大外 + 劲 + 势 | 垃圾 | 枪不需要枪武学增伤，有视为不合格 |

### 环、佩

| 词条 | 判定 | 说明 |
|------|------|------|
| 大外 + 大外 + 全武学增伤 + 劲 + 势 | 顶级 | 可选槽=劲+势，未出现会意/大无相 |
| 大外 + 大外 + 全武学增伤 + 劲 + 大无相 | 优秀 | 可选槽出现大无相（即最大鸣金攻击） |
| 大外 + 大外 + 劲 + 势 + 劲 | 垃圾 | 首饰明确需要 全武学增伤，缺失直接判垃圾 |

### 冠胄、胸甲

| 词条 | 判定 | 说明 |
|------|------|------|
| 会意 + 大外 + 劲 + 势 + 会意 | 顶级 | 未出现大无相（可选槽再取会意合法） |
| 会意 + 大外 + 势 + 大无相 + 劲 | 优秀 | 出现大无相 |
| 会意 + 大外 + 劲 + 会心 + 势 | 能用 | 1 条会心顶替了可选槽 |
| 会意 + 大外 + 会心 + 精准 + 劲 | 垃圾 | 会心/精准 出现 2 条（待确认） |

### 胫甲、腕甲

| 词条 | 判定 | 说明 |
|------|------|------|
| 劲 + 对首领增伤 + 大外 + 劲 + 势 | 顶级 | 非首词条同时出现 劲 + 势 |
| 劲 + 对首领增伤 + 大外 + 劲 + 会意 | 优秀 | 没有势 |
| 劲 + 对玩家增效 + 大外 + 劲 + 势 | 顶级 | 对玩家增效视作有效（PVP/百业战保留） |
| 劲 + 对首领增伤 + 大外 + 会意 + 大无相 | 能用 | 必选的 劲/势 缺失（非增伤类，可降为能用） |
| 劲 + 大外 + 劲 + 势 + 会意 | 垃圾 | 胫甲/腕甲明确需要 对首领增伤，缺失直接判垃圾 |
