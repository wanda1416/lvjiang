# 5.8 外部装备网站（leoq7 / 兵鉴）

律匠可以把自己扫到的装备一键导出成两个外部网站认识的格式，用来在网页上算词条收益、
毕业率或做配装优化。装备页右上角的 **「导出数据」** 会弹出格式选择窗口。

## 两个网站分别做什么

| | leoq7（yysls.leoq7.com） | 兵鉴（yysls-bingjian.com） |
|---|---|---|
| 定位 | 社区参考站，页面结构简单 | 按流派计算表算毕业率的工具站 |
| 装备怎么进 | 把导出文本粘贴进导入框 | 先「导入装备库」，再选装备 |
| 适合做什么 | 看单件词条收益、对照参考数值 | 看整套毕业率、一键优化、转律与承音建议 |
| 覆盖范围 | 通用装备数据 | 12 个流派各自的计算表（每张表有版本号） |

两边都只吃装备数据，不认律匠的备战方案、模拟装备或基础属性设置。

## 从律匠导出

1. 在装备页确认等级筛选与词条筛选（它们只影响背包装备，已穿戴装备始终导出）；
2. 点 **「导出数据」**，在弹窗里选格式：
   - **导出为 leoq7 格式**：文本文件，粘贴到 leoq7 的导入框；
   - **导出为兵鉴格式**：JSON 文件，在兵鉴的「导入装备库」里选择；
3. 勾选 **「导出后用浏览器打开对应网站」**（默认勾选），导出成功后会直接用系统
   浏览器打开对应站点；不想跳转就取消勾选；
4. 选择保存位置，文件名默认是 `{用户名}_leoq7.txt` 或 `{用户名}_bingjian.json`。

两种格式导出的装备范围相同：已穿戴的八件，加上按当前筛选条件过滤后的背包装备；
模拟装备不导出。

## 到 leoq7 使用

打开 `yysls.leoq7.com`，用页面上的导入入口粘贴文本文件内容即可。文本是一行格式
标识加一行编码负载，粘贴时整段复制，不要只复制其中一行。

## 到兵鉴使用

1. 打开 `yysls-bingjian.com`，在装备库里点「导入装备库」；
2. 选择刚导出的 `{用户名}_bingjian.json`；
3. 导入后装备会出现在一个新装备库（名称是角色名），再在方案里挑选。

兵鉴也能识别 leoq7 那份文本，但原生 JSON 会额外带上装备名、紫装标记和「转」标记，
所以去兵鉴时优先用兵鉴格式。

## 注意事项

- **主属性由网站自己查表**：两个站点都不读律匠算出的装备固有攻击，而是按部位与品质
  查当前版本的表。所以导出 110 阶或更低阶装备时，网站会按 115 阶（当前版本）计算
  主属性；词条、定音、承音与「转」标记仍是你的真实数据。
- **词条名要对得上**：网站靠中文词条名识别，个别自定义名称可能识别不了，站上会留空
  并给出提示，不会影响其余装备导入。
- **定音按流派解释**：防具的定音在兵鉴统一按该流派的「指定武学定音」处理，数值保留。
- **只导出装备**：备战方案、基础属性、模拟装备都不在导出内容里；需要这些数据请用
  云同步或本地的方案功能。

## 常见问题

- **导入后少了几件**：装备类型没识别出来（例如 OCR 未取到部位）的条目不会导出；
  重新扫描或在装备页手工补类型后再导出即可。
- **网站上的外功攻击和律匠不一样**：网站按自己的版本表算固有主属性，差异通常来自
  装备等级与表版本，不影响词条部分的对比。
- **点了勾选但浏览器没打开**：律匠会提示站点地址，手动在浏览器里打开即可。
