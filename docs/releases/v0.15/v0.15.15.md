# v0.15.15 — 刷毒和膏等挂机任务更稳、批量任务参数页与插件加载收敛

这一版主要让挂机和批量跑得更稳：**刷毒和膏**每轮都会补姿态与等待，不会再打着打着
停住或走错页；登录选角在慢网络下不再重复点、连点；安卓配置包不会再被误判而装不上。
批量新增「参数」页，可以按全局或按某个执行用户直接改脚本参数，进度页补上轮次导航。

插件加载也做了收敛：宿主不再认识任何具体插件，内置插件按目录发现；对使用体验的影响是
插件相关的界面文案和词表归属更清晰，外置插件目录的用法不变。

## ⚠️ 不兼容变动与升级指引

### 总览历史里不再有周期性「恢复」记录

- **现象：** 总览历史记录里不再出现「到点自动恢复」的记录（以前体力、心力这类每到
  周期边界会自动写一条）。数值本身仍然随当前时间正确增长，总览上的数字不受影响。
  手动或同步实际改动数值时，仍会先记一条「恢复」说明这次恢复了多少，再记一条「更新」
  说明真实增减。
- **原因：** 到点自动写绝对值，用的是上次同步时的旧数字。一台设备离线久了再上线，
  会把它自己推算出的恢复量当成真实值，覆盖别的设备记录的真实消耗。现在所有再生型
  数值都在打开页面/同步时按当前时间现算，不再有这种自动写入。
- **如何调整：** 无需操作。

### 总览历史记录的列与类型标签变化

- **现象：** 类型标签细分为「更新 / 重置 / 恢复 / 锁定」；「来源」列改名「来自」，
  并新增「状态」列；对话框标题改为「总览历史记录」。
- **原因：** 历史里现在有三类含义不同的写入（覆盖、周期归零、恢复），旧的单一标签
  区分不开；锁定状态也进了同一份历史。
- **如何调整：** 无需操作。

### 锁定状态会同步到其他设备

- **现象：** 总览里锁定的条目，锁定状态现在会随同步传到其他设备；网页总览上锁定条目
  显示 `[锁定]`。以前它只是本机标记，换台设备就丢。
- **如何调整：** 无需操作。

### 自定义布局可以声明适配环境（不声明则两端通用）

- **现象：** 布局清单支持 `env: android` / `env: desktop`。系统布局已经声明，手机下发
  时会挡掉桌面布局，手机端不再拿到用不了的桌面布局。**没有声明 `env` 的布局保持原行为**，
  两端都会下发。
- **如何调整：** 无需操作。想让自己在 `config/local/layouts/` 里的布局只给某一端用，
  给它加 `env`；不加就继续两端通用。

## ✨ 新增功能

- **批量新增「参数」页。** 把勾选脚本的参数依次绘成表单，顶部可以选「全局参数」或某个
  执行用户，改完直接生效，不用再进配置对话框逐条翻。文本输入按 250ms 合并保存。
- **批量进度新增轮次导航。** 底部提供「上一轮 / 第 N/M 轮 / 下一轮 / 跳到最新」。
  历史轮的结果不会被下一轮覆盖，可以往回翻着看。
- **账户管理新增「暂停同步 / 恢复同步」。** 暂停只停掉每分钟的自动同步，心跳与在线状态
  不受影响，手动「立即同步」仍然可用；重启后保持。不用再为了停同步去退出登录。
- **用户总览列名菜单支持复制当前键名**，写脚本引用列时不用再手抄。
- **任务历史窗口补最大化按钮**，并按当前屏幕收敛尺寸。
- **网页端总览支持全屏与分组链接。** 全屏占满整个页面（不是浏览器全屏）；
  地址栏可以直接带上分组，例如 `#/profile/overview?group=生活`。
  （网页端已经上线，不需要升级客户端。）

## 🔧 修复

- **「刷毒和膏」挂机会中途停住或走错页。** 每轮都补姿态与等待：进场轻击改成每轮执行，
  后退与拖拽按住时间 1.5 → 2 秒，连续两跳后的固定等待改用命名延迟，循环末尾与后退后
  各补一次页面刷新。不再依赖散落写死的秒数，弱网和慢机器下也能连续跑完整轮。
- **登录选角在慢网络下会重复点、连点。** 改为先确认页面状态再决定是否点击，点完只轮询
  不连点。「角色在线」弹窗晚到时不会再出现「读一帧没看到就再点一次选择角色」；登录页
  没加载完也不会连点关闭按钮。
- **安卓安装配置包时被误判为携带总览数据而拒收。** 打包器漏写了声明字段，导致新导出的
  配置包全部装不上；现在补上，真正的旧包仍会被拦。
- **保存布局会抹掉适配环境。** 布局信息对话框里的 `env` 现在可编辑并随保存保留。
- **布局信息对话框在窄窗口里被挤成一行。**
- **批量窗口关闭后仍处理残留事件**，控件已销毁时直接忽略。
- **历史对话框的类型标签丢失**，补回「锁定」。

## 📦 重构

- **插件加载收敛。** 加载器、注册表与 `AppHooks` 契约集中到 `core/plugins`，宿主只按
  `lvjiang.apps.<name>` 约定导入，不再写死任何插件名；内置名册按子包列举得到，
  打包环境下同样适用，外置目录挂载不变。
- **词表归属更清晰。** 核心词表删掉 113 条只给插件用的重复文案，插件自带词表由插件自己
  声明。
- **插件相关的界面文案去掉内部概念**（自动调律 / 装备数据 / 智能调律）。
- **运行中状态的文案由脚本自己声明**，宿主不再读插件内部状态。
