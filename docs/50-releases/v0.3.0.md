# v0.3.0 — DSL 坐标体系 + 国际化 + 装备扫描增强

## 律匠 v0.3.0

本版本重点：DSL 引入 CoordRef 坐标类型体系与 EntityRef 表达式，支持坐标向量运算；完成国际化（i18n）框架与中英文翻译；装备扫描与背包视图大幅增强；调律进度 UI 整合。

---

### ✨ 新增功能

**DSL 坐标体系与语法**
- CoordRef 坐标统一体系：`CoordRef` / `RectCoordRef` / `CircleCoordRef` / `Offset` 类型层次，支持向量加减运算
- EntityRef 表达式：`$a = [scene].[region]` 可直接赋值给变量，参与算术运算（`$diff = $b - $a`）
- `wait stable on [scene].[region]` 区域限定稳定检测
- int/float 双类型改造：整数运算保持整数，除法始终为 float
- 新增 `split` 内置函数 + 列表索引语法统一为 `$list[0]`
- 废弃场景引用中的字符串形式（`"scene"` → `[scene]` 或 `$var`）

**国际化（i18n）**
- 国际化框架：YAML 翻译文件 + Python `tr()` 包装函数
- 中英文双语翻译覆盖（通用 UI / 调律配置 / 场景编辑器 / 图库管理等）

**装备扫描与背包**
- 装备扫描优化 + `fill_equipment_type` 子过程
- 装备扫描与显示功能增强
- 装备背包等级/词条筛选下拉框
- 钱袋扫描扩展（不肝进度采集）

**调律与进度**
- 调律规则支持禁用（`enabled: false`）与全量规则枚举
- 调律配置对话框增强
- 进度对话框评级语义拆分（最大预期 + 实际评级）

**Profile 与配置**
- Profile 读写管线统一 + decimal 小数支持
- 材料识别支持分组筛选 + 校准/滚动下拉中文化
- 桶发现机制从 YAML 注册改为目录扫描
