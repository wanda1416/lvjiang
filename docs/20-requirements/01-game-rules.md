## 1. 核心机制：顶级装备自动判定

### 1.1 为什么需要这个机制

| 场景 | 说明 |
|------|------|
| 用户要调"会心双刀" | 但身上穿了极品"会意"装备 |
| 会意 vs 会心 | 不同流派顶级词条不同，但都是T0级 |
| 用户可能不懂 | 不知道这件会意装备其实价值很高 |
| 工具的责任 | 自动识别并保护，避免误回收 |

### 1.2 顶级装备判定规则（跨流派通用）

T0级词条（任何流派都认的顶级）：

| 部位 | T0初始词条 | T0调律词条组合 |
|------|-----------|---------------|
| 武器 | 最大外功攻击、敏、势 | 最大外功攻击 + 任意2条三率/劲敏势 |
| 环 | 最大外功攻击 | 最大外功攻击 + 全武学增效 + 任意1条三率 |
| 佩 | 最大外功攻击（仅金） | 同环 |
| 头 | 三率任意 | 3条三率 |
| 胸 | 三率任意 | 3条三率 |
| 腿 | 劲 | 劲 + 2条三率 |
| 腕 | 劲 | 同腿 |

判定逻辑：

```python
def is_top_tier_equipment(equip: Equipment) -> bool:
    """
    跨流派顶级装备判定
    只要满足任一条件，自动保留
    """
    
    # 条件1：初始词条是T0级
    if equip.initial_affix.name in T0_INITIAL_AFFIXES[equip.slot]:
        # 且调律词条至少有2条T0级
        t0_count = sum(1 for a in equip.tuning_affixes 
                      if a.name in T0_TUNING_AFFIXES[equip.slot])
        if t0_count >= 2:
            return True
    
    # 条件2：调律词条4条全T0（初始词条稍差但调律极品）
    all_t0 = all(a.name in T0_TUNING_AFFIXES[equip.slot] 
                 for a in equip.tuning_affixes)
    if all_t0:
        return True
    
    # 条件3：特殊稀有词条
    if has_rare_affix(equip):  # 武学增效、首领增伤等
        return True
    
    return False
```

### 1.3 扫描当前穿戴装备

```
用户勾选流派后
    ↓
自动点击玩家角色/装备栏（或识别当前界面）
    ↓
OCR识别当前穿戴的7件装备
    ↓
逐件判定是否为顶级
    ↓
结果展示给用户：
    - 顶级装备：绿色勾，显示"自动保留"
    - 非顶级：黄色叹号，显示"可优化"
    ↓
用户确认后进入下一步
```

## 2. 流派规则引擎

### 2.1 用户只勾选"目标流派"

单选，不是多选。例如：
我要玩"会心双刀" → 所有调律决策按会心双刀规则

### 2.2 流派规则 vs 顶级判定规则的区别

| 规则类型 | 用途 | 触发时机 |
|---------|------|---------|
| 顶级判定规则 | 保护装备不被误回收 | 扫描穿戴装备时 |
| 流派调律规则 | 决定调律方向和目标 | 处理背包装备时 |

关系：
- 顶级装备 → 不参与调律，直接保留
- 非顶级装备 → 按目标流派规则评估是否值得调律

### 2.3 流派规则结构（简化版）

```python
@dataclass
class FlowRule:
    """单流派规则"""
    name: str  # "会心双刀"
    
    # 各部位目标词条优先级（用于调律决策）
    slot_targets: Dict[Slot, List[str]]
    
    # 最低接受标准
    min_acceptable: Dict[Slot, int]  # 最低目标词条数
    
    # 必须包含词条（硬性要求）
    required_affixes: Dict[Slot, List[str]]
```

示例：会心双刀：

| 部位 | 目标词条优先级 | 最低接受 | 必须包含 |
|------|--------------|---------|---------|
| 武器 | 最大外功攻击>会心>会意>劲>敏 | 3条 | 最大外功攻击 |
| 头 | 会心>会意>精准>劲 | 2条 | - |
| 胸 | 会心>会意>精准>气血 | 2条 | - |
| 腿 | 劲>会心>会意>精准 | 2条 | - |
| 腕 | 劲>会心>会意>精准 | 2条 | - |
| 环 | 最大外功攻击>全武学>会心>会意 | 2条 | - |
| 佩 | 最大外功攻击>全武学>会心>会意 | 2条 | - |

## 3. 批量筛选模式

```
遍历选中部位的背包装备
    ↓
对每件装备：
    1. 点击打开详情
    2. OCR识别词条
    3. 检查是否在"顶级保留列表"（当前穿戴的顶级装备）
       → 是 → 跳过（已保护）
    4. 按目标流派规则评估：
       ├─ 初始词条不合格 → 回收
       ├─ 评分 < 当前穿戴的非顶级装备 → 回收
       ├─ 有潜力 → 进入精调队列（暂停等待或自动处理）
       └─ 已达标 → 保留入库存
    5. 执行决策
    6. 下一件
```

---

## 4. 精调模式

```
选择一件装备（从背包点击，或从批量筛选转入）
    ↓
OCR识别当前词条
    ↓
循环：
    1. 评估当前状态
    2. 决策：
       ├─ 4条全目标词条 → 保留，结束
       ├─ 有垃圾词条 → 转律（选库策略）
       ├─ 缺目标词条 → 继续调律
       ├─ 材料不足/次数超限 → 暂停
       └─ 连续无改善 → 放弃，回收
    3. 执行操作（点击）
    4. 等待动画
    5. 重新识别
```

## 5. 库存管理

| 功能 | 说明 |
|------|------|
| 自动扫描穿戴 | 启动时识别当前装备 |
| 顶级装备保护 | 自动标记，不参与调律 |
| 调律结果入库 | 保留的装备记录到库存 |
| 跨部位隔离 | 武器只和武器比，头和头比 |
| 评分排序 | 同部位按评分排序，方便对比 |
