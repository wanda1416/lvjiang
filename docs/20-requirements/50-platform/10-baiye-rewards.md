# 百业周期领奖

> 状态：已实现（2026-10-07，基线 v0.13.13）。月度购买与迁移后界面仍待实机验收。

从游戏主页进入百业，领取每周分红、兑换赤金小铺的百业惊喜礼盒，检查月度
绕梁之音与银百叶礼盒，再领取活动列表顶部已完成的奖励，正常结束时返回主页。

## 周期与数据边界

| Profile key | 上限 | 重置 |
|---|---:|---|
| `baiye_dividend_of_week` | 1 | 周一 05:00 |
| `baiye_chijin_box_of_week` | 3 | 周一 05:00 |
| `baiye_raoliang_of_month` | 2 | 每月 1 日 05:00 |
| `baiye_silver_box_of_month` | 3 | 每月 1 日 05:00 |

由系统注册表声明 quota、increment_only；不预置业务分组，不覆盖用户已有定义。
绕梁之音在百业声望和银百叶两个入口沿用同一月度记录。已达上限仅跳过该项，
活动奖励仍检查；不设置整项任务的周完成标记。

## 可观察行为

- 每周分红金光表示可领取；无金光仅表示当前不可领取。看到领取结果且金光消失后
  才写完成记录。操作前保存截图。
- 商店先核对目标名、周/月库存和总库存，剩余库存换算为已购买量。选择最大数量
  后购买，以购买后的库存减少确认实际数量；币不足或识别失败不得标记完成。
- 绕梁之音当前在百业声望，迁移后也在银百叶查找，不能写死迁移日期切换入口。
- 活动按顶部可领奖前缀处理。跳过仍占位的“已结束”卡片，遇到未完成项便停止，
  不遍历未完成活动。颜色只采卡片底部背景，不把金色奖励图标当成可领奖。
- 中间色带返回 unknown，保留现场并停止该操作；导航失配不得继续按旧坐标点击。

## 验收与限制

覆盖周期跳过、共享月记录、用户分组保留、未知颜色不点击、库存无变化不写完成，
以及活动领取结果缺失时停止。截图样本和连接参数只留在私人 local 配置。

真机已有分红、赤金购买及三项活动的领取前后样本。月度商品当前库存已空，
实际月度购买和绕梁之音迁入银百叶后的界面仍需到时验收；不得写成已经实测通过。

实现后完整真机流程已返回 0 并确认主页；使用临时 Profile 同步周/月空库存，
另领取了新变为可领奖的顶部活动并在首个不可领奖项处停止。没有新增商店购买。
跨屏活动奖励前缀目前仅有布局与静态检查，尚无连续跨屏领奖的实机样本。
