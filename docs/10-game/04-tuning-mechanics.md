## 目前支持的调律流派

### 装备分级

    我们分装备为五个级别：顶级装备、优秀装备、一般（能用）装备、临时装备 和 垃圾装备
    注意，一般而言，除了小外流，并不是用户可以穿一身顶级装备，那样会出现三率不足的情况，会意和会心大外流一般需要一半顶级和一半优秀搭配。
    我们在调律的过程中，不论用户当前装备的装备是什么等级，优秀 和 顶级装备都需要保留。

    总原则：在保证神力词条的基础上保外功——攻击词条越多越好，三率尽可能少。
    各流派核心攻击：会意 = 大外+势；会心大外 = 大外+劲；会心小外 = 小外+敏。

    顶级装备：在符合增伤词条的要求下，核心攻击词条占满自由槽、三率尽可能少。
        每个流派每个部位的顶级组合基本只有一两种；无神力槽部位（副武器、冠胄/胸甲）
        非首允许 1 条本命率（会意流=会意率、会心流=会心率）参与顶级；
        有神力槽部位（主武器、环佩、胫腕甲）出现本命率 → 优秀封顶。
    优秀装备：能用且无缺陷词条，只是核心攻击未拉满、够不上顶级
        （缺的词条一般可通过转律调出来，缺词条不算缺陷；唯一例外：外功硬门槛，见下）。
    一般装备（能用）：出现了缺陷词条（非首）——会意流 = 会心/精准；
        会心流 = 势、精准+会心（非首）同现；小外流另有 小属攻 1 条。
        另外外功硬门槛：会意/会心大外流 非首必须有 1 条大外，小外流 非首必须有
        1 条小外，缺失即 能用 封顶（没有非首外功的装备只能是一般）。
    临时装备：用户目前什么都没有，急需一件能用的。
    垃圾装备：硬伤——库外废词条、必须神力缺失、流派不要的神力出现、
        缺陷词条超限（如会意流会心/精准 ≥2、小外流小属攻 ≥2）。


### 转律说明

    考虑到会心和会意流派都有一套好的装备共性，所以即使在调律过程中出现其他流派的好装备，也应该保留。
    比如 会心流派 一般不需要 会意，但是如果调 腿甲 的时候碰到 劲 + 对首领增伤 + 劲 + 大外 + 会意， 那么也应该自动保留。

    由于存在转律机制，即对 首词条 以外的词条可以选择一个进行无限次转律。
    这意味着，调律过程中，如果出现一条废词条，我们需要采取一种最优策略模拟其转律结果，再判定其可能。
    比如，对于 会意流派的 副武器，如果出现：  大外、劲、小鸣金。
        此时我们可以假定 小鸣金 按照转律优先级表，直接认定为 大外，然后判断 大外+劲+大外 算什么级别的。
        显然应该继续调律，并且这件装备有希望出 顶级装备。

## 装备词条定义

    注意：以下强调的是 顶级装备 和 优秀装备， 对于 能用装备 的要求更低一些。
    注意：如果指定部位的明确了需要 增伤 词条，但是缺失，直接判定为 垃圾装备。
    注意：大无相 在 非武器的部位表达的含义是 大本属，即所在流派的的 最大属攻攻击。
    注意：所有的装备词条描述为 必选词条 + 可选词条 组合，你可以认为这是一种类似的正则语法。
    注意：[ ] 内框选的词条是必选词条，不符合但是也没有出现垃圾词条，就认为是 能用装备。
    注意：[ ] 之后后接的词条就属于可选词条，一般可选词条就是 能用词条 * 剩余词条数量。

    转律优先级： 描述当我们假定垃圾词条转律后，排除在 2-5 词条中出现过词条，应该假定会转为哪一条词条的优先级。
    可用词条库： 除 武学增效、奇术增效、对单位增效 这些词条后，当前流派能用的词条，出现这些以外的都算废词条。


### 会意流派各部位词条要求

    转律优先级： 大外、势、劲、会意、大无相   （转律库有会心，但是认为是废品词条）
    可用词条库： 上述转律词库 + 会心、精准

    主武器（剑）： [大外 + 剑武学增伤 + 大外 + 劲/势] + 可用词条库 * 1
        非首同时出现 大外 + 劲 + 势，判定为 顶级（3 自由槽即被占满）；
    副武器（枪）： [大外 + 大外 + 劲/势] + 可用词条库 * 2
        非首同时出现 大外 + 劲 + 势，且 会意/大无相 ≥1，判定为 顶级；
    环+佩：  [大外 + 大外 + 全武学增伤] + 可用词条库 * 2
        非首同时出现 大外 + 劲 + 势，判定为 顶级；
    头盔+胸甲： [会意 + 大外 + 劲/势] + 可用词条库 * 2
        非首出现 大外，且 劲/势 ≥1，且没有出现 大鸣金，判定为 顶级；
    胫甲+腕甲： [劲 + 对首领增伤 + 大外] + 可用词条库 * 2
        非首同时出现 大外 + 劲 + 势，判定为 顶级；

    会意流派目前最佳是不需要精准和会心：出现一条 精准 或者 会心（非首）就是缺陷，
    判为 能用 装备；出现两条及以上直接判 垃圾。缺 劲/势 不算缺陷（可转律调出），
    无缺陷但够不上顶级就是 优秀；但非首缺大外是硬门槛，所有部位非首必须有
    1 条大外，缺失即 能用 封顶。
    鸣金流派顶级装备定义：
        对于 剑、环、佩 就是： 增伤 + 大外 + 大外 + 劲 + 势。
        对于 枪 就是： 大外 + 大外 + 劲 + 势 + 会意。  
        对于头盔和胸甲，就是 会意 + 会意 + 大外 + 劲 + 势。
        对于 胫甲、腕甲 就是： 劲 + 对首领增伤 + 大外 + 劲 + 势。
    理论上全部顶级装备组合后将有 5 会意，8 势。这的确是会意流派的顶级组合。 


### 会心大外流各部位词条要求

    转律优先级： 大外、劲、敏、会心、小外、大无相
    可用词条库： 上述转律词库 + 势、精准

    主武器： [大外 + 主武学增伤 + 大外] + 可用词条库 * 2
        非首出现 大外，且没有出现 小外、大无相、会心、精准、势 判定为 顶级；
    副武器： [大外 + 大外 + 劲] + 可用词条库 * 2
        非首同时出现 大外 + 劲，且没有出现 小外、大无相、精准 判定为 顶级
        （不排除会心：副武器无神力槽，允许 1 条本命率参与顶级）；
    环+佩：  [大外 + 全武学增伤 + 大外] + 可用词条库 * 2
        非首出现 大外，且没有出现 小外、大无相、会心、精准、势 判定为 顶级；
    头盔+胸甲： [会心/精准 + 大外 + 劲] + 可用词条库 * 2
        非首同时出现 大外 + 劲，没有出现 小外、大无相、势，
        并且没有 两条精准（包含首词条） 判定为 顶级；
    胫甲+腕甲： [劲 + 对首领增伤 + 大外] + 可用词条库 * 2
        非首出现 大外，且没有出现 小外、大无相、会心、精准、势 判定为 顶级；

    缺陷词条（非首，命中即判 能用）：势；精准 + 会心 同现。
    缺 劲 不算缺陷（可转律调出），无缺陷但够不上顶级就是 优秀；
    但非首缺大外是硬门槛，所有部位非首必须有 1 条大外，缺失即 能用 封顶。


### 会心小外流各部位词条要求

    转律优先级： 小外、敏、大无相、大本属、会心
    可用词条库： 上述转律词库 + 精准、小无相、小本属、小外属

    缺陷词条（非首，命中即判 能用）：小本属/小外属 1 条（≥2 直接判 垃圾）；
    精准 + 会心 同现。注意：势 不在小外流词条库内，出现即废词条直接判 垃圾。
    非首缺小外是硬门槛，所有部位非首必须有 1 条小外，缺失即 能用 封顶。

    主武器： [小外 + 主武学增伤 + 小外] + 可用词条库 * 2
        非首出现 小外，且没有出现 小无相、精准、会心 判定为顶级
    副武器： [小外 + 小外 + 敏] + 可用词条库 * 2
        非首同时出现 小外 + 敏 + 大无相，且 会心/精准 ≥1 判定为顶级
        （副武器无神力槽，允许 1 条本命率参与顶级）
    环+佩：  [小外 + 全武学增伤 + 小外] + 可用词条库 * 2
        非首出现 小外，且没有出现 小本属、会心、精准 判定为顶级
    头盔+胸甲： [会心/精准 + 小外 + 敏/大无相] + 可用词条库 * 2
        非首出现 小外，且 敏/大无相 ≥1，没有出现 小本属，
        并且没有 两条精准（包含首词条） 判定为顶级
    胫甲+腕甲： [会心/精准 + 对首领增伤 + 小外] + 可用词条库 * 2
        非首出现 小外，没有出现 小本属，并且非首词条没有出现 会心/精准 判定为顶级

    会心流派小外流顶级装备定义：
        对于 主武器、环、佩 就是： 增伤 + 小外 + 小外 + 敏 + 大无相。
        对于 副武器 就是： 小外 + 小外 + 敏 + 大无相 + 会心。  
        对于头盔和胸甲，就是： 会心 + 小外 + 敏 + 大无相 + 精准/会心
        对于 胫甲、腕甲 就是： 会心/精准 + 对首领增伤 + 小外 + 敏 + 大无相。


### 治疗流派纯奶各部位词条要求

    治疗流派即 牵丝·霖：主武器为 扇，副武器为 伞。
    纯奶需要 扇武学增效，火拳奶不需要；两者均不需要伞武学增效。

    转律优先级： 大外、劲、小外、敏、会心、大无相、大本属
    可用词条库： 上述转律词库 + 势

    公共条件（非首，按 垃圾→能用→优秀→顶级 顺序首命中即终判）：
        势/大无相/大本属 合计 ≥2 → 垃圾；势 + 会心 同现 → 能用；
        势 ≥1 → 优秀封顶（该备注曾有争议，暂以实现现状为主）。

    主武器（扇）： [大外/小外 + 扇武学增效 + 大外/小外/劲]+ 可用词条库 * 2
        没有出现 会心/大无相/小无相 判定为 顶级，否则判定为 优秀
    副武器（伞）： [大外/小外 + 大外/小外/劲 * 2] + 可用词条库 * 2
        没有出现 大无相/小无相 并且 (敏和会心没有同时出现) 判定为 顶级，否则判定为 优秀
    环+佩：  [大外/小外 + 全武学增伤 + 大外/小外/劲] + 可用词条库 * 2
        没有出现 大无相/小无相 并且 (敏和会心没有同时出现) 判定为 顶级，否则判定为 优秀
    头盔+胸甲： [会心 + 大外/小外/劲 * 2] + 可用词条库 * 2
        没有出现 大无相/小无相 判定为 顶级，否则判定为 优秀
    胫甲+腕甲： [劲 + 对玩家增效 + 大外/小外/劲] + 可用词条库 * 2
        没有出现 大无相/小无相 并且 (敏和会心没有同时出现) 判定为 顶级，否则判定为 优秀


### 治疗流派火拳奶各部位词条要求
    
    火拳奶不需要 指定武学增效，和全部武学增效，但是需要 单体类奇术增伤 和 对首领增伤。

    转律优先级： 大外、劲、小外、敏、会心、大无相、大本属
    可用词条库： 上述转律词库 + 精准、势

    公共与部位能用条件（非首，首命中即终判）：大外 全缺 → 能用；
        主武器/副武器/环佩：劲+大外 全缺 → 能用，势≥1 且 会心/精准≥1 → 能用；
        势 ≥1 → 优秀封顶（该备注曾有争议，暂以实现现状为主）。

    主武器（扇，无增伤要求）： [大外 + 大外 + 小外/劲]+ 可用词条库 * 2
        没有出现 大无相 并且 (敏和会心没有同时出现) 判定为 顶级，否则判定为 优秀
    副武器（伞）： [大外 + 大外 + 小外/劲]+ 可用词条库 * 2
        没有出现 大无相 并且 (敏和会心没有同时出现) 判定为 顶级，否则判定为 优秀
    环+佩：  [大外 + 大外 + 小外/劲] + 可用词条库 * 2
        没有出现 大无相 并且 (敏和会心没有同时出现) 判定为 顶级，否则判定为 优秀
    头盔+胸甲： [会心/精准 + 单体奇术增伤 + 大外] + 可用词条库 * 2
        没有出现 大无相 判定为 顶级，否则判定为 优秀
    胫甲+腕甲： [劲 + 对首领增伤 + 大外] + 可用词条库 * 2
        没有出现 大无相/会心/精准 判定为 顶级，否则判定为 优秀



## 调律材料添加说明

    主要采用一键调律添加 律准石。
    备注：金色装备词条默认至少紫色以上，所以对于金色品阶装备添加紫狗粮是无效的多余行为。
    狗粮添加改为有序规则表制（每轮调律自上而下匹配，首条命中即生效，
    全部不命中则不添加），每条规则 = 三条件（首词条百分比 / 装备期望 /
    装备品阶）+ 动作（添加哪种狗粮或不添加）+ 材料不足时行为，
    可在 UI「调律配置 → 材料配置」自由增删。默认两条规则：
        首词条数值 ≥ 98% 且期望评级 ≥ 顶级 → 每轮添加 彩狗粮；
        首词条数值 ≥ 90% 且期望评级 ≥ 优秀 → 每轮添加 金狗粮。
    另有可选的 大律准石数量检查（低于基准判材料不足，按配置的
