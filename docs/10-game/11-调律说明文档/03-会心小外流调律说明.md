# 03-会心小外流调律说明

公共规则见 `00-调律总说明.md`，本文仅列会心小外流专属规格。
规格权威来源：04 文档「会心小外流各部位词条要求」节。

- 必选配置：指定流派（裂石、破竹、牵丝，**可同时勾选**）和玩法。
- 可选配置：保留 PVP 装备（单体奇术增伤、对玩家增效 视作有效）。
- 主武器类型及所需武学增伤由勾选的流派/玩法决定（见 04「各流派需要的武学增伤说明」表）。
- 大本属 = 勾选流派的最大属攻，非武器部位的 大无相 即指它；勾选多个流派时，
  任一勾选流派的属攻均视作大无相；**未勾选流派的属攻为废词条**。
- 小外属 = **非本流派**的小属攻，在小外流中属可用词条（见下节）。

## 一、神力词条要求

- 主武器：必须有对应的主武学增伤，没有视为不合格（缺失直接判垃圾）。
- 副武器：不需要武学增伤，有视为不合格。
- 首饰（环/佩）：必须有 全武学增伤，没有视为不合格（缺失直接判垃圾）。
- 头盔和胸甲：不需要神力词条；keep_pvp 开启时 单体奇术增伤 视作有效。
- 胫甲和腕甲：必须有 对首领增伤（缺失直接判垃圾）；keep_pvp 开启时
  对玩家增效 可顶替该槽位。

## 二、转律优先级与可用词条库

- 转律优先级：小外、敏、大无相、大属攻、会心。
- 可用词条库：小外、敏、大无相、会心 + 小无相、小本属、小外属。
- **缺陷词条（非首出现 → 能用封顶）**：小属攻（小本属/小外属）1 条；
  精准+会心（非首）同现。小属攻共 2 条及以上 → **垃圾**。
- 小无相、精准 在库内不判垃圾也非缺陷，但会被多数部位顶级条件限制，上限优秀；
  会心（本命率）单独出现非缺陷：无神力部位（副武器/头盔胸甲）可参与顶级，
  有神力部位（主武器/环佩/胫腕甲）优秀封顶。
- 库外词条即废词条，直接判垃圾。典型：**大外、劲、势**（大外系流派的核心词条在
  小外流全是废词条）、会意、未勾选流派的属攻、错位属攻（武器上的大本属、
  非武器上的最大无相攻击）。

## 三、各部位模式与顶级判定

| 部位 | 模式 | 顶级判定（均只看非首词条，另注明者除外） |
|------|------|----------------------|
| 主武器 | [小外(首) + 主武学增伤 + 小外] + 可用词条库 * 2 | 出现 小外+敏+大无相，且未出现 精准/会心 → 顶级，否则 优秀 |
| 副武器 | [小外(首) + 小外 + 敏] + 可用词条库 * 2 | 出现 小外+敏+大无相，且 会心/精准 ≥1 → 顶级，否则 优秀 |
| 环、佩 | [小外(首) + 全武学增伤 + 小外] + 可用词条库 * 2 | 出现 小外+敏，且 会心/精准/大属攻 ≥1，且未出现 小本属 → 顶级，否则 优秀 |
| 头盔、胸甲 | [会心/精准(首) + 小外 + 敏/大无相] + 可用词条库 * 2 | 出现 小外+敏+大属攻，且 会心/精准 ≥1，且 精准 ≤1 条（含首词条），且未出现 小本属 → 顶级，否则 优秀 |
| 胫甲、腕甲 | [会心/精准(首) + 对首领增伤 + 小外] + 可用词条库 * 2 | 出现 小外+敏+大属攻，且未出现 小本属 → 顶级，否则 优秀 |

- 无神力部位（副武器/头盔胸甲）顶级**不排除会心**（本命率可参与顶级）；
  有神力部位（主武器/环佩/胫腕甲）顶级均排除会心，出现即优秀封顶。
- 大无相 为攻击词条不被顶级排除（副武器顶级反而要求大无相）。
- 缺 敏 不构成缺陷，无废词条/缺陷词条即判 优秀；但**非首缺小外是硬门槛**，
  所有部位非首必须有 1 条小外，缺失即 **能用** 封顶。

## 四、顶级装备组合参考

- 主武器、环、佩：增伤 + 小外 + 小外 + 敏 + 大无相。
- 副武器：小外 + 小外 + 敏 + 大无相 + 会心/精准。
- 头盔、胸甲：会心/精准 + 小外 + 敏 + 大属攻 + 会心/精准。
- 胫甲、腕甲：会心/精准 + 对首领增伤 + 小外 + 敏 + 大属攻。

## 五、判定例子

以下词条列表第 1 条均为首词条；示例假定勾选裂石（大本属=最大裂石攻击）。

| 部位 | 词条 | 判定 | 说明 |
|------|------|------|------|
| 主武器（陌刀） | 小外 + 陌刀武学增伤 + 小外 + 敏 + 大无相 | 顶级 | 小外+敏+大无相 齐备，无排除词条 |
| 主武器（陌刀） | 小外 + 陌刀武学增伤 + 小外 + 敏 + 精准 | 优秀 | 缺大无相，顶级条件不满足 |
| 主武器（陌刀） | 小外 + 陌刀武学增伤 + 敏 + 敏 + 大无相 | 能用 | 非首缺小外，外功硬门槛封顶 |
| 副武器 | 小外 + 小外 + 敏 + 大无相 + 会心 | 顶级 | 无神力部位顶级不排除会心（本命率） |
| 副武器 | 小外 + 小外 + 敏 + 会心 + 小无相 | 优秀 | 缺大无相，顶级条件不满足 |
| 环 | 小外 + 全武学增伤 + 小外 + 敏 + 大外 | 垃圾 | 大外为库外废词条（会心大外流 OR 逻辑下可能保留） |
| 头盔 | 会心 + 小外 + 敏 + 大无相 + 会心 | 顶级 | 会心两条不受限（限制的是精准） |
| 头盔 | 精准 + 小外 + 大无相 + 会心 + 精准 | 能用 | 精准+会心（非首）同现，缺陷 |
| 胫甲 | 精准 + 对首领增伤 + 小外 + 敏 + 大本属 | 顶级 | 小外+敏+大属攻 齐备，无小本属 |
| 胫甲 | 会心 + 对首领增伤 + 小外 + 敏 + 会心 | 优秀 | 缺大属攻，顶级条件不满足 |
| 腕甲 | 会心 + 对首领增伤 + 小外 + 劲 + 敏 | 垃圾 | 劲为库外废词条（大外系流派 OR 逻辑下可能保留） |
