# v0.1.3 — DSL 语法扩展 + 材料识别语义重构 + 识别对话框增强

## 律匠 v0.1.3

本版本聚焦 DSL 工作流语法能力扩展、材料识别语义澄清、图像识别对话框交互增强，以及 CI 兼容性修复。

---

### ✨ 新增功能

**DSL 语法扩展**
- 新增 `where` 子句：支持条件过滤，增强工作流数据筛选能力
- 新增字符串拼接语法：支持在表达式中拼接字符串变量
- `log` 命令支持表达式：可直接输出表达式计算结果

**VS Code / Qoder DSL 插件**
- Level 2：语法高亮、代码补全、代码片段
- Level 3：语义智能分析、编辑器增强、静态检查

**图像识别对话框**
- 新增分组筛选：按参考图库分组过滤识别结果
- 新增 top5 结果输出：展示最相似的 5 个候选
- 选框交互重构：更直观的区域选择体验

**场景编辑器**
- 识别增强：支持更多识别模式
- 分割器尺寸持久化：面板分割比例保存与恢复
- 布局保存时按场景定义顺序排序 regions / points / panels

---

### 🔧 修复

- CI 锁定 `windows-2022`：ONNX Runtime 不支持 GitHub Actions 的 Windows Server 2025
- 窗口标题版本号改为动态读取 `_version.py`，避免硬编码
- 截图功能修复：移除不必要的 hide/show 逻辑，避免对话框闪烁消失
- ruff import 排序修复
- CI 跳过依赖 OCR 的背包识别测试（ONNX Runtime 环境不兼容）

---

### 📦 重构

**材料识别语义重构**
- `count` 明确为"用户持有数量"（核心语义）
- `devoted` 独立为"投入数量"（仅调律流程关注）
- OCR 区域改为上下对半分割，提升大数量识别准确率
- 调律流程新增 `devoted == 0` 校验（仅记录，不阻断）

**工作流**
- `log` 命令 concat 迁移为 `+` 拼接，语法更统一
- `count_key` 重命名为 `count_nonempty`，语义更清晰
