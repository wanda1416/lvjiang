# WorkBuddy 本机接入与对话示例

> 最后更新：2026-10-09（基线 v0.13.14）。按官方连接器格式导出 Streamable HTTP 配置，实际 WorkBuddy 界面接入待本机验收。

1. 启动律匠，连接执行目标，打开调律管理旁的智能调律。
2. 选择执行用户和授权目标，勾选需要的操作权限，开启 MCP。
3. 点击“复制 WorkBuddy 配置”或“导出接入配置”。在 WorkBuddy 自定义 MCP
   配置入口导入/粘贴 JSON，连接本机律匠。实际入口名称以安装的客户端为准。
4. 让 Agent 先调用 get_capabilities、read_doc("entry")，确认服务可访问。
5. 可对 Agent 说：“先扫描我的备战方案，再和我讨论这赛季想玩的玩法，看看哪些
   装备值得培养、哪些要换，生成一套新调律配置，保留我原有设置。”
6. Agent 查询和分析，生成新基础规则组及调律规则。回到律匠智能调律页查看建议，
   勾选这套结果需要且用户愿意授予的动作权限，点击一键启动。

导出的配置使用 mcpServers、type=streamableHttp、url 和 Authorization 请求头，
与[WorkBuddy 官方连接器说明](https://open.workbuddy.cn/docs/connector)的格式一致。
本机使用 127.0.0.1；客户端必须运行于能访问此回环地址的同一台机器。不要用这份
地址让云端或另一台机器连接，也不要开放公网端口。若客户端不接受本机 HTTP，
应报告具体客户端错误，不把 CLI 文档当作 GUI 接入已验证的证据。

配置含私人连接令牌，不公开分享；关闭/重开服务或重启软件后重新导出。它不包含
模型 API Key、登录账号或装备数据。智能调律页面的“关闭 MCP”撤销连接，已启动
游戏任务继续按原流程运行，可在调律管理中停止。
