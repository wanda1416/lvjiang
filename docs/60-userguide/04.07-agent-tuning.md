# 4.7 使用外部 Agent 智能调律

> 最后更新：2026-10-09（基线 v0.13.14）。桌面入口与本机 MCP 已实现，WorkBuddy 界面接入和真实游戏过程待实机验收。

智能调律需要开通 Lv1，请先在设置的“功能激活”中激活。未开通时所有 MCP 请求
均返回激活提示，包括初始化、发现和文档读取。

打开“燕云 → 智能调律”，点击“启用智能调律”。以后每次主实例启动都会自动开启 MCP，并同步所选 Agent 的接入配置，不必反复手动导出。默认端口为 18765，服务停止时可修改；另一安装目录占用相同端口时，需为第二个安装修改端口。

先在“配置管理 → AI 设置 → 外部 Agent”填写 Agent 名称和默认导出文件，可添加多个 Agent，保存后供智能调律使用。系统已预置 WorkBuddy 和 QoderWork 的用户目录导出文件。这里也可修改“下载 Agent 链接”；智能调律中的“下载 Agent”会打开该链接，引导安装客户端。

在智能调律中选择使用哪个 Agent，导出文件默认沿用 AI 设置，也可为当前安装单独调整。切换 Agent 或修改导出文件不改变 AI 设置中的默认值。启动后自动合并同步所选 Agent 的配置，保留其他服务和设置。必要时在 Agent 中刷新连接或重启 Agent；实际客户端识别待本机验收。

对话框关闭后服务继续运行，“停用智能调律”关闭服务并取消后续自启；只读实例不能启用服务。流派讨论、用户选择、分析与任务启动全部在 Agent 对话中完成，不需要设置律匠内置模型。

可以对 Agent 说：

> 看看当前用户和我全部用户。先扫描我指定用户的备战方案，再和我讨论想玩的玩法，
> 分析装备怎么培养、哪些需要换，生成新的基础规则组和调律规则，保留原有配置。

AI 能了解当前用户与全部用户。主界面切换用户，或让 AI 处理其他用户，不需要
再次导出连接配置，也不需要逐项授予权限。窗口与手机由 AI 查询接口了解，启动
时指定设备，省略时使用当前设备。设备未连接、任务占用或功能不可用时，AI 会
收到具体原因并向你解释；忙碌任务不会被自动停止。

扫描会切换游戏方案并更新装备和基础属性，目前覆盖可见网格。分析和培养建议
不会直接培养装备。生成配置只新建，不覆盖已有定义；明确要求启动后，Agent
调用现有调律执行器，按最终配置执行回收、重置、锁定或狗粮使用。

生成结果在 Agent 中展示，进度和结果仍在调律管理中查看。只有你要求保存为
默认选择时才写用户调律设置，此后可从原自动调律入口启动。关闭 MCP 服务只
断开 Agent 接入，已启动任务继续运行，仍可使用原暂停/停止入口。

每个安装有独立连接名和私人令牌，请勿公开分享。端口与令牌跨重启保持稳定，切换用户或设备不改变接入配置。开发环境直接读取 docs 中的游戏机制、架构/DSL、用户指南和 Agent 契约，目录与发行版一致，不必为了调试先打包。

完整操作契约见 [Agent 使用入口](../70-agent/README.md)。
