# 9. 移动设备（安卓）

> 入口：菜单 **工具 → 移动设备**

默认打开「离线任务」，第二个 tab 为「应用安装」，其后为设备扫描、设备体检和手势测试。

手机端的律匠是一个独立的 Android app：既可为 PC 提供无障碍截图、点击与并发手势，
也可使用预置或同步的配置独立执行安卓任务（Beta）。这个页面提供**装包**、**设备扫描**、
**设备体检**、**手势实测**和**离线任务**。

## 9.1 安装手机端 app

安装包随每个正式版本一起发布，文件名是 `lvjiang-vX.Y.Z.apk`。页面顶部会显示
当前 PC 版本和对应的安装包名——**两边版本要一致**，详见 9.3。

页面左侧只有**一个**二维码，内容由右侧「二维码来源」决定——同一时刻只有一个码
该被扫：

| 来源 | 适用 | 说明 |
|------|------|------|
| **在线下载（GitHub）** | 手机能上网 | 默认。扫码直接从 GitHub 下载安装 |
| **本机共享（局域网）** | 手机上不了网 | 由电脑提供下载。需要先在本机准备好安装包 |

选中「本机共享」就开始共享，切回「在线下载」即停止——选项本身就是那个开关。
未准备安装包或没有可用局域网地址时它不可选，把鼠标停在上面会说明缺什么。

另有一条不用扫码的路：手机已经用 USB 连着时，准备好安装包后点 **「ADB 直传到
设备」** 直接装。

「下载 APK 到本机」会把包存到软件目录下的 `data/apk/`，并与发布的
`SHA256SUMS.txt` 比对校验和：

- **校验通过**：文件完整。
- **未比对**：取不到校验和文件（离线、代理等）。不拦着安装，但页面会如实标注。
- **校验不一致**：文件已删除，不会留下可安装的包。

手上已经有 APK（比如从别处拷来的）可以点「选择本地 APK…」，同样会算一次校验和。

下载过的包会留在 `data/apk/`，**下次打开这个页面会自动认出来**，不需要重新下载。
只认与当前版本文件名完全对应的那一个：版本不符的旧包不算"手上已有"——两边版本
不一致正是这个页面要帮你发现的问题。

> **「本机共享」会在电脑上临时开一个端口**，只服务这一个文件，切回在线下载或
> 关闭对话框即停止。手机和电脑必须在同一个局域网；「本机地址」可以切换网卡
> ——多网卡机器需要选对与手机同网段的那个，换地址只重算链接，不会中断共享。

安装后首次启动，app 会引导你开启**无障碍服务**——这是点击、滑动、手势和截图的
基础，不开启整个手机端都无法工作。部分系统会在「受限设置」里额外拦一道，需要先
在系统设置里允许。

## 9.2 设备扫描

这个页面始终可以主动寻找尚未出现在设备下拉框里的设备，即使电脑已经通过 USB 或
ADB 连接了其他设备，也不会隐藏：

- **扫描局域网**：发现已开启无线 ADB、且与电脑处于同一网段的设备。多网卡时可以
  指定网段，也可以保留「全部网卡」逐个扫描。
- **扫描本机端口**：发现只监听 `127.0.0.1` 的安卓模拟器。

扫描成功后会刷新对话框顶部的设备列表。这里仅建立 ADB 连接，不会自动连接主界面的
执行目标，也不会改变当前正在使用的窗口或设备；需要运行任务时，仍由主界面明确选择
并连接目标。

## 9.3 设备体检

点「开始体检」连接手机端代理并逐项给出结论。这些信息手机端一直在上报，以前
只能从日志里翻。

| 检查项 | 说明 |
|------|------|
| 设备端版本 | 与 PC 版本不一致时告警；离线同步要求执行代码版本一致 |
| 协议版本 | **不匹配会直接连不上**，并指出该升电脑还是升手机 |
| 无障碍服务 | 未开启则手势、点击、截图全都不可用 |
| Shizuku | 可选能力，只影响 shell 通道；不装也能正常用 |
| 并发手势上限 | 本机同时可注入几路触点。决定输入时间线能写几路并发 |
| 屏幕 | 分辨率、旋转角与画面比例。比例与所选布局要求不符时任务会被拦住 |
| 屏幕标定 | 截图坐标与输入坐标的映射。点位整体偏移时在手机端首页高级面板标定一次 |
| 其他连接 | 除本窗口外还有几路连到这台手机（另一个窗口或另一台电脑），大于 0 时操作会互相打断 |
| 最近一次操作 | 手机端最后收到的指令及其结果，用来区分"没发出去"和"发了但失败" |

下方还会列出**当前通道能跑什么**：声明 `#% requires: [device_gesture]` 的脚本
只有无障碍通道支持，用 ADB / Shizuku 通道时会在**加载脚本时**就被拒绝，而不是
跑到一半才失败。

「复制诊断报告」把以上内容整理成一段纯文本放进剪贴板，字段按
[1.6 遇到问题怎么反馈](01-quick-start.md) 的要求组织，反馈时直接粘贴即可。

## 9.4 手势测试

手机端支持**多路并发手势**，脚本里用输入时间线描述（例如"推着摇杆的同时连点
跳跃"）。输入时间线是 DSL 的能力，语法见
[03.7 输入时间线](../30-architecture/32-grammar/03.7-timeline.md)，需求与边界见
[输入时间线](../20-requirements/50-platform/03-input-timeline.md)（仅源码检出）。这个能力依赖系统和
机型，所以提供一个实测入口。

点「开始测试」后，手机会在**屏幕左下角按住**设定的秒数，期间在**右下角点两次**。
把手机停在游戏里能看出移动和跳跃的画面再点，就能直接看出两路动作是否真的同时发生。

> **"回报成功"不等于"游戏响应了"。** 手机端只能确认系统接受了注入；游戏是否
> 响应必须靠眼睛看。所以测试前一定要先把画面摆好。

结果里还会给出 PC 与手机之间的**往返延迟**（中位数、最快、最慢），用来判断
"是不是手机太慢"——延迟高时识别和点击之间的空档会变长，脚本更容易在页面切换
中途动作。

## 9.5 离线任务（Beta）

**Android APK 独立执行目前为 Beta。复杂任务仍可能导致设备内存不足，游戏被系统 kill（结束）；该问题尚未解决。**
本轮 OCR 与截图优化不保证复杂任务和长时间运行稳定。出现游戏被系统结束时，请停止手机任务并保留诊断信息；复杂任务优先使用 PC 执行。

向手机下发配置需要激活 **Lv1**（设置 → 功能激活）。未激活时“下发配置”按钮禁用；
状态查看、环境检查和手机已经同步配置的离线执行不受此限制。

在「离线任务」页的「同步配置」区选择适用于手机的布局，点「下发配置」。它会把 PC
当前脚本、配置、模板、用户资料和一致性 Profile DB 快照同步到手机，不改变 PC 的
当前用户或布局。任务参数可在 PC 配置后同步，也可在手机按用户独立修改（见 9.6）。
同步包含 `session.json` 与独立的 `interface.json`；界面状态、总览配置、告警和服务器
状态读取新文件，提醒去重历史位于新文件的根节点。

自动调律也可从手机悬浮任务列表启动，使用同步用户在 PC 配好的调律部位和规则。
也可在手机任务设置中选择已下发的调律候选；若在 PC 脚本配置中显式隐藏该任务，手机列表也会隐藏它。

APK 内置官方任务、场景、布局和参照图，新装即可初始化默认用户和空数据库，不必先同步。
手机「用户管理」可创建用户、编辑通用属性；任务参数在「任务设置」修改。
APK 新预置版本只更新官方 system，保留用户参数、local 覆盖和 DB。
PC 同步仍将官方配置写入手机 system，不投影为 local。同步保留手机原有 updates 归档及
基底身份，不将 PC 快照记作官方 r0；手机本轮不自行在线更新配置。

下发配置不回传手机结果；再次下发仍会替换手机 Profile DB，但保留手机任务历史、调律历史、日志和结果文件。
「保留手机任务参数」默认勾选，保留已有通用参数、各用户的独立参数（含自动调律）
及手机独有用户；新任务采用 PC 参数，脚本、布局和 Profile 数据库仍更新。
取消勾选才用 PC 完整覆盖任务参数和用户名册。旧 APK 不支持该选项时会提示先更新。
所有用户资料和任务配置都会下发，不需要选择同步用户或任务；布局仅下发所选项及
必要的继承依赖。初始执行用户取 PC 当前用户，之后可在手机自行选择。
同步只包含运行所需的白名单配置、参照图/模板、用户资料与数据库；不会下发
场景管理截图、本地 data 参考资料、日志或诊断文件。
「远程执行」区的用户和任务来自手机已同步数据，仅用于 PC 远程启动，不控制同步范围。
点击远程启动时会自动开启悬浮控制，无需提前手动开启图标；需要已授予悬浮窗权限。
未授权或系统拒绝开启时会提示原因，不启动任务；正常开启后面板保持收起。
任务运行、暂停或结束中不能同步。传输或校验失败不替换原配置。

手机底部导航栏通过图标和标签提供「工作台」「任务」「用户」「设置」四个入口，
当前页面以选中指示器标记。界面随系统切换深浅色；输入时导航栏暂时隐藏：

- **工作台**：查看运行用户、任务、耗时、实时日志和最近 100 条手机执行记录。
  「选择用户」明确切换下一次执行的用户，并同步任务页的参数用户，执行中不可切换；「选择任务」以该用户进入
  任务准备页面。运行日志可按需展开，运行中的用户不随其他页面的浏览选择改变。
  选择入口下方可直接启动或关闭悬浮窗；开启后回到游戏点击图标执行。任务执行中
  请使用当前任务卡的暂停、继续和结束操作，不能关闭悬浮窗。
  点击记录查看结束原因、结果摘要及日志。进程异常退出遗留的任务会标记为失败/中断，
  需要重新核对游戏内结果；流程结束不等于已经领取奖励。
- **任务**：按分组或名称/说明搜索任务，无需参数的任务也会列出。
  列表仅预览任务说明，进入详情可查看完整说明；配置问题仍完整显示。
  先选择参数用户，进入任务详情检查条件、编辑参数，再点「准备任务」。
  准备会明确选择执行用户并开启悬浮图标；请回到对应游戏角色后展开图标，点击「启动任务」。
  仅浏览列表、切换参数用户或编辑参数不会改变执行用户，也不会启动任务。
- **用户**：选择浏览用户，通过「用户数据」「备战方案」「战斗属性」切换内容，当前浏览用户名在标题旁显示。
  用户数据展示已保存资料和分页变更历史，未采集与零值分开；本页菜单的「用户管理」
  用于创建用户和编辑通用属性，「切换用户」更换浏览对象。用户备战展示燕云方案八个装备槽位，点击「扫描装备」
  浏览装备池及词条详情。完整方案可查看毕业率与 DPS；临时切换
  计算方案或基础属性不会修改已保存方案。模拟装备和无法计算的原因会明确标记。
  「战斗属性」直接展示攻击属性、判定属性、增益效果和伤害加成四张卡片。
  「满等级」「满承音」「满定音」「模拟转律」四项假设可独立勾选，毕业率和属性
  同时按假设更新；关闭后恢复当前装备口径，不修改真实装备。
  毕业率与 DPS、四项假设、模型与基础属性名称各占一行。点击装备查看基础属性、
  词条与定音，常规完整装备在一张弹窗内展示，[转] 接在词条名后，记录时间作为辅助信息。
  展示的是手机保存的快照，重新扫描或电脑同步后重新进入对应页签。模型随官方预置及电脑同步
  导入；Excel 模型先在电脑端转换。浏览、切换方案和计算不改变执行用户。
- **设置**：权限、悬浮控制、PC 连接、标定、诊断和报告分享；也可查看当前版本、
  打开发布说明、手动获取公告或刷新反馈联系二维码。刷新失败时显示原因，有缓存时保留缓存。

任务页菜单提供「任务设置」，用户页菜单提供「用户管理」「切换用户」；高级功能和
自检与诊断统一在设置页。仅打开页面不会执行自检或任务。
也可以在设置的高级功能中启动悬浮图标，直接展开面板、选择用户/任务、点「启动任务」。
运行时顶部左侧「停止任务」、右侧「暂停任务」（暂停后为「继续任务」），其下为
「用户」「任务」，下一行并排「选择用户」「选择任务」；点击进入
二级列表，选择后返回，不会自动启动。启动成功后面板自动收起，启动失败时保留面板。
用户从手机有效资料中选择，运行、暂停或结束中不能切换。切换执行用户
不自动登录或切换游戏角色，请确认资料与当前角色一致；选择仅保存在手机，保留参数同步时保留有效选择。
任务下方仅保留最近 100 行 INFO 及以上日志，更多日志通过 PC 设备状态读取
（最近 200 条记录）。向上浏览时不强制跳回底部，可点「回到最新」恢复跟随；
底部「收起」始终可用。
运行中可暂停或结束，暂停后可继续或结束；收起面板和断开 PC 都不会停止任务。
脚本要求人工处理时会显示原因并真正暂停。确认问题提供「确认」「拒绝」，普通「继续」不能代替选择；
停止可以结束正在等待确认的任务。PC 旧控制入口遇到确认问题时，请在手机工作台或悬浮窗回答。
需重启游戏的任务还需要 Shizuku；不支持的
输入交互会明确失败，不能当成已经处理。

手机「检查离线执行环境」实际检查依赖、插件、引擎和 OCR 推理；失败可复制诊断报告。
手机 OCR 已使用原生管线，工作流和清洗规则仍与 PC 共用。稳定等待遇到横竖屏
变化会重新建立基准；真实 OCR 后端故障或内存不足会停止任务，不当作空识别继续点击。
原生化不代表已完成所有游戏任务的准确率和长时间内存验收。
诊断报告包含当前内存快照。手机私有目录同时保留有界运行诊断日志，记录模型会话、
推理尺寸/耗时/内存与任务阶段；OOM 会明确中止任务，而不是作为“没有识别到”继续点击。
装备详情截图失败会有限重试；连续失败则停止自动调律，日志会给出截图失败原因。
安卓无障碍截图由系统限制最小间隔（约三分之一秒），这不是可以关掉的开关；截图间隔由
app 自己补齐，画面稳定等待的采样间隔也不会低于这个下限，因此脚本里写得更快也不会更快。
PC 页也可以检查环境和控制手机任务。检查环境通过不代表每个游戏任务、当前页面和布局
均已验证；运行前仍需满足任务自己的前置条件。

同步、状态查看不隐藏悬浮球；PC 代理工作流实际执行时才隐藏并占用控制权。
手机任务与 PC 代理输入互斥；外部直接 ADB 输入不受 APK 管控，不能同时运行。

## 9.6 手机任务参数设置

手机任务页的详情进入「编辑参数」；本页右上角「任务设置」和悬浮窗「设置任务参数」仍可使用。
先选择配置用户，再点击需要修改的任务。这里切换的是编辑对象，不改变手机执行用户，
也不会切换游戏角色或启动任务。

普通任务使用开关、数字/文本输入、单选及多选列表，关联字段按条件显示。
自动调律先展示基础规则、部位、规则和执行选项摘要，再进入子页面选择下发的候选。
子页面共用草稿，统一点击顶部「保存」；离开未保存页面会提示保存、放弃或继续编辑。
普通任务可通过菜单「恢复通用配置」删除该用户的独立覆盖，不影响其他用户；
自动调律始终采用用户专属配置，不提供此操作。

手机参数修改不会同步回电脑，下次电脑同步可选择保留。任务执行、暂停或停止过程中
只能查看参数；停止后才可保存。如果编辑期间配置重新同步或被修改，保存会提示
重新加载，避免旧草稿覆盖新配置。

### 手机用户管理

用户页菜单进入「用户管理」，可新增执行用户，点击用户进入资料详情添加或编辑通用属性。
属性名称和内容与电脑端用户管理一致；只在任务需要时填写，不要求配置游戏账号或密码。
详情统一保存，返回时提示未保存修改；创建和编辑用户不会自动改变执行用户或切换角色。
任务运行、暂停或停止过程中只读。资料不回传 PC；同步时同名用户的非任务资料仍取 PC 值，
手机独有用户仅在勾选保留参数时保留。空数据库不等于游戏任务尚未完成，任务仍需满足扫描及页面前置条件。


### 手机批量执行

任务页顶部选择「批量执行」，选择已有配置组，或从菜单「批量配置」新建。点击任务、用户或单元调整本次勾选，长按拖动排序，也可使用上移、下移按钮。任务参数按指定用户查看和编辑，参数浏览不改变批量选择。

「执行」设置轮数和无人值守；未设置异常恢复工作流的组不能开启无人值守。生命周期定义及参数在任务页菜单「批量配置」中编辑，也可在电脑编辑后同步；「恢复默认选择」恢复该组初始顺序与默认勾选，不修改配置组。

点击「准备批量执行」后回到游戏，从悬浮窗启动。准备后修改配置或参数需要重新准备。工作台当前任务卡显示整批进度，点击可查看实时任务明细；暂停、继续、结束均控制整批。批量页的「最近批次」查看结果及报告。

重启游戏可能切换横竖屏，程序等待目标方向及画面恢复后继续。期间可以结束执行；旧识别坐标不能用于旋转后的画面。运行应用生命周期需要启动并授权 Shizuku。应用进程中断后历史标记为中断，不自动恢复游戏操作。

设置页「关于与反馈」分组中的「关于」位于「反馈联系」下方，展示与电脑端共用的功能简介、许可证、免责声明和版权信息，并提供发布页、源码和许可证链接。日常任务列表的次级说明缩进展示。任务页标题旁以较小字号显示当前选中的任务，工作台「选择任务」下方显示同一任务；两处均在超过六个字时显示前六个字和 `...`。

切换正在编辑的配置组不会改变任务页当前组；保存初始顺序也不会覆盖你已调整的本次顺序。删除只清除该组及其本次选择。同步选中「保留手机任务参数与批量配置」时保留手机整份批量定义；取消则使用电脑定义，本次运行草稿仍保留并按新定义协调。

配置组设置了指定排序时，在本次用户选择窗口点击「按指定排序」才会应用；保存排序键本身不会改变顺序。

## 历史与日志回传

在「离线任务」的「回传到电脑」区域分别勾选任务历史、调律历史、任务日志，
结束手机任务后点击「回传历史与日志」。选择按设备保存在电脑，下发配置与回传互不触发。
回传不要求下发配置的 Lv1 权限，但须在电脑主节点操作，并更新到配套 PC 与 APK。
任务历史包含批次记录、结果和报告；调律历史包含过程明细与说明文档；日志可以单独回传。
电脑直接归集手机独有用户的历史，不创建或改变电脑用户资料。任务参数、Profile 和装备仓库不回传。
重复操作按运行记录去重，手机原件保留；断线或取消后可重新回传。
同名记录或附件内容不同时保留电脑原件并提示；手机缺失附件也会明确提示，不能视为完整归档。
旧调律记录缺少来源时，只有报告路径能确认属于当前手机的才归集，其余数量显示在结果中，原件保留。
当前每次导出完整的已结束记录及所选附件，包展开上限 256 MiB；超限可先分开回传类别。
任务结果使用 `config/session/output/<用户>/YYYY-MM/DD/`，任务日志使用 `logs/daily/<用户>/YYYY-MM/DD/`；
回传保持相对目录，原有记录继续按各自保存的路径读取。
