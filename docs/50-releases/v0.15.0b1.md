# v0.15.0b1 — Android 工作台、批量执行与配置更新 Beta

发布日期：2026-10-11。以 v0.13.15 正式版本为基线，跳过 0.14。
本版本是首个 0.15 Beta，不替换当前正式版 0.13.15，不向普通客户端提示升级；
需要测试的用户通过本发布页面手动下载。请先备份配置与数据库。

## ⚠️ 不兼容变动与升级指引

### 在线配置改为安装到 system

- **现象：** 旧 config/remote 中的内容不再作为加载层；官方内容更新后直接安装到 system，local 仍优先。
- **原因：** 官方配置更新方式已调整。
- **如何调整：** 不删除 local 或 session。升级后重新获取有授权的官方配置；自行维护的覆盖放在 local，勿将整份旧 remote 目录直接覆盖到 system。若官方修正未生效，核对相应 local 覆盖。运行中的任务继续使用启动快照，更新影响后续任务。

### 旧配置结构不再自动转换

- **现象：** 顶层 android_apps、scenes.yaml v1、布局集中 disabled 段、旧赛季文件名和 tune_config 的旧启停声明不再生效；批量 v2 不再读取 selected_* 作为默认值。
- **原因：** 清理可自行重配的旧入口，避免启发式兼容继续改写用户文件；Profile 数据库及必要会话迁移仍保留。
- **如何调整：** 备份后按[配置升级调整](../60-userguide/12-config-upgrade.md)修改对应字段；可以先在 0.13.15 保存相关配置再升级。赛季文件手工改名为 seasons.yaml，已有新文件时核对合并；布局保留原坐标，将停用状态放到各实例。用户总览列宽等展示偏好需要时重新设置。

### 两端版本、单向同步与安装方式

- **现象：** PC 与 APK 版本不一致时不能同步；手机上的配置和数据库仍不回传 PC。
- **原因：** 同步采用同版本单向快照，手机配置保留选项不等于双向合并。
- **如何调整：** 测试时将 PC 与 APK 同时升级到 0.15.0b1，同步前备份并核对覆盖提示。Windows 便携版解压到新目录，再复制 local、session；不要覆盖旧便携目录。安装器和 APK 保留用户数据、更新官方内容。

### Android 独立执行仍需实机测试

- **现象：** 手机可设置并执行单任务或批量任务，但连续长时间运行、不同分辨率和低内存设备仍可能遇到问题。
- **原因：** 本版本扩大手机工作台与执行能力，不代表复杂游戏任务已经完成全部设备稳定性验收。
- **如何调整：** 先在可监督的环境测试，确认角色、任务参数和游戏界面；保留日志。需要稳定运行复杂任务时仍可选择 PC 控制。手机客户端本轮不自行在线更新配置，仍由 PC 同步。

## ✨ 新增功能

- **Android 工作台**：首页、任务、用户、设置分区；首页提供悬浮控制入口，参数配置和高级功能不再集中堆放。支持任务设置、用户选择、执行历史与停止／暂停控制。
- **手机批量执行**：配置任务与用户顺序，运行冻结后的批量方案；悬浮窗展示执行进度并提供安全控制，运行报告保留在手机侧。
- **手机备战数据**：支持查看燕云备战装备、词条与毕业率，数据仍以本地快照和任务采集结果为准。
- **脚本分组与刷新**：日常页按脚本元数据分组筛选，提供刷新和加载；脚本编辑支持分组，配置页只读展示分组并标识自定义名称。
- **用户总览总和行**：按分组选择是否显示汇总，保持用户分组与原数据独立。
- **设备预览复制**：复制当前展示帧的原始图像到剪贴板，可直接粘贴，不额外抓帧或保存截图。
- **官方配置更新**：更新后立即生效，无需重启；网络失败继续使用当前可用内容。

## 🔧 修复

- 参数输入合并保存，切换编辑对象和启动任务时保留正确的参数归属，减少频繁写盘造成的卡顿。
- 用户档案直接变更的撤销不再依赖是否触发方向同步。
- 批量运行草稿使用独立界面状态，避免只读实例无法保存本次选择。
- 修正授权配置的地图类型登记时机，避免有效配置包因登记遗漏被整包拒绝。
