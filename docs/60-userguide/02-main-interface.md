# 2. 主界面与用户管理

## 2.1 主窗口布局

启动后主窗口分为四个区域：

```
┌─────────────────────────────────────────────┐
│  顶部菜单 + 设备/窗口选择区                    │
├──────────────┬──────────────────────────────┤
│              │                              │
│  左侧 Tab    │  右侧 Tab                     │
│  · 日常      │  · 运行日志                    │
│  · 批量      │  · 装备状态（插件注入）          │
│  · 调律      │                              │
│  （插件 Tab） │                              │
│              │                              │
└──────────────┴──────────────────────────────┘
```

### 顶部菜单

| 菜单 | 主要入口 |
|------|---------|
| 通用 | 配置管理、用户管理 (F2)、场景管理 (F3)、图库管理 (F4) |
| 工具 | 图像识别、脚本录制、脚本编辑、脚本配置、批量配置、[任务历史](06-workflows.md#76-查看任务历史) |
| 燕云 | 游戏配置 (F5)、调律配置 (F6) |
| 帮助 | 公告、检查更新、[文档](https://github.com/wanda1416/lvjiang/blob/master/docs/60-userguide/README.md)（跳转 GitHub 上的本用户手册）、反馈、关于 |

菜单栏最右侧还有一个不属于任何菜单的**主题切换**图标按钮（☀/☾），点击在浅色/深色
主题间切换，选择会记住，下次启动沿用。

### 顶部设备/窗口选择区

从左到右：
1. **当前用户** 下拉框 — 切换当前激活用户（详见 2.2）
2. **方案** 下拉框 — 一次切换图库、环境、布局三者（详见 2.4）
3. **图库 / 环境 / 布局** 三个下拉框 — 选中方案后由方案填充并锁定，只有
   「- 自定义 -」时可以逐个手动选
4. **窗口/设备选择组** — 扫描窗口 / 扫描设备 / 目标下拉 / 定位·连接按钮 / 显示预览

### 全局热键

| 热键 | 功能 |
|------|------|
| F9 | 开始执行（当前 Tab 的自动化任务） |
| F10 | 停止执行（等待中也能立即打断） |
| F11 | 暂停/恢复执行 |
| F2 | 用户管理 |
| F3 | 场景管理 |
| F4 | 图库管理 |
| F5 | 游戏配置 |
| F6 | 调律配置 |

F12 不是主窗口全局热键。用户必须先从「工具 → 脚本录制」打开
对话框；对话框打开期间才会临时注册系统全局 F12，用于开始/停止录制。
关闭对话框后 F12 立即注销。脚本编辑仅从「工具 → 脚本编辑」打开，不再占用 F7。

## 2.2 用户管理（F2）

律匠支持多用户，每个用户有独立的会话数据（session）和调律产出记录。

### 打开方式

「通用 → 用户管理」或按 **F2**。

### 操作说明

| 操作 | 说明 |
|------|------|
| 创建用户 | 输入用户名，点「创建」。首次启动自动创建「默认用户」 |
| 删除用户 | 选中用户后点「删除」，确认后清除该用户所有数据（不可恢复） |
| 切换激活 | 在列表中选中用户，点「激活」或双击。顶部「当前用户」下拉框同步切换 |
| 调整顺序 | 使用上移/下移按钮调整用户列表顺序 |

### 头像

用户管理对话框和 Profile Tab 的「用户信息」页都能编辑当前用户的头像：悬浮点击头像区
或双击即可打开编辑器，支持导入图片（文件或剪贴板）、从当前设备/窗口刷新截图取一帧、
裁剪后保存。

头像保存进独立的**头像库**，不属于某个用户——多个用户可以共用同一张头像，删除用户
不会清空头像库；只能在头像库里删除**未被任何用户使用**的历史头像。

### 用户与批量任务

在批量任务中，可以通过「用户名列」指定条目表中哪一列的值作为角色名，
执行时会自动切换到对应用户的 session。详见 [3.4 批量任务](03.04-batch-tasks.md)。

日常 Tab 和调律 Tab 各自还有一个独立的「执行用户」选择框，可以固定用某个用户启动本次
任务而不必先切换顶部「当前用户」，详见 [7.1 日常 Tab 布局](06-workflows.md#71-日常-tab-布局)。

### Profile 数据

每个用户有独立的 Profile 数据，记录游戏内的角色信息：

| 数据 | 来源 |
|------|------|
| 货币（通宝、么玉、宝钱、长鸣玉） | 扫描钱袋工作流写入 |
| 不肝进度 | 扫描钱袋工作流写入 |
| 调律产出记录 | 自动调律工作流写入 |

Profile 数据随用户切换自动加载，不同用户之间完全隔离。部分工作流（如扫描钱袋）会更新 Profile 中的数值，可在装备状态 Tab 的 Profile 页查看。

「用户信息」页顶部还提供独立的「便利贴」区域，可为当前用户
逐条新增、编辑和删除短备忘。便利贴不是 Profile 固定数据模型，
不会出现在用户总览列中，数据单独保存在
`config/session/users/{用户名}.notes.json`。

## 2.3 布局切换

顶部「当前布局」下拉框可切换不同的布局配置。布局定义了各场景的坐标区域
（如背包页、调律页等），不同分辨率/窗口比例可能需要不同布局。

- 默认提供「默认布局」，覆盖主流分辨率
- 如需自定义，可在场景管理器 (F3) 中编辑当前布局下的场景坐标

## 2.4 方案

图库、环境、布局这三项必须配套使用：端游要「端游 + 桌面 + 桌面布局」，
手机或模拟器要「手游 + 安卓 + 默认布局」。每次换目标都要点三次，还很容易
漏掉一项——比如连了 ADB，环境却还停在「桌面」，此时点击坐标会整体偏移，
而且不会报错。

**方案**把这三项绑成一个具名整体，并声明它支持哪种连接方式。

### 使用

顶部「方案」下拉框默认是 **`- 自定义 -`**，行为和以前完全一样，三个下拉框
各自随便选。

选中一个已保存的方案后：

- 图库、环境、布局按方案自动填好，并变灰不可改（点一下会提示怎么解开）
- 想手动调整，把方案切回 `- 自定义 -` 即可，切回时会还原你进方案之前的那套组合

### 新建与管理

「通用 → 配置管理 → 方案设置」，上半部分就是方案管理。

| 操作 | 说明 |
|------|------|
| 新建 | 建一个空方案，默认两种连接方式都支持 |
| 从当前组合新建 | **推荐**。直接把主界面当前的图库/环境/布局存成方案，取个名就行 |
| 删除 | 删除选中方案。正在使用的方案被删掉时，主界面自动回到 `- 自定义 -` |

右侧编辑名称、图库、环境、布局，以及「支持模式」的两个勾选框：

- **窗口模式** — 通过「扫描窗口」定位 PC 上的窗口（端游窗口、模拟器窗口、投屏窗口）
- **ADB 模式** — 通过「扫描设备」连接手机或模拟器

至少要勾一个。模拟器比较特殊：它既可以用窗口模式截图，也可以走 ADB，
所以模拟器方案通常两个都勾，但环境必须选「安卓」。

改完点底部「保存」；名称为空或一个模式都没勾会被拦下。

### 连接方式不匹配时

连接（或定位）之后，如果当前连接方式不在方案声明的支持列表里，
**「开始执行」按钮会变灰显示「方案不支持」**，点击会在左下角状态栏说明是
哪个方案不支持哪种模式。F9 热键和托盘菜单的「开始」同样被挡住。

想继续跑，要么切到匹配的方案，要么在方案设置里补勾对应的模式。
