# 4.4 流派规则详解

系统预置 5 套调律规则。每条规则定义了一套完整的词条评级标准，
决定装备在各部位被判定为顶级 / 优秀 / 一般 / 垃圾。

---

## 评级总原则

> 在保证神力词条的基础上保外功——攻击词条越多越好，三率尽可能少。

装备分为五档：

| 评级 | 含义 |
|------|------|
| **顶级 (top)** | 核心攻击占满自由槽、三率尽量少。每流派每部位顶级组合基本只有一两种 |
| **优秀 (excellent)** | 无缺陷词条，核心攻击未拉满（缺词条不算缺陷，可转律调出） |
| **一般 (normal)** | 出现缺陷词条，或有瑕疵但仍非废品 |
| **垃圾 (junk)** | 硬伤——库外废词条、必须神力缺失、缺陷超限 |

**缺陷词条**按流派定义：
- 会意流：会心率、精准率
- 会心大外流：势、精准率+会心率（非首同现）
- 会心小外流：势、精准率+会心率（非首同现）、小属攻
- 治疗纯奶：势+会心率
- 治疗火拳：势、精准率+会心率（非首同现）

**外功硬门槛**：会意/会心大外流非首必须有 1 条大外，小外流非首必须有 1 条小外，缺失即一般封顶。

## 通用会意 (huiyi_general)

| 属性 | 值 |
|------|-----|
| 核心攻击 | 大外 + 势 |
| 主武器 | 剑 |
| 副武器 | 枪 |
| 属性 | 鸣金 |
| 玩法 | 会意（单一） |
| 品阶覆盖 | 环额外放行紫色 |

**词条优先级**：大外 > 势 > 劲 > 会意率 > 大无相 > 大本属(鸣金) > 会心率

**词条池**（12 条）：对首领增伤、全武学增效、大外、势、劲、会意率、大无相、大本属(鸣金)、会心率、精准率、单体奇术增伤、对玩家增效

**各部位首词条**：

| 部位 | 首词条 |
|------|--------|
| 主武器 | 大外 |
| 副武器 | 大外 |
| 环 | 大外 |
| 冠胄 | 会意率 |
| 胫甲 | 劲 |

**缺陷判定**：会心率 + 精准率 ≥ 2 → 垃圾；非首缺大外 → 一般封顶

**支持的玩法**：

| 玩法名 | 主武器 | 副武器 | 属性 |
|--------|--------|--------|------|
| 纯唐 | 横刀 | 陌刀 | 裂石 |
| 双切 | 陌刀 | 横刀 | 裂石 |
| 威威 | 陌刀 | 枪 | 裂石 |

| 翊翊 | 舞绫鼓 | 扇 | 牵丝 |

**词条优先级**：小外 > 敏 > 大无相 > 大本属 > 会心率

**词条池**（14 条）：对首领增伤、全武学增效、小外、敏、会心率、大无相、大本属、精准率、小无相、小本属、小外属、单体奇术增伤、对玩家增效

**各部位首词条**：

| 部位 | 首词条 |
|------|--------|
| 主武器 | 小外 |
| 副武器 | 小外 |
| 环 | 小外 |
| 冠胄 | 会心率 / 精准率 |
| 胫甲 | 会心率 / 精准率 |

**缺陷判定**：小本属 + 小外属 ≥ 2 → 垃圾；会心率 + 精准率 同现 → 一般；非首缺小外 → 一般封顶

> 小外流词条池最宽（含小无相、小本属、小外属），判定也最复杂。

| 部位 | 首词条 |
|------|--------|
| 主武器 | 大外 |
| 副武器 | 大外 |
| 环 | 大外 |
| 冠胄 | 会心率 / 精准率 |

## 转律优先级

每个规则定义了转律优先级表，决定废词条被转律时的目标顺序。
转律时，废词条按优先级表从上到下依次尝试转为目标词条。

例如会心大外流的转律优先级：
1. 大外 → 2. 劲 → 3. 敏 → 4. 会心率 → 5. 小外 → 6. 大无相 → 7. 大本属

> 转律优先级决定了「最优策略模拟」——即使出现废词条，系统也会假设它被转律成优先级最高的可用词条后再判定。

---

## PVP 装备保留

所有规则均受「保留 PVP 装备」全局开关影响。开启后：
- 冠胄/胫甲等部位的垃圾条件中，对「单体奇术增伤」「对玩家增效」的判定会放宽
- 即：带 PVP 词条的装备不会被轻易判为垃圾
