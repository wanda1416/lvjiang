# v0.15.16 — 全局热键更可靠、菜单快捷键可改绑、批量任务可按用户跳过

这一版最直观的变化是**快捷键**：全局热键改由操作系统直接接管，带 Alt/Ctrl 的组合
也能稳定触发，最小化到托盘后热键唤回窗口不再失灵；菜单快捷键可以在「基础配置」里
自己改绑，改完立即生效。批量任务可以**按执行用户声明跳过**，任务列照旧生成，不用
再靠取消勾选来绕开某个号。毕业率数据补齐 **115 级**，并新增站点表格更新检查。

升级时场景与布局配置会自动迁移到新的目录化结构，**无需手工调整**，个人配置
（`config/local`、`config/session`）原样保留。

## ⚠️ 不兼容变动与升级指引

### 场景与布局配置拆分为目录化结构

- **现象：** 首次启动新版本时，`config/system` 里的场景/布局聚合索引会自动拆分为
  「分组/布局定义文件 + 同名子目录 + `_meta.json` 顺序」，日志出现
  「[迁移] 检测到旧聚合配置，开始拆分」。场景、布局的内容与顺序不变。
- **原因：** 聚合单文件已退役为目录化注册表，避免多份清单互相覆盖。
- **如何调整：** 无需操作，自动迁移。迁移失败时按日志提示处理后重试，不要手工半改；
  便携版用户请解压到新目录，再把 `config/local`、`config/session` 拷过去（保留新包的
  `baseline.json`）。

### 全局热键主键收窄到 F8~F12

- **现象：** 全局热键的主键只能选 F8~F12（可带 Alt/Ctrl/Shift）。此前绑在 F7 上的
  热键会回退为该动作的默认键位；Alt+A、Alt+F4 等系统组合不再允许绑定为热键或
  菜单快捷键。
- **原因：** 按键位按「谁用」分段：F1~F4 归通用菜单、F5~F7 归插件菜单、F8~F12 归
  系统级全局热键，避免菜单与全局热键抢同一个键。
- **如何调整：** 若原来用的是 F7，请到「配置管理 → 热键设置」重新选一个 F8~F12 的
  键位；其余无需操作。

### 「自动剧情」入口移到「燕云」菜单

- **现象：** 原来在「工具 → 自动剧情」，现在在「燕云 → 自动剧情」；文案库自动迁移到
  插件自己的目录。
- **原因：** 自动剧情是燕云专属能力，改为独立插件随「燕云」一起提供。
- **如何调整：** 无需操作，旧文案库启动时自动迁移；用 `--all` 或设备端默认名册运行
  时两个插件都已包含；自定义只加载部分插件的启动方式，需要同时带上 `yysls` 和
  `yysls_story`。

## ✨ 新增功能

- **菜单快捷键可以改绑。** 「基础配置」新增菜单快捷键设置，燕云等菜单的快捷键改完
  立即生效，不用重启。
- **全局热键统一走系统注册。** 带 Alt/Ctrl/Shift 的组合可靠触发（例如暂停/恢复不再
  偶尔互相抵消、按一次触发两次）；最小化到托盘后，热键唤回窗口的兜底通道更稳。
- **批量任务可按用户声明跳过。** 可以指定某些执行用户跳过某个任务，任务列照旧生成，
  进度与结果不受影响。
- **任务参数页可与全局参数对照。** 给某个用户设独立参数时，能同时看到全局值，方便
  核对差异。
- **备注编辑冲突保护。** 其他设备或实例刚写过的备注，本机编辑保存时会提示而不是
  静默覆盖。
- **毕业率更新。** 新增 115 级毕业率数据；支持检查站点表格是否有更新。
- **只读实例也能管账户。** 第二开的只读实例可以打开账户页并手动「立即同步」。
- **自写脚本增强。** 内置函数补齐字符串与正则处理；需要无上限条件循环的脚本可在
  元数据声明 `requires: [unbounded_loops]`（未声明的脚本维持原有护栏不变）。

## 🔧 修复

- **授权被停用后不再「一票否决到永远」。** 停用结论改为每次启动在线复核，授权恢复
  后软件自动回到可用状态，不需要手动处理。
- **恢复登录态后立即同步一轮**，不再干等一个节拍才刷新。
- **总览数值同秒内的多次变动不再随机乱序**，按实际到达顺序记账。
- **手动重算（regen）固化不再依赖同步状态**，总览账本每行保持「新值 = 旧值 + 增量」
  可核对。
- **总览列宽不再随设备缩放折算**，换设备后列宽保持稳定。
- **总览历史筛选弹层可以输入中文**，聚合候选默认显示 20 项。
- **批量轮次边界整轮复位为未执行**，待执行按条目推进，上一轮的残留状态不会混进
  新一轮。
- **下载排版不再多创建备份目录。**
- **每日江湖号令把「多人模式保持」提到「合影」之前**，执行顺序恢复正常。
- **每轮都 `continue` 的条件循环不再绕过次数上限**变成真正的死循环。
