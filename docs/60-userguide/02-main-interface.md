# 2. 主界面与用户管理

## 2.1 主窗口布局

启动后主窗口分为四个区域：

```
┌─────────────────────────────────────────────┐
│  顶部菜单 + 设备/窗口选择区                    │
├──────────────┬──────────────────────────────┤
│              │                              │
│  左侧 Tab    │  右侧 Tab                     │
│  · 日常      │  · 运行日志                    │
│  · 批量      │  · 装备状态（插件注入）          │
│  · 调律      │                              │
│  （插件 Tab） │                              │
│              │                              │
└──────────────┴──────────────────────────────┘
```

### 顶部菜单

| 菜单 | 主要入口 |
|------|---------|
| 通用 | 配置管理、用户管理 (F2)、场景管理 (F3)、图库管理 (F4) |
| 工具 | 图像识别、脚本录制、脚本编辑、脚本配置、批量配置 |
| 燕云 | 游戏配置 (F5)、调律配置 (F6) |

### 顶部设备/窗口选择区

从左到右：
1. **当前用户** 下拉框 — 切换当前激活用户（详见 2.2）
2. **当前布局** 下拉框 — 切换布局配置（如「默认布局」）
3. **窗口/设备选择组** — 扫描窗口 / 扫描设备 / 目标下拉 / 定位·连接按钮 / 显示预览

### 全局热键

| 热键 | 功能 |
|------|------|
| F9 | 开始执行（当前 Tab 的自动化任务） |
| F10 | 停止执行（等待中也能立即打断） |
| F8 | 脚本录制（须先完成定位/连接） |
| F7 | 脚本编辑（新建 / 修改 / 删除 .wf 脚本） |
| F2 | 用户管理 |
| F3 | 场景管理 |
| F4 | 图库管理 |
| F5 | 游戏配置 |
| F6 | 调律配置 |

## 2.2 用户管理（F2）

律匠支持多用户，每个用户有独立的会话数据（session）和调律产出记录。

### 打开方式

「通用 → 用户管理」或按 **F2**。

### 操作说明

| 操作 | 说明 |
|------|------|
| 创建用户 | 输入用户名，点「创建」。首次启动自动创建「默认用户」 |
| 删除用户 | 选中用户后点「删除」，确认后清除该用户所有数据（不可恢复） |
| 切换激活 | 在列表中选中用户，点「激活」或双击。顶部「当前用户」下拉框同步切换 |
| 调整顺序 | 使用上移/下移按钮调整用户列表顺序 |

### 用户与批量任务

在批量任务中，可以通过「用户名列」指定条目表中哪一列的值作为角色名，
执行时会自动切换到对应用户的 session。详见 [3.4 批量任务](03.04-batch-tasks.md)。

### Profile 数据

每个用户有独立的 Profile 数据，记录游戏内的角色信息：

| 数据 | 来源 |
|------|------|
| 货币（通宝、么玉、宝钱、长鸣玉） | 扫描钱袋工作流写入 |
| 不肝进度 | 扫描钱袋工作流写入 |
| 调律产出记录 | 自动调律工作流写入 |

Profile 数据随用户切换自动加载，不同用户之间完全隔离。部分工作流（如扫描钱袋）会更新 Profile 中的数值，可在装备状态 Tab 的 Profile 页查看。

## 2.3 布局切换

顶部「当前布局」下拉框可切换不同的布局配置。布局定义了各场景的坐标区域
（如背包页、调律页等），不同分辨率/窗口比例可能需要不同布局。

- 默认提供「默认布局」，覆盖主流分辨率
- 如需自定义，可在场景管理器 (F3) 中编辑当前布局下的场景坐标
