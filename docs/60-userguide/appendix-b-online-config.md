# 附录 B. 官方在线配置与会员内容

> 适用：0.15.0 开发及预发布客户端；尚未正式发布。旧客户端按对应版本发布说明操作。

## 获取与生效

开启设置中的“接收在线配置更新”后，PC 在启动检查中获取与应用版本匹配的官方更新。
只比较修订号：远端最新修订与本机记录相同就不下载、不改动；不同才下载该修订并应用。
场景、布局、默认规则及已有任务都可以在线修正；应用成功后立即生效，无须重启。
正在执行的任务（包括一整批任务）使用启动时的配置，新任务使用更新后的内容。
网络失败保留当前可用内容，不影响启动。

自己的本地覆盖始终优先；若官方修正没有改变某项设置，先检查对应本地覆盖。
更新不会删除用户设置和数据库。已打开的编辑窗口保存时可能提示配置已变化，
请核对差异后再决定是否覆盖，不要将旧草稿直接当作最新官方配置。

## 本地激活与在线会员授权

有效 Lv1 及以上授权可获取作者发布的会员配置，服务地址内置，无需填写地址或 Token。
激活方法见[附录 C 功能激活与恢复](appendix-c-activation.md)。已有激活码无需因更新机制而更换，
但需要签发者已将其登记到内容服务；未达到等级不会请求会员服务。

“功能激活”分别显示本地激活和在线会员授权。本地已激活不代表云端允许下载会员内容；
在线状态由后台检查更新，未检查或检查失败不能视为通过。
未登记、过期或云端停用时，请联系签发者核对。临时断网保留已安装且本机授权有效的内容，
云端停用需联网后才能确认。

会员包按客户端版本范围选择，与公开修订各自比较修订号：远端会员修订比本机记录新就拉取并合并，
索引撤销或不再有适用包时撤下会员内容。会员包不再要求与某个公开修订对齐。
安装成功不等于所有业务资源都可用；具体脚本或地图有误时，由对应功能报告。

## 关闭、撤销与手机同步

关闭“接收在线配置更新”或进入完全离线模式，会恢复官方预置并撤下会员内容，
不删除本地覆盖、用户数据或数据库；恢复失败会保留完整旧配置并记录原因。
重新打开后再次检查在线内容。设置页显示的是已安装的公开修订。

发布者撤销更新后，下次成功检查会从 r0 重建并换成索引当前指向的较早修订；索引不再包含本系列时
回到预置。断网或下载失败不会被当成撤销。
手机本阶段不自行在线更新，使用 APK 预置或 PC 同步结果，见[移动设备](07-mobile-device.md)。

## 需要人工恢复时

先关闭所有律匠实例并备份配置。仅在确需修复安装目录时，将当前版本的
`config/updates/vX.Y.Z/r0.zip` 解压到 `config/system`；ZIP 根目录就是配置文件，
不要再套一层 system。测试包使用完整版本目录，例如 `v0.15.0b1`，不能与正式版混用。
保留 `config/session/baseline.json` 和 local，不要删除全部配置，也不要用其他版本的预置恢复。

已被在线更新的 system 不能用于重建丢失的原始 r0；缺少可信预置时应恢复配套安装包，
不要自行伪造基底。若要持续使用预置，先关闭在线更新；人工恢复预置不会恢复会员内容。
配置格式升级与手工调整见[附录 A 配置升级调整](appendix-a-config-upgrade.md)。
