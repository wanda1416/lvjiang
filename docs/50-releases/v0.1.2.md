# v0.1.2 — 调律规则增强 + DSL subcall 架构 + 自动更新检查

## 律匠 v0.1.2

本版本聚焦调律规则系统的语义增强、DSL 工作流 subcall 架构升级、以及用户体验优化。

---

### ✨ 新增功能

**调律规则系统**
- 新增自选词条判定语义（`judge_scope: affix`）：按装备词条名匹配规则，支持弹窗勾选词条
- 判定结果词条改为弹窗多选方式（`_AffixEntriesButton` + `_AffixEntriesDialog`），替代下拉菜单
- 新增武器跳过规则：支持按部位配置跳过特定武器
- 装备回收锁定检测：回收确认弹窗无「确认」字样时判定装备锁定，自动关闭弹窗避免卡死
- 品阶精确匹配：新增 `purple_only` / `gold_only` 精确品阶档位（区别于阈值语义）

**自动更新检查**
- 启动时自动检查最新版本
- 支持跳过指定版本功能

**场景编辑器**
- 支持 region / point / panel key 重命名
- 场景 key 拼音化重命名（游戏术语用拼音，通用 UI 术语用英文）

---

### 🔧 修复

- 批处理账号切换逻辑改进：使用 `role` 字段而非 `account`
- DSL 语法允许块语句内空行
- 修复 `QUALITY_RANK` 共享污染：狗粮规则校验改用独立 `_VALID_FOOD_QUALITIES`
- 修复基础配置页测试适配新默认值

---

### 📦 重构

**DSL subcall 架构**
- DSL subcall 桥接引擎能力：导航逻辑迁移至 DSL subcall
- `equip_analysis.wf` 改用 subcall 与局部收集模式
- 导航 subcall 统一收口：`nav_main_to_equip` / `nav_equip_to_tune` / `nav_back_to_main`

**调律规则编辑器**
- 列顺序与命名优化
- 调律门槛配置移至基础配置页

**工作流重构**
- 江湖号令工作流重构与场景配置更新
- `ConfigResolver` dev_mode 构造时缓存
