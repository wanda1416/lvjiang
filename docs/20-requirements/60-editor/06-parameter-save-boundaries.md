# 日常参数保存边界与连续输入合并

- 日常参数保存只更新当前编辑对象的修改字段，不扫描脚本，不隐式删除其他
  任务配置。脚本刷新也不自动清理参数，临时解析失败不等于脚本被删除。
- 文本连续输入用 GUI 单次计时器合并，约 250ms 保存；显隐依赖即时更新。
  勾选、下拉选择即时保存；数字键盘编辑不逐个保存中间数字。
- 切换脚本、用户、参数来源、环境、执行目标，筛选、刷新、加载、查看全部
  用户参数及正常退出前保存旧面板。日常与批量的参数快照必须在保存后构建。
- 编辑归属固定在面板构建时的脚本、参数来源和用户，不在计时器触发时按
  当前活动选择猜测。合并只更新实际修改的字段，不回写其他字段的旧副本。
- 临时外部脚本参数只保存在该临时项内存中；切换、筛选、刷新保留，加载
  新临时项时替换，不写入共享或用户参数配置。
- 复用既有原子更新能力，不引入后台保存线程、全局配置缓存或格式迁移。
- 保存失败保留修改，批量不得继续启动；运行快照的只读展示不作为新编辑，
  任务结束或退出时不得将历史参数覆盖回最新配置。

回归覆盖连续输入合并、立即启动批量读到最新值、切换不串写、字段合并不
覆盖其他更新、错误脚本配置不被清理以及临时脚本参数往返。
