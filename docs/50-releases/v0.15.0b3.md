# v0.15.0b3 — 一次性激活与设备连接恢复（Beta3）

本版本是 0.15.0 的第三个测试包，供手动下载测试，不替换当前正式版 0.13.15，
不向普通客户端提示更新。相对正式版的完整升级注意事项见 [Beta1 说明](v0.15.0b1.md)。

## ⚠️ 不兼容变动与升级指引

- **MCP 接入需要重新启用。** 接入参数改为随客户端保存在 config/session/mcp.json，
  原用户主目录中的接入记录不再读取。已使用智能调律 Agent 的用户，请在
  “燕云 → 智能调律”中重新启用 MCP 服务并同步外部 Agent 配置；如改过端口，请重新填写。
  后续移动客户端时保留 config/session，即可保留接入参数。
- **一次性码首次激活必须联网。** 有效期从首次绑定成功开始计算，旧客户端不支持这种码。
  请升级 PC 客户端，在“配置管理 → 功能激活”粘贴码并激活；完全离线模式需先关闭。
  原预绑定和免绑定码继续有效，无需重发。Android 尚未提供首次在线激活入口，沿用现有离线配置快照。
- PC 与 APK 测试同步时请同时升级到 0.15.0b3，先核对单向覆盖提示。
  配置包仍按 0.15.0 系列匹配，Beta3 的更新状态独立位于 updates/v0.15.0b3；
  不要复制 Beta2 的更新状态，重新同步即可，local/session 无需删除。
- Windows 便携包请解压到新目录，再复制 config/local 和 config/session；安装器及 APK 保留用户数据。

## ✨ 新增功能

- PC 支持一次性激活码：首次在线激活后绑定本机并显示到期时间，同机重新激活可恢复原授权，
  不延长有效期；已绑定其他设备的码会明确提示。首次成功后，未到期的授权可离线使用。
- 会员包获取使用服务器签名状态证明，停用或到期后撤销对应授权；普通网络失败保留既有有效授权。
  损坏的本地激活记录可通过“清除激活”后在原设备重新联网恢复。
- “配置管理 → 高级设置”可调整 Android 代理及 ADB 重连次数、间隔和是否允许普通输入降级到 ADB。
  重试后仍未恢复会等待用户选择继续检查或停止对应任务，主界面仍可操作其他目标。
- MCP 接入状态随客户端保存，移动客户端时不再依赖原安装路径对应的用户主目录记录。
