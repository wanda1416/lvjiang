# 4.1 调律配置 — 页面结构

入口：「燕云 → 调律配置」或按 **F6**。

这是调律行为的核心配置，决定了哪些装备进调律、怎么判定好坏、调律后怎么处理。

> 本对话框**没有保存按钮**：任何改动即时校验，校验通过自动保存生效；
> 校验不通过会提示错误并拒绝保存。

---

## 界面布局

对话框左侧为一级导航，右侧为对应的配置内容区：

```
┌──────────────┬──────────────────────────────┐
│  基础配置     │                              │
│  扫描处理     │    （右侧内容区）              │
│  材料处理     │                              │
│  结束处理     │                              │
│  ─────────   │                              │
│  规则A        │                              │
│  规则B        │                              │
│  规则C        │                              │
│              │                              │
│ [＋ 新增规则] │                              │
│ [装备调律验证] │                              │
├──────────────┴──────────────────────────────┤
│  状态栏：校验结果 / 最后保存时间                │
└─────────────────────────────────────────────┘
```

导航分为两组：

| 区域 | 包含项 | 说明 |
|------|--------|------|
| **全局配置**（上方 4 项） | 基础配置、扫描处理、材料处理、结束处理 | 控制调律的整体行为 |
| **调律规则**（分割线以下） | 每个规则一项 | 定义各流派的评判标准 |

---

## 调律规则内部结构

点击分割线以下的任一规则，右侧显示该规则的**二级导航**（共 9 项）：

```
规则设置        ← 流派、玩法等基础设定
词条库设置      ← 该规则可用的词条池
通用判定        ← 跨部位的通用判定条件
───────────     ← 分割线
主武器          ← 主武器各词条评级
副武器          ← 副武器各词条评级
环 · 佩         ← 环和佩的词条评级
冠胄 · 胸甲     ← 冠胄和胸甲的词条评级
胫甲 · 腕甲     ← 胫甲和腕甲的词条评级
```

### 规则设置

| 配置项 | 说明 |
|--------|------|
| 流派 | 该规则适用的武器流派 |
| 玩法 | 可选多个玩法，调律 Tab 中按规则勾选玩法 |
| 品阶门槛（覆盖） | 可选，按部位覆盖全局默认品阶门槛 |

### 词条库设置

定义该规则可用的词条池。词条池决定了扫描处理、结束处理中「传入规则」判定能看到哪些词条，也是各部位评级页的候选来源。

### 通用判定

跨部位的通用判定条件（如通用垃圾条件、通用一般条件等）。

### 各部位评级页（5 个）

每个部位页独立配置该部位下各词条的评级模式。评级结果直接影响扫描处理和结束处理的判定。

---

## 规则管理

### 新增规则

点左下 **「＋ 新增规则」**，弹出对话框：

| 字段 | 要求 |
|------|------|
| 标识 key | 小写英文标识（字母开头，可含数字/下划线），作文件名 |
| 规则名称 | 中文显示名（如「治疗-纯奶」） |

### 重命名规则

在左侧导航中**双击**规则项，弹出重命名对话框。注意：全局配置页（基础配置等）不可改名。

### 删除规则

在规则内部的「规则设置」页底部有删除按钮。删除后不可恢复。

---

## 装备调律验证

左下 **「装备调律验证」** 按钮打开判定测试对话框。

功能：手动输入装备词条，验证当前规则的判定结果。

> 调规则时建议先在这里验证，确认判定逻辑符合预期后再实际运行。
