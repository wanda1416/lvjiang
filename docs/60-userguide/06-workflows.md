# 6. 工作流与日常任务

日常 Tab 是运行工作流的主入口：选择脚本 → 配置参数 → 执行。

---

## 7.1 日常 Tab 布局

```
┌──────────────────────────────────────┐
│  [开始执行 (F9)]  [暂停]              │
├──────────────────────────────────────┤
│  脚本：[▼ 下拉选择] [加载]            │
├──────────────────────────────────────┤
│  说明：运行前请确认……                 │
├──────────────────────────────────────┤
│  参数设置                             │
│    参数1：[____]                      │
│    参数2：[☑]                         │
│    ...                                │
└──────────────────────────────────────┘
```

| 区域 | 说明 |
|------|------|
| 开始执行 (F9) | 启动当前选中脚本；运行中变为「停止 (F10)」 |
| 暂停 | 运行中可暂停；暂停后变为「恢复」 |
| 脚本下拉 | 列出当前展示的脚本（在「工具 → 脚本配置」里勾选、排序、改名） |
| 加载 | 切换脚本并加载其参数面板 |
| 说明 | 显示脚本 `#% note` 元数据；内容按左侧 Tab 宽度自动换行 |
| 参数设置 | 根据选中脚本动态生成；不同脚本参数不同 |

脚本可用单行或 YAML 多行文本声明说明。较长说明推荐主动分行，界面还会
根据左侧 Tab 的实际宽度继续自动换行：

```text
#% note: |-
#%   请先进入目标页面，确认出现操作按钮
#%   再开始执行脚本。
```

> 脚本列表与顺序通过「工具 → 脚本配置」管理，可控制每个脚本是否在日常下拉中暴露、显示名和排序。

可直接启动的普通脚本放在 `workflows/` 顶层；依赖用户先手动到达指定位置、
不适合串联批量执行的独立脚本放在 `workflows/standalone/`。两个目录都会被
脚本发现层注册，但 `standalone/` 脚本不会进入批量页候选；`subcall/`、
`batch/`、`archived/` 等内部目录不会注册。

---

## 7.2 运行控制

| 操作 | 热键 | 说明 |
|------|------|------|
| 开始 / 停止 | F9 / F10 | 启动当前脚本；运行中按 F10 停止（当前步骤完成后退出） |
| 暂停 / 恢复 | F11 | 运行中按 F11 或点击「暂停」，脚本在当前语句执行后挂起；再次操作则继续 |

暂停期间：
- 按钮文字切换为「恢复」
- 脚本不执行任何操作，但保持运行上下文
- 可以安全查看日志或切换窗口

停止后：
- 脚本完全退出，上下文清空
- 按钮恢复为「开始执行 (F9)」

## 7.3 工作流清单

以下为日常 Tab 中可用的全部工作流。每个工作流列出一句话说明、参数和前置条件（游戏需要停在哪个页面）。

### 每日江湖号令

刷新并执行江湖号令任务（换装、合影、情境、看报、醉意）。

| 参数 | 说明 | 默认 |
|------|------|------|
| 单任务最大刷新次数 | 单个 label 未命中目标任务时最多刷新几次 | 50 |
| 领取奖励 | 每个任务完成后点击标签领取奖励 | 否 |

**前置**：停在江湖号令活动页或游戏首页（自动识别）。

### 每日自动签到

自动完成每日签到流程（当前支持朝夕共赏等活动）。

**前置**：停在游戏首页。

### 自动购买不肝

进入包裹 → 钱袋 → 购买不肝进度。

| 参数 | 说明 | 默认 |
|------|------|------|
| 战斗养成购买项 | 逐项勾选要买的类目（心法/武学/奇术/振玉/生活/宝钱/短陌钱） | 全选 |
| 购买营生 | 是否购买营生类目 | 是 |

赛季类目始终全买，不做成参数。

**前置**：停在游戏首页。

### 自动购买心法

可先打开背包普通道具中的全部心法心得，再进入商店购买心法。

| 参数 | 说明 | 默认 |
|------|------|------|
| 打开背包全部心法 | 扫描当前背包页及向上滚动一次后的普通道具，依次打开所有“心法心得” | 否 |

**前置**：停在游戏首页。

### 扫描备战装备

扫描当前已穿戴的八件装备，并写入任务启动时绑定的备战方案。

**前置**：停在游戏首页；先选择正确用户和目标备战方案。

| 参数 | 无 |
|------|---|

### 扫描全部装备

按所选部位扫描背包装备，解析后写入当前用户的公共装备池。支持最低等级截止，主副武器共享武器背包且只扫描一次。

**前置**：停在游戏首页；先选择正确用户。

| 参数 | 说明 | 默认 |
|------|------|------|
| 扫描部位 | 武器、环、佩、冠胄、胸甲、胫甲、腕甲，可多选 | 全部 |
| 装备最小等级 | 低于该等级时结束当前部位的有序扫描 | 110 |

装备数据的产生、去重和核对方法见[5.2 装备数据如何产生](05.02-equipment-data-acquisition.md)。

### 扫描钱袋货币

进入包裹 → 钱袋，识别各货币数量并写入 Profile。支持容差校验，防止异常值覆盖。

| 参数 | 说明 | 默认 |
|------|------|------|
| 通宝允许差值(万) | 新值与旧值差超过此值则跳过写入 | 0（不限制） |
| 么玉允许差值 | 同上 | 0 |
| 宝钱允许差值(万) | 同上 | 0 |
| 长鸣玉允许差值 | 同上 | 0 |

**前置**：停在游戏首页。

### 太极炸鱼

自动执行炸鱼循环操作。

| 参数 | 说明 | 默认 |
|------|------|------|
| 最大循环次数 | 最多执行几轮 | 500 |

**前置**：停在炸鱼活动入口。

## 7.4 专用脚本

部分脚本标记为「专用」（`scope: dedicated`），不在日常 Tab 管理参数，而是由专属页面控制：

| 脚本 | 专属入口 | 说明 |
|------|----------|------|
| 自动调律 | 左侧「调律」Tab | 参数在调律 Tab 三页中配置，见 [运行自动调律](04.06-running-tuning.md) |

专用脚本仍可通过批量 Tab 执行（勾选脚本后批量运行）。

---

## 7.5 脚本配置管理

入口：「工具 → 脚本配置」。

| 配置项 | 说明 |
|--------|------|
| 暴露 | 勾选后在日常下拉中显示 |
| 显示名 | 下拉中显示的名称（覆盖默认） |
| 脚本性质 | `日常` = 日常 Tab 管理参数；`专用` = 专属页面管理 |
| 排序 | 调整下拉中的先后顺序 |

> 修改后立即生效，下次打开日常 Tab 下拉即可看到变化。

## 7.6 查看任务历史

入口：「工具 → 任务历史」。日常任务和自动调律等专用任务都会记录，分为两个页面：

- 「任务历史」可按多个用户、多个任务和日期范围组合筛选；选择记录后可查看输入参数、
  开始/结束时间、耗时、状态，并直接打开结果 JSON 和该次执行的独立日志；
- 「批量历史」记录整批任务的配置和输入快照。选择一批后点「查看全部单任务」，可查看
  该批次下每个用户、每个脚本对应的单独执行记录。

每次单任务都有唯一的「任务记录 ID」，每次批量执行另有唯一的「批量记录 ID」。批量中的
单任务同时携带这两个 ID；单独运行的任务没有批量记录 ID。

## 7.7 脚本工作台（新建 / 修改 / 选指令 / 取点取色 / 单步调试）

入口：「工具 → 脚本编辑」（不设键盘快捷键）。三栏：左侧全部 `.wf` 脚本（标注 `[system]` 系统 / `[local]` 本地），
中间带语法高亮的编辑区，右侧「指令」「调试」两个 Tab。

### 指令：不记语法，像快捷指令一样选操作

「指令」Tab 列出全部可用操作，按 交互 / 感知 / 图色 / 控制流 / 数据与输出 分组，顶部可搜索
（中文名或英文指令名都行）。选中一个后下方出现它的槽位表单：

| 槽位类型 | 怎么填 |
|---------|--------|
| 场景 / 区域 | 下拉（区域下拉随场景变，含区域 / 坐标点 / 面板） |
| 延迟 | 下拉：配置管理里的命名等待参数 |
| 模板 | 下拉：`config/system/templates/` 里的图 |
| 坐标 / 区域 / 颜色 | 点「取画布」用调试画布最近一次取点 / 框选的值（画布已有值时自动预填） |
| 文字 / 变量 / 数值 | 直接输入（文字自动加引号，变量自动补 `$`） |

带 `*` 的必填，其余留空就不出现（例如「操作后等待」留空就没有 `after wait`）。
预览区实时显示生成的语句，缺必填项会标红说明；「插入到脚本」落到编辑区光标处
（光标行已有内容时自动另起一行，并沿用当前缩进；`if` / `loop` 这类块会带好 `end`，光标停在块内）。

### 画布：截图上取坐标 / 取色 / 框区域

先在主窗口定位窗口或连接设备，再点「刷新截图」。画布按当前布局的 canvas 裁过，
取到的就是脚本里直接能用的归一化坐标：

| 操作 | 效果 |
|------|------|
| 鼠标移动 | 底部实时显示 `x= y= rgb=#…` |
| 左键点一下 | 取点 + 取色 → 「插入坐标」写 `(x, y)`、「插入颜色」写 `"#rrggbb"` |
| 左键拖框（可拖角调整） | 取区域 → 「插入区域」写 `(x, y, w, h)` |
| 右键拖 / 滚轮 | 平移 / 缩放 |

插入的 `(x, y, w, h)` 赋给变量后就是一个矩形坐标，可 `click $r`，也可喂 `color_ratio($r, …)`、
`find_icons($r, …)` 等图色函数；`(x, y)` 同样可直接喂 `pixel($p)` / `bright($p)`。

### 运行与单步

| 按钮 | 作用 |
|------|------|
| 运行 | 把编辑区内容存成临时脚本 `_editor_run.wf` 后在后台线程执行 |
| 单步 | 未运行时：以单步模式启动，停在第 1 条语句前；运行中：执行当前高亮行，停在下一条 |
| 继续 | 退出单步，跑到结束 |
| 暂停 | 在下一条语句前停住（不打断正在执行的动作） |
| 停止 | 立即结束（包括停在断点上的脚本） |

执行到哪一行，编辑区就高亮哪一行；变量表每条语句前刷新一次，日志区显示本次运行的引擎日志。
运行期间编辑区只读（改了行号，高亮就对不上）。运行环境（截图、输入、OCR、布局、用户）
与日常页执行完全相同。

| 按钮 | 作用 |
|------|------|
| 新建 | 输入脚本 id（即文件名）和显示名，生成带 `#% name` / `#% env` 头的模板；新脚本自动加入日常下拉 |
| 保存 | 写回当前脚本，随后自动做语法 + 当前布局引用校验，结果显示在底部 |
| 另存为 | 以新 id 复制一份 |
| 删除 | 删除当前脚本 |
| 检查 | 只做语法检查，不需要保存 |

> 改动写在 `config/local/workflows/`，不会动系统文件。**系统脚本不可删除**，
> 删除按钮对它们是灰的；不想在日常页看到某个脚本，请在「工具 → 脚本配置」
> 里取消勾选。你自己新建的脚本可以随时删除。
> 脚本 id 不能以 `_` 开头——`_` 前缀文件被当作临时脚本，不会出现在列表里。
