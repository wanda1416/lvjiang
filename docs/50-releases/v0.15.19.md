# v0.15.19 — 袅袅之音清单、设备 ID 自助找回与主页图标重标定

这一版的主线是「袅袅之音」常驻来源清单：把 107 条常驻来源逐条记下来、可选写进总览账本，
并且能自己增删改、分类、拖动排序、批量绑定。另外补上设备 ID 自助找回、把主页图标区域
按「图标 / 小地图」两种语义拆开重标定。**升级需要动手的只有主页区域的本地覆盖（第 1 条）**，
其余为新增能力或无需操作。

## ⚠️ 不兼容变动与升级指引

### 1. 主页「地图」区域拆分：`ditu` 只作地图图标，实时小地图独立为 `ditu_mini`

- **现象：** 主页图标区域的几何与模板整体换了位置和尺寸；`ditu` 现在只承担「点它/按 M 打开
  地图」的坐标与按键，不再作为识别依据；桌面端那块实时小地图拆到新区域 `ditu_mini`；
  组队区域不再绑定模板。如果你在本机改过主页的场景或布局，界面里显示的还是旧框，
  与新模板错位。
- **原因：** 同一个 `ditu` 在安卓指入口图标（可做模板匹配）、在桌面指实时小地图（随账号与
  地图变化，必然匹配不上），一个 key 两种语义让静态检查与页面判定说不清。另外安卓那份
  `ditu` 模板把记录分辨率写成了旧设备的 2048×920，匹配器会把图放大 1.367× 再比对，
  实测分数 0.534（低于阈值 0.8），图标兜底通道实际是失效的。
- **如何调整：** 没改过主页区域 → 无需操作（安装器与 APK 会整目录替换 `config/system`）。
  改过 → 删掉 `config/local` 里对应的 `game_main_page` 场景或布局覆盖，或在编辑器里按新框
  重画一遍；否则新模板落在旧框里仍会匹配失败。自定义脚本里引用 `game_main_page.ditu`
  照常可用，只是它已不含模板；要按图找小地图请改用 `ditu_mini`。

### 2. 安卓无障碍与前台服务的名称、说明文案中性化

- **现象：** 系统无障碍设置里这个服务显示为「律匠辅助」，说明是「辅助完成屏幕上的点击与
  滑动操作。」；前台通知的服务类型说明里不再出现「游戏辅助自动化」「调律」。
- **原因：** 服务的 label 与 description 会展示在系统无障碍设置页，任何应用也能通过系统
  接口读到，原文等于明文自述自动化用途。
- **如何调整：** 无需操作。若你按旧名字在系统设置里找这个开关，请找「律匠辅助」。

### 3. 周期型清单条目要用你自己 profile 里的配额 key

- **现象：** 新增的周期条目（觉障林·无我 单排/双排/五排、逐战商店、百珍商店、不肝商店、
  地华商店）「已得」显示 0，勾了也不写账，日志里有一条「入账目标 … 不在定义里，本次只记录」。
- **原因：** 这些条目按「配额 key 本周期当前值」读值，而 key 属于你个人总览定义
  （`config/session/profile.yaml`），不随包下发——包里带 key 会把变量值当常量。
- **如何调整：** 在「用户总览」里补出对应配额 key。本版用到的 key 与周期：
  `nn_juezhang_of_halfseason`（半赛季，上限 3）、`nn_of_halfseason`（半赛季）、
  `niaoniao_of_week`（周）、`nn_bugan_of_week`（周）、`dihua_of_month`（月）。
  缺 key 时条目仍可记录，只是不入账；补齐后重新勾一次即可补写。

### 4. 调律「重置最小等待」独立成配置项，二次确认标签改名

- **现象：** 游戏配置 → 基础配置 → 调律设置里多了一项「重置最小等待时间」（0–60 秒，
  缺省 3 秒）；原来的「二次确认等待（包括装备冷却）」改成「二次确认等待」，区间不变。
- **原因：** 游戏重置冷却与等待弹窗渲染原先挤在同一段固定区间里，游戏缩短冷却时只能整段改。
- **如何调整：** 无需操作，缺省值沿用旧行为。若你在 `config/local` 覆盖过 `app.yaml`
  的这段标签文案，删掉覆盖才会看到新文案。

### 5. 「袅袅之音」清单是新增功能，不涉及历史数据迁移

- **现象：** 菜单「燕云 → 袅袅之音」是新入口，记录写在 `config/session/users/<用户名>.linger.json`
  并随账号同步。旧版「以武会友」笔记（`ywhy_<地区>`）原样保留，不会被读取也不会被删除。
- **原因：** 清单功能在本版首次发布，之前的开发期结构改动没有对外数据。
- **如何调整：** 无需操作。以武会友的旧笔记如需并入清单，请在页面里按位勾选一次。

## ⚠️ 已知限制

- **清单编辑器里「记法」下拉仍与配额 key 是否存在耦合。** 只有当前 profile 里存在配额 key 时，
  编辑器才会给出「周期」这一项；没有配额 key 时选不到「周期」记法。
- **编辑器遇到不认识的记法值时会把它临时显示成「固定」。**
- 以上两条只影响编辑器的可选项与显示，不改变已保存的 `kind` / `target`，也不影响记录与入账
  数据；后续版本会随语义调整一并收拾。
- **数据记录能力仍在调整期。** 清单的记法与入账目标语义、条目字段与记录文件结构后续仍会
  继续调整，**本版不承诺这部分配置与记录文件格式长期稳定**。升级前建议备份
  `config/local/yysls/lingering.yaml` 与 `config/session/users/<用户名>.linger.json`。

## ✨ 新增功能

- **袅袅之音清单。** 菜单「燕云 → 袅袅之音」打开核对页：左栏按地区显示进度，右侧逐条列出
  地区 / 类型 / 条目 / 枚数 / 已得 / 记法 / 详情 / 更新时间，勾选即记录、修改即落盘。
  随包 9 个地区共 107 条、224 枚（常驻 214 枚 + 周期 10 枚），常驻分母与地区进度只统计
  非周期条目。
- **清单可在页面里维护。** 条目新增 / 编辑 / 删除、分类改名与清除、拖动排序、多选批量绑定；
  改动写 `config/local/yysls/lingering.yaml`（与 system 同名同结构、优先级更高），只存被改的
  条目，system 升级新增的条目照常出现。删除内置条目是打隐藏标记，历史记录保留。
- **记法与入账目标解耦、顶部同步模型可配置。** 记法（固定 / 逐位 / 周期声明）与入账目标
  （库存 key / 配额 key / 不同步）是两个独立决定；周期形态只看目标是否为配额 key。
  顶部「同步模型」从 30 多项库存下拉改成「按钮 + 配置对话框」：勾选哪些 key 进候选、设置
  默认目标；条目可显式绑定，也可「跟随同步模型」，「不同步」表示只记录不写账。
- **逐位条目内置对手名单。** 以武会友、四海豪客这类逐位条目把位名提升为项目级数据，
  每位直接显示名字，不必每个用户重复录入；只有游戏里改了名才需要手动改，改动只存用户层。
- **可选「同步记账」。** 按用户记录、默认关闭：关闭时勾选只写记录；打开后按差额写进总览账本
  （库存目标不触发同步，避免误扣八音窍累计），账本写失败会留在「待入账」。
- **设备 ID 自助找回。** 安卓设置页账户卡新增设备 ID 区块（32 位值单独成行、可就地复制）、
  「设备」行显示在线/总数并可查看每台设备明细；PC 账户管理未登录时顶部显示当前设备 ID
  与复制按钮，登录后改为「设备管理」行内「复制 ID」。忘了密码时这是管理员重置前唯一能
  核对的凭据。
- **调律「重置最小等待」改为配置项**（见升级指引第 4 条）。
- **自助服务提示语补「修改密码」**，与实际支持的操作对齐。

## 🔧 修复

- **安卓批量任务会被另一端的占位区域挡下。** 批量检查的布局引用校验漏传运行环境，按
  「环境未知」把桌面分支里只摆坐标、没绑模板的区域也算进去，于是安卓批量里整条任务被判成
  不可执行（`page_detection.wf:53 [game_main_page].[dongzuo] — 区域未绑定模板`）。现在检查与
  执行用同一套本端判据；环境未知时仍会报出另一端的占位区域。
- **主页图标区域两端语义混用、安卓模板记录分辨率写错，图标兜底通道实际失效。** 见不兼容
  第 1 条。

## 📦 重构

- **主页图标区域重标定。** 桌面顶右一排统一 63×63、顶边 6.8px，左侧竖排统一 40×42；安卓中右
  两按钮 52×57、左下三按钮 53×53；四张模板直接按现有截图重裁，做到「框 = 模板 = 识别区域」，
  两端五个模板实测全部 1.000。
- **清单收成第一块清单板（`ChecklistBoard` / `LINGER_BOARD`）**，清单、记录与入账按板身份落点，
  下一块清单复用同一读写入口。
- **清单结构与条目 id 收敛。** 顶层直接以地区 id 为键（不再套 `regions` 容器）；记录键改为
  纯条目 id，系统条目 id 改为无属性纯随机 uuid8，id 与地区 / 分类 / 条目名 / 记法完全解耦，
  改任何字段都不断用户记录与本地覆盖的关联。
- **安卓无障碍与前台服务自述文案中性化**（见不兼容第 2 条）。
- **设置页排版对齐 Material 3**：分组标题统一 16sp 中等字重，列表行尾部指示改为矢量图标
  并对读屏隐藏装饰。
