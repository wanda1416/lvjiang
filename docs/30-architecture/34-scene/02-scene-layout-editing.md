# 场景编辑器的配置、布局与运行边界

> 最后更新：2026-10-09（基线 v0.13.14）。

## 所有权

场景定义拥有实体身份、视图与列表顺序；布局拥有坐标、点击范围、模板和画布。编辑器当前选中的布局与视图是编辑上下文，不改变主页面运行选择。

## 保存与撤销

布局未保存草稿包括坐标、点击范围、画布和模板。“放弃改动”回到该布局最近一次保存状态；场景定义的创建、删除和排序即时保存，不在该撤销范围内。多视图重排只交换当前可见对象的槽位。

## 引用与点击

跨场景引用由源对象拥有身份和坐标，目标侧展示只读投影。Region 的显式点击范围限制在其外框内，使用局部比例并随外框缩放；默认范围来自全局设置。模板截取范围与点击范围分别拥有各自语义。
