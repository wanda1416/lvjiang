# 水饺直观调律子插件

基于律匠（lvjiang）开源项目，将直观调律面板整理为可选子插件。保留原项目版权、授权机制与 PolyForm Noncommercial License 1.0.0；禁止商用、冒充原作者及违规违法使用。

## 加载

使用当前源码及其正常开发环境，将本目录放在仓库的 `plugins/shuijiao_tuning` 下：

```text
python -m lvjiang -reg yysls -reg shuijiao_tuning
```

必须先注册 yysls。原项目的调律、备战、菜单与其他页面继续保留，左侧新增“水饺调律”，右侧新增“水饺记录与统计”。这是源码合入插件，不是能直接放进任意旧版EXE的安装包。

## 使用

1. 按原项目方式选择PC游戏窗口并定位，在新增页面选择本次培养流派。
2. 八部位分别展示五词条。首条深红，神力金色，刚需红色，灵活候选蓝色，空位为------；编辑后保存。刚需允许最多一次合法转律，神力仍遵循自然产出规则。
3. 按需选择严格部位、材料库存下限、首条数值保护和背包扫描方式；点击“开始调律”。仍可用宿主暂停或停止。
4. 在记录与统计页查看115级金装的首条与自然调律频率。频率是本地观测，不是官方概率。

用户配置独立存放在 `workflow_params.shuijiao_tuning`；不改原 `auto_tuning` 配置。默认不勾选任何培养流派。预设包含13种玩法的八部位词条，源自用户指定版本保存的目标要求，没有带入账户文档、设备、历史、截图、数据库或服务凭据。尚未填完整的未选流派不会阻断当前培养，选择该流派时会要求补齐。
