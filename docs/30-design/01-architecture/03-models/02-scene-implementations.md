## 战斗 (general_combat)

**游戏内位置**：任意可操作角色的战斗画面

独立单视图场景，集中声明武器切换、武学技、特殊技、奇术、卸势、蓄力、
轻击、闪避、跳跃与弓箭。Android 布局提供触控位置，桌面布局为同一批实体
绑定键盘按键，使工作流统一通过 `[general_combat].[动作]` 调用。

## 移动 (general_move)

**游戏内位置**：任意局内画面，左屏虚拟摇杆与右屏视角拖动区

单视图场景，只承载角色移动与镜头转向的坐标锚点。命名规则：`move_*`
是左屏摇杆的**平移**（不改变视角，桌面端对应 `W/S/A/D`），`look_*` 是右屏
拖动的**镜头转向**（不移动角色，桌面端为鼠标相对位移，暂未绑定）。
四个方向点到中心的像素距离相等，左/中/右同一纵坐标，上/中/下同一横坐标。

### Points

| 字段 Key | 字段名称 | 说明 |
|----------|----------|------|
| `move_center` | 移动中心 | 摇杆中心，移动 arrow 的起点 |
| `move_forward` | 前进 | 桌面绑定 `W` |
| `move_backward` | 后退 | 桌面绑定 `S` |
| `move_left` | 左移 | 桌面绑定 `A` |
| `move_right` | 右移 | 桌面绑定 `D` |
| `look_center` | 视角中心 | 右屏拖动起点 |
| `look_up` | 抬头 | 镜头上仰 |
| `look_down` | 低头 | 镜头下俯 |
| `look_left` | 左转视角 | 镜头左转 |
| `look_right` | 右转视角 | 镜头右转 |

### Arrows

每个方向点各有一条同名 arrow，从对应中心指向该点：
`drag [general_move].[move_backward] duration 0.1 hold 2.1 exact` 即"0.1 秒推杆到位、后退并保持 2.1 秒"；`scale 0.5` 可半推（走路），方向类拖拽建议带 `exact` 关掉抖动。

## 夜宿谜影 (fsjs_night) — 独立任务包私有场景

**位置**：不在全局 `config/system/scenes/` 里，而是随独立任务包
`config/system/workflows/standalone/fengshajiusi/` 交付（分组 `fsjs`，场景
`fsjs_night`）。包内 `scenes/`、`layouts/` 与全局结构一致，运行期由
`task_package_runtime_scope` 合并、退出即释放，不污染全局场景与布局；详见
[独立任务包](../../02-decisions/02-editor/13-standalone-task-package.md)。

**游戏内位置**：风沙酒肆活动 → 客栈下榻 → 守夜（门外来客）；同一场景内还包含
躺下前的房间状态与每夜结算画面，按**阶段拆成四个视图**（视图只影响编辑期可见性
与底图，不进入运行时寻址，`.wf` 仍统一写 `[fsjs_night].[key]`）：

| 视图 | 名称 | 关系 | 说明 |
|------|------|------|------|
| `base` | 客栈房间 | 基底 | 刚进房间：任务栏「来到客栈 / 下榻休息 0/1」+ 床上「躺下」 |
| `watch` | 守夜 | page ← /base | 躺下后：任务栏「门外来客(X/5)」+ 顶部提示 + 开门/不开/听风辨位 |
| `settle` | 结算 | page ← /base | 每夜收尾：「客栈夜话 / 奖励」标题 + 「再来一局」 |
| `clue_dialog` | 线索弹窗 | modal ← /watch | 「尚有未查看的线索」拦截框（守夜与结算画面都可能被它压住） |

`hide_all_views: true`：四个阶段互斥，编辑器不提供把它们叠在一起的「全部」视图。

**标定来源**：安卓布局按 2800×1260（20:9）实机诊断帧标定；桌面布局按
1936×1119 窗口帧（画布 1920×1080）标定。两端坐标都取自实机 `find` 的命中框
（画布归一化，可直接作为区域比例，不需要再换算）+ 少量外扩。

| 字段 Key | 字段名称 | 视图 | 说明 |
|----------|----------|------|------|
| `quest_track` | 任务栏 | base / watch | 左上「来到客栈 / 下榻休息 0/1」与「门外来客(X/5)」 |
| `lie_down` | 躺下 | base | 床上的「躺下」按钮 |
| `prompt_bar` | 顶部提示 | watch | 「XX秒后门外人离开」「是否开门?」与等待队友提示 |
| `open_btn` | 开门 | watch | 安卓「开门（N人选择）」按钮 / 桌面「Y 开门」行 |
| `refuse_btn` | 不开 | watch | 安卓「不开（N人选择）」按钮 / 桌面「N 不开」行 |
| `listen_btn` | 听风辨位 | watch | 门边金色耳朵图标（图标按钮，不做 OCR）；桌面无此元素，标 `disabled` |
| `settle_title` | 夜话标题 | settle | 结算画面「客栈夜话 / 奖励」标题区 |
| `again_btn` | 再来一局 | settle | 结算右下「再来一局」按钮（桌面为「F 再来一局」） |
| `clue_tip` | 线索弹窗提示 | clue_dialog | 「尚有未查看的线索…」提示行（判断弹窗是否存在） |
| `clue_check` | 今日不再提醒 | clue_dialog | 弹窗里的勾选项 |
| `clue_confirm` | 弹窗确认 | clue_dialog | 弹窗「确认」按钮；桌面只是「Space 确认」键提示，标 `disabled` |

尚未标定、仍走整屏识别的两处：听风辨位打开的线索物品/身份面板（实机只跑过
「只开 2、5」策略，没点过听风辨位，无样本）、多人模式的「确认进入」匹配框。
补到实机帧后按同名方式加区域即可。
