# 3.3 图库管理（F4）

入口：「通用 → 图库管理」或按 **F4**。

图库管理维护两类完全不同的图，别混用：

- **参考图**：回答「这是什么东西」——`recognize` 按分组比对，带 label/meta，同一时刻只有一套生效；
- **模板图**：回答「它在画面哪里」——`find` / `scan … by image` 按名字取图定位，没有空间概念。

四个页签：**新增图像** / **参考图管理** / **参考图元数据** / **模板图管理**。

### 核心概念

| 概念 | 说明 |
|------|------|
| 空间 (Space) | **参考图**的顶层分组（`android` / `desktop` / 自建），同一时刻只有一套生效 |
| 分组 (Group) | 参考图：空间内的二级分类；**模板图**：模板目录的第一级（布局分组 / 普通分组） |
| 参考图 | 供 `recognize` 分类的图，带标签与元数据 |
| 模板图 | 供 `find` / `scan by image` 定位的小图，按名字寻址 |
| 元数据 (Meta) | 参考图的附加信息（标签、备注、自定义字段等） |

### 操作说明

| 操作 | 说明 |
|------|------|
| 导入图片 | 从本地文件导入参考图 |
| 粘贴 (Ctrl+V) | 从剪贴板粘贴截图 |
| 截图 | 直接从当前连接的设备/窗口截取画面 |
| 编辑元数据 | 选中参考图后在编辑区修改 input 字段（标签、备注等） |
| 批量编辑 | 多选后统一修改元数据 |
| 筛选 | 按分组、标签等条件过滤显示 |

### 输入/输出字段

图库严格区分两类字段：

| 类型 | 说明 | 可编辑 |
|------|------|--------|
| input 字段 | 用户维护的元信息（标签、备注、自定义输入字段） | 可编辑 |
| output 字段 | 从图像中 OCR 识别的结果（如等级区域、数量区域） | **不可编辑** |

> output 字段是机器读取的结果，不应手动修改。

### 图片目录与分组

参考图的图片按**分组分目录**存放，目录名就是分组名，一眼能看出哪张图属于哪一组：

```text
config/system/references/android/调律材料/94A752E3.png
config/local/references/android/调律材料/xxxxxxx.png   # 用户层同名覆盖
```

目录的第一级是**空间 key**（`android` / `desktop`），界面显示的是它的中文名
（手游 / 端游）；key 与布局根、环境、模板命名空间同名，是稳定身份，展示名可以随
界面语言变化（`android.yaml` 顶层的 `name` 里写 `zh_CN` / `en_US`）。

- 新增参考图、修改分组时，图片自动落进（或移动到）**第一个分组**对应的目录；
  分组语义仍可写多个（`装备培养,调律材料`），但一张图只能待在一个目录里。
- 没有分组的参考图放在 `default/` 目录。`default` 是保留目录名，**不能当分组
  使用**；含路径分隔符或以 `.` 开头的分组名同样会被拒绝。
- 目录名不会被当成分组声明：手工把图片挪到别的分组目录，检索照样按文件名找到
  它，分组归属仍以参考图的「分组」字段为准。

### 空间切换与管理

顶部下拉框选择要查看/编辑的空间，右侧四个按钮：

| 按钮 | 作用 |
|------|------|
| 编辑 | 改这个空间的**展示名**（按语言分别填写）；key 置灰只读——它同时是目录名与方案里的引用 |
| 刷新 | 重扫空间目录并重载当前空间，外部改过 yaml 或图片目录后用它对齐 |
| 新建 | 与「编辑」同一个对话框，区别只是 **key 可填**：填 key + 中英文展示名即可创建 |
| 删除 | 删除选中空间及其全部参考图；系统空间与最后一个空间不可删（按钮禁用并说明原因） |

新建与编辑共用同一个表单：

- **新建**：`空间 key` 可编辑（小写字母、数字、下划线，不能与已有空间重名），
  「简体中文」与「English」两行**必填**——只填一种语言，切到另一种界面语言时就会
  露出裸露的 key；
- **编辑**：`空间 key` 置灰不可改（要换 key 请新建空间），展示名可以逐语言改，
  全部留空表示直接显示 key；
- 两行必填语言固定排在最前，其余语言按随包顺序排在后面。

**运行用哪个图库不由这里决定。** 运行时空间由主页面的图库下拉或连接方案给出；
这里下拉只切换「正在编辑的空间」，切完不回写运行时设置，关掉窗口后主页面仍是
原来那个空间。两者不一致时，右上角会写成「运行用：手游 ｜ 正在编辑：端游」。

不同空间可有不同 meta_schema（元数据字段定义），切换后编辑区和筛选区会自动按
新空间的 schema 重建。

### 预置空间说明

系统预置两个空间，分别对应桌面游戏窗口和手游画面（key 在括号里）：

| | 端游（`desktop`） | 手游（`android`） |
|---|---|---|
| **用途** | 桌面游戏画面的参考图匹配 | 手游画面的参考图匹配 |
| **分组方式** | 按调律材料、货币资产等用途分组 | 同样按用途分组 |
| **图片来源** | 以桌面截图或剪贴板素材为主 | 以手游截图为主 |
| **覆盖重点** | 调律材料、定音转律、普通道具等 | 货币资产及手游常见道具 |

**共性：**

- 元数据结构相同：都有「等级」（input）、「等级文本区域」「数量文本区域」（output）
- 都支持按 group 字段进行语义筛选；目录和配置文件分别位于对应的空间下
- 参考图格式一致，均可用于图像匹配和 OCR 识别

**如何选择：**

- 直接操作 PC 端游窗口时选择「端游」；连接手机、模拟器或手游投屏时选择「手游」
- 建议直接选择预置连接方案，让图库、环境和布局一起切换，避免画面与参考图空间不一致
- 两个空间可以共存；自定义工作流仍应确认它实际使用的图库空间

两个空间各预置了哪些参考图、哪些是共用的、哪些只在一个空间里有，以及哪些 label 被工作流与
自动调律实际引用（改名前必须核对的清单），见 [预置图库内容](../03-automation/01-preset-gallery.md)。

## 模板图（find / scan by image）

模板图是**定位**用的小图，与参考图库无关：不进图库空间、不参与 `recognize`。
图片在 `config/{system,local}/templates/<分组>/…png`，尺寸等元数据在
`config/{system,local}/templates/templates.yaml`（用户层只存差异，键级合并）。

### 分组

| 分组类型 | 判定 | 谁来管 |
|---|---|---|
| **布局分组** | 目录名 = 根布局 key（`android` / `desktop`） | **场景管理**：截取/删除都在场景编辑器里，本页只读 |
| **普通分组** | 其他名字（`common` 及自建） | **图库管理**：可新建、改名、删除；`common` 是快速截取的默认位置 |

布局分组的模板名字固定为「布局 / 场景 / Region」，尺寸记在布局绑定的 `template` 里；
图库侧再改一次就会同时破坏名字与尺寸两条契约，所以改名/删除按钮对它们是禁用的。

### 新增图像 → 模板图

「新增图像」页签右上角选择**写入目标**：

- **参考图**：框选 → 网格参数 → 执行切割 → 逐格填标签/分组/元数据（原有流程）；
- **模板图**：在画布上**框选一个矩形**即可，不进入网格流程。填分组（留空写 `common`）
  与名字，界面会显示像素尺寸与**录制画布**（按当前布局的画布比例换算），可先
  「测试匹配」看分数，保存后给出可直接粘贴的用法：
  - 普通分组 → `find as $v by image "common/xxx"`；
  - 布局分组 → `scan [scene].[region] as $hit by image`（只读展示，不能在此写入）。

录制画布是跨分辨率归一的依据：`find` 用到按名模板时按「当前画布宽 ÷ 录制宽」缩放一次；
未登记尺寸的模板按原始像素匹配（同分辨率专用）。

### 模板图管理

分组下拉**一次只看一组**（不提供「全部」）：共享分组排在布局分组之前，所以 `common`
永远在第一位；列表只显示名字本身（分组已由下拉确定，不再占位）。

右侧是模板详情：名字与分组**就地可改**（改完点「保存修改」，换分组等于把模板移到新组），
删除在卡片右上角；下面依次是像素尺寸、录制画布、来源层（系统/本地）、**引用位置**
（哪个布局/场景/Region 绑定、哪个脚本按名引用）与用法。操作按所有权开放：

| 分组/角色 | 重命名 | 删除 | 说明 |
|---|---|---|---|
| 布局分组 | ✗ | ✗ | 由场景管理维护，本页只读 |
| 普通分组 | ✓（就地改名字/分组，可在普通分组之间移动） | ✓ | 有引用时会先列出受影响位置 |
| `role: sample`（如装备锁图标） | ✗ | ✗ | 算法标定样本，运行期按颜色比例判定，永久保留 |

要替换一张普通分组的模板，回「新增图像」用同名保存即可覆盖（会先确认）。

## 图像识别工具

入口：「工具 → 图像识别」。

对当前画面做 OCR 自查，验证识别结果是否符合预期。怀疑识别有问题时先用这个工具确认。
