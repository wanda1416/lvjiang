# 云端同步、端到端加密与备战分享

> 说明律匠账号的云端同步范围、全文档端到端加密（E2E）及备战方案快照分享的安全边界。

---

## 一、哪些数据端到端加密，哪些仍以明文保存

端到端加密密钥在客户端与网页端登录瞬间由**账号登录口令**本地派生（PBKDF2-HMAC-SHA256），口令与派生密钥均不上传云端。

| 数据内容 | 同步方式与存储形态 | 说明 |
|---|---|---|
| **用户配置**（高隐私） | 端到端加密 | 可能包含账号、角色、尾号或自定义敏感项，无口令/密钥时网页端隐藏并显示占位，**绝不参与对外分享** |
| **便利贴**（个人隐私备忘） | 端到端加密（先 gzip 压缩再 AES-GCM 加密） | 个人隐私备忘内容，云端不持久化存储明文，**绝不参与对外分享** |
| **其余云端文档**（备战方案、玩法预设、批量配置、工作流参数、袅袅之音及后续新增文档） | **全文档端到端加密**（先 gzip 压缩再 AES-GCM 加密） | 云端不持久化存储明文；兼容旧版明文与无压缩密文的平滑读取与自动升级 |
| **主动发布的备战分享** | **明文独立快照** | 见第三节：由浏览器解密后仅抽取方案、装备与引用游戏数值生成公开只读快照，**严禁包含用户配置、便利贴与角色名** |
| **总览数值流水与快照** | 服务端明文 | 用于资源看板与历史查询，不参与 E2E 加密 |
| **字段定义、页面布局、角色头像** | 服务端明文 | 用于多端界面结构同步与头像展示 |

> **安全边界说明**：全文档端到端加密指客户端同步上云后云端不再持久化文档明文；一旦启用，**清空云端同步数据也不会回退该加密保护**（未升级的旧版客户端将被服务端以 HTTP 426 拦截以防写坏本地文件）。历史数据库备份不会追溯擦除，且使用公开链接分享出去的快照以服务端可读形式供访问者浏览。

## 二、改密、忘记密码与管理员重置的不可逆提示

1. **正常修改密码**：
   - 账号修改密码后，E2E 密钥会随新口令一起轮换；
   - 客户端会在下一次同步时用新密钥**自动重新加密并重推全部文档**。建议先在持有完整本地数据的主电脑上完成一次同步，再在其他设备用新密码登录。
2. **忘记密码 / 管理员重置密码（不可逆警告）**：
   - 由于云端不保存你的 E2E 密钥，**通过管理员重置密码（覆盖为新口令）后，旧口令派生的密钥将无法再解密云端已有的全部加密数据**（包括用户配置、便利贴、备战方案、工作流配置与批量配置）；
   - 重置前请务必先确认本地电脑仍保留有完整明文配置文件；重设后在本地以新口令重新同步上推即可重建云端密文。
3. **本地密钥缓存的清除时机**：
   - 登录时客户端用口令在本地派生密钥，并缓存一份十六进制副本，只为下次启动免去重新派生（本地磁盘上本来就是明文数据，缓存不降低安全性）；
   - **退出登录**、或账号被服务端判定会话失效（被踢下线、令牌过期、账号被禁用）时，这份缓存与进程内存里的密钥会**一并清除**；重新登录会用新输入的口令重新派生，不影响云端已有密文。

## 三、备战方案分享（历史快照）

在网页端「角色工作台 → 备战方案」点击「分享」即可生成只读展示链接（无需登录即可打开）：

1. **历史静态快照与严格数据范围**：
   - 创建分享时由浏览器在本地解密并仅抽取必要配装数据：**公开包含**所选备战方案（或勾选的同角色全部方案）、对应装备（默认仅穿戴装备，可勾选全部装备池）、世界等级，以及选中方案实际引用的自定义基础属性数值（使用系统预置时不打包个人数值）；
   - **绝不包含（严格隐私隔离）**：**用户配置**（账号、角色、尾号等键值配置）、**便利贴**（个人隐私备忘）、账号名与角色标识名、头像、总览账本，以及任何工作流或批量配置；
   - 创建成功后页面将**自动跳转到分享预览页**，登录态作者可当场核对公开内容并在顶部点击「撤回此分享」立即作废链接；
   - 链接一经生成即固定为创建时刻的内容，后续修改本地配装不会同步改变已发出的链接（可在分享管理列表点击「重新生成」发布新快照）。
2. **有效期（1~90 天，默认 30 天）**：
   - 结合游戏赛季更替，新创建的分享链接**取消永久有效**，可选 **7 天 / 30 天（默认）/ 90 天**；到期或手动撤销后链接立即失效。
   - 本规范上线前已存在的历史永久 / 365 天分享链接会继续保留至原到期时间或手动撤销；但当账号启用全文档加密后，依赖旧明文文档的旧分享将失效，需要重新生成一次快照链接。
