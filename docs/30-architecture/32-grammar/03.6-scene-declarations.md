# 场景位置声明

`scene` 声明流程走到源码此处时，作者预期处于哪个场景/视图。它是正式 DSL 语句，保存在 AST 中，
仅用于阅读、编辑和静态分析。执行器直接跳过，不检测页面、不改变运行时状态、不产生布局绑定依赖。

```text
scene [game_settings]
scene [game_settings] view [other]
scene unknown
```

- 省略 `view` 表示未声明具体视图，不默认选择基底。
- `view [base]` 明确声明基底；单视图场景也接受此写法。
- `unknown` 表示当前场景不确定。
- 当前仅支持静态 key，不接受变量或动态表达式。
- `[scene].[entity]` 保持原有实体寻址含义，视图使用独立的 `view` 关键字。

```text
press "/"
wait 1
scene [game_settings] view [base]
click [game_settings].[other] after wait @page_refresh
scene [game_settings] view [other]
```

此示例表达流程预期，不证明页面已经到达。如果需要运行时确认，仍应显式扫描识别，并在成功分支声明位置。
声明可位于主流程、过程、循环和条件分支。每条声明保留源码行号；静态检查遍历所有分支和过程，
只检查场景/视图是否存在，不将分支内的位置泄漏为全局状态，也不推断过程返回后的页面。

`collect_scene_declarations` / `validate_scene_declarations` 独立于运行时引用收集；
VS Code 语义诊断以 warning 提示不存在的场景/视图，提供 scene 代码片段，内置编辑器支持高亮。

页面调用方由场景定义中的导航契约描述。此语句不创建调用栈，不设置 `@caller`，也不等同于 DSL 过程调用关系。
