# 4.3 三种处理配置项详解

本文详解扫描处理、材料处理、调律处理三个页面的配置项。三个页面的规则
可以选择不同的「判定语义」，先看下表再设置可能回收装备的动作。

## 四种判定语义

「判定语义」决定当前**这一行规则**如何取得「判定结果」，不改变运行时选中的
调律目标，也不改变其他行的设置。

| 界面选项 | 配置值 | 如何取得判定结果 | 适合的用途 |
|----------|--------|------------------|------------|
| 传入规则 | `incoming` | 使用本次运行选中的流派规则及玩法，计算装备的最高预期评级 | 只按当前要调律的流派决定是否处理 |
| 全部规则 | `all` | 使用全部已配置的流派规则，取其中适用规则的最高预期评级 | 保护对其他流派仍有价值的装备 |
| 自选规则 | `custom` | 在弹窗中指定参与判定的规则，再取适用规则的最高预期评级 | 只兼顾选定的其他流派 |
| 自选词条 | `affix` | 不计算潜力评级；装备词条名称命中所选名称即成立 | 按珍贵词条直接保护或处置装备 |

前三种语义下，「判定结果」勾选的是顶级、优秀、一般、垃圾等**具体档位**，
只有算出的档位属于勾选集合才命中；不选档位表示不限评级。
跳过或不适用的流派规则不参与取最高档；没有任何适用规则时，行为判定按垃圾档
兜底。自选词条下，同一列改为选择**词条名称**，至少选一个；默认匹配装备任意
词条，扫描处理勾选「仅首词条」后只匹配首条。该模式不读取评级档位。

例如同一件装备对当前流派的预期评级为垃圾，对另一流派为优秀：选择「传入
规则」得到垃圾；选择「全部规则」可能得到优秀；「自选规则」只会考虑弹窗中
选定的规则。因此一条“垃圾 → 回收”规则若要避免误收其他流派的可用装备，
需明确选择合适的判定语义，并把保护规则放在回收规则之前。

自选规则中已删除的规则会被忽略；若指定规则全部失效，运行时记录警告并
回退到全部规则。扫描处理的「进入门槛」固定按传入规则判定，不受处置表的
逐行判定语义影响。扫描处置表的「仅首词条」在评级模式下是只把首词条作为
当前已出现的词条，其余槽位留给潜力推演；这不等于只检查首词条的现有评级。

## 扫描处理

三个处理页面的「添加规则」行右侧都有「校验规则」。点击后，规则表下方
只显示部位与金/紫品阶没有启用候选规则的组合；再点「清理结果」即可收起。
平时结果区域隐藏。「有候选规则」不代表装备必定命中：判定结果、传入规则
和首词条条件仍要等实际运行时才能确定。

对满足等级要求但未达调律门槛的装备进行处置。

词条已满的装备也先走调律门槛；通过后由调律处理决定保留、锁定或回收。

### 进入门槛

进入门槛在「基础配置」页设置（数据存为 `behavior.scan.entry_min_rating`）。

| 配置项 | 说明 |
|--------|------|
| 进入门槛评级 | 传入规则预期评级 ≥ 此值 → 进入调律；未达 → 进入处置表 |
| 仅识别首词条 | 默认勾选。调律门槛只看首词条胚子的最大潜力；进入后仍用完整实际词条做调律处理 |

系统「默认规则」组的门槛为 `top`（顶级），预期评级达到顶级才直接进调律；
「激进规则」组为 `excellent`（优秀）。应以当前选中的基础规则组为准。

### 处置规则表

有序规则表，条件不命中时检查下一条；首条命中后执行该行处置。
每行配置项：

| 配置项 | 说明 |
|--------|------|
| 部位 (parts) | 该规则适用的部位列表（可多选：武器/环/佩/冠胄/胸甲/胫甲/腕甲） |
| 品阶上限 (max_quality) | 品阶范围：`gold_only`（仅金装）/ `gold`（不限）/ `purple_only`（仅紫装）/ `purple`（紫装及以下）/ `blue`（蓝装及以下） |
| 词条进度 (pct) | 词条填充百分比阈值 |
| 进度比较 (pct_op) | `ge`（≥）或 `le`（≤） |
| 评级 (ratings) | 匹配的评级列表（如 `junk`、`top`、`excellent`、`normal`） |
| 判定语义 (judge_scope) | 传入规则 / 全部规则 / 自选规则 / 自选词条，见上文 |
| 自选规则 (judge_rules) | 只在判定语义为自选规则时选择参与判定的规则 |
| 处置 (action) | 见下表 |
| 仅首词条 (first_affix_only) | 评级模式下只用首词条作为现有词条来推演潜力；自选词条模式下只匹配首条名称 |

### 处置动作

| 动作 | 说明 |
|------|------|
| `skip` | 跳过该装备，不进入调律 |
| `recycle` | 直接回收该装备 |
| `tune_full_recycle` | 未满时进调律调满后回收（回收可获更多材料）；已满时等价于直接回收 |
| `tune_this` | 无视进入门槛，强制进入调律流程（高级自定义用途） |

> 无命中时默认**保留**装备（不进调律也不回收）。

## 材料处理

每轮调律开始前的材料准备逻辑。

| 配置项 | 说明 |
|--------|------|
| 启动大律准石数量检查 | 勾选后在每轮调律前检查大律准石数量 |
| 数量基准 | 低于此值触发「不足时」动作（默认 80） |
| 不足时 | 三选一 |

**不足时的三个选项**：

| 选项 | 行为 |
|------|------|
| `skip` | 跳过该装备，继续下一件 |
| `abort` | 结束全部调律 |
| `ask` | 弹窗询问是否继续（确认后本次运行不再检查） |

### 材料处理规则

有序规则表，自上而下**首条命中即生效**。每行配置项：

| 配置项 | 说明 |
|--------|------|
| 部位 (parts) | 适用部位列表；全选显示“全部” |
| 品阶 (max_quality) | 不限、仅金装、仅紫装、紫装及以下或蓝装及以下 |
| 判定语义 (judge_scope) | 传入规则、全部规则、自选规则或自选词条，见上文 |
| 判定结果 (ratings) | 允许命中的具体评级；自选词条语义下改为词条名 |
| 比较方向 (pct_op) | 材料处理固定为 `ge`（≥） |
| 首词条百分比 (pct) | 首词条初始数值阈值；0 表示不限 |
| 每轮添加 (food) | `彩狗粮` / `金狗粮` / `紫狗粮` / 空=不添加 |
| 材料不足时 (on_insufficient) | `skip` 跳过装备；`continue` 不添加并继续调律；`next` 顺延下一规则 |

> 规则顺序很重要：排在前面的优先匹配。可以用上移/下移调整顺序。
> 例如把“顶级金装添加彩狗粮”的不足动作设为 `next`，下一条允许顶级或
> 优秀金装添加金狗粮，即可在彩狗粮不足时自动降级使用金狗粮。

## 调律处理

装备通过扫描准入后立即执行一次，之后在每轮调律**结束后**再执行的决策规则表。
首次决策使用装备的完整实际词条；回收和跳过可在装备详情页直接完成，不必进入调律页。

### 行为规则表

有序规则表，自上而下**首条命中即生效**。每行配置项：

| 配置项 | 说明 |
|--------|------|
| 部位 (parts) | 适用部位列表 |
| 品阶上限 (max_quality) | 品阶范围 |
| 词条进度 (pct) | 词条填充百分比阈值 |
| 进度比较 (pct_op) | `ge`（≥）或 `le`（≤） |
| 评级 (ratings) | 匹配的评级列表 |
| 判定语义 (judge_scope) | 同上文四种选择；逐行设置 |
| 处置 (action) | 见下表 |

### 处置动作

| 动作 | 说明 |
|------|------|
| `continue` | 继续调律或锁定：未满时继续；已满时结束，并按“锁定优秀及以上装备”设置处理 |
| `reset` | 重置调律：清空首词条以外的全部词条，重新开始。**每件装备单次运行只重置一次** |
| `recycle` | 回收该装备 |
| `skip` | 结束保留：停止调律，保留当前状态 |
| `tune_full_recycle` | 调满五词条后回收；命中后不再逐轮做行为规则判定或添加狗粮 |

> 词条已满时，无命中默认结束并保留，不会自动锁定。只有明确命中 `continue` 规则，开启“锁定优秀及以上装备”，传入规则最终评级达到优秀或顶级，且本次确实调律过至少一轮，返回详情页后才自动锁定。
> 词条未满时无命中默认继续调律。

### 重置设置

| 配置项 | 说明 |
|--------|------|
| 最大重置次数 (max_resets) | 同一件装备单次运行最多重置几次（默认 3） |
| 重置耗尽处置 (reset_exhausted_action) | 达到重置上限后的处置（默认 `recycle`） |
| 锁定优秀及以上装备 (lock_qualified) | 默认勾选。已调律至少一轮、词条已满、明确命中 `continue` 规则且传入规则最终评级达到优秀或顶级时自动锁定；最大预期评级不能触发锁定，无规则命中只保留 |
