# 4.3 三种处理配置项详解

本文详解扫描处理、材料处理、调律处理三个页面的**全部配置项**。

---

## 扫描处理

对满足等级要求但未达调律门槛的装备进行处置。

词条已满的装备也先走调律门槛；通过后由调律处理决定保留、锁定或回收。

### 进入门槛

进入门槛在「基础配置」页设置（数据存为 `behavior.scan.entry_min_rating`）。

| 配置项 | 说明 |
|--------|------|
| 启用 | 勾选后启用扫描处置；取消则未达门槛的装备直接保留 |
| 进入门槛评级 | 传入规则预期评级 ≥ 此值 → 进入调律；未达 → 进入处置表 |
| 仅识别首词条 | 默认勾选。调律门槛只看首词条胚子的最大潜力；进入后仍用完整实际词条做调律处理 |

默认门槛为 `excellent`（优秀），即预期评级达到优秀及以上的装备直接进调律，其余进入处置表。

### 处置规则表

有序规则表，自上而下**首条命中即生效**。每行配置项：

| 配置项 | 说明 |
|--------|------|
| 部位 (parts) | 该规则适用的部位列表（可多选：武器/环/佩/冠胄/胸甲/胫甲/腕甲） |
| 品阶上限 (max_quality) | 品阶范围：`gold_only`（仅金装）/ `gold`（金装及以下）/ `purple_only`（仅紫装）/ `purple`（紫装及以下）/ `blue` |
| 词条进度 (pct) | 词条填充百分比阈值 |
| 进度比较 (pct_op) | `ge`（≥）或 `le`（≤） |
| 评级 (ratings) | 匹配的评级列表（如 `junk`、`top`、`excellent`、`normal`） |
| 判定范围 (judge_scope) | `incoming`（传入规则）/ `all`（全部规则）/ `affix`（自选词条）/ `rules`（自选规则） |
| 判定规则 (judge_rules) | 当 judge_scope = rules 时，指定参与判定的规则列表 |
| 处置 (action) | 见下表 |
| 仅首词条 (first_affix_only) | 勾选后取评级时只注入首词条 |

### 处置动作

| 动作 | 说明 |
|------|------|
| `skip` | 跳过该装备，不进入调律 |
| `recycle` | 直接回收该装备 |
| `tune_full_recycle` | 未满时进调律调满后回收（回收可获更多材料）；已满时等价于直接回收 |
| `tune_this` | 无视进入门槛，强制进入调律流程（高级自定义用途） |

> 无命中时默认**保留**装备（不进调律也不回收）。

## 材料处理

每轮调律开始前的材料准备逻辑。

### 大律准石数量检查

| 配置项 | 说明 |
|--------|------|
| 启用检查 | 勾选后在每轮调律前检查大律准石数量 |
| 数量基准 | 低于此值触发「不足时」动作（默认 80） |
| 不足时 | 三选一 |

**不足时的三个选项**：

| 选项 | 行为 |
|------|------|
| `skip` | 跳过该装备，继续下一件 |
| `stop` | 结束全部调律 |
| `ask` | 弹窗询问是否继续（确认后本次运行不再检查） |

### 狗粮添加规则

有序规则表，自上而下**首条命中即生效**。每行配置项：

| 配置项 | 说明 |
|--------|------|
| 词条进度 (pct) | 当前词条填充百分比阈值 |
| 预期评级 (min_expect) | 预期最低评级（`top` / `excellent` / `normal`） |
| 品阶 (min_quality) | 品阶条件（`gold` / `purple`） |
| 狗粮 (food) | 添加的狗粮类型（`彩狗粮` / `金狗粮` / `紫狗粮` / 空=不加） |
| 不足时 (on_insufficient) | `skip`（跳过该装备）/ `continue`（不加狗粮继续调律） |

> 规则顺序很重要：排在前面的优先匹配。可以用上移/下移调整顺序。
> 金装规则应排在紫装前面，因为金装优先匹配更精细的规则。

---

## 调律处理

装备通过扫描准入后立即执行一次，之后在每轮调律**结束后**再执行的决策规则表。
首次决策使用装备的完整实际词条；回收和跳过可在装备详情页直接完成，不必进入调律页。

### 行为规则表

有序规则表，自上而下**首条命中即生效**。每行配置项：

| 配置项 | 说明 |
|--------|------|
| 部位 (parts) | 适用部位列表 |
| 品阶上限 (max_quality) | 品阶范围 |
| 词条进度 (pct) | 词条填充百分比阈值 |
| 进度比较 (pct_op) | `ge`（≥）或 `le`（≤） |
| 评级 (ratings) | 匹配的评级列表 |
| 判定范围 (judge_scope) | 同扫描处理 |
| 处置 (action) | 见下表 |

### 处置动作

| 动作 | 说明 |
|------|------|
| `continue` | 继续调律或锁定：未满时继续；已满时结束，并按“锁定合格装备”设置处理 |
| `reset` | 重置调律：清空首词条以外的全部词条，重新开始。**每件装备单次运行只重置一次** |
| `recycle` | 回收该装备 |
| `skip` | 结束保留：停止调律，保留当前状态 |

> 词条已满时，无命中默认结束；若开启“锁定合格装备”，且本次确实调律过至少一轮，返回详情页后自动锁定，否则只保留。
> 词条未满时无命中默认继续调律。

### 重置设置

| 配置项 | 说明 |
|--------|------|
| 最大重置次数 (max_resets) | 同一件装备单次运行最多重置几次（默认 3） |
| 重置耗尽处置 (reset_exhausted_action) | 达到重置上限后的处置（默认 `recycle`） |
| 锁定合格装备 (lock_qualified) | 默认勾选。已调律至少一轮、词条已满并按默认或 `continue` 结束的装备自动锁定；已锁定时绝不重复点击 |
