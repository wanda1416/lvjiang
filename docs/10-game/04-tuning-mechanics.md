## 简写与标准字段映射

本文档示例中的词条均为简写，实现时必须映射为 `config/system/yysls/attributes.yaml` 中 `affix_caps._aliases` 定义的标准字段名，不得使用 `attributes.yaml` 之外的词条名。

| 简写 | 标准字段 | 说明 |
|------|----------|------|
| 大外 | 最大外功攻击 | 外功系最大攻击 |
| 小外 | 最小外功攻击 | 外功系最小攻击 |
| 劲 / 势 / 敏 | 劲 / 势 / 敏 | 五维属性，本身即标准字段 |
| 会意 | 会意率 | 会意流派本命率 |
| 会心 | 会心率 | 会心流派本命率 |
| 精准 | 精准率 | 通用率属性 |
| 大无相 | 最大无相攻击 | 武器部位：最大无相属攻；非武器部位：最大本属（大本属） |
| 小无相 | 最小无相攻击 | 武器部位：最小无相属攻；非武器部位：最小本属（小本属） |
| 大本属 | 最大{裂石/牵丝/破竹/鸣金}攻击 | 所选流派的最大属攻（非武器部位的大无相指的是它） |
| 小本属 | 最小{裂石/牵丝/破竹/鸣金}攻击 | 所选流派的最小属攻 |
| 主武学增伤 | 指定武学增效类中对应武器的具体词条 | 如 剑武学增伤、横刀武学增伤、舞绫鼓武学增伤 |
| 全武学增伤 | 全武学增效 | 独立词条，不指定武器类型 |
| 对首领增伤 | 对首领单位增伤 | 副本/首领战专属 |
| 对玩家增效 | 对玩家单位增效 | PVP 模式专属 |
| 单体奇术增伤 | 单体类奇术增伤 | 输出向治疗的奇术增伤 |


## 装备分级体系

### 五级分类

装备评估分为五个等级：

| 等级 | 定义 | 留存策略 |
|------|------|--------|
| **顶级** | 核心攻击词条占满自由槽、无缺陷词条、符合流派要求的最优组合 | ✅ 永远保留 |
| **优秀** | 能用且无缺陷词条，核心攻击未拉满但可转律调出 | ✅ 永远保留 |
| **能用** | 出现缺陷词条或外功硬门槛缺失，但仍可穿戴 | 根据背包空间选择 |
| **临时** | 当前缺乏更好选择，应被优秀/顶级装备取代 | 有替代品即弃 |
| **垃圾** | 库外废词条、神力硬缺失、缺陷词条超限 | ❌ 直接回收 |

### 关键原则

**总则**：在保证神力词条的基础上保外功——攻击词条越多越好，三率（会心/会意/精准）尽可能少。

**各流派核心攻击组合**：
- **会意流**：大外 + 势（鸣金系属攻）
- **会心大外流**：大外 + 劲（强势属性）
- **会心小外流**：小外 + 敏（灵巧属性）
- **治疗流**：取决于玩法，见流派专属说明

**神力槽位差异**：
- **有神力槽**（主武器、环佩、胫腕甲）：本命率出现 → 顶级封顶降为优秀
- **无神力槽**（副武器、冠胄、胸甲）：允许 1 条本命率参与顶级（流派限制见各部位规则）

**外功硬门槛**（非首词条必须）：
- 会意/会心大外流：必须有 1 条大外
- 会心小外流：必须有 1 条小外
- 缺失即最高判定为「能用」

**理论穿配**：除小外流外，用户一般无法穿一身顶级装备（会导致三率不足）。会意流和会心大外流通常搭配「一半顶级 + 一半优秀」。调律过程中，无论当前装备等级，顶级和优秀装备都应保留。


### 转律说明

    考虑到会心和会意流派都有一套好的装备共性，所以即使在调律过程中出现其他流派的好装备，也应该保留。
    比如 会心流派 一般不需要 会意，但是如果调 腿甲 的时候碰到 劲 + 对首领增伤 + 劲 + 大外 + 会意， 那么也应该自动保留。

    由于存在转律机制，即对 首词条 以外的词条可以选择一个进行无限次转律。
    这意味着，调律过程中，如果出现一条废词条，我们需要采取一种最优策略模拟其转律结果，再判定其可能。
    比如，对于 会意流派的 副武器，如果出现：  大外、劲、小鸣金。
        此时我们可以假定 小鸣金 按照转律优先级表，直接认定为 大外，然后判断 大外+劲+大外 算什么级别的。
        显然应该继续调律，并且这件装备有希望出 顶级装备。

## 词条定义说明

本节规定各流派各部位的词条要求，是调律规则的核心。

### 符号与术语

**装备词条格式**：`[必选词条] + 可选词条 * 数量`
- **必选词条**（`[ ]` 框选）：不符合则最高判为「能用」（除非同时出现垃圾词条）
- **可选词条**：剩余槽位可填充的有效词条，支持多条且可重复

**首词条**：装备的第一条词条，在顶级判定中被特殊处理（见各部位说明）

**转律优先级**：当装备出现废词条时，假定其转律为何词条进行重新评估（按降序应用）

**可用词条库**：当前流派能接受的所有词条。库外词条为废词条，命中即判垃圾。

### 重要注意

- ✓ 以下规则重点规定**顶级**和**优秀**装备标准；**能用**装备要求更低（见各流派规则）
- ✓ 神力词条缺失（如剑缺「剑武学增伤」）直接判垃圾，不走等级判定流程
- ✓ 大无相在非武器部位等同于大本属（所选流派的最大属攻），不是无相属性
- ✓ 出现缺陷词条即判「能用」；出现多条缺陷或库外词条判「垃圾」（具体数量见各流派规则）
- ✓ 非首词条缺大外/小外是「硬门槛」，缺失直接判「能用」封顶（见外功硬门槛说明）


### 会意流派（鸣金·虹 / 鸣金·影）

**适用范围**：主武器 剑 + 副武器 枪（两者可互换槽位）

**神力词条要求**：
| 部位 | 要求 | 缺失判定 |
|------|------|--------|
| 剑 | 必须剑武学增伤 | 垃圾 |
| 枪 | 无神力要求 | — |
| 环、佩 | 必须全武学增伤 | 垃圾 |
| 冠胄、胸甲 | 无神力要求（单体奇术增伤可作 PVP 备用） | — |
| 胫甲、腕甲 | 必须对首领增伤（对玩家增效可作 PVP 备用） | 垃圾 |

**转律优先级**：大外、势、劲、会意、大无相、大鸣金

**可用词条库**：大外、势、劲、会意、大无相、大鸣金 + 会心、精准

**各部位顶级判定**（仅看非首词条）：

| 部位 | 词条组成 | 顶级条件 | 备注 |
|------|--------|--------|------|
| **剑(主)** | [大外(首) + 剑武学增伤 + 大外 + 劲/势] + 可用 * 1 | 非首同现 大外+劲+势 | 3自由槽被占满 |
| **枪(副)** | [大外(首) + 大外 + 劲/势] + 可用 * 2 | 非首同现 大外+劲+势，且 会意/大无相 ≥1 | 可含1条本命率 |
| **环、佩** | [大外(首) + 大外 + 全武学增伤] + 可用 * 2 | 非首同现 大外+劲+势 | 3自由槽被占满 |
| **冠胄、胸甲** | [会意(首) + 大外 + 劲/势] + 可用 * 2 | 出现 大外，且 劲/势 ≥1，未出现大鸣金 | 可含1条会意 |
| **胫甲、腕甲** | [劲(首) + 对首领增伤 + 大外] + 可用 * 2 | 非首同现 大外+劲+势 | 可含1条本命率 |

**流派专属定级规则**：

- 会意流不需要会心和精准
  - 出现 1 条会心/精准 → 上限「能用」
  - 出现 2 条及以上 → 「垃圾」
- 缺劲/势不构成缺陷（可转律调出），无缺陷即判「优秀」
- **非首缺大外 → 硬门槛，上限「能用」**

**顶级装备模型**（展示一种典型组合）：
- **剑、环、佩**：增伤 + 大外 + 大外 + 劲 + 势
- **枪**：大外 + 大外 + 劲 + 势 + 会意
- **冠胄、胸甲**：会意 + 会意 + 大外 + 劲 + 势
- **胫甲、腕甲**：劲 + 对首领增伤 + 大外 + 劲 + 势

**理论毕业标准**：全部顶级装备组合 → 5 会意 + 8 势，这是会意流派的最优配置。 


### 会心大外流（裂石 / 破竹 / 牵丝均可）

**适用范围**：主武器 大外类武器 + 副武器 大外类武器

**神力词条要求**：
| 部位 | 要求 | 缺失判定 |
|------|------|--------|
| 主武器 | 必须主武学增伤（按选定流派） | 垃圾 |
| 副武器 | 无神力要求 | — |
| 环、佩 | 必须全武学增伤 | 垃圾 |
| 冠胄、胸甲 | 无神力要求 | — |
| 胫甲、腕甲 | 必须对首领增伤 | 垃圾 |

**转律优先级**：大外、劲、敏、会心、小外、大无相

**可用词条库**：大外、劲、敏、会心、小外、大无相 + 势、精准

**各部位顶级判定**（仅看非首词条）：

| 部位 | 词条组成 | 顶级条件 | 备注 |
|------|--------|--------|------|
| **主武器** | [大外(首) + 主武学增伤 + 大外] + 可用 * 2 | 出现 大外，且不含 小外、大无相、会心、精准、势 | — |
| **副武器** | [大外(首) + 大外 + 劲] + 可用 * 2 | 非首同现 大外+劲，且不含 小外、大无相、精准 | 可含1条会心 |
| **环、佩** | [大外(首) + 全武学增伤 + 大外] + 可用 * 2 | 出现 大外，且不含 小外、大无相、会心、精准、势 | — |
| **冠胄、胸甲** | [会心/精准(首) + 大外 + 劲] + 可用 * 2 | 非首同现 大外+劲，不含 小外、大无相、势，且无2条精准 | 可含首精准/会心 |
| **胫甲、腕甲** | [劲(首) + 对首领增伤 + 大外] + 可用 * 2 | 出现 大外，且不含 小外、大无相、会心、精准、势 | — |

**流派专属定级规则**：

- 缺陷词条（非首，命中即判「能用」）：
  - 势（大外流不需要势）
  - 精准 + 会心 同现
- 缺劲不构成缺陷（可转律调出），无缺陷即判「优秀」
- **非首缺大外 → 硬门槛，上限「能用」**

**各部位顶级判定**（仅看非首词条）：

| **副武器** | [小外(首) + 小外 + 敏] + 可用 * 2 | 非首同现 小外+敏+大无相，且 会心/精准 ≥1 | 可含1条本命率 |
| **环、佩** | [小外(首) + 全武学增伤 + 小外] + 可用 * 2 | 出现 小外，且不含 小本属、会心、精准 | — |

- 缺陷词条（非首，命中即判「能用」）：

  - 精准 + 会心 同现
- **注意**：势是库外废词条，出现即判垃圾
- 无缺陷即判「优秀」
- **非首缺小外 → 硬门槛，上限「能用」**

**顶级装备模型**（展示一种典型组合）：
- **主武器、环、佩**：增伤 + 小外 + 小外 + 敏 + 大无相
- **副武器**：小外 + 小外 + 敏 + 大无相 + 会心
- **冠胄、胸甲**：会心 + 小外 + 敏 + 大无相 + 精准/会心
- **胫甲、腕甲**：会心/精准 + 对首领增伤 + 小外 + 敏 + 大无相


### 治疗流派·纯奶（牵丝·霖）

**适用范围**：主武器 扇 + 副武器 伞

**神力词条要求**：
| 部位 | 要求 | 缺失判定 |
|------|------|--------|
| 扇(主) | 必须扇武学增效 | 垃圾 |
| 伞(副) | 无神力要求 | — |
| 环、佩 | 必须全武学增伤 | 垃圾 |
| 冠胄、胸甲 | 无神力要求 | — |
| 胫甲、腕甲 | 无神力要求 | — |

**转律优先级**：大外、劲、小外、敏、会心、大无相、大本属

**可用词条库**：大外、劲、小外、敏、会心、大无相、大本属 + 势

**各部位顶级判定**（仅看非首词条）：

| 部位 | 词条组成 | 顶级条件 | 备注 |
|------|--------|--------|------|
| **扇(主)** | [大外/小外(首) + 扇武学增效 + 大外/小外/劲] + 可用 * 2 | 不含 会心、大无相、小无相 → 顶级 | 否则优秀 |
| **伞(副)** | [大外/小外(首) + 大外/小外/劲*2] + 可用 * 2 | 不含 大无相/小无相，敏和会心不同现 → 顶级 | 否则优秀 |
| **环、佩** | [大外/小外(首) + 全武学增伤 + 大外/小外/劲] + 可用 * 2 | 不含 大无相/小无相，敏和会心不同现 → 顶级 | 否则优秀 |
| **冠胄、胸甲** | [会心(首) + 大外/小外/劲*2] + 可用 * 2 | 不含 大无相/小无相 → 顶级 | 否则优秀 |
| **胫甲、腕甲** | [劲(首) + 对玩家增效 + 大外/小外/劲] + 可用 * 2 | 不含 大无相/小无相，敏和会心不同现 → 顶级 | 否则优秀 |

**流派专属定级规则**（非首，按垃圾→能用→优秀→顶级顺序首命中终判）：

- **垃圾**：势/大无相/大本属 合计 ≥2
- **能用**：势 + 会心 同现
- **优秀**：势 ≥1（无法突破至顶级，因势和会心互斥）


### 治疗流派·火拳奶（牵丝·霖输出向）

**适用范围**：主武器 扇 + 副武器 伞（与纯奶相同，但配置和词条库不同）

**神力词条要求**：
| 部位 | 要求 | 缺失判定 |
|------|------|--------|
| 扇(主) | 无固定增伤要求 | — |
| 伞(副) | 无神力要求 | — |
| 环、佩 | 无固定武学增伤要求 | — |
| 冠胄、胸甲 | 必须单体奇术增伤 | 垃圾 |
| 胫甲、腕甲 | 必须对首领增伤 | 垃圾 |

**转律优先级**：大外、劲、小外、敏、会心、大无相、大本属

**可用词条库**：大外、劲、小外、敏、会心、大无相、大本属 + 精准、势

**各部位顶级判定**（仅看非首词条）：

| 部位 | 词条组成 | 顶级条件 | 备注 |
|------|--------|--------|------|
| **扇(主)** | [大外(首) + 大外 + 小外/劲] + 可用 * 2 | 不含 大无相，敏和会心不同现 → 顶级 | 否则优秀 |
| **伞(副)** | [大外(首) + 大外 + 小外/劲] + 可用 * 2 | 不含 大无相，敏和会心不同现 → 顶级 | 否则优秀 |
| **环、佩** | [大外(首) + 大外 + 小外/劲] + 可用 * 2 | 不含 大无相，敏和会心不同现 → 顶级 | 否则优秀 |
| **冠胄、胸甲** | [会心/精准(首) + 单体奇术增伤 + 大外] + 可用 * 2 | 不含 大无相 → 顶级 | 否则优秀 |
| **胫甲、腕甲** | [劲(首) + 对首领增伤 + 大外] + 可用 * 2 | 不含 大无相/会心/精准 → 顶级 | 否则优秀 |

**流派专属定级规则**（非首，按垃圾→能用→优秀→顶级顺序首命中终判）：

- **能用条件**（命中即判「能用」）：
  - 大外全缺（所有部位都没有大外）
  - 主/副武器/环佩：劲+大外同缺
  - 势 ≥1 且 会心/精准 ≥1
- **优秀**：势 ≥1（无法突破至顶级，受势的限制）



## 调律材料添加策略

### 狗粮添加机制

调律时自动投入狗粮提升词条品阶，采用**有序规则匹配**：

- 每轮自上而下逐条判定，首条命中即生效，全部不命中则本轮不添加
- 每条规则包含：
  - **触发条件**：首词条百分比 / 装备期望评级 / 装备品阶
  - **动作**：添加狗粮类型（或不添加）
  - **材料不足处理**：跳过 / 终止 / 询问用户
- 可在 UI「调律配置 → 材料配置」自由增删规则

**默认规则**：

| 优先级 | 首词条数值 | 期望评级 | 添加材料 | 说明 |
|--------|----------|--------|--------|------|
| 1 | ≥ 98% | ≥ 顶级 | 彩狗粮 | 顶级装备最后冲刺 |
| 2 | ≥ 90% | ≥ 优秀 | 金狗粮 | 优秀装备稳定提升 |

**注意**：金色品阶装备词条默认至少紫色以上，故添加紫狗粮无效（会被忽略）。

### 律准石管理

- 主调律材料，用于打开词条调律次数上限
- 可选的**大律准石数量检查**：
  - 若当前库存低于配置基准 → 判「材料不足」
  - 按配置选择：跳过该装备 / 终止全部调律 / 询问用户是否继续
