# v0.3.1 — 毕业率计算系统 + 战斗属性面板 + DSL 增强

## 律匠 v0.3.1

本版本新增全流派毕业率计算系统（11 个流派），战斗属性 Tab 与装备状态页 UI 重构，DSL 引擎增加 click/drag 时序控制与数据类型增强。

---

### ✨ 新增功能

**毕业率计算系统**
- 全流派毕业率计算器：抽象基类 + GenericCalculator 通用实现，从 JSON 数据文件加载
- 11 个流派完整支持：鸣金·虹/影、裂石·威/钧、牵丝·玉/霖/翊、破竹·尘/风/鸢/樽
- Excel 数据自动提取脚本：从原始 Excel 计算器提取技能轴/技能定义/增益效果
- 桥接函数动态适配：按流派自动设置主属性（鸣金/裂石/牵丝/破竹）与主武器增伤
- 战斗属性面板集成毕业率实时展示卡片（DPS + 毕业率百分比）

**DSL 引擎增强**
- click/drag 时序控制：`before` / `after` combo 支持
- generalized tuple 通用元组语法
- clock/datetime 拆分：独立的时间与日期时间类型

**战斗属性与装备**
- 战斗属性数据模型（CombatAttributes）与玩法配置持久化
- 装备指纹共享函数与自动调律委托
- 新增流派「破竹·樽」配置
