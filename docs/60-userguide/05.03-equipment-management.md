# 5.3 装备管理与编辑

装备面板分为上方八个当前方案槽位和下方未穿戴装备网格。真实装备以扫描结果为准；模拟装备用于校正、对比和假设计算。

---

## 筛选与排序

装备网格支持以下条件：

| 条件 | 选项 | 影响 |
|---|---|---|
| 排序 | 默认、等级倒序、等级正序 | 只改变展示顺序 |
| 部位 | 全部或八个槽位 | 武器会按当前流派主副类型分组 |
| 品阶 | 全部、金装、紫装、白装 | “白装”包含蓝、绿以及其他非金非紫装备 |
| 等级 | 全部或最低等级 | 同时传给最优组合窗口 |
| 词条 | 全部、已定音、满调律、未满调律 | “未满调律”指普通词条不超过四条 |
| 状态 | 全部、备战中、未备战 | 按装备是否被任意备战方案引用筛选 |
| 类型 | 全部、背包、模拟 | 只控制装备网格的数据来源 |

点击上方槽位也会切换部位筛选；再次点击同一槽位会取消筛选。筛选配置按用户保存，切换用户后会恢复各自设置。

排序和类型始终显示。部位至状态属于一组可折叠筛选：点击状态右侧的向左箭头图标可收起整组，收起后点击原位置的向右箭头图标即可展开；收起不会清空已经选择的条件。

当前方案已经穿戴的装备不会在下方网格重复出现。被其他备战方案使用的装备仍可显示，并带有备战标记。

## 穿戴与卸下

在下方装备卡片上右键选择 **「装备」**：

- 防具和首饰直接进入对应槽位；
- 武器必须匹配当前方案解析出的主、副武器类型；
- 主副武器类型不同且匹配唯一时自动路由；
- 主副同型或信息不足时弹出槽位选择；
- 与当前流派两种武器都不匹配时拒绝穿戴，应新建正确流派的方案。

在上方已穿戴槽位右键选择 **「卸载」**，只清空当前方案的槽位引用。装备仍保留在公共装备池，并重新出现在下方网格。

任何穿戴变化都会触发战斗属性和毕业率重新计算。

## 真实装备为什么不能直接编辑

真实装备代表 OCR 对游戏状态的记录。允许直接改写会使本地数据与游戏脱离，并让后续重新扫描产生难以解释的重复指纹。

真实装备支持：

- 穿戴、卸下；
- 复制为模拟装备；
- 删除；
- 导出。

如果只是识别错误，应优先修正识别配置后重新扫描。如果要快速验证“这件装备数值正确时毕业率是多少”，使用复制功能生成模拟装备。

## 模拟装备

点击顶部 **「模拟装备」**。创建对话框允许设置：

- 部位和武器类型；
- 装备名称；
- 等级、金/紫品阶、承音状态；
- 由部位、等级和品阶自动生成的装备基础属性；
- 宫、商、角、徵、羽五条普通词条；
- 定音词条；
- 自定义、满数值、满承音三种词条填充模式。

词条下拉来自游戏配置，并按装备部位限制。数值旁会显示当前等级的上限和占比，便于构造可实现的装备。

创建成功后，装备带有“模拟”标签和 `mock_` 指纹。页面会自动切换到模拟类型，并清除可能遮挡新装备的部位、品阶、词条和状态筛选。

创建窗口底栏左侧提供 **「删除全部模拟装备」**。该操作会在二次确认后删除当前用户的全部模拟装备，并清空所有备战方案对这些装备的引用；真实装备不受影响。

类型选择 **「模拟」** 后，页面显示 **「批量复制装备」**。进入批量模式后，普通筛选栏和已穿戴槽位暂时隐藏，当前用户的全部模拟装备统一进入左上角复选模式。可全选或逐件选择，再通过 **「复制到…」** 同时勾选一个或多个其他用户。复制只把独立装备写入目标用户的未穿戴装备池，不复制备战方案引用，也不会让后续编辑和删除跨用户联动。目标用户已有相同装备时跳过；同指纹内容冲突时不会覆盖。

## 复制真实装备进行校正

在任意装备卡片右键选择 **「复制」**：

1. 系统深拷贝该装备；
2. 名称追加“【复制】”；
3. 打开模拟装备对话框；
4. 修改识别错误或构造目标数值；
5. 保存为新的模拟装备。

原真实装备不会被修改。这是比较 OCR 数据与人工校正数据最安全的方式。

## 编辑模拟装备

模拟装备在未穿戴网格和已穿戴槽位中都可以右键编辑。

编辑可能改变指纹。系统会先写入新装备并迁移方案引用，再清理不再被任何方案使用的旧指纹，避免编辑过程中丢失装备。若旧模拟装备仍被其他方案引用，它会继续保留。

## 删除装备

| 操作 | 结果 |
|---|---|
| 删除真实装备 | 从公共装备池移除，并清空所有方案中的对应引用 |
| 删除模拟装备 | 同上，但只针对该模拟装备 |
| 删除筛选装备 | 只删除当前筛选命中的未穿戴真实背包装备；确认框会列出数量和全部筛选条件 |
| 删除全部模拟装备 | 删除当前用户全部 `mock_` 装备，并清空相关方案引用 |
| 删除备战方案 | 删除槽位组合，不删除公共装备池中的装备 |

当前方案已穿戴装备不会进入“删除筛选装备”的目标集合。该按钮不支持模拟装备：类型选择“模拟”时按钮隐藏，其他类型下确认框中的类型固定显示为“背包（此处不支持删除模拟装备）”。被其他方案引用但未在当前方案穿戴的真实装备可以被筛选删除，删除后对应方案引用会一并清空。

上述批量删除均会二次确认，且不可撤销。

## 合并承音前后的装备快照

手动承音、传律或再次转律后重新扫描时，同一件实体装备会因等级、数值或转律词条变化而产生新指纹。点击顶部 **「承音装备」** 会遍历全部用户，查找疑似历史快照。

只有双方都属于“支持承音”的等级、同部位与同品阶、恰好五条普通词条并存在定音的真实装备才会参与比较。装备名称、套装和定音内容不作为身份依据；普通词条位置必须一致，可比较的同名词条数值只能整体提高，不能出现一部分 A 较高、另一部分 B 较高。首次转律允许固定槽位由未转律变为转律；双方都已转律且词条名变化时，两边等级都必须支持“无限转律”。转律槽位不能移动，第一词条不能转律。

候选会以两列可滚动卡片展示，每组都标明用户名，左侧为待删除的旧版本，右侧为保留版本。逐组核对并勾选“合并”，再点击底部固定的 **「合并选中项」**。系统会在装备所属用户中迁移所有备战方案引用并删除左侧快照；不会自动合并未勾选的装备，也不会把不同用户的数据互相合并。

## 冷却装备

装备扫描记录了冷却到期时间。冷却已经到期的装备会在卡片右上角显示 **“!”**；卡片状态会在进入页面、装备数据变化或手动刷新时重新计算。

在装备卡片的 **「属性」** 窗口中，可以查看冷却到期时间及“天、小时、分钟”倒计时，并执行：

- **清除冷却时间**：移除该装备的冷却记录；
- **重置冷却时间**：把到期时间设置为当前时间五天后。

点击顶部 **「冷却装备」** 可查看所有用户存在合法冷却时间的装备。对话框默认以六列可滚动网格展示，每项包含用户名、冷却倒计时和复用的装备卡片，并按到期时间升序排列，最早到期的装备在前。卡片右键只开放“属性”，可从中清除或重置冷却。

## 导出数据

点击 **「导出数据」** 可以导出 leoq7 V2 文本格式。导出内容包括：

- 当前方案已穿戴装备；
- 真实背包装备；
- 当前装备页的等级和词条筛选条件会应用到真实背包装备。

已穿戴装备不受这两项筛选影响，模拟装备当前不会导出。页面上的部位、来源和排序条件也不影响导出内容。

文件默认命名为：

```text
{用户名}_leoq7.txt
```

导出文本用于粘贴到 leoq7 兼容工具。目前装备页没有对应的导入按钮，它不是可直接恢复到本地仓储的备份文件。

## 建议的编辑原则

- 真实装备只通过扫描产生，以游戏数据为准；
- 识别错误先复制为模拟装备验证，再修正 OCR；
- 假设未来装备时创建模拟装备，不要覆盖真实装备；
- 计算真实毕业率时排除模拟装备并关闭三个满值开关；
- 删除前先检查它是否被其他备战方案使用。
