# v0.2.3 — 玩家档案增强 + 自动购买不肝 + 引擎动态引用

## 律匠 v0.2.3

本版本重点增强玩家档案模块：历史表新增来源追踪、配额进度可视化、模块化拆分；新增自动购买不肝工作流；引擎 PanelRef 支持动态引用。

---

### ✨ 新增功能

**工作流**
- 新增 `purchase_bugan` 自动购买不肝工作流
- 新增对应场景 `bugan_detail`（不肝购买详情页）

**引擎**
- PanelRef 的 `scene` / `panel` 字段支持 `$var` 动态引用，可在运行时解析变量

**玩家档案**
- 历史表新增 `source` 列，记录每条变更的来源（定时 / 操作 / 覆写）
- 来源词表管理：可在 UI 中查看、新增来源标签
- 快捷菜单与自定义对话框适配 source 列
- 配额周期（周/月）按进度着色：
  - 绿色：已达上限
  - 红色：距重置 ≤ 48 小时且未达上限
  - 橙色：周期过半但未达一半
- Tooltip 显示"距重置: X天 Y小时"

---

### 🔧 修复

- profile_tab: `_sync_to_stock` 日志格式 `:+d` → `:+g` 兼容 float delta，避免格式化异常

---

### 📦 重构

**玩家档案 UI 模块化**
- 将 1867 行的 `profile_tab.py` 与 777 行的 `profile_settings_dialog.py` 拆分为 `ui/profile/` 子包（6 个文件）：
  - `__init__.py`：对外导出 + `__getattr__` 延迟导入，保持"插件 import 不触发 PyQt6"约定
  - `cell_formatting.py`：单元格格式化 + 配额周期辅助纯函数
  - `dialogs.py`：`HistoryDialog` / `ask_value_dialog` / re-export `ProfileDefinitionDialog`
  - `overview.py`：`ProfileOverviewTab` 主类（宽表 + 分组管理）
  - `settings_dialog.py`：`ProfileDefinitionDialog`（原文件整体迁移）
  - `tab.py`：`ProfileTab` + `_DetailPage` + 共享常量 `REFRESH_BTN_STYLE`
- 删除已完成使命的 `scripts/migrate_profile_json_to_sql.py`

**脚本**
- `count_file_and_code.py` 改为仅统计 `src` 和 `docs` 目录
