# v0.13.10 — 多执行目标、移动设备增强与破竹毕业率更新

> 本文以 v0.13.9 正式版（提交 `5a7bc05e`）为基线。

本轮把“已经连接到什么”和“下一项任务实际在哪执行”正式拆开：一个窗口和多台 Android
设备可以同时保持连接，任务只使用当前明确选中的执行目标。移动设备工具补上独立的设备
扫描页，并修复 0.13.9 首次开放后暴露的线程、体检、安装与手势测试问题。

燕云侧更新了破竹毕业率数据和 115 级破竹·风基础方案；装备与套装相关界面统一采用
游戏标准称呼“攻具”。

## ⚠️ 不兼容变动与升级指引

### 1. 新连接不再自动抢占当前执行目标

- **现象：** 窗口与 Android 设备现在可以同时保持连接；在已有执行目标时再连接另一端，
  新连接不会自动成为任务目标。任务启动前会使用连接控制台左侧明确选中的目标。
- **原因：** 旧版把“最后连接的平台”同时当成连接状态和任务目标，扫描窗口会拆掉设备，
  扫描设备也会清除窗口，无法在两端之间快速切换。现在连接集合与执行选择彼此独立。
- **如何调整：** 连接另一端后，如需在那里运行任务，请在执行目标列表中点选对应目标。
  首个成功连接的目标仍会自动选中。任务运行期间目标冻结，需停止任务后才能切换。

### 2. 截屏与录屏改存到统一的采集目录

- **现象：** 新生成的截图位于 `data/capture/picture`，录屏位于
  `data/capture/video`；旧版 `data/picture`、`data/video` 中的历史文件不会出现在新目录。
- **原因：** 截图和视频统一归入 `data/capture`，避免运行数据继续散落在 `data` 根目录。
- **如何调整：** 无需迁移即可继续使用；需要查看旧文件时仍到旧目录。想集中保存可自行把
  旧文件移动到新目录。安装器与 APK 不会删除个人采集文件。

### 3. 毕业率 Excel 中被实际使用的错误单元格不再静默忽略

- **现象：** 导入的 Excel 若在计算实际引用区域内含 `#REF!`、`#VALUE!` 等错误值，
  现在会明确拒绝并指出来源，不再继续生成看似正常但数值错误的方案。
- **原因：** 旧版会把部分 Excel 错误折叠成空值，错误可能直到毕业率异常时才被发现。
- **如何调整：** 根据错误提示修复对应公式或单元格后重新导入。未被方案实际使用的区域
  不会因此阻止导入。

### 4. 破竹毕业率系统数据已更新

- **现象：** 破竹相关方案的毕业率、最优组合和属性分析结果可能与 0.13.9 不同；新增
  115 级破竹·风基础方案，并更新破竹·樽方案版本及配套计算表。
- **原因：** 本版本纳入了新的社区竞速毕业率数据与基础方案。
- **如何调整：** 使用随包系统方案无需操作。若在 `config/local` 保存过同名方案或自行
  导入过旧表，本地配置仍会优先于 system；需要新口径时请重新导入或删除对应本地覆盖。
  Windows 便携版仍应解压到新目录，再复制 `config/local` 与 `config/session`，避免旧的
  system 文件残留。

## ✨ 新增功能

### 窗口与多台设备同时连接，显式选择执行目标

- Windows 目标与 Android 目标不再互斥：窗口最多一个，Android 设备可以连接多台。
- 连接控制台左侧集中展示执行目标、连接信息和状态信息；目标行支持断开、重新连接，
  窗口目标支持刷新位置。
- 任务启动时冻结目标的截图、输入方式和环境快照；运行中查看或刷新非执行目标不会改道。
- 连接控制台可以折叠，主界面只查看备战方案时不再长期占用空间。
- 前台/后台输入、前台/后台截图、scrcpy 流式截图和设备端执行改由目标右键菜单配置，
  连接状态与配置草稿不再混成一组复选框。

### 移动设备工具增加设备扫描

“工具 → 移动设备”新增“设备扫描”页，与主界面共用局域网、本机模拟器端口和 USB ADB
扫描后端。即使当前已有 ADB 设备连接，也可以独立发现并连接其他设备，不必先断开现有目标。

### Profile 多值变动规则编辑

Profile 数据模型的变动规则现在可以在一行中编辑多个数值和多个来源/用途。旧的单值
`value/source` 格式继续可读；用户再次保存时按当前编辑结果写出多值结构，不会自动把既有
规则强行合并。表格按实际行数调整高度，把更多空间留给变动规则。

## 🔧 修复

- **移动设备窗口二次打开崩溃。** 关闭后残留的 Qt 对象引用会访问已删除的对话框；现在
  入口会识别失效对象并重建。
- **移动设备后台线程可能在关窗时触发原生崩溃。** 下载、哈希、安装、扫描和代理体检
  统一接入可取消的线程生命周期，窗口不再在工作线程尚未退出时销毁其 Qt 父对象。
- ADB 安装、设备列表和本地 APK 检查移出 GUI 线程，避免界面最多冻结数分钟。
- 设备体检保留握手已取得的协议、版本和权限状态，协议不匹配或无障碍未开启时不再全部
  退化成笼统的“未连接”；后台异常后按钮也会恢复。
- 手势实测现在真正把双路时间线下发到设备，而不是只完成连接与能力查询。
- Android 自带任务不再因入口模块导入 PyQt6 而失败，手机端可以正常打开调律参数等页面。
- ADB 当前应用探测兼容空的进程输出，不再记录 `NoneType.strip` 告警。
- 设备切换、APK 哈希与本机共享服务补齐任务对象校验，避免报告标错设备或二维码继续分发
  上一个 APK。
- 装备识别读到套装说明后，不再把说明区域中的文字当成后续五音词条并制造顺序告警。
- 毕业率 Excel 的错误传播和来源校验更准确；方案等级标签与来源文件保持一致。

## 📦 重构

- 连接目标由独立会话模型保存，运行入口只消费明确选择的目标快照；窗口定位和设备连接
  不再互相拆除后端。
- scrcpy 服务端文件从单文件目录迁入 `data/adb`，与随包 ADB 资源统一管理。
- 截图与录屏输出收拢到 `data/capture/picture` 和 `data/capture/video`。
- 燕云装备领域文案统一为“攻具 / 防具”；内部稳定 key、武器类型和词条分类“武器类”
  保持不变，不产生配置迁移。

## ⚠️ 已知限制

- 同一时刻仍只允许一个任务运行；多目标连接用于保留连接并快速切换，不代表多个任务并行。
- 任务运行期间不能更换执行目标。运行目标掉线时按现有暂停/停止边界处理，不能在运行中
  通过目标列表重新连接后热切换。
- 后台截图仍是实验性能力，很多脚本暂时无法在该模式下跑通，该模式下的功能不可用问题
  暂不受理。
- 115 级毕业率数据仍取决于已导入的社区表格；未更新的流派继续使用其现有最高等级方案。
