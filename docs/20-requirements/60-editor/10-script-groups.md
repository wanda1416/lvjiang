# 脚本展示分组与刷新

> 状态：已实现（2026-10-13，基线 v0.15.0）。

## 范围与边界

- 脚本可通过可选字符串 `group` 声明展示分组，缺省或空白显示为「未分组」。
  分组不改变 `scope`、运行能力、批量配置或脚本顺序。
- 日常页第一行是全宽脚本选择，第二行是分组选择、刷新、加载；默认展示全部。
  脚本选择与展示分组保存在 `interface.json` 的 `daily.workflow_id`、`daily.group`，
  启动时先恢复分组再恢复脚本；无记录或分组已不存在时展示全部。
  分组筛选不自动改变持久化的默认脚本，只读节点的选择只在内存生效。
- 刷新重新发现脚本和元数据，保留有效选择及已编辑参数；临时加载的脚本继续保留。
  批量页只刷新候选，不重置本次执行顺序和勾选，也不改变已启动任务的快照。
- 元数据表单编辑分组；脚本配置页只读展示分组，不提供分组覆盖。
- 显示名不同于作者原名时加粗并使用主题强调色，提示原名；这表示名称覆盖，
  不是未保存状态。恢复原名后取消标记，保存和重新打开后仍正确展示覆盖。
- 执行用户和当前配置使用无冒号标签、相同标签列宽与间距，下拉框左边缘对齐。

## 验证契约

筛选与刷新不能写入默认脚本选择；按稳定脚本 ID 查找参数，不能用筛选后索引
访问全量目录。表单往返保留分组；配置页分组不可编辑，改名标记在保存、撤销
和排序后保持正确。
