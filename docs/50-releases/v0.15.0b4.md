# v0.15.0b4 — 配置刷新与备战扫描（Beta4）

本版本是 0.15.0 的第四个测试包，供手动下载测试，不替换当前正式版 0.13.15，
不向普通客户端提示更新。相对正式版的完整升级注意事项见 [Beta1 说明](v0.15.0b1.md)，
一次性激活及 MCP 接入调整见 [Beta3 说明](v0.15.0b3.md)。

## ⚠️ 不兼容变动与升级指引

- **配置基底记录移入 config/session/baseline.json。** 原位置不再读取，安装器会清理旧文件。
  请使用完整新包升级，不单独替换可执行文件。便携包解压到新目录后再复制
  config/local 和 config/session；保留新包的 baseline.json，跳过旧 content.json 与 config.lock。
  安装器及 APK 保留个人数据。
- **手动修改场景或布局后需要刷新。** 任务按修订索引复用配置；手工修改文件不会自动更新索引。
  请在场景管理点击「刷新」或重启应用，未保存的编辑需先自行保存或撤销。
  正常编辑保存会更新修订索引，无需额外操作。local 覆盖始终优先；改过的系统配置需自行同步本地覆盖。
- PC 与 APK 测试同步时请同时升级到 0.15.0b4。在线配置仍按 0.15.0 系列匹配，
  Beta4 的更新状态独立位于 updates/v0.15.0b4；不要复制其他 Beta 的更新状态。
- **备战方案管理改为显式保存。** 编辑、排序、新建和删除先进入草稿，点击「保存」才写入；
  放弃未保存改动不会改变主页面的活动方案。

## ✨ 新增功能

- 场景管理顶部提供「刷新」，从磁盘重新加载场景和布局；保存时遇到后台修改会提示是否覆盖。
  场景支持一次隐藏全部视图，配置来源只展示本地或系统，不再展示内部修订号。
- Profile 的变更脚本可勾选「同步修改」：在数据写入前执行，脚本拒绝或失败时整条数据库变更回滚；
  默认仍为异步执行。脚本可按来源、时间和增减方向聚合历史记录，实现来源限额。
- 历史记录支持确认后直接删除；只删除所选记录，不修改当前数值、不追加删除记录。
  依赖历史累计的限额会随记录删除而变化，请谨慎使用。
- 不肝商店支持逐战商店购买及配额记录，并完善进度同步。

## 🔧 修复

- 扫描全部备战方案遇到历史定音提示时，只选择「改用当前定音」，不点击消耗玉的「确认」。
  安全按钮识别失败或弹窗未关闭时保存截图并停止扫描。
- 打开菜单后首次未识别到菜单，会保存截图并延迟二次确认，避免仅因界面显示较慢立即中断。
- 修正批量重启过程的共享状态传递和心法开箱数量参数，保留原任务上限。
- 调整 Profile 编辑区域、备战方案表格列宽与双击编辑行为。

## 📦 重构

- 任务按配置修订复用场景和布局解析，执行中保留本次配置快照；开发版不安装在线包，发行版继续加载对应版本的在线配置。
- 代理和 ADB 共用连接恢复流程，沿用高级设置中的重试、降级及用户确认选项。
- 反馈二维码改为联网获取并缓存到 session，不再随安装包预置。
