# 词条大全

《燕云十六声》装备普通词条的名称、出现部位与单位。这是**游戏事实**，与律匠如何解析、
评级无关；结构化字段与解析流程见
[装备领域模型](../30-architecture/31-models/01-equipment-models.md)。

数值范围与稀有规则尚未整理（见 [本层索引](README.md) 的待补清单）。词条上限随赛季等级
变化，属于机制约定，登记在 [游戏机制约定](06-mechanics-conventions.md)。

## 与赛季的关系

词条**注册**与词条**产出**是两件事：注册表保留全部历史词条（OCR、旧装备加载与真实值
计算都要用），产出范围只控制某个等级能否调律出该词条。南吕相和把单体 / 群体奇术增伤
的产出截止在 110、把全奇术增伤开放到 115——口径见
[南吕相和赛季](07-nanlu-season.md)，历史装备不因停产出而失效。
