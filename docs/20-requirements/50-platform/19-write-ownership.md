# 主节点写入与用户占用

> 状态：已实现（2026-10-13，基线 v0.15.0）。

## 边界

- 同一客户端目录只有主节点修改共享配置；只读节点不落盘配置、选择、迁移或修订索引。
- 只读节点的活动选择、日常筛选和窗口展示状态只在本实例内生效。
- 同一用户任务占用独立于主节点身份。用户数据写入复用该占用门禁，不为资料、装备、便签
  等文件另建锁；只读节点仅能在已授权任务上下文写其执行用户的数据。
- 配置保存、安装与快照读取只在进程内协调；消费者刷新不持安装临界区。
  阻塞调用等待当前操作完成，不设固定超时；非阻塞探测取不到锁时返回失败。
  安装后的修订索引重建仍在临界区内，与安装内容保持一致，插件与 UI 消费者刷新在锁外执行。
- 用户数据写入从占用检查到序列化、原子写盘结束均持进程内全局占用互斥锁，期间其他用户
  的写入及占用获取/释放也会等待。该边界防止写入中途释放或抢占用户；写入回调不得等待
  另一个需要占用锁的线程，也不应包含网络请求或消费者刷新。
- 长期内存 Session 保存合并本次变化，同字段磁盘冲突拒绝覆盖；批量编辑保存检查加载基线，
  磁盘已改变时由用户确认是否覆盖。原子文件替换、数据库事务和跨文档恢复日志保持不变。
- 客户端内部文件锁只保留主节点所有权和用户占用。外部 Agent 接入文件的锁不属于本轮清理。
- 旧锁不在启动时自动清理；停机维护只删除明确废弃的锁，不删除用户数据和仍在使用的占用锁。

## 验证

验证主节点/只读节点配置写入边界、授权用户写入、快照冲突、安装后回调与快照的协调，以及
用户执行互斥。测试仅使用临时目录，不访问真实 Session/Profile。

停机维护脚本见 [废弃锁清理](../../../scripts/one_off/README.md)。只读节点的
用户界面筛选也只保留在内存，不会创建用户文档侧车锁。
