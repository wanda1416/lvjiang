# v0.2.5 — 批量生命周期重构 + 调律规则增强 + 模拟调律

## 律匠 v0.2.5

本版本重点：批量执行四阶段生命周期重构；调律规则系统支持禁用与全量枚举；新增模拟调律功能。

---

### ✨ 新增功能

**批量执行**
- 四阶段生命周期重构：`batch_setup` → `prepare_item` → `finish_item` → `batch_teardown`，脚本执行流程更清晰

**调律规则**
- 支持规则禁用（`enabled: false`）
- 全量规则枚举：可列出所有可用规则
- 调律配置对话框增强
- 调律设置页面增强

**装备判定**
- 新增模拟调律功能（`equip_judge_dialog`）
