# v0.1.4 — 图库空间配置拆分 + 布局别名 + 调律交互增强

## 律匠 v0.1.4

本版本聚焦图库空间配置独立化、布局别名机制、调律流程交互增强，以及场景编辑器 UI 持久化修复。

---

### ✨ 新增功能

**图库空间配置**
- 多空间独立配置集：每个空间拥有独立的 references.yaml、layouts.yaml 等配置
- 调律启动预检：自动校验激活空间的配置完整性
- 空间栏增强：新增"激活空间"按钮与当前激活空间状态显示

**布局别名机制**
- 支持 extends 继承：别名布局复用父布局的场景定义，仅画布配置独立
- 截图独立管理：别名布局使用自己的截图目录，避免污染父布局
- 禁止别名布局另存为：防止误操作破坏继承语义

**调律流程交互**
- 材料不足三选项对话框：继续调律 / 跳过当前装备 / 结束本次调律
- 结束本次调律按标准流程返回游戏主页（区分用户中断 F10）

---

### 🔧 修复

- 场景编辑器 UI 状态持久化：main_window 改为 read-modify-write，不再覆盖 scene_editor_* 字段
- 新建空间移除预填字段：meta_schema 初始化为空，避免业务侵入
- 场景编辑器识别结果按场景定义顺序展示
- 材料识别逻辑：count=None 视为装备而非材料，按不足处理（count=0）

---

### 📦 重构

**图库管理**
- references.yaml 退化为名册：实际配置由空间目录提供
- 编辑区/批量区/筛选区仅展示 input 字段，output 字段（OCR 结果）不可编辑
- 元数据输入/输出场景划分：明确 input/output 语义边界

**材料识别**
- 材料识别与背包网格从独立 region 迁移到 panel grid
- 统一使用 panel 坐标系，提升识别准确性
