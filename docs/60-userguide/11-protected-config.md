# 官方在线配置与会员内容

以下为 0.15.0 新协议；旧客户端仍使用原有更新机制。

开启设置中的“接收在线配置更新”后，PC 在启动检查中获取与本应用版本匹配的官方更新。
场景、布局、默认规则及已有任务都可以在线修正；校验成功后立即应用，不需要重启。
正在执行的任务（包括一整批任务）使用启动时的配置，新任务使用更新后的内容。
网络失败保留当前可用内容，不影响启动。

自己的 local 配置始终优先；若某处修正看不到，请检查是否有本地覆盖。
更新不会删除你的设置、数据库或未保存草稿。编辑窗口已打开时，保存前请核对更新后的官方基底。

## 会员内容

有效 Lv1 及以上授权可获取作者发布的会员配置。服务地址内置，无需填写地址或 Token。
已有激活码无需更换，但需要作者已将其登记到内容服务。未达到等级不会请求会员服务。
未登记、已过期或被云端停用的码无法获取密钥；可联系作者检查登记状态。

临时断网保留已安装且本机授权有效的内容；云端停用需联网后才能确认。
会员包可以声明客户端兼容范围及公开配置依赖；缺少依赖时不安装半套内容。
会员内容无随包预置，下载后的密文保存在 updates/member，不进入用户 local。

## 关闭与恢复

关闭“接收在线配置更新”或进入完全离线模式，会恢复公开预置 r0 并撤下会员内容，
不删除 local、Session 或用户数据库；若恢复失败会保留完整旧配置并记录原因。
重新打开后再次检查在线内容。设置页显示已安装的公开修订 rN，而非下载候选。

极端情况下可以关闭所有律匠实例，备份后移除 config/system，再将
config/updates/v<当前三段版本>/r0.zip 解压到 config/system。压缩包根目录就是配置文件，
不要再套一层 system。若要持续使用预置，先关闭在线更新；此操作不恢复会员内容。
不要删除 system-baseline.json，也不要拿其它版本的 r0 恢复。

手机本轮不自行在线更新，使用 APK 预置或 PC 同步结果；PC 同步仍替换手机 system，
不改为 local 覆盖。手机同步参数与数据库规则见[移动设备](09-mobile-device.md)。
