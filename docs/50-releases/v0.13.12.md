# v0.13.12 — 数据模型重命名审计、搭配导入与连接控制优化

发布日期：2026-10-06。以 v0.13.11 正式标签（`727fd921`）为基线。

## ⚠️ 不兼容变动与升级指引

### 出装搭配改为独立文件，约束跟随搭配保存

- **现象：** 原 `yysls/game_config/builds.yaml` 中的自定义搭配不再出现在列表中，公共约束也不再自动应用到新搭配。
- **原因：** 每套搭配改为独立文件，词条约束由搭配自身持有，避免修改一套影响其他搭配。
- **如何调整：** 内置搭配已转换，无需操作。自定义搭配请在玩法配置中重新建立，或拆成 `config/local/yysls/gear_sets/<id>.yaml`，保留原 ID 与参数，补充 `schema_version: 2`、`content_version: 1` 和 `id`，把所需公共约束写入各自 `requirements`。出装搭配当前只支持 PVE；旧 PVP 搭配不能按新格式直接使用。具体格式见[模拟计算器指南](../60-userguide/05.07-build-calculator.md)。

### 数据模型历史自动升级，周期重置单独记录

- **现象：** 历史记录将周期重置与普通恢复区分；依赖 `change_type == "tick"` 捕获周期清零的自定义变更脚本，需要调整判断。
- **原因：** 数据库将数量变化和同步来源分开存储，周期重置明确使用 `reset`，不再混在 `tick` 中。
- **如何调整：** 数据及历史无需手工迁移。应用自动升级数据库并保留 `profile.before-v7.db` 备份；无法解释的旧详情会归档而非丢弃。自定义脚本如需处理周期重置，请判断 `reset`。不要用旧版本直接打开升级后的数据库；确需回退，请退出应用后恢复升级前备份。

### 升级安装与本地覆盖

- **现象：** 自定义过聊天场景或布局的用户可能仍使用旧区域；便携版覆盖解压可能留下已移除的系统文件。
- **原因：** `config/local` 优先于系统配置，ZIP 升级不会主动清理旧文件。
- **如何调整：** Windows 便携版解压到新目录，再复制 `config/local`、`config/session`。安装器与 APK 自动清理随包系统配置，不改用户数据。本地聊天覆盖如需使用新区域，请手动同步或删除不再需要的对应覆盖；本版本没有自动提升配置 `content_version`。

## ✨ 新增功能

- 数据模型支持通过「编辑」入口重命名 key，同时更新用户数据及结构化引用，保留独立重命名审计；普通数值历史不混入重命名记录。脚本中的引用由用户自行修改，不扫描或改写脚本。
- 用户总览分组支持拖动排序并保存，分组内数据和当前选择保持不变。
- 出装搭配支持合法的双向词条拖拽交换，显示可交换位置及拒绝原因；未满足约束直接显示在词条共享滚动区。
- 保存的搭配可导入备战方案，生成八件满值模拟装备并应用弓玦与 PVE 设置。替换前确认，原装备及其他方案不受影响，导入后不与源搭配自动同步。
- 属性配置对所有用户开放；承音装备合并增加一键勾选。玩法配置补齐匹配关键字编辑和搭配分区。
- 补齐牵丝·翊、破竹·鸢、裂石·钧的 115 级毕业率方案及对应源表；方案按等级、版本倒序展示。

## 🔧 修复

- 启动任务后仅所属页面提供停止、暂停等控制；其他任务页明确显示实际运行任务并禁用按钮，避免误操作，停止文案统一。
- 刷新窗口定位时重新校验窗口身份和坐标，失效窗口明确标为离线。
- 切换场景管理布局不再改动主页面实际执行布局。
- 数据模型数值覆写补齐同步选项并改善精度展示；备注类型隐藏无效同步配置。

## 📦 重构

- 连接控制台默认更紧凑，标题可隐藏，支持拖动扩展；优化目标切换和预览刷新开销。
- 出装搭配按独立文件管理，系统预置与本地编辑边界明确，多窗口保存冲突不静默覆盖。
- 数据模型历史改为结构化数量和同步来源；定义编辑与总览列编辑共用保存及审计入口。
