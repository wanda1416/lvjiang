# 国际化（i18n）支持框架

> **状态**：✅ 已实现（v0.2.5）
> **优先级**：P2
> **依赖**：无前置依赖

---

## 1. 背景与目标

燕云十六声有国际版，项目需要对律匠进行国际化改造，至少额外支持英语（en_US）。

### 1.1 现状统计

| 类型 | 数量（字符串 token） | 是否需要翻译 |
|------|---------------------|-------------|
| 文档字符串（docstring） | ~2,409 | 否，保留中文 |
| UI 字符串（按钮/标签/菜单/对话框） | ~955 | 是 |
| 日志消息（logger.*） | ~233 | 否，开发者日志保持中文 |
| 错误/异常消息（面向用户） | ~187 | 是 |
| 其他字符串（含 YAML 配置 label/name） | ~938 | 按需评估 |

### 1.2 目标

1. 建立全局 i18n 框架，支持通过配置切换语言
2. 首先支持中文（zh_CN）和英文（en_US）
3. 后续新增语言只需添加翻译文件，无需改代码
4. 所有面向用户的 UI 字符串、错误消息、配置显示名均走翻译通道

---

## 2. 技术方案

### 2.1 总体架构

采用 **YAML 翻译文件 + Python tr() 包装函数** 方案，不依赖 Qt 的 .ts/.qm 工具链。

```
┌─────────────────────────────────────────────┐
│              lvjiang.i18n 模块               │
│                                             │
│  init_i18n(language)  ← 启动时调用           │
│  tr(text)             ← 非 QObject 上下文    │
│  set_language(code)   ← 运行时切换（重启生效）│
│  available_languages() ← 扫描翻译文件        │
│                                             │
│  内部：加载 YAML 翻译文件 → 扁平 dict 查找    │
│  Fallback：找不到翻译 → 返回中文原文          │
└─────────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────────┐
│         config/i18n/ 翻译文件目录             │
│                                             │
│  zh_CN.yaml   ← 中文基准（所有 key 的源）    │
│  en_US.yaml   ← 英文翻译                    │
│  ja_JP.yaml   ← 未来扩展                    │
└─────────────────────────────────────────────┘
```

### 2.2 翻译文件格式

翻译文件按模块/文件分层组织，结构示例：

```yaml
# config/i18n/zh_CN.yaml
meta:
  language: zh_CN
  display_name: "简体中文"
  version: "0.2.5"

ui:
  main_window:
    title: "律匠 - 通用视觉 RPA 引擎"
    menu_general: "通用"
    # ... 按模块分层
  settings_dialog:
    title: "配置管理"
    language_label: "界面语言"

messages:
  errors:
    layout_not_found: "无法加载布局: {name}"
    panel_not_defined: "布局中未定义 panel {scene}.{panel}"
  dialogs:
    confirm_exit_title: "工作流运行中"

config:
  workflows:
    equip_analysis: "当前装备分析"
  scenes:
    group_names:
      group_1: "通用"
  delay_params:
    步骤间等待: "步骤间等待"
```

`en_US.yaml` 结构完全一致，值替换为英文。

### 2.3 tr() API

**统一使用 `tr()` 函数**，不区分 QObject 内外。`tr()` 以中文原文为 key，在翻译文件中查找对应值；找不到则返回原文（中文 fallback）。

```python
from lvjiang.i18n import tr

# UI 字符串
settings_menu = menubar.addMenu(tr("通用"))

# 含变量的字符串
QMessageBox.information(self, tr("发现新版本"),
    tr("发现新版本 v{latest}\n当前版本: v{current}\n\n是否前往下载？")
    .format(latest=latest, current=current))

# 错误消息
raise WorkflowUserError(tr("布局中未定义 panel ..."))
```

### 2.4 语言配置

在 `session.json` 的 `settings` 节点存储 `language` 字段：

- `"zh_CN"` — 中文（默认）
- `"en_US"` — 英文
- `"auto"` — 跟随系统 locale

启动时读取该配置，加载对应翻译文件。语言切换后需重启应用生效。

### 2.5 关键设计决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 翻译文件格式 | YAML | 项目已重度使用 YAML，团队熟悉 |
| 翻译 key 策略 | 中文原文作 key，找不到时返回原文 | 未翻译的条目不会空白，直接显示中文 |
| 日志消息 | 引擎日志保持中文，UI 面板日志走翻译 | 开发者调试不受影响 |
| 运行时切换 | 重启生效 | 避免热切换的 UI 重建复杂度 |
| 默认语言 | zh_CN | 当前用户群以中文为主 |
| 文档字符串 | 不翻译 | 面向开发者，保持中文 |

## 4. 验证标准

### 4.1 功能验证

1. 启动应用（默认 zh_CN），所有 UI 显示中文
2. 在设置中切换为 en_US，重启后所有 UI 显示英文
3. 未翻译的条目显示中文原文（不空白、不报错）
4. 切换回 zh_CN 时，翻译查找直接返回原文（零开销）

### 4.2 测试用例

```python
# tests/test_i18n.py
def test_tr_returns_original_for_zh_cn():
    """zh_CN 模式下 tr() 直接返回原文"""
    from lvjiang.i18n import init_i18n, tr
    init_i18n("zh_CN")
    assert tr("开始执行") == "开始执行"

def test_tr_returns_translation_for_en_us():
    """en_US 模式下 tr() 返回英文翻译"""
    from lvjiang.i18n import init_i18n, tr
    init_i18n("en_US")
    assert tr("配置管理") == "Settings"

def test_tr_fallback_to_original():
    """未翻译的条目返回原文"""
    from lvjiang.i18n import init_i18n, tr
    init_i18n("en_US")
    assert tr("这是一个未翻译的字符串") == "这是一个未翻译的字符串"

def test_available_languages():
    """可用语言列表至少包含 zh_CN"""
    from lvjiang.i18n import available_languages
    langs = available_languages()
    assert any(l["code"] == "zh_CN" for l in langs)
```

## 5. 后续扩展

### 5.1 新增语言

1. 复制 `config/i18n/zh_CN.yaml` 为 `config/i18n/{lang_code}.yaml`
2. 翻译所有条目的值（保持 key 不变）
3. 在设置对话框中自动出现新语言选项（`available_languages()` 自动扫描）

### 5.2 翻译平台集成

后续可接入 Crowdin / Transifex 等翻译平台，只需将 YAML 文件同步到平台即可。

### 5.3 字符串提取脚本

待实现：`scripts/extract_i18n.py`，扫描所有 `.py` 文件中的 `tr("...")` 调用，生成/更新 `zh_CN.yaml` 基准文件，对比已有翻译文件报告新增/删除/变更条目。

### 5.4 热切换（可选）

当前方案语言切换需重启。如需热切换：
1. `set_language()` 加载新翻译文件后发射 `language_changed` 信号
2. 各 UI 组件订阅信号，重新调用 `tr()` 更新文本
3. 复杂度高，建议非必要不实现
