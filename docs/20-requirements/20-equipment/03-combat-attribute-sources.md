# 当前方案战斗属性来源

> 状态：已实现（2026-10-07，基线 v0.13.13）。来源计算、只读窗口和标题行入口已通过定向回归及 Qt 布局检查。

入口位于战斗属性面板的「攻击属性」标题行最右侧，文字为蓝色链接「属性来源」，
字号与属性名称一致。沿用现有标题行，不增加卡片行数或高度。

页面只读展示当前面板的同一份计算快照：用户、方案、所选基础属性、流派、世界等级及
已启用假设。预览面板使用预览副本，不能读取真实穿戴代替预览数据。

逐属性列出已存基础属性、弓玦、装备套装、装备普通词条、装备定音、装备固有数值，
同时展示白字合计与黄字生效值。展开属性可查看对应部位和词条；五维词条转换后的
贡献仍归普通词条或定音，不额外累计。已存基础属性作为整体来源，暂不自动拆解。

来源计算复用公共装备归一化、词条聚合、固有值、套装、无相穿透折算和抗性处理。
同名只取最高、部位不适用等被归一化排除的词条提供说明，不能重复计入。
百分比保留两位小数，其他数值保留一位；查看和刷新不保存配置。
各来源与合计、生效值全部为零的属性直接过滤。名称、数值字号和行间距沿用战斗属性
卡片；一级、二级数值统一右对齐。刷新时按完整明细测量列宽，展开和收起不触发
自动扩列，用户可手动调整列宽。

验收覆盖：来源之和与公共计算结果一致；三率、穿透、动态增伤与面板一致；装备假设
与预览隔离；查看不写配置。卡片标题行尺寸通过实际 Qt 布局检查确认。
