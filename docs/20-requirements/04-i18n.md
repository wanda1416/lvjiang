# 国际化（i18n）支持框架

> **状态**：待实现
> **优先级**：P2
> **依赖**：无前置依赖，可独立实施

---

## 1. 背景与目标

燕云十六声有国际版，项目需要对律匠进行国际化改造，至少额外支持英语（en_US）。同时允许后续通过配置语言版本来支持更多语言。

### 1.1 现状统计

| 类型 | 数量（字符串 token） | 是否需要翻译 |
|------|---------------------|-------------|
| 文档字符串（docstring） | ~2,409 | 否，保留中文 |
| UI 字符串（按钮/标签/菜单/对话框） | ~955 | 是 |
| 日志消息（logger.*） | ~233 | 否，开发者日志保持中文 |
| 错误/异常消息（面向用户） | ~187 | 是 |
| 其他字符串（含 YAML 配置 label/name） | ~938 | 按需评估 |

此外 YAML 配置文件中也有中文：
- `config/system/workflows.yaml` — 工作流显示名
- `config/system/scenes.yaml` — 场景分组名
- `config/system/layouts.yaml` — 布局名称
- `config/system/app.yaml` — 延迟参数标签
- `config/system/yysls/game_config.yaml` — 游戏配置标签

### 1.2 目标

1. 建立全局 i18n 框架，支持通过配置切换语言
2. 首先支持中文（zh_CN）和英文（en_US）
3. 后续新增语言只需添加翻译文件，无需改代码
4. 所有面向用户的 UI 字符串、错误消息、配置显示名均走翻译通道

---

## 2. 技术方案

### 2.1 总体架构

采用 **YAML 翻译文件 + Python tr() 包装函数** 方案，不依赖 Qt 的 .ts/.qm 工具链（避免引入 pylupdate6/lrelease 编译步骤）。

```
┌─────────────────────────────────────────────┐
│              lvjiang.i18n 模块               │
│                                             │
│  init_i18n(language)  ← 启动时调用           │
│  tr(text)             ← 非 QObject 上下文    │
│  set_language(code)   ← 运行时切换（重启生效）│
│  available_languages() ← 扫描翻译文件        │
│                                             │
│  内部：加载 YAML 翻译文件 → 扁平 dict 查找    │
│  Fallback：找不到翻译 → 返回中文原文          │
└─────────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────────┐
│         config/i18n/ 翻译文件目录             │
│                                             │
│  zh_CN.yaml   ← 中文基准（所有 key 的源）    │
│  en_US.yaml   ← 英文翻译                    │
│  ja_JP.yaml   ← 未来扩展                    │
└─────────────────────────────────────────────┘
```

### 2.3 两层翻译 API

**QObject 子类内**：使用模块级 `tr()` 函数（因为 `self.tr()` 需要 Qt .qm 机制配合，我们改用统一的 YAML 方案）

```python
from lvjiang.i18n import tr

class MainWindow(QMainWindow):
    def _setup_menu(self):
        settings_menu = menubar.addMenu(tr("通用"))
        user_mgmt = QAction(tr("用户管理"), self)
```

**非 QObject 上下文**：同样使用 `tr()`

```python
from lvjiang.i18n import tr

def some_function():
    raise WorkflowUserError(tr("布局中未定义 panel ..."))
```

**统一使用 `tr()` 函数**，不区分 QObject 内外。`tr()` 以中文原文为 key，在翻译文件中查找对应值；找不到则返回原文（中文 fallback）。

### 2.4 语言配置

在 `session.json` 的 `settings` 节点新增 `language` 字段：

```json
{
  "settings": {
    "language": "zh_CN"
  }
}
```

- `"zh_CN"` — 中文
- `"en_US"` — 英文
- `"auto"` — 跟随系统 locale（读取 `QLocale.system().name()`）
- 默认值 `"zh_CN"`

启动时读取该配置，加载对应翻译文件。语言切换后需重启应用生效（避免热切换的 UI 重建复杂度）。

### 2.5 关键设计决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 翻译文件格式 | YAML | 项目已重度使用 YAML，团队熟悉 |
| 翻译 key 策略 | 中文原文作 key，找不到时返回原文 | 未翻译的条目不会空白，直接显示中文 |
| 日志消息 | 引擎日志保持中文，UI 面板日志走翻译 | 开发者调试不受影响 |
| 运行时切换 | 重启生效 | 避免热切换的 UI 重建复杂度 |
| 默认语言 | zh_CN | 当前用户群以中文为主 |
| 文档字符串 | 不翻译 | 面向开发者，保持中文 |

## 3. 实施步骤

### 步骤 1：创建 i18n 核心模块

**新建文件**：`src/lvjiang/i18n/__init__.py`

```python
"""国际化支持（i18n）—— 翻译加载与查询

翻译文件位于 config/i18n/{lang}.yaml，启动时根据用户配置加载。
tr(text) 以中文原文为 key 查找翻译，找不到则返回原文。
"""
from __future__ import annotations

import logging
from pathlib import Path
from typing import Any

import yaml

from ..constants import PROJECT_ROOT

logger = logging.getLogger(__name__)

# ── 全局状态 ──
_translations: dict[str, str] = {}   # 扁平化翻译表：dotted_key → translated_text
_current_language: str = "zh_CN"
_i18n_dir: Path = PROJECT_ROOT / "config" / "i18n"


def init_i18n(language: str | None = None) -> str:
    """初始化 i18n，加载翻译文件。

    Args:
        language: 语言代码（如 "zh_CN"、"en_US"），None 表示读取用户配置。

    Returns:
        实际加载的语言代码。
    """
    global _current_language, _translations

    if language is None or language == "auto":
        language = _detect_system_language() if language == "auto" else _load_config_language()

    _current_language = language
    _translations = _load_translation_file(language)

    if language != "zh_CN":
        logger.info(f"[i18n] 已加载语言: {language}，共 {len(_translations)} 条翻译")
    return language


def tr(text: str) -> str:
    """查找翻译。

    以中文原文 text 为 key，在当前翻译表中查找对应值。
    找不到时返回原文（中文 fallback）。
    """
    if _current_language == "zh_CN":
        return text
    return _translations.get(text, text)


def set_language(language: str) -> None:
    """切换语言（需重启生效）。

    更新 session.json 中的 language 配置，下次启动时生效。
    """
    from ..core.config import save_settings
    save_settings({"language": language})


def current_language() -> str:
    """返回当前语言代码。"""
    return _current_language


def available_languages() -> list[dict[str, str]]:
    """扫描 config/i18n/ 目录，返回可用语言列表。

    Returns:
        [{"code": "zh_CN", "name": "简体中文"}, ...]
    """
    languages = []
    if not _i18n_dir.exists():
        return [{"code": "zh_CN", "name": "简体中文"}]

    for yaml_file in sorted(_i18n_dir.glob("*.yaml")):
        code = yaml_file.stem
        try:
            with open(yaml_file, "r", encoding="utf-8") as f:
                data = yaml.safe_load(f) or {}
            display_name = data.get("meta", {}).get("display_name", code)
            languages.append({"code": code, "name": display_name})
        except Exception:
            logger.warning(f"[i18n] 加载语言文件失败: {yaml_file}")

    return languages or [{"code": "zh_CN", "name": "简体中文"}]


# ── 内部函数 ──

def _load_translation_file(language: str) -> dict[str, str]:
    """加载指定语言的翻译文件，扁平化为 {原文: 译文} 字典。"""
    yaml_file = _i18n_dir / f"{language}.yaml"
    if not yaml_file.exists():
        logger.warning(f"[i18n] 翻译文件不存在: {yaml_file}")
        return {}

    try:
        with open(yaml_file, "r", encoding="utf-8") as f:
            data = yaml.safe_load(f) or {}
    except Exception:
        logger.exception(f"[i18n] 解析翻译文件失败: {yaml_file}")
        return {}

    # 扁平化：递归遍历嵌套 dict，生成 dotted key
    # 但我们实际用原文作 key，所以需要从翻译文件中提取所有叶子节点的值
    # 建立 中文原文 → 译文 的映射
    # 翻译文件结构：ui.main_window.title: "xxx"
    # 对应 zh_CN.yaml 中同路径的值为中文原文
    zh_file = _i18n_dir / "zh_CN.yaml"
    zh_data = {}
    if zh_file.exists() and language != "zh_CN":
        try:
            with open(zh_file, "r", encoding="utf-8") as f:
                zh_data = yaml.safe_load(f) or {}
        except Exception:
            pass

    result = {}
    _build_translation_map(zh_data, data, result)
    return result


def _build_translation_map(zh_data: dict, trans_data: dict, result: dict, prefix: str = "") -> None:
    """递归遍历 zh_data 和 trans_data，建立 中文值 → 翻译值 的映射。"""
    for key in trans_data:
        if key == "meta":
            continue
        zh_value = _deep_get(zh_data, key, prefix)
        trans_value = trans_data[key]

        if isinstance(trans_value, dict) and isinstance(zh_value, dict):
            new_prefix = f"{prefix}.{key}" if prefix else key
            _build_translation_map(zh_value, trans_value, result, new_prefix)
        elif isinstance(zh_value, str) and isinstance(trans_value, str):
            # 中文原文 → 译文
            result[zh_value] = trans_value
        elif isinstance(trans_value, str) and not isinstance(zh_value, dict):
            # zh_data 中可能没有对应 key（新增条目），用 key 本身作为 fallback
            pass


def _deep_get(data: dict, key: str, prefix: str = "") -> Any:
    """从嵌套 dict 中按 key 获取值（支持 prefix 上下文）。"""
    if not isinstance(data, dict):
        return None
    return data.get(key)


def _detect_system_language() -> str:
    """检测系统语言。"""
    try:
        from PyQt6.QtCore import QLocale
        name = QLocale.system().name()  # 如 "en_US"
        if name:
            return name
    except Exception:
        pass
    return "zh_CN"


def _load_config_language() -> str:
    """从 session.json 读取语言配置。"""
    try:
        from ..core.config import get_session_store
        settings = get_session_store().get_node("settings", {})
        return settings.get("language", "zh_CN")
    except Exception:
        return "zh_CN"
```

**要点**：
- `tr()` 以中文原文为 key 查找翻译，找不到返回原文
- `init_i18n()` 在 `QApplication` 创建后调用
- `available_languages()` 扫描 `config/i18n/` 目录自动发现可用语言
- 翻译文件不存在时优雅降级到中文

```python
def _build_basic_tab(self) -> QWidget:
    widget = QWidget()
    layout = QFormLayout(widget)

    # ── 语言选择 ──
    from ..i18n import available_languages, current_language
    self._lang_combo = QComboBox()
    languages = available_languages()
    for lang in languages:
        self._lang_combo.addItem(f"{lang['name']} ({lang['code']})", lang["code"])
    current = current_language()
    idx = self._lang_combo.findData(current)
    if idx >= 0:
        self._lang_combo.setCurrentIndex(idx)
    layout.addRow("界面语言:", self._lang_combo)

    # ── 其余原有字段 ... ──
    return widget
```

```python
def _on_save(self):

    from ..i18n import set_language

    if lang:
        set_language(lang)
```

### 步骤 8：字符串提取脚本

**新建文件**：`scripts/extract_i18n.py`

功能：
1. 扫描所有 `.py` 文件中的 `tr("...")` 调用
2. 生成/更新 `config/i18n/zh_CN.yaml` 基准文件
3. 对比已有翻译文件，报告新增/删除/变更的条目

```python
#!/usr/bin/env python3
"""从代码中提取 tr() 字符串，生成/更新翻译基准文件。

用法：
    python scripts/extract_i18n.py              # 更新 zh_CN.yaml
    python scripts/extract_i18n.py --check      # 检查是否有未提取的字符串
    python scripts/extract_i18n.py --diff en_US # 对比 en_US.yaml 缺失项
"""
import ast
import os
import re
from pathlib import Path

import yaml

PROJECT_ROOT = Path(__file__).parent.parent
SRC_DIR = PROJECT_ROOT / "src" / "lvjiang"
I18N_DIR = PROJECT_ROOT / "config" / "i18n"


def extract_tr_strings() -> list[dict]:
    """扫描所有 .py 文件，提取 tr("...") 调用。

    Returns:
        [{"text": "中文原文", "file": "relative/path.py", "line": 42}, ...]
    """
    pattern = re.compile(r'\btr\(\s*["\'](.+?)["\']\s*\)')
    results = []

    for py_file in sorted(SRC_DIR.rglob("*.py")):
        content = py_file.read_text(encoding="utf-8")
        for i, line in enumerate(content.splitlines(), 1):
            for match in pattern.finditer(line):
                text = match.group(1)
                if text and any('\u4e00' <= c <= '\u9fff' for c in text):
                    results.append({
                        "text": text,
                        "file": str(py_file.relative_to(PROJECT_ROOT)),
                        "line": i,
                    })

    return results


def update_zh_cn(strings: list[dict]) -> None:
    """更新 zh_CN.yaml 基准文件。"""
    I18N_DIR.mkdir(parents=True, exist_ok=True)
    zh_file = I18N_DIR / "zh_CN.yaml"

    # 加载现有文件（如果有）
    existing = {}
    if zh_file.exists():
        with open(zh_file, "r", encoding="utf-8") as f:
            existing = yaml.safe_load(f) or {}

    # 更新 meta
    from lvjiang._version import __version__
    existing.setdefault("meta", {})
    existing["meta"]["language"] = "zh_CN"
    existing["meta"]["display_name"] = "简体中文"
    existing["meta"]["version"] = str(__version__)

    # 将所有提取的字符串加入翻译文件（按文件分组）
    # 具体分组逻辑 ...

    with open(zh_file, "w", encoding="utf-8") as f:
        yaml.dump(existing, f, allow_unicode=True, default_flow_style=False, sort_keys=False)

    print(f"已更新 {zh_file}，共 {len(strings)} 条字符串")


def check_coverage(lang: str) -> None:
    """检查指定语言的翻译覆盖率。"""
    zh_file = I18N_DIR / "zh_CN.yaml"
    lang_file = I18N_DIR / f"{lang}.yaml"

    if not zh_file.exists():
        print(f"错误: {zh_file} 不存在，请先运行 extract")
        return

        return

    import argparse
    parser = argparse.ArgumentParser(description="i18n 字符串提取工具")
    parser.add_argument("--check", action="store_true", help="检查未提取的字符串")
    parser.add_argument("--diff", metavar="LANG", help="对比指定语言的缺失项")
    args = parser.parse_args()

    strings = extract_tr_strings()

    if args.diff:
        check_coverage(args.diff)
    elif args.check:

        print(f"共发现 {len(strings)} 条 tr() 字符串")
    else:
```
