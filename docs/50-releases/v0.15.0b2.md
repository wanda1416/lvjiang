# v0.15.0b2 — 配置更新加载修正（Beta2）

本版本是 0.15.0 的第二个测试包，供手动下载测试，不替换当前正式版 0.13.15，
不向普通客户端提示更新。完整功能与相对正式版的升级注意事项见 [Beta1 说明](v0.15.0b1.md)。

## ⚠️ 不兼容变动与升级指引

相对 Beta1，本版本无新增不兼容配置格式变动。

- PC 与 APK 测试同步时须同时升级到 0.15.0b2；同步仍是单向覆盖，请先核对覆盖提示。
- 配置包继续按 0.15.0 系列匹配，Beta2 的 r0 与安装状态独立存储在 updates/v0.15.0b2，
  不要手工复制 Beta1 的更新状态。有效授权下重新获取会员配置即可，local/session 无需删除。
- Windows 便携包解压到新目录，再复制 config/local 与 config/session；安装器和 APK 保留用户数据。

## ✨ 新增功能

- 通用配置分别展示本地激活状态和最近一次云端会员授权检查状态，不再把本地激活有效当作云端授权已通过。
- DEBUG 日志说明会员更新未执行或被拒绝的具体原因，便于区分未填激活码、云端停用和网络失败。

## 🔧 修复

- 修复部分会员配置无法获取的问题。
  安装只检查包级协议、版本、授权、完整性及解包安全；具体业务问题由对应功能处理。
- 修复部分官方配置更新失败的问题。
- 配置安装后单项缓存或界面刷新失败不会撤销已安装文件，也不阻断其他功能刷新。
- 修复退出时战斗属性页面的延迟布局回调访问已销毁控件而报错的问题。

## 📦 重构

- 配置安装固定按 r0 → public → member 组合，安装提交与消费者刷新分离；用户 local 覆盖不变。

## 📚 文档

- 对齐在线配置安装边界、会员覆盖和授权状态的操作说明。

## 📝 变更统计

- 相对 Beta1 包含 3 个功能／维护提交，另计 1 个发布准备提交；准备前共 27 个文件变更。
- 系统预置与 Beta1 一致，不修改 content_version、在线配置索引、公告或正式版 Latest。
- 已用真实 r0 与线上会员 r3 在隔离目录验证安装、非开发模式主窗口启动与重启加载；
  授权在启动模拟中使用有效授权替身，不代表完成真实游戏任务验收。
- 跨设备、长时间执行与 Windows 安装后的实机行为仍需测试，Beta2 不作为正式稳定性承诺。
