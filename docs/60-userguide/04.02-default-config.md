# 4.2 默认配置含义

系统自带一套经过调优的默认配置，开箱即用。本文解释默认配置的设计思路，
帮助你理解每项配置的「为什么」，再根据需要微调。

---

## 默认三种处理概览

调律配置的全局配置区包含三个处理阶段，对应装备调律生命周期的三个时间点：

```
装备进入 → 等级达标？→ 词条已满？
                          ├─ 否 → 预期评级 ≥ 进入门槛？
                          │         ├─ 是 → 进调律 → [材料处理] → 执行调律 → [结束处理]
                          │         └─ 否 → [扫描处理]（处置表按传入规则评级匹配）
                          └─ 是 → 终局判定 → [扫描处理]（处置表按传入规则评级匹配）
```

| 处理阶段 | 时机 | 核心问题 |
|----------|------|--------|
| **扫描处理** | 满足等级要求但未达调律门槛，或词条已满时 | 这件装备该怎么处置？回收、保留、还是强制调律？ |
| **材料处理** | 每轮调律开始前 | 大律准石够不够？要不要加狗粮？加什么狗粮？ |
| **结束处理** | 每轮调律结束后 | 继续调？重置？回收？还是保留当前状态？ |

> 注意：等级低于 `scan.min_level` 的装备直接跳过，不进入任何行为判定。
> 扫描处理有两个入口：① 未满装备未达进入门槛；② 词条已满装备（跳过门槛检查，直接进处置表）。
> 两种入口都通过传入规则评级来匹配处置规则。

### 默认扫描处理

默认 4 条处置规则，对**未达进入门槛**或**词条已满**的装备进行二次处置，自上而下首条命中即生效：

| # | 条件 | 处置 | 设计意图 |
|---|------|------|--------|
| 1 | 金装、词条满(≤98%)、评级=垃圾、全部规则 | 调满后回收 | 金装词条接近满但判定为垃圾 → 未满时进调律调满后回收换材料；已满时直接回收 |
| 2 | 武器(仅金装)、词条≥90%、含大外/小外、只看首词条 | 跳过 | 紫装武器首词条数值较好但品阶不够 → 保留，跳过 |
| 3 | 全部位(≤紫装)、词条≥0%、评级=顶级/优秀、全部规则 | 跳过 | 对别的流派规则有用 → 保留，跳过 |
| 4 | 全部位(≤紫装)、词条≤100%、评级=垃圾、当前规则 | 回收 | 判定为垃圾 → 直接回收 |

> 无命中时默认**保留**装备（不进调律也不回收）。

### 默认材料处理

**大律准石检查**：启用，基准 80，不足时询问是否继续。

**狗粮添加规则**（金装优先匹配）：

| 品阶 | 词条进度 | 预期评级 | 加什么狗粮 | 不足时 |
|------|---------|---------|-----------|--------|
| 金装 | ≥98% | 顶级 | 彩狗粮 | 跳过 |
| 金装 | ≥88% | 优秀 | 金狗粮 | 跳过 |
| 金装 | 任意 | 一般 | 不加 | 继续 |
| 紫装 | ≥90% | 顶级 | 金狗粮 | 跳过 |
| 紫装 | 任意 | 优秀 | 紫狗粮 | 继续 |

> 逻辑：词条越满、预期越高 → 用越好的狗粮冲；预期一般 → 不加狗粮省材料。

### 默认结束处理

默认 3 条规则 + 重置上限 3 次：

| # | 条件 | 处置 | 设计意图 |
|---|------|------|---------|
| 1 | 金装、词条≥92%、评级=垃圾 | 重置调律 | 金装词条快满了但调出垃圾 → 清空重来（每件装备最多重置 3 次） |
| 2 | ≤紫装、词条≤92%、评级=垃圾 | 回收 | 紫装/蓝装垃圾 → 不值得重置，直接回收 |
| 3 | 金装、词条≤100%、评级=优秀/一般/垃圾 | 结束保留 | 金装虽然不是顶级但能用 → 保留 |

> 重置上限 3 次后仍未达标 → 按 `次数用尽后` 处置（默认回收）。

## 默认五种流派规则概览

系统预置 5 套调律规则，覆盖游戏当前所有主流流派：

| 规则 | key | 核心攻击 | 适用武器 | 属性 |
|------|-----|---------|---------|------|
| **通用会意** | huiyi_general | 大外+势 | 剑(主) + 枪(副) | 鸣金 |
| **会心小外** | huixin_small | 小外+敏 | 横刀/陌刀/手甲/双刀/伞/舞绫鼓 + 对应副武器 | 裂石/破竹/牵丝 |
| **会心大外** | huixin_big | 大外+劲 | 同小外（武器组合相同） | 裂石/破竹/牵丝 |
| **治疗纯奶** | heal_pure | 大外+劲+小外 | 扇(主) + 伞(副) | 牵丝 |
| **治疗火拳** | heal_fire | 大外+劲+小外 | 扇(主) + 伞(副) | 牵丝 |

### 会意 vs 会心

- **会意流**：核心攻击 = 大外 + 势。只有一个玩法「会意」，通用性强。
- **会心流**：核心攻击 = 大外 + 劲（大外流）或小外 + 敏（小外流）。需要指定具体流派（裂石/破竹/牵丝），因为不同流派的本属攻击不同。

### 大外 vs 小外

- **大外流**：追求最大外功攻击，因为默认10%左右会意率的原因，最小外功攻击略差一些。
- **小外流**：追求最小外功攻击，优先最小外功攻击，其次最大本属攻击，佩额外允许紫装。

### 治疗两派

- **纯奶**：专注治疗量，词条池偏防御（对玩家增效、全武学增效）
- **火拳**：主打输出，词条池偏攻击（对首领增伤、单体奇术增伤、精准率）

### 跨流派保留

五条规则同时启用时，装备只要被**任一规则**判定为有价值就自动保留（OR 逻辑）。
例如：会意流派判定为垃圾的装备，如果会心大外流派判定为优秀，仍然保留。
