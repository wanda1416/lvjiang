# 治疗火拳奶调律规则

公共规则见 [调律评价规则](README.md)，本文仅列治疗火拳奶专属规格。

- 治疗流派即 **牵丝·霖**：主武器为 扇，副武器为 伞。
- 必选配置：玩法（纯奶、火拳奶，可同时勾选）；可选配置：无（无 keep_pvp 配置）。
- 火拳奶不需要 指定武学增效 和 全武学增效，但需要 **单体类奇术增伤** 和 **对首领增伤**。
- 大本属 = 最大牵丝攻击，非武器部位的 大无相 即指它。

## 一、神力词条要求

- 主武器（扇）：**无增伤要求**，出现武学增效视为废词条判垃圾。
- 副武器（伞）：不需要武学增伤，有视为不合格。
- 首饰（环/佩）：**不需要全武学增效**，出现即废词条判垃圾（已确认，与其他输出流派相反）。
- 头盔和胸甲：必须有 **单体奇术增伤**（缺失直接判垃圾）。
- 胫甲和腕甲：必须有 **对首领增伤**（缺失直接判垃圾）。

## 二、转律优先级与可用词条库

- 转律优先级：大外、劲、小外、敏、会心、大无相、大本属、大牵丝。
- 可用词条库：大外、劲、小外、敏、会心、大无相、大本属、大牵丝 + 势。
- 注意：会心、大无相、大本属、大牵丝、势 在库内**不判垃圾**（可命中可选槽），其中
  大无相/大本属 会被所有部位的顶级条件排除；**势 → 优秀封顶**（见下节公共条件）。
- 库外词条即废词条，直接判垃圾。典型：会意、精准、小无相、非牵丝流派的属攻、
  错位属攻（武器上的大本属、非武器上的最大无相攻击）、流派不需要的神力词条
  （指定武学增效、全武学增效等）。

## 三、公共与部位能用条件（heal_fire，均只看非首词条）

按 垃圾 → 能用 → 优秀 → 顶级 顺序求值，首命中即终判：

1. 公共优秀：非首 大外 全缺 → **优秀封顶**；
2. 部位优秀（主武器/副武器/环佩）：劲+大外 全缺 → 优秀封顶；势≥1 且 会心/精准≥1 → 优秀封顶；
3. 公共优秀：势 ≥1 → **优秀封顶**（不再参与顶级判定；该备注曾有争议，暂以实现现状为主）。

## 四、各部位模式与顶级判定

| 部位 | 模式 | 顶级判定（命中模式后） |
|------|------|----------------------|
| 主武器（扇） | [大外(首) + 大外 + 小外/劲] + 可用词条库 * 2 | 未出现 大无相，且（敏和会心未同时出现）→ 顶级，否则 优秀 |
| 副武器（伞） | [大外(首) + 大外 + 小外/劲] + 可用词条库 * 2 | 未出现 大无相，且（敏和会心未同时出现）→ 顶级，否则 优秀 |
| 环、佩 | [大外(首) + 大外 + 小外/劲] + 可用词条库 * 2 | 未出现 大本属，且（敏和会心未同时出现）→ 顶级，否则 优秀 |
| 头盔、胸甲 | [会心/精准(首) + 单体奇术增伤 + 大外] + 可用词条库 * 2 | 未出现 大本属 → 顶级，否则 优秀 |
| 胫甲、腕甲 | [劲(首) + 对首领增伤 + 大外] + 可用词条库 * 2 | 未出现 大本属/会心/精准 → 顶级，否则 优秀 |

- 主武器、副武器、环、佩 四类部位模式与顶级条件完全相同（首词条均要求大外）。
- 冠胄/胸甲首词条接受 会心 或 精准（config `first: [会心率, 精准率]`）。
- 胫甲/腕甲的顶级条件额外排除 会心/精准，其顶级可选槽实际只剩 大外/劲/小外/敏。

## 五、判定例子

以下词条列表第 1 条均为首词条。

| 部位 | 词条 | 判定 | 说明 |
|------|------|------|------|
| 主武器（扇） | 大外 + 大外 + 劲 + 小外 + 势 | 优秀 | 势 ≥1 → 优秀封顶（公共条件） |
| 主武器（扇） | 大外 + 扇武学增效 + 大外 + 劲 + 敏 | 垃圾 | 火拳不需要扇武学增效，出现即废词条 |
| 副武器（伞） | 大外 + 大外 + 小外 + 敏 + 会心 | 优秀 | 敏和会心同时出现 |
| 环 | 大外 + 大外 + 劲 + 精准 + 会心 | 顶级 | 精准/会心在库内且不触发同现限制（无敏） |
| 环 | 大外 + 全武学增伤 + 大外 + 劲 + 敏 | 垃圾 | 火拳环/佩不需要全武学增效，出现即废词条 |
| 头盔 | 会心 + 单体奇术增伤 + 大外 + 劲 + 会心 | 顶级 | 头盔顶级只排除大本属 |
| 头盔 | 会心 + 单体奇术增伤 + 大外 + 敏 + 大本属 | 优秀 | 大本属即大无相，被顶级条件排除 |
| 胫甲 | 劲 + 对首领增伤 + 大外 + 劲 + 势 | 优秀 | 势 ≥1 → 优秀封顶（公共条件） |
| 胫甲 | 劲 + 对首领增伤 + 大外 + 敏 + 精准 | 优秀 | 胫甲顶级排除精准 |
| 腕甲 | 劲 + 对首领增伤 + 大外 + 小无相 + 敏 | 垃圾 | 小无相为库外废词条（小外流 OR 逻辑下可能保留） |
